왜 '우와'가 되는가

정보가 지도 위에 산다는 것을 처음 3초 안에 보여준다. 렌즈·연동 하이라이트·카메라 이동은 모두 실제 기능(XI 맵 지도보기, 카드 검토)의 시각적 예고편이며, 새 기능을 추가하지 않는다.

기존 기능 대응

처리 대기 = 카드 발행 승인 대기 + 가입 승인 + 미답변 문의(기존 3위젯 통합). KPI 5→4는 '전체 사용자/발행 카드/승인 대기/문의'로 축약하되 나머지는 툴팁. 백본·스토리지·프로젝트 용량은 우측 컬럼으로 이동.

절제

움직이는 것은 스캔 스윕 1개, 펄스, 진입 순차 등장뿐. 유리 패널은 흰 82% + 블러로 지도가 비치되 글자는 항상 잉크색. 감소 모션 설정 시 모든 애니메이션 정지.
