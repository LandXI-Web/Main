## 5. Craft 재비평 기록
1. **1차** — 전 화면이 굵은 Paperlogy 로 찍힘(이 PC 에 Pretendard 미설치 + `@import` 가 `@font-face` 뒤라 무시됨) → `@import` 를 스타일 맨 앞으로. 선택 3 서랍이 5건짜리 업무 열을 가리고 카드 하단이 잘림 → 열 순서 긴급·업무·일반, 서랍 496, 카드 96 + 줄높이 고정. 레일 활성 라벨이 72 폭을 넘김 → 굵기 제거. FAQ 답변 아래 빈 줄 → 줄 수를 시드에서 계산.
2. **2차** — 문의 열람 판: 제목을 2줄로 가정한 절대 좌표라 답변이 푸터까지 넘침 → 판 전체를 flex 세로 흐름으로 다시 짬(상태·등록 일시는 판 머리 오른쪽, 첨부 32px 행, 답변 = 남는 높이). 검증 판: 오류 문구가 첨부 줄과 겹침 → 폼도 flex 흐름(내용 칸이 줄어 오류 줄을 받는다). 활용사례 제목이 "관 / 내" 로 끊김 → 전역 `word-break:keep-all`. 모달 좌열 하단 빈 띠 → 이미지 248→300.
3. **3차** — `Notice-Detail` 머리 줄이 1384 를 넘김 → `?notice=7` 짧은 표기. FAQ 좌 열 "구분 / 전체" 큰 글자가 레일 첫 행과 중복 → 삭제, 레일을 입력 줄 높이로 올림. 취소 확인 모달 빈 공간 212→172. 빈 목록의 0 은 회색. 필수 표시 `*` 는 잉크(빨강은 검증 문구·긴급에만). 미답변 열람의 점선 답변 칸을 내용 높이로.
- 최종 확인: 넘침·겹침·잘림 0(17판 PNG 직접 확인) · 14px 미만 0 · 첫 화면 위계 = 큰 숫자 → 선택 행 → 열람 제목.

## 7. 유보
- 선택 2 의 기본 상태는 첫 행이 열람 판에 열려 있다(원본은 목록만). 빈 판 기본을 원하면 `Notice-Empty` 우측 점선 판이 그 모양이다.
- 활용사례 상세: 현행 원본 소스는 페이지 전환 뷰, 인벤토리·발주는 모달 — 모달로 그렸다. 페이지 뷰로 가면 공지 열람 판과 같은 부품을 쓴다.
- 활용사례 썸네일은 원본 PNG(`uc-road-safety.png` · `uc-farm-nongview.png`) 대신 남원 2025 정사영상 크롭이다 — 사례와 같은 지역·주제이나 해당 사업의 실제 장면이라는 뜻은 아니다(이미지 라벨로 출처만 표기).
- 매뉴얼 본문은 원본에 없다. `SP_MANUALS` 5건을 `시연` 카테고리로 썼고 본문은 점선 결손. 5번(보고서 생성)은 개편 범위에 화면이 없어 미리보기 없음.
- FAQ 좌 열의 `문의하기 ›` 는 기존 탭으로 가는 링크(새 기능 아님). 불필요하면 삭제 — 좌 열 하단이 빈다.
- 토스트(등록 완료 · 다운로드 · 첨부 제한) 아트보드는 공용 알림 부품이 정해진 뒤 추가.
- 미답변 열람(`Contact-View-Pending`)은 내용이 짧아 판 하단이 빈다 — 원본 데이터 길이 그대로.
- 렌더 시 `design-canvas/v2/_tmp` 를 다른 그룹과 공유해 동시 실행에서 ENOENT 가 났다(재시도로 해결). 컨트롤러 일괄 렌더는 순차 실행 권장.
