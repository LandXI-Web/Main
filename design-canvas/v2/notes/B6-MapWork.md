## B6-MapWork — 지도 작업공간 컨셉 · 선택 1 · 2 · 3 (2026-09-20 자동 설계)

발주 원문(2026-09-20): *"우리 AI 학습데이터를 구축하고 관리하는 모든 기능을 지도에서 했으면 하거든. 그때 (3D를) 다시 고려해볼 만하다."*
→ 현 프로젝트 원판 11장(D5)은 **탭마다 화면이 바뀌는** 구조(개요 · 데이터 · 라벨링 · 학습 · 분석 · 배포)다. 이 컨셉은 같은 기능을 **한 판의 지도 위에 고정**해 두고 단계만 바꾸는 배치 실험이다. 생성기 `tools/design/gen-b6-mapwork.mjs`.

**기능 발명 0.** 다섯 단계는 원본 프로젝트 8스텝을 접은 것이다 — 01 영상(④ 파일 업로드 + 데이터 관리 아카이브) · 02 라벨링(⑤) · 03 데이터셋(⑥) · 04 학습(⑦) · 05 분석 · 발행(⑧ 분석 + ⑨ 모델 등록 + ⑩⑪ 발행 요청). 개요(③ kv · 구성원 · 수정/삭제)는 마스트헤드의 프로젝트명에서 열리는 패널로 간다(세 안 공통, 미도시).

**권장: 선택 3**, 단 폼이 큰 세 단계(데이터셋 만들기 · 학습 설정 · 발행 요청)는 선택 2 의 좌측 작업면을 **드로어로** 빌려 온다. 선택 1 의 도크는 선택 3 의 좌하 "이 프로젝트 한 줄"(영상 10 → 라벨 1,674 → 데이터셋 2 → 학습 5 → 발행 대기 1)로 축약해 이미 들어 있다.

### 조판 실측
- 공통: 레일 72(원본 메뉴 10 · 활성 = 프로젝트) · 마스트헤드 64(`‹ 프로젝트 목록` + 프로젝트명 Paperlogy 26 + 상태어 파랑 + `시연`) · 판 = `img/map-vw-z14.jpg`(V-World 위성 실캡처 · 남원) · 도구 열 40×4(검색 · 레이어 · + · −) · 축척/좌표 띠 14px Inter.
- 풋프린트 = 흰 코너 브래킷 12(선택 = 파랑 2px) + 아래 라벨 띠, 라벨 0 인 시점 = 흰 점선(결손 규칙). 선택된 풋프린트 안에만 청록 필지(AI 결과 · 라벨 전용 색).
- 색: 파랑 = 선택 · 활성 단계 · 링크 · 큰 숫자 1개 / 빨강 = `발행 대기 1` 글자만 / 청록 = 라벨 · 결과 / 채운 파란 버튼 0 · 1차 버튼 잉크 · 2차 브래킷. 라운드 · 그림자 · 그라디언트 0. 최소 14px.
- 수치: 도엽 10 · GSD · 범위 = `imagery.js`, 라벨 1,674(단동 1,469 · 다동 205) · 2,098 = `results.js`, 학습 5 회 · IoU 0.82 = 원본 시드(`시연`), 데이터셋 2 건 이름·버전 = `추정`(D5 원판과 동일 표기).

### 유보
- (a) 판 위 풋프린트 위치 · 청록 필지는 원판용 배치다 — 구현은 `imagery.js` bounds 와 결과 GeoJSON 을 투영한다.
- (b) 세 안 모두 **한 상태씩만** 그렸다. 채택되면 채택안으로 5단계 × 주요 상태(라벨링 편집 툴바 · 학습 결과 · 분석 3탭 · 발행 폼)를 D5 원판 11장에서 옮겨 그린다.
- (c) 데이터 관리(업로드 · 아카이브 · 레이어 발행)를 같은 판으로 합칠지는 별도 결정 — 01 영상 단계의 `파일 추가`가 아카이브 목록 모달(원본 그대로)을 여는 데까지만 그렸다.
