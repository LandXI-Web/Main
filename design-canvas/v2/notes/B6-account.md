## 6. Craft 재비평 기록
1. 1차: Pretendard 미적용(@import 가 @font-face 뒤) → 순서 교정. 레일 `LAND XI` 14px 줄바꿈 → 자간 .06em · nowrap. 디스크 히어로 CTA 가 1384 를 넘고 `2,048 GB` 와 겹침 → 판 머리 우측으로. 막대–이력 사이 160px 빈 띠 → 가로 막대를 **칸 판**으로 교체(높이 101 · 고스트 칸), 표 아래 점선 `새 증량 신청` 행(10 – 10,240 GB).
2. 2차: 좌 원장에 아이디·전화번호 2행 추가(인벤토리 "열람") 후 버튼이 브랜드 머리와 겹침 → 이름 46 · 행 40 · 브랜드 블록 재조판(미리보기 87 · 자를 값 옆으로). 계정 신청 2단계가 520 카드에서 버튼과 겹침 → 카드 600 · 행 92. 회원정보 수정 우 판 아래 200px 빈 띠 → 동의 행 64/56 · 안내 상자 행간 32 · 작업 띠 y722.
3. 3차: 결과 4판 본문–버튼 사이 150px 빈 띠 → 제목(34) + `결과` 칩, 본문 세로 중앙. 3단계 완료 표 행 56. 토스트가 H1 룰(156)을 넘음 → 높이 64 · y80. 전 판 재렌더 후 넘침·겹침·잘림 0 확인.

## 7. 유보
1. **계정 탈퇴**: 원본 `mypage.html` · `layout.js` 어디에도 탈퇴 UI 가 없다(약관 본문에만 "회원탈퇴"). 인벤토리 항목이라 `B6-My-Withdraw` 를 `추정` 꼬리표로 그렸다(진입 링크도 이 판에만). 채택 여부는 컨트롤러 판단.
2. **디스크 수치 불일치**: 원본 마이페이지 시드 612.4 / 2,048 GB(30 %) · B5-Dashboard-User 1,420 GB · B5-DataMgmt 1,965 GB(96 %). 이 화면군은 자기 원본 시드를 따랐다. 생성기 `STORAGE` 상수 한 줄로 통일 가능(96 % 로 맞추면 큰 숫자는 조치 필요 빨강).
3. **심볼 기본 크기**: 원본 기본 35px(`lx_symbol.png`). 개편 레일의 기본 심볼은 B5 레일 실측 19px 글리프라 `현재 가로 크기 19px` 로 적었다. 범위 16–50px 은 원본 그대로.
4. **인증 1차 버튼 색**: 승인된 로그인은 `로그인` 만 액센트 채움(로그인 예외). 가족 판은 법전대로 잉크 채움. 로그인과 맞추려면 `aBtn1` 의 배경 한 값.
5. **레일 로그아웃**: 원본은 MY 플라이아웃 안에만 로그아웃이 있고, B5 레일은 로그아웃 항목을 따로 둔다. Flyout 판은 원본대로 둘 다 보인다 — 구현 시 한쪽 정리 필요.
6. 계정 신청의 소속 부서 목록 · 문의처(`도로관리과 063-713-1218`) · placeholder 도메인은 원본(남원 시드) 그대로 — LX 값으로 바꿀지 미정. 입력 예시값(홍길동 · hong@lx.or.kr)은 원본 placeholder 에서 이은 `시연`.
7. 원본 `signup.html` 에는 단계 표시 DOM 이 없다(JS 만 `.step-item` 참조). 단계 이름은 원본 주석(`Step 1: 약관 동의` · `Step 2: 정보 입력` · `Step 3: 완료`)에서 가져왔다.
