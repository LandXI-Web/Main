## 1. 서체 (정확히 3개, 더 없음)
- 표시: **SUIT 500** 단일 굵기 — H1 64/80 · H2 52/57 · H3 32/40. letter-spacing −0.01em. 굵기로 크기를 대신하지 않는다.
- 본문: **Pretendard 400** — 16/23(한글 행간 1.6), 라벨 12/14(1.2).
- 숫자·좌표·캡션: **Inter 400 tabular** — 통계 124px(본문의 7.75배), 헤드라인 카운트 52px, 캡션 12px, letter-spacing 0.02–0.04em.
- 금지: Gothic A1, IBM Plex, Inter를 본문에 쓰는 것, 제3의 서체.

## 2. 색 (정확히 이 값, 분량 90/8/2)
- 바탕 `#FFFFFF`(90%). 잉크 `#010102`.
- 회색 `#686868`(보조 텍스트) · `#CCCCCC`(비활성) · 헤어라인 `#DDDDDD`(8%).
- 액센트 **`#006DF7` 한 번**(2%) — 데이터·활성 상태에만. 브랜드 마크는 잉크.
- 앰버 `#FFB633` — 탐지/정지점 순간 380ms만. 그 외 어디에도 없음.
- 청록 `#0FA9A0` — AI 결과 폴리곤/필라멘트 전용.
- 금지: 그라디언트, 유리(backdrop-filter), 그림자, 라운드(0), 제3의 텍스트 색, 상태색 남용.

## 3. 좌표·그리드 (1440 기준)
- 좌 레일 **72px**(원본 11개 메뉴, 원본 라벨 순서), 마스트헤드 **64px** 헤어라인.
- 콘텐츠 마진 **56px**, 12열 그리드 거터 24px, 원장 컬럼 **372px**(대시보드) / **300–344px**(축소형).
- 섹션 패딩 120/160. 헤어라인 1px. 코너 브래킷 12px.
- 명명 레이아웃 5종만 조합: `PLATE-FULL` `SPLIT-5050` `LEDGER` `EVIDENCE-PAIR` `CHIP-RAIL`. 화면당 일탈 **1회**(판이 마진을 뚫는 것).

## 4. 모션 (이징 하나, 사다리 넷)
- 이징 `cubic-bezier(0.15,1,0.3,1)`; 지속 500/750/1000/1250ms만.
- 호버 180ms `cubic-bezier(.22,1,.36,1)` — 물리적 반응(4px 이동·브래킷 성장·밑줄 스윕), 색만 바꾸는 호버 금지.
- 텍스트 인 `translateY(20px)→0` 600ms/60ms 스태거; 숫자는 글자별 40ms 현상; 이미지 `clip-path inset(100% 0 0)→inset(0)` 1s.
- 유휴: 화면당 움직이는 요소 **1개**(실데이터에 묶인 것), 주기 ≥6s. `prefers-reduced-motion` = 정지.

## 5. 콘텐츠 규칙 (콘티 원칙)
- 이 산출물은 신규 개발 콘티. 지어낸 운영 서사 금지: 담당자명, 대기 일수, 활동 기록, KPI 추세, "운영 리포트".
- 숫자는 `results.js` `services.js` `models.js` `imagery.js`에서만. 결과 없는 서비스 = `준비 중`. 원본 데모 시드 = `시연`, 추정치 = `[추정]`.
- HUD 숫자는 해설(단위·범위·기준시점 필수). 장식 숫자 금지.
- 결손은 점선 무채 + 이유 한 줄. 예측은 점선 고스트.

## 6. 화면별 역할
- 메인 = 디오라마 스크럽 필름(하강 → 지역 → 결과) + 핸드오프. 카피 = 데이터 저널리즘.
- 로그인 = 플랫폼 소개(모토·비전·3축) + 디오라마 판.
- 대시보드 = **지도 없음**. 축소된 현황: 상단 큰 숫자 밴드 + 원본 위젯 12개 헤어라인 목록.
- 데이터 관리 = 4탭을 파이프라인 단계로, 영상 썸네일이 1급 시민.
- XI맵 = 지도 혁신의 자리(실영상·탐지·임계·스와이프·타임라인).
- 기능은 원본과 1:1. 구조는 자유(구조 복제는 개편이 아님).

## 7. 보고 전 필수 게이트 (3-비평가)
1. Brief 비평가: 원본 기능 1:1인가(인벤토리 대조).
2. System 비평가: 이 파일 §1–§5 위반 0인가.
3. **Craft 비평가(최상위 모델, 렌더 스크린샷만 보고)**: "잘 만든 제품 화면으로 읽히는가, 원본 재스킨으로 읽히는가". 불합격이면 보고 금지.
