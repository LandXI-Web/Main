고르는 법 — 버튼을 누르고, 고칠 점이 있으면 한 줄 적어 주세요. 고른 것은 이 브라우저에 저장됩니다. 다 고르시면 아래 결정 복사를 눌러 대화창에 붙여 넣어 주세요. 안 고른 항목은 그대로 두셔도 됩니다.

결과만 쌓는 구조와 XI맵 — 결정 넷

10-09 말씀("분석결과만 수시 생산 이력관리" · "지리원 API를 통해서 영상을 호출할 수 있는걸 예전에 확인한게 있다")에 따라 직접 불러 보고, 남원 한 곳에서 실제로 분석했습니다. 국토지리정보원 항공영상은 API로 전국을 해마다(2020~2025 약 25cm · 2011~2019 약 50cm) 부를 수 있습니다. 브이월드 영상은 그 최신판이지만 촬영 연도를 알려 주지 않습니다. 같은 2023년 영상을 파일과 API로 돌려 보니 경작지 95% · 건물 85%를 같이 찾았고, 비닐하우스는 압축 때문에 46%만 찾았습니다. 자세한 표와 출처는 설계 문서에 있습니다.

영상API-1

[구조][Land-XI] 결과만 쌓는 구조 — 어디까지

지금

지금은 항공영상 파일(2023 한 해 · 67개 시군구)을 내려받아 두고 그 위에서만 분석합니다. 나머지 지역은 '영상 등록 필요'에서 멈추고, 해마다의 변화는 볼 수 없습니다.

제안

ⓐ 부를 때만 — 기관 · 직원이 지역과 연도를 고르면 그때 API로 불러 분석하고 결과만 연도별로 쌓습니다. 호출 · GPU가 가장 적지만, 전국 지도는 쓰인 곳만 차오릅니다(첫걸음 약 1주 · 추정). ⓑ 해마다 전국 결과 장부 + 바뀐 곳만 다시 — ⓐ에 더해, 새 해 영상이 나오면 전국을 낮은 해상도로 먼저 훑고 바뀐 칸만 25cm로 분석해 252곳 결과를 해마다 채웁니다. 첫해 전국 한 번은 GPU 한 장으로 약 34~44시간(추정)이고, 받는 날수는 허용 호출량에 달립니다. 결과 저장은 한 해 약 4GB이고, 영상 파일로 쌓으면 6~7TB입니다(ⓐ 뒤 약 2~3주 · 추정). 오퍼스 추천 ⓑ — '전국 수시 변화 + 결과 이력'을 그대로 이루는 쪽이고, ⓐ가 그 엔진입니다.

영상API-2

[운영][Land-XI] 영상 API 이용 범위 — 정식 확인을 먼저 받을까

지금

공공데이터포털에는 두 영상 API가 모두 '공공누리 제1유형(출처 표시 · 상업 이용 · 변경 가능)'으로 올라 있습니다. 그런데 브이월드 약관에는 결과 저장 · 복제 제한 조항이 있습니다. 우리가 부른 국토지리정보원 길은 지도 화면용이라 공식 안내 문서와 호출량 숫자가 없습니다. Land-XI에는 국토지리정보원 키가 없고, 브이월드 키는 개발 키입니다.

제안

ⓐ 정식 확인 먼저 — LX 이름으로 국토지리정보원 · 공간정보산업진흥원에 '영상은 저장하지 않고 분석 결과만 저장 · 출처 표시'라는 이용 범위와 하루 호출량을 묻습니다. 국토지리정보원 오픈 API 키와 브이월드 운영 키도 함께 받습니다. 답이 오기 전에는 시험(작은 범위)만 합니다. ⓑ 시범 병행 — 확인을 요청해 두고, 그동안 지금 열린 길로 작은 속도로 시범 운영합니다(답이 다르면 멈춤). 오퍼스 추천 ⓐ — 전국을 해마다 부르는 운영은 호출량이 커서, 막히면 서비스 전체가 멈춥니다.

영상API-3

[AI][Land-XI] 비닐하우스 재학습 — 무엇부터

지금

같은 2023년 영상을 API로 부르면 경작지 95% · 건물 85% · 주차장 77%를 파일과 같이 찾습니다. 비닐하우스는 46%(학습 모델은 9%)만 찾습니다. 같은 파일을 API처럼 압축해 돌렸을 때도 같은 만큼 줄었으니, 압축이 주원인입니다.

제안

ⓐ 건물 · 경작지부터 — 흔들리지 않는 둘로 먼저 전국 장부를 시작합니다. 그동안 API 영상으로 비닐하우스 표본을 만들어 다시 학습하고, 끝나면 더합니다. ⓑ 네 가지를 함께 — 비닐하우스 재학습이 끝날 때까지(표본 · 학습 · 결과 확인, 약 1~2주 · 추정) 기다렸다가 네 가지를 한 번에 시작합니다. 오퍼스 추천 ⓐ — 장부를 먼저 돌려 구조를 검증하고, 메인 · XI맵에 늦게 들어가는 것은 비닐하우스 하나뿐입니다.

XI맵-1

[구조][Land-XI] XI맵을 정의대로 — 영상 API 위의 한 지도

지금

지금 XI맵은 시군구 하나로 도착해 큰 숫자와 결과 점을 보여 주는 결과판입니다. 파일로 등록한 영상이 있는 곳에서만 분석하고, 연도 고르기가 없습니다. 해외는 다른 화면에 있습니다. 정의는 '전국 · 해외의 위성 · 항공 · 드론 영상을 실시간 분석하는 틀 + 그 결과 보기'입니다(원칙 6 · 141).

제안

ⓐ 다시 짜기 — 첫 화면은 국내 전체(해외 기관은 그 나라)에 결과 장부를 칠한 한 지도입니다. 영상 원천(항공 · 위성 · 드론)과 연도 막대를 고르고, 어디서든 읍면동 · 그린 범위 · 시군구 전체를 바로 분석합니다. 연도를 넘기며 결과와 '생김 · 없어짐'을 봅니다. 해외도 같은 지도 · 같은 틀입니다. ⓑ 지금 위에 더하기 — 지금 화면(시군구 도착 · 큰 숫자)은 두고, 영상 원천 · 연도 고르기와 '어디서든 분석'만 더합니다. 전국 장부 지도와 해외는 따로 둡니다(작업이 작고 빠름). 오퍼스 추천 ⓐ — 영상 API 구조의 앞 화면이 바로 XI맵이고, ⓑ로는 '플랫폼의 심장 · 글로벌'을 화면에서 보일 수 없습니다. 시안은 페블이 진단 → 방향 둘로 이어받습니다.
