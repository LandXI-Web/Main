[둘 다] 새 지자체는 무엇으로 시작하나 — 여섯 단계

지금

다른 시군이 영농관리를 원하거나 전남이 해양쓰레기 대상 해안을 넓힐 때 무엇을 다시 쓰고 무엇만 새로 하는지 정해진 절차가 없습니다. 기관 만들기·계정은 아직 관리자 화면 밖(스크립트)이고, 기관 영상이 없으면 시작할 수 없는 것처럼 되어 있습니다.

제안

카드는 그대로, 그 지역의 영상·필지·대장·CI 만 새로 합니다. 여섯 단 — 1 업무 정하기(갈래 판별) → 2 기관 만들기(CI · 관할 · 한도 · 기관 관리자 1) → 3 영상 올리기(파일에서 자동 AI 분석) → 4 지역에 적용(카드에 지역 한 줄 → 전역 분석 · 승인 1회) → 5 결과 확인(표본 20건 이상 · 사람) → 6 공개 · 가입 승인. 넷은 화면 안 자동, 사람 시간은 5 입니다. 전남 해양쓰레기 확대는 기관 만들기 없이 같은 카드에 해안 한 줄, 카드가 없는 신규 사업(관광인파 등)은 1 뒤에 프로젝트가 먼저 섭니다. 시작 방식은 갈림길입니다. ⓐ 기관 영상이 없어도 등록된 25cm 항공 영상으로 '기본 결과'(농지 위 건물·비닐하우스·경작지)를 먼저 열고 드론 영상은 뒤에 얹습니다. ⓑ 기관(또는 LX) 고해상 영상을 확보한 뒤에 엽니다.

외부 시스템 연결 창구(API) — 결과를 가져가고, 분석을 맡기는 구조

기관이 이미 쓰는 도로안전·영농관리 시스템이나 도청 GIS 가 사람 대신 Land-XI 에 직접 묻고 답을 받아 가는 창구를 설계했습니다. 화면보다 넓게 열리는 것은 없습니다 — 같은 관할, 같은 서비스, 같은 한도 장부. 고르실 것은 네 가지입니다.

API-1

[둘 다] API 로 내주는 것 · 맡길 것 · 막는 것

지금

지금 Land-XI 결과는 사람이 화면에 로그인해야만 볼 수 있습니다. 남원 도로안전·영농관리처럼 기관이 이미 쓰는 시스템이 결과를 받으려면 담당자가 화면에서 보고 옮겨 적어야 하고, 기계가 들어올 문(출입증)이 없습니다.

제안

기관의 다른 시스템이 출입증(API 키)을 들고 들어와, 사람이 화면에서 보는 것과 같은 결과를 그 기관 관할 안에서만 받아 가게 합니다. 은행 창구 옆 ATM 처럼 할 수 있는 일은 창구보다 적고, 내 계좌(관할) 밖은 열리지 않습니다. 결과 보기(약 5일) → 영상 맡겨 분석 받기 + 끝나면 알림(약 5일) → 개발자 안내 페이지(약 2.5일) 순서로 만들고, 학습·모델 바꾸기·원본 영상·다른 기관 자료·개인정보는 열지 않습니다.

API-2

[Land-XI] 누구에게 여나 — 키는 LX 관리자가 기관 서랍에서 만든다

지금

지금 기관 계정은 화면 로그인용뿐이고, API 를 누구에게 열지는 정해진 적이 없습니다. 키를 만들고 거두는 자리도 없습니다.

제안

키는 LX 관리자 화면 → 기관 → 기관 행을 누른 서랍의 'API 연동' 칸에서, 입력 세 칸(이름 · 할 수 있는 일 · 서비스)으로 만들고 딱 한 번만 보여 줍니다(새 메뉴 없음 · 결재 없음 · 폐기는 한 번 눌러 바로). 여는 대상은 ⓐ 서비스를 받는 기관(계약·협약)만 — 그 기관 관할·서비스 안에서, 또는 ⓑ ⓐ에 더해 다른 공공기관에도 요약 숫자·지도 조각만 신청·승인으로(필지·조각 모양은 계약 기관만).

API-3

[둘 다] 분석 맡기기 — 한도와 비용

지금

기관마다 한 달 분석 시간 한도가 있습니다(남원시 10시간 · 광주전남 6시간). 분석 기계는 전력 규칙 때문에 한 번에 한 장만 세게 돌고, 화면에서 누른 분석과 같은 줄에 섭니다.

제안

ⓐ 기관 한도 안에서 따로 비용 없이, 화면 분석 뒤 순서로(끝나면 알림 · 24시간 안 약속) ⓑ 한도를 넘는 양은 맡긴 넓이·시간 기록으로 따로 정산 ⓒ 처음엔 분석 맡기기를 열지 않고 결과 보기만. 참고로 남원시만 한 시군구(약 750㎢)를 항공영상으로 한 번 분석한 기록이 분석 기계 약 21분 — 남원시 한 달 한도의 4% 정도입니다.

API-4

[둘 다] 결과를 어느 수준까지 내주나

지금

기관 화면은 AI 가 찾은 조각·필지의 모양과 '결과 확인 전 / 확인됨'을 함께 보여 줍니다. AI 결과는 참고자료이고 처분은 사람이 합니다.

제안

ⓐ 화면과 같게 — 조각·필지 모양까지 주고, 모든 결과에 '결과 확인 전/확인됨'과 '참고자료' 표시 ⓑ 결과 확인을 마친 것만 모양까지, 확인 전은 숫자만 ⓒ 숫자·지도 조각·보고서만(모양 파일 없음). ⓐ는 바깥 시스템이 확인 전 결과를 사실처럼 쓸 수 있다는 걱정이 남고, ⓑ는 결과 확인이 밀리면 바깥 시스템이 받을 것이 적어집니다.
