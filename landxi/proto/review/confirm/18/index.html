[문서][둘 다] 결합 — 꼭 해야 하나

지금

데이터 올리기(남원시)에 '영상 → 지적 → 대장 → 결합' 네 단계와 '필지 결합률 55.2%' 큰 숫자, '결합 실행' 버튼이 있습니다. 결합이 무엇을 주는지, 안 하면 무엇을 잃는지가 화면에 없고, 결합률은 화면 55.2% · 서버 60.8% 로 출처가 둘입니다. 대장 결합(옛 D7)은 2차 · 3차 확인에서 보류된 채입니다.

제안

결합은 두 겹입니다. ① 필지 결합 = AI 결과(면)를 연속지적과 겹쳐 필지마다 세는 일 — 이것이 있어야 '현장 확인 필요 1,035필지' · 지목 규칙 · 필지 보고서가 나옵니다(남원: 332,084필지 → 의심 20,872 → 현장 확인 1,035). ② 대장 비교 = 기관의 엑셀 대장과 필지를 맞춰 '대장과 다른 필지'만 남기는 일. 세 길 가운데 ⓑ + ⓒ 를 추천합니다: 필지 결합은 필지 대조 서비스(영농 · 건축물 · 곤포 · 주차장)에서 서버가 분석 뒤 자동으로 하고 직원 화면의 단계 · 버튼 · 결합률 숫자는 없앱니다(탐지형 서비스와 지적 없는 해외는 결과만). 대장 비교는 기관 화면 '행정정보와 결합해 비교 분석' 옵션(원칙 75)에서 기관이 원할 때만, 기본 틀(필지 찾는 열 + 비교 열) + 커스텀(원칙 58). 옛 D7 의 갈림길(어디서 계산하나)은 이 길에서 자연히 ⓐ 서버 한 곳으로 닫힙니다.
