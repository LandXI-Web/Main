R-D5-1

오탐 신고 — 남원 GeoVision 농정과 담당자의 화면부터

지금

2차 설계는 LX 신고함·표본·기준값 이야기가 중심이었고, 기관 쪽은 이유 4택 한 줄뿐이었습니다. 지금 기관 판정 화면에서 '대장과 같음'을 누르면 담당자가 모르는 새 신고로 바뀌고, 답을 받을 곳이 없습니다.

제안

필지 카드(판정·결과 지도·XI맵 세 곳 같은 카드)에 '실제와 다릅니다' 버튼 → 이유 하나(담당자 말: 실제로는 대장대로입니다 / 대장이 최신이 아닙니다 / 기준이 너무 엄합니다 / 계절·일시적입니다) + 사진·메모(선택) → 'LX 에 전달'(30초, 클릭 3번). 판정 '대장과 같음'도 같은 시트를 열되 저절로 전달되지 않습니다. 서비스 안 '내가 알린 필지' 탭에서 상태 3단(전달됨 → LX 확인 중 → 답변)과 답변 5종(AI 결과가 맞습니다 / AI 오류 — 다음 분석부터 반영 / 기준값 조정 / 대장 갱신 확인 / 다음 시점 재확인)을 보고, 답이 오면 알림 한 줄. 'AI 오류' 필지는 할 일에서 빠집니다. 여러 건 한 번에 가능. 기관 화면에 LX 말(재학습·표본·신고함) 0. LX 는 신고함에서 판정 3택 + 원인 → 판정이 곧 기관 답변.

R-D5-2

재학습은 누가 판단하나 — 두 단(프로젝트장 → LX 관리자) 추천

지금

2차 설계는 신호 5개가 '다음 할 일'을 정하고 직원이 '재학습 시작'을 누르는 구조라 누가 책임지는지, GPU 를 누가 여는지가 없었습니다. 지금 화면은 '30일 신고 5건' 규칙 하나로 재학습을 권합니다.

제안

판단을 둘로 나눕니다. ① 필요한가 = 프로젝트장(모델·표본·오탐 원인을 아는 사람): 근거판(신호 5·표본·원인 비율·적용 지역·예상 GPU 시간)이 자동으로 붙는 '재학습 요청' + 가이드 5 체크(AI 오류가 오탐의 절반 이상인가 · 새 표본 20건 이상인가 · 지역 쏠림 · 기관 영향 · 자원). ② 지금 돌려도 되는가 = LX 관리자: 결재함에서 승인(시간대·순서 지정) 또는 반려(사유 필수: GPU 여유 없음 / 표본 부족 / 근거 부족 / 기준값 조정 먼저 / 기타) — 관리자 승인 없이 학습이 대기열에 들어가는 경로 0. 자동 실행은 두지 않고 '권장(신호 2개 이상)' 표시까지만. 학습 뒤 정밀도 전·후 비교 → 새 버전(서비스 만들기 버전 규칙) → 갱신 배포 결재. 대안: ⓑ 프로젝트장 단독(관리자는 사후 기록) / ⓒ LX 관리자 단독(직원은 신호만 봄).
