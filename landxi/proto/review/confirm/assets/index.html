설계 12차 — AI 학습 데이터를 자산으로 관리하기

'AI 학습 데이터를 자산으로 관리하는 부분도 필요하다'(10-07)에 따라 설계했습니다. Land-XI 플랫폼의 LX 직원 화면입니다. 학습 데이터 한 건 = 클래스 목록이 같은 라벨 묶음 하나로, 지금 대장 27줄은 48건이 됩니다. 코드는 고치지 않았습니다(GPU 0 · 원본 이동 0). 세 가지를 골라 주시면 그대로 만듭니다.

자산-1

[화면][Land-XI] 학습 데이터 관리 — 어디까지 만들까

지금

지금은 '서비스 만들기'용 작은 표본 5건만 서버에 있고, 15만 장 묶음 같은 큰 자료 22줄은 대장 문서에만 있습니다. 결과를 보며 고친 것이나 기관이 알린 오탐(지금 105건 쌓임)이 학습 데이터로 돌아가는 길이 없습니다.

제안

ⓐ 목록 · 한 건 · 이용 조건만 — 48건을 들여 사진 · 수량 · 출처 · 이용 조건 · 쓰인 모델을 봅니다. 판은 1판으로 고정. 가장 작음. ⓑ ⓐ + 판 관리 · 다음 판에 담을 것 — 모델이 쓴 판은 잠그고, 라벨을 고치면 새 판. 'AI 결과가 맞는지 보기'의 오탐 판정과 기관 오탐 알림이 그 자산의 '다음 판에 담을 것'으로 모이고, 프로젝트장이 골라 새 판을 만들어 다시 학습합니다(추천 — 고친 만큼 모델이 좋아지는 길). ⓒ ⓑ + 화면 안 라벨링 도구 — 구 Land-XI의 클래스 등록 · 라벨링 · 데이터 셋 생성처럼 도형을 직접 그리고 고칩니다(사람이 그리는 것부터 · 가장 큼).

자산-2

[화면][Land-XI] 학습 데이터를 어디에 둘까

지금

지금 LX 직원 메뉴 '데이터'에는 데이터 올리기(영상 · 행정 자료) 화면만 있고, 학습 표본은 프로젝트의 '학습데이터 구축' 단계에서만 보입니다.

제안

ⓐ 데이터 메뉴 안 '학습 데이터' 탭에 전체 목록 + 프로젝트 '학습데이터 구축' 단계에는 그 프로젝트 것만 같은 표로(목록에서 고르기 · 새로 올리기). 프로젝트에 안 붙은 44건도 갈 곳이 있습니다(추천). ⓑ 프로젝트 안에만 — 메뉴는 그대로지만, 어느 프로젝트에도 안 붙은 44건은 볼 곳이 없습니다. ⓒ 왼쪽 메뉴에 '학습 데이터' 칸을 따로 — 찾기 쉬우나 메뉴가 일곱 칸이 됩니다.

자산-3

[운영][Land-XI] 이용 조건이 확인 안 된 자료 — 얼마나 막을까

지금

48건 중 38건(AI Hub 가공 · 공개 묶음 · 출처 추정)은 약관 원문을 아직 보지 못했습니다. 지금 비닐하우스 · 건축물 · 주차장 카드의 모델도 그중 하나에서 나왔습니다.

제안

ⓐ LX 관리자가 자산마다 넷 칸(LX 안 학습 · 국내 기관 모델 · 해외 기관 모델 · 원본 내보내기)을 정하고, 정하기 전에는 그 자료로 만든 모델을 해외 기관에 배포하지 못하게 서버가 막습니다(가장 안전 · 해외 배포가 늦어질 수 있음). ⓑ 막지 않고, 배포 결재 화면에 '이용 조건 확인 전 자료로 학습' 경고 한 줄만(빠름 · 놓칠 수 있음). ⓒ 출처별로 한 번에 정하고(AI Hub 전부 · 공개 묶음 전부) 다른 것만 자산마다 — 38건을 두세 번 누름으로(정하는 수고 가장 적음).
