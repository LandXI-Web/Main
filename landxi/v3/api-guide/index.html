표준 가이드

인증

  • 모든 요청 머리글에 Authorization: Bearer lxk_… 를 넣습니다.
  • 키는 서버에만 두세요. 웹 화면 코드 · 앱 · 저장소에 넣지 마세요.
  • 키마다 범위(지역) · 권한 · 영상 원천 · 한도 · 끝나는 날이 정해져 있습니다. GET /v1/me 로 확인합니다.
  • Land-XI 화면 로그인으로는 API를 부를 수 없고, 키로는 화면을 쓸 수 없습니다.

주소

기본 주소 https://api.land-xi.dev/v1

GET /me키 확인 — 시스템 · 서비스 · 권한 · 범위 · 원천 · 한도 · 끝나는 날
GET /services이 키로 쓸 수 있는 서비스
GET /services/{서비스}서비스 설명 — 찾는 대상(종류) · 서비스 판 · 형식
GET /services/{서비스}/coverage결과가 있는 곳 — 지역 × 원천 × 연도 × 분석한 날 × 건수
GET /services/{서비스}/results결과 조회(GeoJSON 한 쪽 · 최대 1,000개)
POST /services/{서비스}/results/search결과 조회 — 범위를 도형(GeoJSON)으로 보낼 때
GET /services/{서비스}/summary요약 — 종류별 개수 · 넓이 · 지역 · 읍면동별
GET /services/{서비스}/exports/{형식}파일로 받기 — geojson · shp · parcels(필지 엑셀)
GET /usage내 호출 수(오늘 · 이번 달)
/imagery · /services/{서비스}/analyses분석 호출 · 상태 · 취소 아직 열리지 않음

범위 · 원천 · 연도 고르기

region행정구역 코드 — 시도 2자리 · 시군구 5자리 · 읍면동 10자리, 쉼표로 여럿
bbox서,남,동,북 경위도(예: 127.38,35.40,127.41,35.42)
source · year영상 원천 · 연도. 안 주면 곳마다 가장 최근 결과
kind종류 코드로 거르기(서비스 설명의 종류)
since이 시각 뒤에 분석한 결과만(ISO 8601)
cursor · limit다음 쪽 열쇠(앞 쪽 답의 lx.next) · 한 쪽 개수(최대 1,000)
crs4326(기본 · 경위도) · 5186 · 5179

범위는 키의 범위 안이어야 합니다. 밖이면 ‘없음’(404)으로 답합니다.

  • score 는 AI 점수(0–1)이며 확률이 아닙니다. area_m2 는 ㎡입니다.
  • parcel 은 필지 번호 19자리(글자)입니다. 필지와 잇지 않은 서비스는 비어 있습니다.
  • AI 결과는 참고자료입니다. 처분 · 행정 결정은 사람이 확인한 뒤 합니다.

오류 · 한도 · 기록

400 bad_request값이 맞지 않음
401 unauthorized · key_revoked · key_expired키 없음 · 틀림 · 폐기 · 기간 끝
403 key_paused · forbidden멈춘 키 · 키에 없는 형식 · 권한 밖
404 not_found없는 주소 · 서비스, 또는 키 범위 밖
429 rate_limited호출 한도를 넘음(Retry-After 뒤 다시)
501 not_open분석 호출 — 아직 열리지 않음
  • 호출 한도 처음 값은 1분 60회 · 하루 20,000회이며 키마다 다릅니다.
  • 모든 호출은 기록됩니다(시각 · 키 끝 네 자리 · 무엇을 · 몇 건 · 결과 · 접속 주소).
  • /v1 안에서는 더하기만 합니다. 모르는 필드는 무시하도록 만들어 주세요.

예제

curl

# 키 확인
curl -H "Authorization: Bearer $LANDXI_KEY" https://api.land-xi.dev/v1/me

# 결과가 있는 곳
curl -H "Authorization: Bearer $LANDXI_KEY" https://api.land-xi.dev/v1/services/farm/coverage

# 결과 조회(남원시 · 2025)
curl -H "Authorization: Bearer $LANDXI_KEY" \
  "https://api.land-xi.dev/v1/services/farm/results?region=52190&year=2025"

# 파일로 받기(SHP)
curl -o farm_shp.zip -H "Authorization: Bearer $LANDXI_KEY" \
  "https://api.land-xi.dev/v1/services/farm/exports/shp?region=52190"

Python

import os, requests

BASE = "https://api.land-xi.dev/v1"
S = requests.Session()
S.headers["Authorization"] = "Bearer " + os.environ["LANDXI_KEY"]

def results(service, **params):
    """결과를 끝까지 받기(쪽 나눠 받기)."""
    feats, cursor = [], None
    while True:
        q = {**params, **({"cursor": cursor} if cursor else {})}
        r = S.get(f"{BASE}/services/{service}/results", params=q, timeout=60)
        r.raise_for_status()
        page = r.json()
        feats += page["features"]
        cursor = page["lx"]["next"]
        if not cursor:
            return feats

feats = results("farm", region="52190", year=2025)
print(len(feats), "건")
