# 구름 데크 브레이크스루 — 텍스처 & 사용법

`tools/clouds/make_clouds.py` 로 생성한 3매 패럴랙스 구름 평면 + 화이트아웃용
haze 텍스처. "카메라가 구름을 뚫고 위성지도 위로 나오는" 시네마틱 스크롤
모먼트에 사용한다. 프리뷰: `tools/clouds/preview.html` (스크린샷:
`shots/clouds/f0..f3.png`).

## 파일

| 파일 | 크기 | 용도 |
| --- | --- | --- |
| `cloud_far.webp`  | 2048×2048, tileable | 상층 얇은 고주파 베일 (권생운 느낌) |
| `cloud_mid.webp`  | 2048×2048, tileable | 중층 갈라진 데크, 틈(gap) 뚜렷 (커버리지 ~55%) |
| `cloud_near.webp` | 2048×2048, tileable | 근경 크고 부드러운 뭉게구름 (커버리지 ~70%) |
| `haze.webp`       | 1024×1024 | 방사형 화이트아웃 플래시 (데크 한가운데를 관통하는 순간) |

모두 RGBA 스트레이트 알파 WebP. 알파는 하드 엣지 없이 quintic-smoothstep로
부드럽게 페이드되며, 알파가 낮아지는 가장자리는 흰색 쪽으로 살짝 당겨져
("premultiplied-looking") 밝은 배경 위에서 어두운 프린징이 생기지 않는다.
그림자면은 `#B8C6D6`(블루그레이) 쪽으로 multiply, 정점/윗면은 흰색 쪽으로
하이라이트된다. 세 텍스처 모두 가로/세로 모두 이음매 없이 반복된다
(격자 좌표를 modulo 인덱싱하는 tileable value-noise fBm 기법).

## 레이어링 순서 (뒤→앞)

1. 배경: 위성지도(MapLibre 캔버스)
2. `cloud_far`  — 가장 멀고 느리게 움직이며 가장 늦게 걷힌다
3. `cloud_mid`  — 중간
4. `cloud_near` — 가장 가깝고 빠르게 움직이며 가장 먼저 걷힌다 (카메라가 처음 통과하는 층)
5. `haze` — 관통 정점에서만 짧게 번쩍이는 화이트아웃 플래시 (최상단, `screen` 블렌드)

이 순서는 실제 비행 관통 시 카메라에 가장 가까운 구름이 먼저 스쳐 지나가고,
가장 얇고 먼 상층 베일이 마지막까지 남는 현상을 모사한다.

## CSS 블렌드 모드

- `cloud_far` / `cloud_mid` / `cloud_near`: **`mix-blend-mode: normal`** 권장.
  텍스처 자체가 이미 그림자/하이라이트 셰이딩과 소프트 알파를 포함하므로
  `normal` 이 입체감 있는 "물리적 구름"으로 읽힌다. `screen` 은 그림자 쪽
  블루그레이 톤을 날려버려서 뭉게구름의 볼륨감이 사라지고 얇은 안개처럼
  평면적으로 보인다 (프리뷰의 blend-mode 토글 버튼으로 직접 비교 가능).
- `haze`: **`mix-blend-mode: screen`** 권장. 관통 순간의 하얀 플래시는
  가산광처럼 화면을 밝히는 것이 목적이라 `screen` 이 자연스럽다.

```css
.cloud-layer { mix-blend-mode: normal; }
.haze-layer  { mix-blend-mode: screen; }
```

## 스케일 / 오파시티 커브 (p: 0.22 → 0.30)

전체 페이지 스크롤 진행도 `p` 중 브레이크스루는 **p = 0.22 → 0.30** 구간에서만
일어난다. 이 구간을 `local = clamp((p - 0.22) / 0.08, 0, 1)` 로 정규화한 뒤,
레이어별로 서로 다른 로컬 구간에서 스태거(stagger)를 준다 — near가 가장
먼저, far가 가장 늦게 걷히도록.

| 레이어 | 활성 local 구간 | scale (1 → X) | opacity (1 → 0) | parallax |
| --- | --- | --- | --- | --- |
| `cloud_near` | 0.00 → 0.60 | 1 → **2.3** | 1.0 → 0 | 가장 큼 (가장 가까움) |
| `cloud_mid`  | 0.15 → 0.85 | 1 → **2.8** | 1.0 → 0 | 중간 |
| `cloud_far`  | 0.35 → 1.00 | 1 → **3.2** | 0.95 → 0 | 가장 작음 (가장 멂) |
| `haze` | 종형(bell) 곡선, 정점 local≈0.42 | 1 → 1.6 | 0 → **0.85** → 0 | — |

각 레이어는 자신의 `(a, b)` 구간에 대해 `t = smoothstep(a, b, local)` 을 구한
뒤 `scale = lerp(1, scaleTo, t)`, `opacity = opacityFrom * (1 - t)` 로 계산한다.
`p < 0.22` 에서는 모든 레이어가 `scale=1, opacity=최대` (데크가 화면을
완전히 덮은 상태), `p > 0.30` 에서는 모든 레이어가 커지고 사라져 지도가
완전히 드러난다. `haze` 는 관통이 절반쯤 진행된 local≈0.42 부근에서만
짧게 밝아졌다 사라지는 종형 곡선을 쓴다 — 카메라가 데크 한복판을
지나는 그 짧은 순간에만 화면이 하얗게 번쩍이도록.

정확한 JS 구현/에디터는 `tools/clouds/preview.html` 참조 (`apply(p)` 함수).
쿼리스트링 `?p=0.27` 로 특정 진행도를 바로 열 수 있고 `?blend=screen` 으로
블렌드 모드 비교도 가능하다.

## 검증

`tools/clouds/preview.html` 을 `shots/research/v-namwon.png` 위에 스택해
`shots/clouds/f0..f3.png` (p = 0.20 / 0.24 / 0.27 / 0.34) 로 스크린샷 검증함.
f0(데크 완전 커버) → f1(화이트아웃 피크 + 뭉게구름 형태) → f2(갈라지며
지형 드러남) → f3(옅은 상층 베일만 남고 위성지도 완전 노출) 흐름으로,
안개가 아니라 입체감 있는 물리적 구름이 갈라지는 것으로 읽힌다.
