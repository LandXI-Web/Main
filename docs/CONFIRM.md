# Land-XI 확인 대장 — 기록 → 사용자 확인 → 구현 → 구현 확인

> 2026-09-30 사용자: "방향성을 잃지 않도록 자주 기록해 놓고 기록에 대해 나에게 피드백을 점검받아. 제대로 된 부분만 구현을 진행하고, 구현에 대한 피드백도 점검받는다. 이러한 걸 다 기록화하고 컨펌 안 된 건 구현하지 않고. 오퍼스 5.5, 소넷 5.5 지시할 때도 기록을 공유하여 체계적인 지시·관리한다."

## 보는 곳
확인 요청 페이지(캡처·열어 볼 주소·계정·고르는 버튼): https://landxi-web.github.io/Main/landxi/proto/review/confirm/ — 생성 `python tools/review/build-confirm.py`

## 규칙
1. 새 기획·변경은 먼저 이 대장에 **확인 대기**로 적고, 확인 요청 페이지에 **지금 · 제안 · 보는 곳(캡처 + 열어 볼 주소·계정·누를 곳) · 고를 것**을 올려 사용자에게 보여 준다. "무엇을 보고 무엇을 고르는지" 없이 확인을 요청하지 않는다.
2. 사용자가 **확인**한 항목만 구현한다. **보류·반려**는 구현하지 않는다(이유를 적어 둔다).
3. 구현이 끝나면 **구현 확인 대기**로 올리고 화면(주소·캡처·영상)을 보여 준다. 사용자 피드백을 받아 **완료** 또는 **다시**.
4. 에이전트(Opus 5.5·Sonnet 5.5·Fable 5.1)에게 일을 줄 때는 이 대장의 항목 번호와 확인 내용을 그대로 넘긴다. 대장에 없는 일·확인 안 된 일은 지시하지 않는다.
5. 사용자가 준 지시 자체(USER-DIRECTIVES.md 원칙)는 확인된 것으로 본다. 그 지시를 **어떻게** 구현할지(방법·문구·주소 이름 등)가 새로 정해지면 여기서 확인받는다.
