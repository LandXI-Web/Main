## 0. 판정 — 지금 이 화면은 무엇으로 읽히는가

**"KPI 띠를 얹은 파일 관리자"** 로 읽힌다. 파일이 생산 라인에 들어와 레이어가 되고 카드로 나가는 **LX 양산 라인의 입구**로는 읽히지 않는다. 화면의 70%가 150px 타일 격자와 말줄임된 기계 이름(`NW_ortho…`)이고, 이 플랫폼의 정체성인 지도·영상은 우 패널 구석 **241×135px 액자**(1440) 하나다 — 같은 플랫폼의 지도 서비스 판(677×721)의 1/15 면적이다. 4탭은 "파이프라인 단계"라고 법전(§6)이 못 박았지만 어떤 건도 단계를 건너가지 않고, 유일하게 움직이는 것은 99→62로 되감기는 가짜 진행률이다. 새로고침하면 모든 조작이 사라진다. 기능 밀도는 높고(원본 4탭 필터·검색·폼·모달 거의 1:1, 콘솔 오류 0, 법전 시각 위반 0) 정직성 장치("왜 못 그리는지 자백", 시연 표기)도 좋지만, **이야기가 없고 무게 중심이 뒤집혔다.** 사용자 표현으로는 여전히 "딱딱한 업무 시스템 목업"이다. 완성도 60% · 몰입감 3.5/10 이라는 감사관의 수치에 동의한다.

## 1. 무엇이 뒤집혀 있는가 — 세 가지 구조적 오독

### 1.1 주인공이 바뀌었다 (그림 < 대장)
- `01-overview-1440.png`: 개요는 세로로 긴 사진 4장을 나열한 정적 포스터. 세 번째 구역(레이어 발행중)의 대표 그림은 **빈 점선 상자 "좌표계가 없다"** — 이 화면에 처음 들어온 사람이 보는 4장 중 1장이 실패 포스터다. 대표 그림은 "이 단계에 지금 무엇이 지나가는가"를 보여야 하는데, 시드 배열의 첫 항목(`ovRows(id).slice(0,1)`)을 기계적으로 뽑았다.
- `14-manage-d4-map.png` · `24-archive-a1-map.png` · `fx/c-plate-only-1440.png`: 실제 MapLibre 판 + 실측 도엽 타일 + 청록 성과 폴리곤이 **241×135px** 안에 있다. 1920에서도 392×203. 그 옆의 정보 표(이름 · 형식 · 크기 · 등록자 · 범위 좌표)가 판보다 넓다. 정사영상 플랫폼이 정사영상을 우표 크기로 보여 주고 문자를 크게 보여 준다.
- `02-upload-board.png`: 타일 격자 아래 y≈670–830 빈 띠. 우 패널의 진행 현황판은 스프레드시트다.

### 1.2 시간이 흐르지 않는다 (파이프라인 = 정적 분류함)
- `dataset.js:428` `u.pct = u.pct >= 99 ? 62 : Math.min(99, u.pct + 1)` — 업로드는 절대 끝나지 않는다. 법전 §4 "유휴 운동 1개 = **실데이터에 묶인 것**"의 정면 위반이다. 대기 건은 영원히 `대기중 0%`(`08-upload-after-submit.png`).
- 발행 단계는 오르지 않고(`22-publishing-p3-run.png` 3/4 62% 고정), 발행이 끝나 아카이브에 들어오는 순간은 존재하지 않는다. 폼 제출 → `setTab('publishing')` 한 번의 화면 전환이 유일한 "전이"다.
- 보조 실측: 개요를 4.5초 지켜봤을 때 텍스트 변화 0, 애니메이션 요소 0, 아카이브 선택 상태에서 `[data-live]` 0. **화면에 살아 있는 것이 없다.**
- 결과: "4탭 = 파이프라인"이라는 말이 화면에 없다. 사용자는 폴더 4개를 본다.

### 1.3 이 화면이 두 층을 잇는 자리라는 사실이 보이지 않는다
- two-tier §3 · card-architecture §5.2 R7: **원본 정사영상은 LX 보관 · 밖으로 내보내지 않음 · 공유는 타일만.** 이것이 이 플랫폼의 데이터 주권 서사이고, 그 서사가 화면에 나타날 자리는 **정확히 이 화면의 공유 모달**이다. 그런데 `26-share-modal.png`는 원본 정사영상(`NW_ortho_202604_section_A.tif`)에 `남원시청 · 편집`을 허용한다. `registry.js:156 ASSET_TIERS`가 있는데 `dataset.js`가 참조하지 않는다. 스펙 위반이기 이전에 **이 화면이 자기 역할을 말할 유일한 기회를 버린 것**이다.
- 아카이브 상세 `사용 현황`(프로젝트 · 데이터셋 · 서비스)은 링크가 아니다(`dataset.js:755`, `title`에만 출처). "이 영상이 어느 카드/배포본을 돌리고 있나"(DEPLOYS · cards.js)가 없다. 데이터 → 모델 → 카드 → 행정 활용이라는 플랫폼 축의 첫 마디가 뒷마디와 끊겨 있다.
- 디스크 1,965/2,048 GB(시연)와 `infra.js` 저장 16 TB/120 TB는 서로 모르는 두 세계다.

## 3. 인터랙티브 개선 제안 — 기존 기능에 묶인 것만

원칙: 새 기능 0. 창의성은 **지도 · 영상 · AI 결과가 살아 움직이는 방식**에만. 법전 준수(흰 바탕 · 잉크 · #006DF7 · 청록은 AI 결과 · 라운드/그림자/유리 0 · 이징 하나 · 사다리 500/750/1000/1250 · 유휴 운동 1개는 실데이터에 묶임).
