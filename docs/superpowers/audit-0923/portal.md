- `admin-home.html` → 열림(“운영 현황 — LX 관리자”)
- `dataset.html` · `admin-users.html` · `admin-publish.html` → 전부 열림 — `03-namwon-login-then-admin-users.png`
- `portal-dp-gj-marine-25.html`(남의 기관) → 열림

기관 레일의 `MY` → `mypage.html` 은 LX 관리자 레일(운영 현황·데이터 관리·카드 발행·생산 관리·서비스 관리)과 “관리자 admin@namwon.go.kr” 로 뜬다 — `14-rail-mypage_html.png`. 로그아웃은 LX 메인 필름(`scrub/index.html`)으로 간다(`shell.js:142-145`). 발주자 요구 “지자체에서는 나만의 AI 시스템처럼”(9/21)과 스펙 R12(LX 전용 메뉴는 기관 레일에 안 뜬다)를 **주소 한 번**에 무너뜨린다. 필요: `lx_tenant` 세션 키, 관문의 테넌트 판정(기관 세션은 `portal-*` + 기관 허용 화면만), 기관 전용 MY/로그아웃.

**P1-2 가짜 컨트롤(placebo).** 누르면 `aria-pressed` 와 문구만 바뀌는 버튼: 드론 플레이어 `재생`·`탐지 상자`(`portal-ui.js:493-503`), 밀도 격자 `50/100/200 m`(`:429-437`). 광주전남 플레이어도 비활성 자리(`20-dp-gj-marine-25-result.png`). 사용자는 “동작하는 화면으로 판단”한다 — 결과가 없으면 컨트롤을 세우지 말고 빈 판 + 이유로 둬야 한다. 로컬에 여수 해양쓰레기 드론 자산이 있는데 영상이 한 프레임도 안 걸린다.

**P1-3 기관 레일이 비어 있다.** 기관(역할 없음=admin) 레일: 마크 · MY · 로그아웃뿐(`result.json` “home rail”). `TENANTS.menus = ['portal','analysis','map','support']`(`landxi/assets/data/portal.js:30`) 인데 셸이 역할 표(admin)로 먼저 걸러 `지도`·`서비스 지원`이 사라진다. 스펙 production §3 골격 8부위 중 “서비스 지원”이 기관 화면에 없다. staff 로 들어가면 반대로 LX `ximap.html` · `notice.html` 이 뜬다(`result.json` “lx_role=staff portal rail”).

**P1-4 피드백 고리(오류 신고)가 없다.** 두-층 스펙 §3 “피드백: 지도 결과 → 오류 신고 → 프로젝트”, production §1 “기관 임무는 오류 신고 하나”. 화면에는 “오탐·누락은 서비스 지원으로 신고하면…” 문장만 있고(`portal-ui.js:597`) 신고 버튼·폼·연결이 없다. 필지/결과 줄 선택 → “이 결과 신고” 가 있어야 한다.

**P1-5 두 벌의 포털.** 남원 5장(새 골격 `data-gen="rows"`)과 광주전남 2장(구 골격 + 인라인 CSS 60줄 + 인라인 모듈)이 **다른 제품처럼 보인다**: 헤더 크기·서브타이틀 문구(“— 모델과 결과 품질은 LX 가 책임진다” 유무), 지도 크기(526px vs 234px), 지도 배경(V-World 위성 vs OpenFreeMap 벡터+영문 지명 `Hwayang-myeon`), 표 스타일(`gj-tb` 14.5px). 비교: `20-dp-nw-farm-25-map.png` ↔ `20-dp-gj-marine-25-map.png`. 생산화 논리(골격 한 벌, R9)와 정면 충돌.

**P1-6 기관 사용자에게 LX 내부 생산 문구 노출.** 광주전남 전 탭 하단 “이 화면은 명세에서 생성되었습니다 · 블록 7개 · 기관 요구 1건 반영 · 접수 1건 대기 — 요구는 LX 가 명세를 고쳐 다시 찍습니다”(`portal-ui.js:970-973`), “발주할 것은 자료·모델 11종 — 화면은 발주 목록에 없다”(gj-27), 블록 제목 `머리 숫자`(생산자 말 — 생성기 주석이 기관 화면에선 덮는다고 했는데 gj 는 안 덮임). 남원 화면의 “서식은 LX 가 한 벌로 관리합니다 — 기관은 CI 한 벌만 냅니다”(`portal-ui.js:564`)도 기관 직원이 볼 말이 아니다.

### P2

**P2-1 지도 위 읍면동 채움이 결과를 덮는다.** 행정경계를 `QUINT_FILL`(청록 계열)로 채워(`portal-ui.js:856`, `map-gl.js:146`) 지도 전면이 청록 판이 된다 — 청록은 법전 §2 “AI 결과 폴리곤 전용”. 농지 결과 점(청록)이 경계 채움과 구분되지 않는다 — `20-dp-nw-farm-25-map.png`, 결과 없는 road/crowd 에서도 지도 전체가 “AI 결과처럼” 보인다 — `20-dp-nw-road-26-map.png`.

**P2-2 법전 §2 경고색 오용(광주전남).** `.gj-gap{border-left:2px solid var(--warn)}` + `b{color:var(--warn)}`(`portal-dp-gj-marine-25.html` 인라인 CSS) — warn 은 “테두리 금지, 조치 필요 글자에만”. “해안선 구간 등급”·모의 경고 문단 전체가 빨강(`20-dp-gj-marine-27-map.png`) — 조치 항목이 아니다.

**P2-3 법전 §4 모션 위반.** 카드 호버/포커스 `translateY(-10px)`(측정: `matrix(1,0,0,1,0,-10)`; `portal.css:136,172`) — 법전 4px. 지속 320/420ms(`portal.css:133,150,175,179`) — 사다리는 500/750/1000/1250. veil 이징 `cubic-bezier(.45,0,.2,1)`(`portal.css:175`) — 이징은 하나(0.15,1,0.3,1).

**P2-4 지어낸 운영 서사.** `studio.js:67-78` `REQUESTS` — “남원시 농정과 2026-07-02”, “광주전남특별시 해양항만과 2026-09-18” 등 부서명·접수일·처리일은 실제 요구 기록이 아니다(콘티 §5 “담당자명·대기 일수·활동 기록 금지”). 포털 화면에 “기관 요구 반영” 표식·“접수 1건 대기”로 새어 나온다. `시연` 표식 필요.

**P2-5 상태 모순.** 생활환경(living-23) 카드가 `운영`(홈 `10-home-1440.png`) 인데 작업공간은 “분석 실행 전입니다”. 홈 `실측 보유 1개` 인데 변화 탐지도 시점 쌍 실측을 가진다. `운영`의 정의(결과를 지금 쓸 수 있다, 홈 타일 부제)와 어긋난다.

## 4. 사용자 품질 기준 대비 — 4 / 10

- **동작**: farm-25 · change 는 “진짜로 도는” 업무 화면이다(실 geojson, flyTo, 시점 전환, 크롭). 이 둘만 보면 6점.
- **몰입감**: 거의 없다. 홈 덱의 카드 펴기(veil)가 유일한 연출이고, 도착 후는 백색 표·범례의 업무 시스템이다. 메인 필름(9/20 감사 “기준점”)과 비교하면 같은 제품 가족으로 안 읽힌다. 지도는 청록 판에 덮여 있고 결과 없는 3개 서비스는 빈 판 + 문장. 사용자가 거부한 “딱딱한 업무 시스템 목업”에 가장 가까운 영역.
- **정직성**: 결과 없음 표기는 좋다. 그러나 가짜 컨트롤(P1-2)과 지어낸 요구 기록(P2-4)이 점수를 깎는다.
- **감점 결정타**: 기관 입구가 LX 관리자 문으로 이어지는 것(P0-1) — 시연 중 `MY` 한 번 누르면 “관리자 · 운영 현황”이 뜬다.
