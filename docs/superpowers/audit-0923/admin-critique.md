## 0. 판정 — 지금 이 영역은 무엇으로 읽히는가

**"문 하나만 색이 다른 직원 사무실."** 운영 현황 한 장은 검은 마스트헤드와 여섯 줄 레일로 다른 집을 선언한다. 그런데 레일에서 두 번째 줄(데이터 관리)을 누르면 직원 레일 열 줄이 그대로 돌아오고(`c1-admin-dataset-rail-leak.png`), 거기서 대시보드를 누르면 아무 말 없이 운영 현황으로 튕긴다(`c2-denied-silent.png`). 서비스 관리 다섯 쪽은 원본 게시판을 정돈한 업무 시스템이고, 흰 마스트헤드·사용자 공지 띠·Family Site 푸터가 직원 사이트와 같다. 동작은 성실하다 — 컨트롤 161개 전수 통과, 콘솔 오류 0, 법전 위반 0. 그러나 관리자가 이 화면을 여는 이유인 **결재 숫자가 상수**이고(`admin-home.js:46-50`), **관리한 공지가 사용자에게 닿지 않으며**(두 벌 저장소), 지도·영상·AI 결과가 살아 움직이는 순간은 지도 속성 관리의 MapLibre 미리보기 한 장뿐이다. GeoAI 플랫폼의 **관제실**이 아니라 **게시판 관리자 콘솔**로 읽힌다. 발주자가 여러 번 거부한 '딱딱한 업무 시스템 목업' 문법 그대로다.

- 실측 감사 판정(구현 68% · 몰입 3/10)에 동의한다. 여기에 감사가 놓친 P1 하나(A15 레일 누출)를 더한다.

## 2. UX 문제 (실측 감사 A1–A14 대조 + 추가)

감사 항목은 모두 재확인했다. 우선순위를 **사용자 여정** 순으로 다시 세운다.

1. **[A15 · P1 · 신규] 관리자 레일이 데이터 관리에서 직원 레일로 되돌아간다.** `dataset.js:37` 이 `roles.js` 를 읽지 않고 제 `NAV` 를 그린다(`critique.json › dataset.rail` 12줄 vs `admin-home.rail` 9줄). 관리자 레일 여섯 줄 중 두 번째가 데이터 관리인데, 거기 들어가면 "완전히 다른 사이트"가 한 클릭 만에 무너진다. 거기서 대시보드·프로젝트를 누르면 `?denied=` 로 조용히 튕긴다(A10과 결합해 **왜 튕겼는지 모르는 미로**). 관문은 지키는데 레일이 거짓말을 하는 상태다.
2. **[A1 · P1] 결재 대기가 상수다.** 관리자의 첫 질문은 "오늘 내가 처리할 것"인데 2/1/6 이 처리해도 안 바뀐다. `pendingCounts()` 가 이미 있다. 발행 대기는 `publish-data` 저장소에서 읽어야 한다.
3. **[A3 · P1] 공지·FAQ 관리가 아무것도 바꾸지 못한다.** 관리자 공지 12건(`admin-data.js`)과 사용자 공지 8건(`support-data.js`)은 다른 우주다. 관리자 마스트에 뜨는 공지는 관리자가 관리하지 않는 공지이며, 누르면 관리자 레일에서 뺀 서비스 지원으로 간다(`65-admin-mast-notice-target.png`). 관리 화면의 존재 이유가 없다.
4. **[A2 · P1] 다른 사이트는 첫 화면 한 장.** `data-site=admin` 은 `admin-home.js:41` 에서만 켠다. 나머지 8쪽은 흰 마스트헤드·사용자 공지 띠·Family Site 푸터. 관리자 전용 URL·로그인 없음.
5. **[A4 · P1] 3단 위계를 관리할 자리가 없다.** 권한 선택지가 남원시청 다섯 역할뿐. `roles.js` 의 admin/staff/sales 와 `CAPS` 10개를 보거나 바꾸는 화면이 없고, 기관(테넌트) 패싯도 없다. 스펙(`2026-09-20-platform-roles.md`)이 세운 위계를 관리자 사이트가 모른다.
6. **[A5 · P1] 390px 여섯 쪽 전부 가로 넘침**(137–537px). 마스트 공지와 기준일 글자가 겹친다(`20-admin-users-390.png`).
7. **[A14 · P2 · 핵심] 운영 현황이 정적 숫자 격자다.** 배포본 7개 · 기관 3곳 · 긴급 1건이 **어디**인지 보이지 않는다. 법전 §4 유휴 요소(실데이터에 묶인 움직임 1개)도 없다. GeoAI 플랫폼 관제실이 지도 없이 서 있다.
8. **[A6 · P2] 레일 활성이 틀리고 아이콘이 겹친다.** 운영 현황에서 서비스 관리에 불이 켜짐(`active:'admin'`). 둘 다 `gear`. 여섯 줄이 위 2 / 아래 4로 갈라져 가운데 400px 비어 있다.
9. **[A7 · P2] 기준일 셋**(06.08 / 04.23 / 04.22) + 지도 속성 수정 일시만 벽시계. 한 사이트 안에서 시간이 세 갈래다.
10. **[A9 · P2] 카드 발행 승인 2 → 전체 목록.** 원본은 `?status=대기`. 대기 2건을 보러 갔는데 6건이 뜬다.
11. **[A11 · P2] 1920 빈 띠.** 위 표 참조.
12. **[A8 · P2] GPU 2,337 vs 2,517.** 추론만 / 추론+재학습. 표기 없음.
13. **[A12 · P3] 조치 숫자 색 불일치.** 운영 현황 결재 대기는 파랑, 사용자 관리 밴드는 빨강. 법전 §2 는 `가입 승인 대기 · 미답변 문의` 큰 숫자 = 경고색.
14. **[A13 · P3] admin caps 에 build/run/edit/request 잔존.**
15. **[A10 · P2] denied 안내 없음** — A15 와 함께 고친다.
