**다만 흐름으로 이어 보면 끊어진다.** 새로 만든 프로젝트는 라벨링 단계에서 막혀 더 나아가지 못한다. 프로젝트의 마지막 단계인 `카드 발행 요청`을 누르면, 프로젝트를 쓸 수 있는 유일한 역할(LX 직원)이 역할 관문에 걸려 목록으로 튕겨 나온다. 학습·분석·업로드는 누르면 상태가 멈춘 채 그대로 있고, 저장은 대부분 토스트만 띄운다.

## 5. 인터랙티브·몰입감 — 3.5 / 10 (냉정 평가)

**점수를 받은 것**
- 만들기에서 유형을 고르면 실제 판독 결과가 원본 위로 쓸려 덮이는 `clip-path` 스윕(`project.css:319-321`, `12`). 이 영역에서 유일하게 "보여 주는" 순간이다.
- 라벨링·분석 판의 MapLibre 실지도 + 실 GeoJSON. 도형을 누르면 선택, 옮기면 점선 고스트가 남는다(`85` `86`).
- 카드 역추적에서 분석 서비스 카드로 실제로 넘어가는 고리(`39`).

**점수를 잃은 것**
- 화면 대부분이 좌 격자 + 우 속성 판(LEDGER) 반복이다. 여섯 탭이 같은 문법이라 "작업실"이 아니라 "관리 화면"으로 읽힌다.
- 움직이는 것이 없다. 학습 곡선은 정지 SVG, 진행률은 멈춤, 워크플로우 노드는 정적 상자다. Roboflow·W&B급이라면 epoch가 흐르며 곡선이 그려지고, 노드 사이로 데이터가 흐르고, 검증 샘플이 넘어가야 한다.
- 8단계가 "파이프라인"으로 한눈에 보이지 않는다. 탭 여섯 개가 나란히 있을 뿐, 이 과제가 지금 어느 단계에 있고 다음에 무엇이 막혀 있는지 공간적으로 보여 주지 않는다.
- 라벨링 작업공간이 그리기 도구로서 가짜다(B8). 가장 손맛이 나야 할 곳이 가장 얕다.
- WebGL은 MapLibre 기본 렌더뿐이다. 3D·지형·결과 파티클·전후 스와이프 같은 연출이 없다.

## 6. 권고 (구현 투입 순서 · 난이도)

1. **[P0 · 소]** 발행 요청 고리를 직원 안에서 닫는다. 직원에게는 `ai-publish-create.html`(프로젝트 범위 요청 폼)을 `project` 메뉴 키로 열어 주거나, 배포 탭 안에 요청 이력 표(원본 7열)를 둔다. 요청은 관리자 발행 큐가 읽는 저장소(`publish-data.js`)에 쓴다. `shell-gate.js MENU` 와 `roles.js` 를 함께 고친다. 거부 시 `?denied=` 안내 한 줄.
2. **[P0 · 중]** 새 프로젝트 전 구간 통과. `labelingOf()` 가 `files` 에 들어온 영상을 `미작업` 행으로 돌려주고, 작업공간에서 저장하면 세션 저장에 라벨이 쌓이게 한다 → 데이터셋 → 학습 → 분석 → 배포까지 새 과제로 끝까지 도는 e2e 테스트를 추가한다.
3. **[P1 · 소]** 새 과제 상태를 정직하게: `mid` 를 물려주지 말고 `학습 결과 없음`, 클래스 0, 대표 이미지는 고른 영상에서 가져온다.
4. **[P1 · 중]** 시연 시뮬레이터 한 벌: 학습(epoch 틱 + 곡선이 그려짐), 분석(5단계 진행), 업로드(%)를 `requestAnimationFrame`/타이머로 굴리고 `견본·시연` 을 표기한다. 법전 §4 유휴 움직임 1개를 이것으로 채운다.
5. **[P1 · 중]** 분석 편집 저장을 실제 반영(세션 저장에 편집된 FeatureCollection 저장). 필지 표는 선택한 도형의 속성에서 생성한다(가짜 PARCELS 제거).
6. **[P1 · 상]** 라벨링 작업공간 그리기: 사각형 드래그, 폴리곤 꼭짓점 찍기(더블클릭 종료), 꼭짓점 편집, 키보드 단축키(1/2 클래스, Del, Ctrl+Z), 저장 영속화. Roboflow 비교를 이기는 자리다.
7. **[P1 · 중]** 개요 한 화면화: KPI를 히어로 위 오버레이로 올리고, 최근 학습·카드 역추적은 우측 판 탭으로 보낸다. 1920 KPI 잘림을 해결한다.
8. **[P1 · 상, 몰입]** "생산 라인" 첫 화면: 목록 위에 8단계 파이프라인 띠(과제별 현재 단계 · 막힌 곳 · 학습 대기열 · 발행 대기)와 능동 운영 신호(`ops.js actionsFor` — 임계 미달 배포본 → 재학습 제안), 기관 오류 신고 수신함을 둔다. two-tier §6 "양산" 과 production §1 "능동" 을 화면으로 보여 주는 자리다.
9. **[P2]** 토스트만 띄우는 버튼 정리(B7): 검색·삭제·다운로드는 실제 동작으로 바꾸고, 못 하는 것은 비활성 + `준비 중`. 모델 등록 표 열 폭(B9), 학습 날짜 열(B14), 🔒 이모지 → SVG(B15).
10. **[P2]** 390 반응형: 레일을 하단 탭바로, split을 세로로 쌓고, 툴바는 가로 스크롤 칩 레일로.
