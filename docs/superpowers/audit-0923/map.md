## 0. 한 줄 판정

**기능은 대부분 "진짜로 돈다"(실타일·실 GeoJSON·실측정·실집계). 그런데 1440×900 에서 지도가 화면의 절반도 못 가진다.** "한 화면에 다 넣는다" 규칙이 지도를 서류 사이에 끼워 넣었고, 정보 판을 여는 순간 지도는 270px 띠가 되고 아래 표는 글자가 세로로 한 자씩 선다(x22). 법전이 말한 "지도 혁신의 자리"가 아니라 **지도가 딸린 업무 양식**으로 읽힌다. 게다가 내려받기 3곳은 여전히 "시작되었습니다" 라고 **말만 하고 파일이 떨어지지 않는다** — 9/21 발주자 지적("말만 하던 것")이 이 영역에는 적용되지 않았다.

- 완성도 추정: **68 %** (원본 인벤토리 §6 + 9/20 스펙 대비)
- 몰입감·인터랙티브 점수: **4 / 10** (표류 예측만 5–6 수준, XI맵 본판은 3–4)

## 4. 발견 (심각도순)

### P0

**M-01 · 정보 판을 열면 1440×900 에서 화면이 무너진다** — broken/ux
- 재현: `ximap.html` → 결과 켜기 → 표 펼치기 → 행 클릭(= 가장 기본 흐름).
- 결과(x22): 좌 설정 판 690px + 우 정보 판 410px 사이에 지도 **약 270px**. 하단 표 머리·탭·빵부스러기가 **한 글자씩 세로로 쌓이고**(`공/간/정/보`, `농지/이용·/불법/건축/물`), 탭 문구가 정보 판의 `조치 상태 변경` 위에 **겹쳐 그려지고**, `통계 자세히 보기`·`보고서 발급` 단추가 쪽넘김 위에 겹친다.
- 원인: `map.css:540-554` 가 세로 ≤1000px 이면 좌 판을 `clamp(372px, 100vw-rail-600px, 690px)` 두 칸으로 편다. 서랍을 열 때만 좌 판을 접고(`map.js:154-157 fitLeft`) **정보 판(side='info')에선 접지 않는다**.
- 1920×1080 에서는 멀쩡하다(v-ximap-1920x1080) — 즉 **발주자·직원이 가장 많이 쓰는 1440·1280 노트북에서만 깨진다.**

### P1

**M-02 · 1440×900 기본 상태에서도 지도가 화면의 47 %** — ux/system
- x01·x05: 좌 판 두 칸(690px)이 지도(680px)와 같은 폭. 하단 표를 펴면 지도 높이 370px·표는 **1행만 보임**(x18: `총 2,098건 중 1~10행` 인데 한 줄), 열 `부번`이 잘림, 탭 `공간 정보`가 두 줄로 접힌다.
- 시점 스트립이 범례와 번호 표식을 덮는다(x18 번호 6·7이 스트립 위, x20 읍면동 라벨 `대강면`·`송동면`이 스트립과 겹침).
- 1280×800 은 가로 넘침 **68px**(v-ximap-1280x800) + 번호 표식이 범례 위에 무더기로 겹침.
- 법전 §6 "XI맵 = 지도 혁신의 자리". 지금 배치는 목록·표가 주인이고 지도가 곁다리다.

**M-03 · 내려받기 3곳이 파일을 주지 않는다** — data-honesty/broken
- 보안 서약까지 다 채우고 `다운로드 실행` → 토스트 "다운로드가 시작되었습니다" → Playwright `download` 이벤트 **0건**(result.json `downloads`: 3/3 null).
- `map.js:1000`, `map-stats.js:139`, `map-report.js:170` 모두 `onDone` 에서 `say()` 만 부른다. 같은 저장소의 `download.js`(9/21 "실제로 파일이 떨어진다")를 쓰지 않는다. 결과 GeoJSON 은 저장소에 **실제로 있다**(`map-data.js` `l.geojson`) — 붙이기만 하면 된다.
- 발주자 9/21: "눌렀는데 아무것도 안 떨어지는 버튼" — 이 영역엔 반영 안 됨.

**M-04 · 통계 `기준` 바꾸고 `통계 보기` → 다시 계산했다고 거짓말** — data-honesty
- s04: `남원시 3권역 · 농지활용 분석 [시연]` 선택 → `통계 보기` → 토스트 "기준 · 남원시 3권역 … 으로 통계를 다시 계산했습니다". 수치는 1순위 실 결과 그대로(315.9 ha 체계). `basis` 는 표시에만 쓰이고 집계(`map-stats.js:73-79 rowsOf`)는 늘 `ctxRef.geo`.
- 시드 기준에는 자료가 없으니 "이 기준은 시연 목록이라 집계할 결과가 없습니다"로 막아야 콘티 원칙(§5)에 맞다.

**M-05 · 겹쳐보기에서 비교 판이 자동으로 열려 지도가 270px** — ux
- x28·x29: 겹쳐보기 진입 즉시 좌 판(690) + 비교 결과 판(410) → 스와이프 대상 지도 270px. 좌/우 시점 표지(`기준 2025.04 1.08 cm` / `비교 대상`)가 서로 겹쳐 읽을 수 없고, 범례가 스와이프 선 위에 올라탄다. 아래 띠 `비교 대 / 상 ·` 세로 접힘. 스와이프 자체는 동작(드래그·←→ 키).

**M-06 · 원본 인벤토리·9/20 스펙 대비 빠진 것** — missing-feature
- **오류 신고(피드백 고리)** 없음 — two-tier §3 "지도 결과 → 오류 신고 → 프로젝트". 탐지 정보 판(`map.js:820-857`)에 오탐·누락 신고 단추가 없다. 이원화의 "AI 연결 고리" 중 기관→LX 방향이 지도에 **없다**.
- 원본 `전체 지우기`(결과 레이어 일괄 끄기) 없음.
- 원본 탐지 결과 표 3종(지목별/필지별/**도로지점별**) 중 필지별만. `심각도` 열 없음(도로 결과 레이어 자체가 없음 — `준비 중 11`).
- `?task=` 딥링크(원본 7과제 키) 미지원 — `?result=` 로 대체. 외부(분석 서비스·포털)에서 과제 키로 들어오는 길이 끊김.
- 지역 검색 시도/시군구 선택이 **옵션 1개짜리 고정 select**(`map.js:704-705`) — 지역 설정 "저장" 없음.
- 글로벌 분기(roles §3): 지도에서 지자체/글로벌 분기 표시·전환 없음. `scopeCtx` 는 있으나 글로벌 레이어가 0이라 화면에 나타날 일이 없다(구조만 있음 — 스펙이 요구한 "필터·배지 동작"은 지도에 없음).

## 7. 사용자 품질 기준 대비 — 몰입감 4 / 10

잘 된 것(진짜 동작):
- MapLibre 실지도 + V-World 위성 + 남원 4시점 LX 정사영상 실타일 + 실 GeoJSON 2,098 필지. 창 안 건수 HUD가 지도 이동에 따라 **실시간 재계산**(`GL.inView`).
- 측정(거리 13.93 km 실측, x10)·면적·반경·그리기·관심 구역(2,270.4 ha 저장, x12)이 실제로 돈다.
- 표 행 ↔ 판 위 번호 ↔ 정보 판 콜아웃이 서로 따라간다. 읍면동 5분위 코로플레스가 실집계로 칠해진다(s01 — 이 영역에서 가장 보기 좋은 한 장).
- 표류 예측: RK4 이류·유선 750개 애니메이션·재생/배속/스크럽 — 유일하게 "살아 있는" 화면.

냉정한 이유:
- **첫 인상이 목록이다.** 1440 에서 왼쪽 절반이 카드 목록·체크박스, 오른쪽이 지도. Awwwards 급은 지도가 화면을 먹고 UI가 그 위에 떠야 한다.
- 모션이 없다. 레이어를 켜도 폴리곤이 그냥 나타난다(법전 §4의 clip-path 현상·앰버 380ms 탐지 순간 미사용). 4시점 정사영상이 있는데 **타임라인 스크럽(시점을 끌어 넘기는 연속 전환)이 없고** 썸네일 클릭뿐.
- 3D·지형·기울기 없음(`dragRotate:false`, `pitchWithRotate:false` — `map-gl.js`). 저장소엔 DEM 소스(`js/sources.js:5`)까지 있는데 안 쓴다.
- 정보 판·비교 판을 열면 지도가 오히려 줄어든다(M-01·M-05) — 몰입의 반대 방향.
- 표류 예측은 움직이지만 배경이 무채 positron 에 영문 라벨, 입자가 몇 덩어리로 뭉쳐 보여 "과학 시각화" 로는 약하다(d07).

## 8. 권고(우선순위)

1. **판 배치 원칙 뒤집기(M-01·02·05)** — 지도를 전폭 PLATE-FULL 로 깔고 좌 목록·하단 표·우 정보 판을 지도 위 떠 있는 판(흰 바탕, 그림자 없이 헤어라인)으로. 판이 열려도 지도 캔버스 크기는 불변. 최소한 즉시: 정보 판·비교 판이 열릴 때 좌 판을 서랍과 똑같이 접는다(`fitLeft` 조건 확장).
2. **내려받기 3곳을 `download.js` 로(M-03)** — 결과 GeoJSON 원본 그대로, 통계·보고서는 CSV(BOM) 실집계로.
3. **가짜 동작 제거(M-04·07·12)** — 시드 기준은 선택 불가 + 사유 한 줄, 기간 칩은 실제 거르기 또는 제거, 비교 모드 도구는 A 판 도구를 공유, 레이어 탭 12줄은 실자료 연결 전까지 `시연 · 지도에 안 올라감` 명시.
4. **피드백 고리(M-06)** — 탐지 정보 판에 `오탐 신고 / 누락 신고` → 프로젝트 라벨링 큐로 가는 한 단추(two-tier §3).
5. **관문·테스트(M-R1·R2)** — `shell-gate.js` MENU 에 두 페이지 추가, `proto-map.spec.mjs` 에 `lx_role=staff`.
6. **몰입 한 수** — 4시점 정사영상 **타임라인 스크럽 + 스와이프**를 XI맵의 대표 인터랙션으로, 탐지 폴리곤 현상 모션(1s), 남원 DEM hillshade/3D 기울기 토글. 표류 예측은 로컬 배경 스타일 + 한글 라벨 + 확산 난수 시드 고정.
7. **폐쇄망(M-10)** — 로컬 정사영상/캐시 타일을 기본 배경으로 두고, 외부 배경은 선택지로.
