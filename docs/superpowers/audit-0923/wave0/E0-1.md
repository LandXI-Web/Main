## 목표

네 주체(LX 관리자 · 직원 · 영업 · 기관)가 서로의 화면으로 새지 않는다. **Q1 확정: 기관 계정은 완전 별도** — `roles.js` 에 넣지 않는다. 기관 세션은 LX 셸 화면에 절대 들어가지 못하고, LX 세션(관리자 포함)은 기관 작업공간에 들어가지 못한다. 로그아웃은 그쪽 키를 전부 지운다. 모든 `?denied=` 튕김에 한 줄 안내(S8)가 붙는다.

### 5. `shell.js`
- `export function signOut(base = '')`: 세 키 전부 제거 → 착지 = 기관 세션이었으면 `TENANTS` 의 `login`, LX 면 `login.html`(admin 도 W0 는 `login.html` — E1-6 뒤 `admin-login.html`). 기존 `logout()` 은 `signOut` 의 별칭으로 남긴다(다른 파일이 import 중: `mypage.js:5,318`).
- `export const TENANT = (() => JSON.parse(localStorage.lx_tenant_session) 안전 파싱 || null)()`.
- `gate()`: §7.2 판정표 미러(shell-gate 를 빠뜨린 화면의 안전망). 기관 세션이면 LX 화면 진입 불가 → 기관 홈 `?denied=`.
- `mountShell` 끝: ① `?denied=` 읽어 `say()` 한 줄 — 문구 규약: LX 셸 `${화면명} 화면은 ${허용 역할명 나열} 전용입니다 — 지금은 ${현재 역할명}으로 들어와 있습니다`(화면명 = `NAV.find(n => n.key === SCREEN_MENU[file]).name`, 허용 역할 = `ROLES.filter(r => sees(r.id, key)).map(r => r.name)`; 표에 없는 화면이면 `${file} 화면에는 들어갈 수 없습니다`) → `history.replaceState` 로 `denied` 쿼리 제거 ② `if (ROLE === 'admin') document.documentElement.dataset.site = 'admin'`(CSS 는 E1-6) ③ `applyCustomSymbol()` 호출(`import { applyCustomSymbol } from './account-brand.js'` — 읽기 import) ④ `#mast-asof` 는 지금처럼 `AS_OF` 렌더(E1-4 가 `prov()` 를 붙일 자리 — `id` 유지).
- `FAMILY`: 기관 항목 href 를 **로그인 문**으로(`portal-login-namwon.html` · `portal-login-gwangju-jeonnam.html`). `kind: '지자체 · 로그인'`.
- 기관 세션에서 `mountShell` 이 불리는 화면은 포털만(portal-ui.js). 그때 레일은 `TENANTS.menus` 로 세운다: `mountShell({ ..., tenant: TENANT })` 옵션을 받아 `withRail` 분기에서 LX `NAV` 대신 `[{key:'portal', name:'내 서비스', href: TENANTS.home, icon:'stack'}]` + 로그아웃 버튼만(MY 없음 — 기관 MY 는 E1-2 포털판). `rail-mark` 는 portal-ui.js 가 지금처럼 CI 로 바꾼다.

### 6. `portal-login.js` (+ `portal-login.css`)
- 제출 성공 = 기관 signIn: `localStorage.setItem('lx_tenant_session', JSON.stringify({ tenant: TENANT, at: new Date().toISOString() }))` + `removeItem('lx_logged_in')` + `removeItem('lx_role')`. 착지 `nextOf()` 유지(같은 폴더 html 만).
- `?denied=` 가 있으면 폼 위 안내 한 줄(잉크 글자 · 헤어라인 · 라운드 0): `기관 작업공간은 기관 계정으로만 들어갑니다 — LX 계정은 로그아웃 뒤 기관 아이디로 로그인하세요`. LX 세션을 **자동으로 지우지 않는다**(사용자가 로그인하면 R-S1 이 지운다).
- 이미 같은 기관 세션이면 바로 `nextOf()`(관문이 잠깐 보낸 것).

### 7. `portal-ui.js`
- `mountShell({ ..., tenant: TENANT })` 로 기관 레일(위 5) · 기존 `:79-86` 레일 거르기 코드 삭제 · `svcNav` 개조 코드 삭제.
- `?denied=` 도착 시 `say()`: `${file}은 LX 플랫폼 화면입니다 — 기관 계정은 내 서비스 작업공간에서 씁니다` 또는 다른 기관 화면이면 `${file}은 다른 기관의 작업공간입니다`. 그 뒤 `replaceState`.
- 로그아웃 = 셸 `signOut`(레일 버튼은 셸이 그린다 → 별도 코드 없음).
