## 단계별 할 일

1. **카드 높이**: `login.css` 의 `--lg-card-h` 고정값을 풀고 `min-height` + 콘텐츠 높이로. 계정 종류 3행(`fieldset.lg-role label` 세 줄) → **한 줄 세그먼트**(라디오 3칸 · 선택 = 코너 브래킷 12px · 라운드 0 · 채움 없음). 1280×720 에서 `.lg-card` 아래 `.lg-foot` 이 뷰포트 안에 들어오고 겹치지 않는다. 안 들어오면 카드가 아니라 **필름 판 비율**을 줄인다(폼 글자 크기는 법전 바닥 14 유지 · 줄이지 않는다).
2. **역할 캡션**: 라디오가 바뀌면 좌측 필름 판 하단 캡션에 `ROLES[role].what` 과 CAPS 이름 3–4개가 60ms 스태거로 들어온다(`import { ROLES, CAPS } from '../assets/data/roles.js'`). reduced-motion 이면 즉시.
3. **버튼**: `.lg-submit` 채운 파랑 → **잉크 채움**(`#010102` 바탕 · 흰 글자). 호버 180ms 물리 반응(4px 이동 또는 브래킷). 액센트는 워드마크 밑줄 · 찾기 링크 2 · 포커스 룰만 → 정지 상태 ≤ 3곳.
4. **워드마크**: `login.html:20` `href="dive.html"` → `href="scrub/index.html"`.
5. **세션 계약**(`login.js`): 성공 시 `localStorage.setItem('lx_logged_in','1')` · `setItem('lx_role', role)` · **`removeItem('lx_tenant_session')`**. `?logout` 처리: `lx_logged_in` · `lx_role` · `lx_tenant_session` 세 개 `removeItem`. `HOME` 표는 `roles.js homeOf(role)` 를 import 해 쓴다(중복 표 제거). 현재 계정 안내(`lg-role-now`)는 유지 — 기관 세션이면 `지금 ${기관명} 계정으로 들어와 있습니다 — LX 계정으로 로그인하면 기관 세션은 끝납니다`(`portal.js tenantById`).
6. **정책 링크**: `[data-policy]` 는 지금처럼 `preventDefault` 유지(정책 화면 `site/policy.html` 은 E1-1). 없는 페이지로 링크하지 않는다.
7. **390**: 카드 1열 스택 · 필름 판 위 · 가로 넘침 0.
8. **테스트**(`proto-login.spec.mjs`): `boot` 는 세션 없이 여는 화면이라 그대로. `:224` 액센트 기대값 갱신(≤3 · 버튼 배경 = 잉크) · `:337` 성공 목적지 = 역할별 `HOME`(라디오 3벌 각 1건) · 신규: 4폭 `boundingBox` 검사(`#lgSubmit.bottom <= viewport.height` · `.lg-card` ∩ `.lg-foot` = 0) · `?logout` 세 키 null · 기관 세션 심고 로그인 → `lx_tenant_session` null.
