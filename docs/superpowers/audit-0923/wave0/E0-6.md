## 단계별 할 일

1. **셸 이관**: `dashboard.html` 의 `<aside id="rail">` · `<header id="mast">` · 인라인 관문(`:5-12` — `shell-gate.js` 는 남긴다) · 자체 푸터 마크업 삭제 → `<main id="main">` 안에 본문만. `dashboard.js` 에서 `import { mountShell, say, openModal, AS_OF, esc, nf, ymd } from './shell.js'` · `mountShell({ active: 'dashboard', title: '대시보드', subtitle: '…', asOf: AS_OF, demo: true })`. `db-data.js` 의 `NAV` · `NAV_FOOT` · `NAV_MY` · `RAIL_TO` · `RAIL_GO` · `logout()` · `$('#rail')` 핸들러 · 자체 `say` · MY 플라이아웃 코드 삭제(셸이 그린다). `NOTICE` · `T1` 은 셸 `NOTICE` · `AS_OF` 와 값이 같은지 확인하고 셸 것을 쓴다(값이 다르면 결과 문서에 요청).
2. **직원 화면으로(D-2)**: 제목 `대시보드`(`<title>대시보드 — Land-XI</title>`). 화면에서 제거: 승인 KPI 3(`카드 발행 승인 대기` · `가입 승인 대기` · `미답변 문의`) · EVIDENCE-PAIR 승인 목록 · 관리 바로가기 타일 4. 데이터(`DASH.queue` · `ADMIN_TILES` · `KPI` 배열의 act 항목)는 **`db-data.js` 에 남기고 렌더만 하지 않는다**(E1-6 이 운영 현황에 다시 세운다). 남는 KPI 2(정보) + 백본 모델 카드 + 판 + 운영 지표 탭 + 공지 스트립. 빈 띠 80px 초과 금지 — 뺀 자리는 **판을 키운다**(법전 §6 254→420).
3. **링크 전수(D-3)**: 남은 모든 `a[href]` · 클릭 핸들러가 실제 목적지로. 제자리(`dashboard.html?…`) 0 · staff 가 못 가는 화면(publish · admin · produce) 링크 0. 판 셀 클릭 → `ximap.html?result=<resultId>`(E0-5 수신 · `db-cells.js` 의 셀 → 결과 id 매핑을 `results.js` 로) — `?cell=` · `&mode=res` 제거.
4. **D-4 · D-6**: 관리 타일이 빠지므로 `dashboard.css:328-333` 절대 배치 규칙 삭제. 1100px 아래 H1 과 KPI 겹침 제거(KPI 밴드 2열 → 1열). 390 은 가로 넘침 0 까지만(하단 탭바는 E3-2).
5. **D-10 · D-11**: MY 플라이아웃 · Family Site · 전화번호는 셸 것을 쓰므로 자체 코드 삭제로 해소 — 스펙에서 Esc 닫힘 · Family 링크 200 단언.
6. **`dashboard-128/` 삭제**: 폴더 전체(`dashboard.css` `dashboard.html` `dashboard.js` `db-charts.js` `db-data.js` `db-plate.js` `proto-dashboard-128.spec.mjs.txt`). 저장소 어디서도 링크하지 않음을 `grep -rn "dashboard-128" landxi tests docs/superpowers/specs` 로 확인(감사 문서의 언급은 무방).
