## 단계별 할 일

1. **M-01 · M-05**: `fitLeft()` 조건을 `leftPinned` 아니면 `drawerOpen() || S.side === 'info' || S.mode !== 'basic'` 일 때 `S.left = 'off'` 로. 정보 판이 닫히면(`side-x`) 좌 판은 사용자가 접기 전 상태로 복귀(`leftPinned` 존중). 겹쳐보기 진입 시 비교 판 자동 열림 제거 — 대신 비교 판 헤더에 `변화 결과 보기 ›` 버튼으로 연다. 하단 표 탭 4개가 세로로 서는 것(`x22`)은 최소 폭 `min-width` + `white-space:nowrap` 로 막고, 좁으면 탭 라벨 대신 아이콘+툴팁이 아니라 **가로 스크롤**(글자 축소 금지).
2. **M-03 내려받기 3곳**: `download.js` 에 `export function downloadCSV(filename, header, rows)`(`﻿` BOM · `\r\n` · 쉼표 이스케이프 · `text/csv;charset=utf-8`). ① 내보내기(`map.js doExport onDone`) → 켜진 결과마다 `downloadGeoJSON(l.title, l.geojson 경로, geo.get(l.id))` ② 통계 엑셀(`map-stats.js:139`) → `rowsOf()` 를 CSV 로(읍면동 · 클래스별 건수 · 면적) ③ 보고서 엑셀(`map-report.js:170`) → 읍면동 × 클래스 집계 CSV. 토스트는 사실만(`${n}개 파일이 내려갔습니다`).
3. **M-04 정직화**: 시연 기준 2줄(`남원시 3권역` 등 자료 없는 기준)은 `select option[disabled]` + 라벨 끝 `· 시연 · 집계 자료 없음`. '통계 보기' 토스트에 '다시 계산' 문구 제거 → `기준 · ${basis.title}` 사실만. 기간 칩 4×2 · 실행자 · 기준일 · 발급 일자 거르개는 `analyzedAt` 으로 **실제로 거르거나**(결과 1건이라 거르면 0건이 되는 자리는) DOM 에서 제거 — 말만 하는 컨트롤 0.
4. **비교 띠 · 표**: `renderBands` · `renderCompareSide` 의 상수(`2,098` 는 2025.06 결과 수인데 2025.04 띠에 붙음 · `0.62 km²` · `드론`) → `D.EPOCHS` 실값(`gsdCm` · `bounds` 로 km² 계산 · `IMAGERY.kind`) 또는 결과가 없는 시점은 `—`.
5. **비교 도구 14개**: `renderCompareOverlays` 의 `tools(side)` 버튼에 `data-tool` 을 붙이고 A 판 `TOOLS` 핸들러를 공유(측정 · 그리기 · 배경 · 검색 · 관심 구역 · LX 레이어). 못 잇는 도구는 `disabled` + `title='준비 중 · B 판 도구 미연결'` 이 아니라 DOM 제거(빈 버튼 0).
6. **레이어 탭 12줄**: 실자료 없는 리프는 라벨 옆 `<em class="tag">시연 · 지도 미연결</em>` + 체크박스 `disabled`. 실자료 있는 리프(결과 5)는 체크 시 지도에 실제로 켜진다(이미 결과 체크와 같은 경로면 재사용).
7. **`?result=<id>` 수신**(C-23 · D-5): `readUrl` 에 `result` 가 오면 `S.on` 에 그 id 를 더하고 `fit(A, layer.bbox, 900ms)` → `?on=` 으로 정규화해 `replaceState`. `?cell=` 은 받지 않는다(E0-6 이 `?result=` 로 보낸다).
8. **발급 폼**: `syncIssue` 가 필드를 채우면 오류 문구를 지운다 · 요청자 = `role.name`(`shell.js role`) · 접수 시각 = `AS_OF`(벽시계 금지).
9. **테스트**(`proto-map.spec.mjs` 71건): `boot` → `bootAs(page, url, 'staff', props ? {'lx-map-props': JSON.stringify(props)} : {'lx-map-props': null})`. 추가 5건: ① 1440×900 결과 켜기 → 표 펼치기 → 행 클릭 → `#map-a` 캔버스 면적 / `#mw` 면적 ≥ 0.6 · 하단 탭 `getBoundingClientRect().height < width` ② 겹쳐보기 진입 → A 캔버스 ≥ 0.45 · 비교 판 자동 열림 0 ③ 내보내기 · 통계 CSV · 보고서 CSV 각 `download` 1건(파일명 기록) ④ `ximap.html?result=namwon-farmland-2025` → 체크됨 + 줌 변화 ⑤ 시연 기준 `option[disabled]` 2 · '다시 계산' 텍스트 0.
10. **재촬영**: `shots/audit-0923/map/audit.mjs` · `critique.mjs` 를 `shots/w0/E0-5/` 로 복사 · 역할 심어 실행 → `x22` · `x28` · `crit-05-info-1440` 동명 파일. 추가 `dl-01-export.png` · `dl-02-stats-csv.png` · `dl-03-report-csv.png`.
