## 1. 시스템 개편 — AI 결과 표현 공통 규칙 (실제 서비스 화면)

적용 범위 = 결과를 그리는 공통 함수 한 곳(`landxi/xi/fx/arrive.js` `farPaint` · `addResultLayers`)이라 XI맵 · 기관 지도 서비스(`xi-clean`) · 전국 결과(`national.js` · `board.js`)가 한 번에 바뀐다. `lx-map/app.js` 는 자기 색표(`CLS_COLOR`)를 쓰므로 이번엔 손대지 않는다(시간 남으면 §1-E).

### 1-A. 분류색 면 채움 (필수)

1. 새 파일 `landxi/xi/fx/result-colors.js` — 지도 결과 분류색 **한 표**. 영농 네 묶음은 아래 새 색(A안), 나머지 분류는 서버 `server/landxi_api/card_cover.py` 33~42행 `COLOR` 표 값 그대로(주석: "영농 4색은 11-02 PM 시안 A안 · 나머지는 서버 card_cover.py COLOR 와 같은 값"). `export const CLS_COLOR`, `export const clsColorExpr = (fallback='#15C39A') => ['match', ['to-string', ['get','cls']], ...pairs, fallback]`.

   **영농 결과 색 — A안(구현) · B안(색표 값만 바꾸면 됨)**

   | 묶음 | 데이터 `cls` | A안(권장) | B안 | 뜻 |
   |---|---|---|---|---|
   | 경작 | 경작지 · 경작 | **`#15C39A`** 청록 | `#7CE86B` 연두 | 'AI 결과' 청록 계열 — 법전 `--ai` 와 한 식구 |
   | 휴경 | 비경작지 · 휴경 | **`#FF8A3D`** 주황 | `#FFB020` 황색 | 경작의 반대색 — 색약에도 구분 |
   | 시설 | 비닐하우스 · 비닐하우스_단동 · 비닐하우스_다동 | **`#FFD23F`** 노랑 | `#4DA3FF` 하늘 | 작은 객체 — 밝은 노랑이 위성 위에서 가장 잘 섬 |
   | 전용 의심 | 건물 · 건축물 · 주차장 · 포장 확대 · 신축(농지 결과 안에서만) | **`#FF4D6D`** 분홍빨강 | `#FF4D6D` | 조치가 필요한 것 = 붉은 계열 하나 |

   - 표현 규칙(네 묶음 공통): 채움 **0.50**(가까이) · 분류색 선 1.4px · **흰 바깥선 2.4px**(필지끼리 갈라 보이게) · 휴경은 선 점선 유지(`farmland` 규칙 `[3,2]`). 빛 테두리(글로우) 는 **쓰지 않는다**(시안 4번째 칸 — 더 또렷해지지 않고 층만 늘어남).
   - **바탕 영상 채도 낮춤**: 'AI 분석' 층이 켜져 있는 동안 영상(raster) 층 `raster-saturation -0.35`(끄면 0 · `applyLayers()` 에서 함께). 결과 색이 바탕보다 먼저 읽히게 하는 장치 — 시안 2·3번째 칸이 이것. 기관이 원본을 봐야 할 땐 'AI 분석' 을 끄면 원래 채도.
   - 서버 카드 대표 그림(초록 `#2E9E5B` · 주황 `#E8590C`)과 지도 색이 달라진다 — 서버 수정 금지라 이번엔 두고 보고에 "카드 그림 색을 A안으로 맞추기(서버 card_cover.py FARM_G · FARM_F)" 를 다음 일로 올린다.
2. `arrive.js` `farPaint(kind)`:
   - `kind === 'result'`(한 색 `o.color` 를 주지 않았을 때) → `fillColor` · `lineColor` = `clsColorExpr()`. `haloNear` 는 흰색 `rgba(255,255,255,.95)` 로(분류색 위 흰 바깥선 — 영상 위 대비).
   - 가까운 줌 채움 진하기(`nearDef.fill`): 큰 면(경작지 · 비경작지 등 `LARGE_CLS`) **0.50**, 작은 객체(비닐하우스 · 건물 · 해양쓰레기 …) **0.55**. 호버 0.9 그대로. 지금 값 0.18 은 폐기(원칙 267 '멀리' 값 0.7~0.8 은 그대로).
   - 테두리: 큰 면 — 분류색 선 1.4 + 흰 바깥선 2.4 / 작은 객체 — 분류색 1.6 + 흰 바깥선 3(지금 `haloW` 규칙 유지, 색만 흰색).
   - `kind === 'landcover'` 는 전국 토지피복 — 색을 `CLS_COLOR` 로 맞춘다(경작지 청록 · 비닐하우스 노랑 · 건물 분홍빨강이 아니라 **건물은 서버 표 파랑 `#3182F6`** — 토지피복에서 건물은 '전용 의심' 이 아니다). `national.js` `NCOLOR` 와 `board.js` `NAMED` 는 `result-colors.js` 에서 import 로 바꿔 세 곳이 한 표. '전용 의심' 붉은색은 **경작·휴경 결과 세트 안의 건물 · 주차장 · 포장 확대 · 신축에만**(세트 이름 또는 `style` 로 판단 · 없으면 서버 표 색).
   - 경작·휴경 세트를 서비스로 골랐을 때(`?service=card-farm` · 목록에서 고름) 다른 결과 세트가 함께 켜지는 문제(§0 마지막 줄)는 **이번엔 고치지 않는다** — 녹화에서만 끈다. 코드 위치만 보고에 적는다(`xi-clean/app.js` 1318행 근처 `S.resOn`).
3. 사람이 고른 색(`kit/colors.js` `paintLayers`) 은 그대로 우선 — 바꾸지 않는다.
4. 확인: `https://namwon.land-xi.dev/landxi/v3/xi-clean/?region=52190&service=card-farm` 로그인 → 층 판에서 경작·휴경 세트만 켜고 z13 · z15 · z17 캡처 3장. 경작 청록 면 · 휴경 주황 면 · 흰 테두리가 보이고 바탕이 차분해져야 함. 층 판(`층` 단추) 클래스 점 색이 지도와 같아야 함. 'AI 분석' 끄면 바탕 채도가 원래로. 콘솔 오류 0. 시안 `fable/sian-farm-colors.jpg` A안 칸과 나란히 두고 같은 느낌인지 눈으로 대조.

## 4. 부드럽게 찍는 법 (필수)

### 4-A. 지도 장면(3 · 4 · 5 · 장면 1–2 지도판) = 결정론 프레임
- 원칙: **프레임 수 = 초 × 30**. 프레임마다 ① 카메라를 `jumpTo`(t 의 순수 함수 · easeInOut) ② `map.loaded() && map.areTilesLoaded()` 대기(최대 8초) ③ `requestAnimationFrame` 두 번 ④ 오버레이 DOM(괄호 · 손잡이) 위치 못박기 ⑤ `page.screenshot({ type:'jpeg', quality:93 })`. 이것이 `tools/film/frames.mjs` 가 하는 일 — 녹화 스크립트는 `work/cap-*.mjs` 의 루프 N 을 `초×30` 으로 바꾸고 `ready()` 를 반드시 기다린다(지금은 `.catch(()=>{})` 로 넘어가 흐린 타일이 들어갔음 — 8초 넘으면 그 프레임은 **앞 프레임 복사** 로 메우고 횟수를 로그).
- 미리 한 번 같은 길을 걸어 타일을 받아 둔다(지금 방식 유지).
- 조립: `-framerate 30 -i z%04d.jpg` 로 **그대로 30fps** — `framerate=` · `minterpolate` 필터 금지(겹침의 원인).
- 비용: 프레임 0.3~0.5초 → 장면 4(14초 420장) ≈ 3분 · 장면 5 ≈ 3분 · 장면 3(480장) ≈ 4분 · 지도판 22초(660장) ≈ 6분.

### 4-C. 스틸 장면(4 첫머리 · 7) = 느린 확대

### 4-D. 부드러움 확인(넘기기 전)
