## 3. 담당자(산림청 · 시군 산림부서)가 실제로 원하는 것 — 조사

- **지정 절차:** 산림청 기초조사(우선지역) → 실태조사(현장 점수 70점 + 사면 안정해석 · 토석류 시뮬레이션) → 열람 공고 → 지정위원회 심의 → 고시. 2016년 2월 전국 18,444곳. 경주시 2026년 304곳 실태조사 사례. 감사원 지적: 인가 50m 안 산지가 기초조사 우선지역에서 빠짐.

- **위험 예측:** 산림청 산사태위험지도(9인자 통계 → 2026 AI 13인자 이상) · 산사태정보시스템 · 토양함수량 기반 대피 기준. **지형 · 토양 · 강우 모델이지 영상 변화탐지가 아니다** → 우리가 같은 것을 만들 이유가 없고 만들 수도 없다.
- **영상으로 하는 일(실제 있음):** 산림사범수사팀이 연도별 위성영상 + 드론 정사로 불법 산지전용 130건(2020) 적발. 즉 산림 부서가 영상 변화에서 원하는 것은 **훼손 · 전용 · 벌채 · 임도** 를 빠르게 찾는 것이다.
- **공개 자료로 비교 가능한가:** 산사태위험지도 1~5등급 = WMS(그림)만 · 전국 shp 없음 / 취약지역 = 시군 · 도별 표(고양 CSV 는 위경도 · 면적 · 등급 있음, 강원은 주소만) / 산사태 우려지역 API 좌표 없음 / **과거 산사태 발생 이력 API(산림청 15074816 · 무료)** = 정답 후보 / 고시 도면은 국유림관리소 열람 · 토지이용규제정보시스템(LURIS) 열람 → 면 경계는 기관 제공이 필요.

**결론:** 담당자에게 "산사태 위험"을 AI 영상으로 판정해 주겠다는 것은 그들의 체계(지형 · 강우)와 맞지 않는다. 그들이 영상에서 원하는 것은 ① 취약지역 **안과 둘레(인가 50m)** 에서 두 해 사이 **무엇이 바뀌었나**(벌채 · 절개 · 임도 · 건물 · 태양광 · 개간) ② 그 지구를 **가서 볼 순서**(바뀐 넓이 · 급경사 · 인가 가까움) ③ 과거 발생지 · 지정 등급과 한 화면.
