## 2. XI ChatGEO 통계 리포팅 화면 — 발표 17장 핵심
### 보여야 하는 화면 (한 화면)
- **XI맵 위에** 통계 리포팅 결과가 지도로 뜨고, 오른쪽(또는 아래)에 **ChatGEO 대화 내역**이 있는 화면. 즉 "말로 물으면 → 도구가 돌고 → 지도에 결과 층 · 통계 패널이 뜨고 → 보고서(한글 · 엑셀)가 나온다"가 **한 화면에서** 보여야 한다.
- 지도: 대상 구간 + 판정 층(지목미정리 · 점유의심 · 포장 밖 강조) + 변화 폴리곤 + 집계 패널(요약 수치 · 판정별 막대 · 용도별 · 미정리 연속 구간 · 점유의심 상위 필지)
- 대화: 사용자 질문 · 도구 호출 표시(도구명 · 소요 초) · 답변(수치는 도구 출력 그대로) · "보고서 만들기" 버튼 → 한글(hwpx) · 엑셀
- 이미 있는 **통계 보고서 틀(turn1_report_view)** 을 XI맵 안 패널로 올리면 됨. 새 디자인 금지 — 기존 XI맵 · ChatGEO 창 그대로.

### 고칠 것 (재실행 전)
1. 대상지 문맥: 질문에 구간 이름이 있으면 그 구간의 최신 결과(변화 · 이지목 · 점유의심)를 읽는다. 없으면 직전 프로젝트.
2. 이지목 결과가 있으면 "대장 없음" 응답 금지.
3. 전국 집계 조회 도구 1개(nation_summary · rank · idle 읽기, 재계산 없음).
4. 답변 결과를 **XI맵 층 + 통계 패널로 띄우는 동작** — 답변에 결과 층 ID가 붙고, 지도에 자동 표시.

### 질문 3개 (확정 구간 이름으로)
1. "○○ 구간 2019 이후 변화와 지목 불일치를 정리해 보고서로 만들어줘"
2. "이 구간에서 포장 밖(법면 · 잔여지)에 경작 · 건물이 있는 필지만 표로 뽑아줘"
3. "전국 고속국도 이지목 상위 시군구 5곳과 점유의심 면적을 요약해줘"

### 산출
- `chatgeo_sessions.json`: 턴별 사용자 문장 · 도구 호출(도구명 · 인자 · 초 · 결과 요약) · 답변 마크다운 · 표 데이터 · 결과 층 ID · 첨부 경로
