## 2. P3 — 2023 25cm 남원 도엽 → XYZ

1. `p3_index.py`: 전북비도시 1,609장의 TFW로 인덱스를 만들고, `namwon-emd.geojson`(39 법정동, make_valid 적용)의 합집합과 교차시켜 **159장**을 골랐다. 대상 폴더는 `35705·35706·35707·35709·35710·35711`이다.
2. 좌표계: TIF에 CRS 태그가 없다. TFW 원점(예: 35512060 → 106779, 309230)과 도엽번호의 경위도(35°N·125°E권 1:5만 12번 = 35.25–35.5N, 125.75–126E)를 대조해 **EPSG:5186(중부원점, FE 200000 / FN 600000)**으로 확정했다.
3. 비도시 커버 우려(ASSET-LEDGER §6)는 해소됐다. 159장이 남원 경계를 100% 덮고, 표본 도엽에 검정·흰색 채움이 없으며 시가지도 들어 있다. 도엽 크기는 9,504–9,552 × 11,520–11,544px로 조금씩 다르다.
4. 명령:
   ```
   gdalbuildvrt -addalpha -a_srs EPSG:5186 -input_file_list c01_namwon_list.txt namwon_ap25_2023.vrt
   gdal2tiles --xyz -z 10-18 --tiledriver=WEBP --webp-quality=82 --processes=48 -r average -w none --exclude namwon_ap25_2023.vrt tiles/namwon_ap25_2023
   ```
   베이스 z18은 5분 21초, 오버뷰까지 합치면 **6분 33초**다. 첫 시도는 `-addalpha` 없이 돌렸다가 도엽 바깥이 검게 칠해져서 다시 만들었다(QA 모자이크 `_work/qa_ap25_z12.jpg`).
5. 결과: z10 5 · z11 11 · z12 30 · z13 91 · z14 303 · z15 1,101 · z16 4,231 · z17 16,672 · z18 65,960 = **88,404타일, 946MB**. bounds [127.1667, 35.2905, 127.6831, 35.5769]. 도엽 사각 범위라서 남원 경계 바깥(곡성·순창·장수 쪽)도 조금 포함된다. 원본 0.25m는 z19급이지만 지시대로 z18까지만 만들었다.
