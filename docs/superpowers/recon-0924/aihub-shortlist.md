# AI Hub 실데이터 후보 목록 — Land-XI (recon-0924)

조사일: 2026-09-24 · 방법: AI Hub 데이터 페이지 열람과 웹 검색, `aihubshell -mode l` API로 파일 목록과 용량 조회(키 없이 가능). **데이터 다운로드는 하지 않았다.**

## 0. 먼저 알아둘 것

- **번호 체계가 두 가지다.** AI Hub 페이지 URL의 `dataSetSn`과 aihubshell의 `-datasetkey`는 **같은 번호**다. 반면 이 PC에 있는 "124/125/126/304/294"는 다운로드 폴더 이름 앞의 **일련번호**이고 datasetkey가 아니다. 파일 트리로 확인한 대응은 다음과 같다.
  - 124 토지피복(경상) = **641** · 125 토지피복(전라) = **642** · 126 토지피복(제주) = **643** · 304 토지피복지도 항공위성 이미지(수도권, 2022) = **71361** · 294 아산시 하천부지 점유현황 = **71387** → 이 다섯 개는 목록에서 뺐다.
- **"지리참조" 등급**(웹 지도에 올릴 수 있는가)
  - **A**: GeoTIFF나 좌표계(EPSG)가 명시돼 있다. 타일이나 래스터 단위로 V-World 위에 바로 정합할 수 있다.
  - **B**: 촬영 지점의 위경도만 메타데이터에 있다(지상 사진이나 경사 드론 사진). 지도에는 **점 마커**로만 올릴 수 있다.
  - **C**: 주소나 지역명만 있다. 지오코딩을 거쳐야 위치를 잡을 수 있다.
  - **D**: 좌표가 없고 이미지 픽셀 좌표뿐이다. 모델 학습에만 쓸 수 있다.
- 모든 후보에 공통으로 해당하는 사항: **내국인만 신청할 수 있고**, 데이터셋마다 웹에서 **다운로드 신청을 해서 승인을 받아야** aihubshell `-mode d`가 동작한다. 모든 후보에 **샘플(경량) 데이터가 있다**(웹 페이지의 샘플 버튼, 로그인 필요).
- 용량은 `aihubshell -mode l -datasetkey N`의 파일 크기 합계다. 파일별 표기가 반올림이라 합계는 근사치다.

## 3. aihubshell 사용 절차(Windows)

1. **사전 신청(웹)**: aihub.or.kr에 로그인하고 각 데이터셋 페이지에서 "다운로드" → 이용 목적 선택 → 약관 동의로 **승인 신청**한다(PC 웹에서만, 내국인만). `-mode d`는 이 승인이 끝난 데이터셋에만 동작한다. 목록 조회(`-mode l`)에는 키도 승인도 필요 없다.
2. **API 키**: aihub.or.kr > AI 허브 오픈 API 안내(https://www.aihub.or.kr/devsport/apishell/list.do)에서 **"API key 발급"** 버튼을 누르면 키가 회원 이메일로 온다. 이 키는 aihubshell과 AI 허브 MCP에서 쓴다.
3. **설치**: aihubshell은 **bash 스크립트**(v0.6, 2025-09-19)이고 curl·tar·find·sort -V·xargs를 쓴다. Windows에서는 **Git Bash**로 충분하다. 이 PC의 Git Bash에서 스크립트 수신과 목록 API 호출을 확인했다. WSL도 쓸 수 있다. PowerShell이나 cmd에서는 바로 실행할 수 없다.
   ```bash
   mkdir -p /e/aihub && cd /e/aihub
   curl -o aihubshell https://api.aihub.or.kr/api/aihubshell.do
   chmod +x aihubshell
   export LANG=ko_KR.UTF-8          # 한글 파일명과 트리 표시용
   export AIHUB_APIKEY='발급키'      # 이렇게 두면 -aihubapikey를 생략할 수 있다
   ```
4. **목록 조회**
   ```bash
   ./aihubshell -mode l | grep 토지             # 전체 데이터셋 [datasetkey, 이름]
   ./aihubshell -mode l -datasetkey 71712       # 파일 트리: 파일명 | 용량 | filekey
   ```
5. **부분 다운로드(filekey, 쉼표로 여러 개)**
   ```bash
   ./aihubshell -mode d -datasetkey 71712 -filekey 524323,524401,524400 -aihubapikey "$AIHUB_APIKEY"
   ```
   - **`-filekey`를 빼면 데이터셋 전체를 받는다**(수백 GB~TB). 반드시 넣어야 한다.
   - 실행한 폴더에 `download.tar`를 받은 뒤 자동으로 tar 해제 → `.part*` 병합 → tar 삭제 순으로 진행된다. 중단하면 `download.tar`가 지워진다(Ctrl+C trap).
   - 71594·71330·71751·556처럼 원천이 `TS.z01…TS.zip` **분할 zip**인 데이터셋은 모든 조각이 있어야 7-Zip으로 풀 수 있다. 부분 다운로드는 **라벨만** 의미가 있다.
6. **샘플**은 aihubshell 목록에 없고, 각 데이터셋 웹 페이지의 "샘플 데이터" 버튼으로 받는다(로그인 필요).
