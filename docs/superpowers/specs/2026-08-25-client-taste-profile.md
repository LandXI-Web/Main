## 2. 레퍼런스에서 읽히는 공통분모 (가설 → 벤치마크 확정 대기)
- **위성영상을 사진으로 다룬다** — planet, Vantor, all4land 히어로 전부 실영상 풀블리드. 벡터 지도는 오버레이일 뿐.
- **어두운 바닥 위 발광 데이터** — kepler(다크 베이스+네온 레이어), all4land(시안 필라멘트), vw-lab(3D 도시 발광). 밝은 B안과의 결합 = "서사 페이지는 밝은 아틀라스, 분석 뷰는 어두운 발광".
- **한 대의 연속 카메라** — 궤도→돌파→강하→착지. 페이지 전환이 아니라 카메라 이동.
- **탐지의 사건화** — all4land: 스캔 → 브래킷 → 노랑 DETECTED(2초만) → 카운트업. 데이터가 "도착"하는 순간이 있어야 함.
- **절제된 색** — 거의 단색 + 액센트 1개. 무지개 히트맵·보라→파랑 그라디언트는 즉시 "AI 슬롭"으로 읽힘(B안 작업 중 sat-korea.jpg 폐기 사례).
- **숫자는 mono, 큰 제목은 굵고 짧게** — B안 헤드라인 "부처는 다섯, 영상은 하나다"에 긍정 반응. 카피는 데이터 저널리즘 톤.
- **살아있음의 최소 조건** — 유휴: 실데이터에 묶인 느린 앰비언트 ≥1 / 호버: 150–250ms 물리적 반응 / 스크롤: 카메라 연속.

### 2.1 확정 (kepler/planet/영상 벤치마크, c238d8e)
- 영상의 정체: **Airbus "Pléiades Neo"** 광고 필름 — 우주 → 30cm 영상 → 탐지 소프트웨어까지 **컷 없는 하강**. 반응한 것은 우주가 아니라 *궤도에서 데이터로 내려오는 연속 카메라*.
- 세 레퍼런스 공통: 어두운 **무대** 위 발광 데이터(다크테마가 아님) · **명암 교대** 리듬 · 이미지를 사진으로 대접(장소·GSD·센서 캡션) · 채도 1색 · 크고 가는 타이포 · 연속 카메라 · 항상 숫자 증거.
- **"단조롭다"의 정체 = 밝기가 아니라 명암이 교대하지 않는 것.**
- 구조 = **3악장**: 디센트(검정: 히어로·전환) / 아틀라스(밝음: 서사·서비스 목록·리포트, B안) / 옵서버토리(어두움: 분석·탐지·시간재생, kepler). 악장 전환은 슬며시가 아니라 **하드 엣지** — 그것이 연출.
- 장치: 3단 하강 프로파일 3,400ms · 가산 발광(`blendFunc [SRC_ALPHA, ONE]`) · 밝은 지도 위 어두운 유리 시간 스크러버(`#242730`, 유일하게 허용되는 유리) · 신뢰도 임계 드래그 범례(숫자 노출).

## 3. 명시적 거부 목록 (다시 하면 안 되는 것)
1. 균일한 카드 그리드·유리 패널 나열·중앙정렬 히어로+통계 3개
2. Gothic A1 + IBM Plex 조합(무표정), 기본 막대/도넛 차트
3. 벡터 라이트 베이스맵, 플레이스홀더 육각형 경계, "이 자리에 들어갑니다"
4. 유휴 시 정지, 호버 시 색만 변경, 장면당 flyTo 한 번
5. 관리자 SaaS 크롬(사이드바+테이블+탭)이 첫인상인 화면
6. 가짜 숫자·가짜 신뢰도 게이지·로렘 입숨

## 4. 서체·색·모션 체계 v3 (Vantor 실측 기반, 확정)
- **서체**: 표시 **SUIT Medium(500) 단일 굵기**(크기는 스케일·여백으로), 본문 **Pretendard 400**, 숫자·좌표 **Inter 400**(tabular). 스케일: H1 64/80, H2 52/57, 본문 16/23, **통계 숫자 124px**. letter-spacing ±0.01em. 한글 행간은 한 단계 느슨하게(표시 1.25, 본문 1.6, 라벨 1.2).
- **색**: 바탕 `#010102` / `#FFFFFF` 둘뿐, 섹션 단위 **하드 반전**(그라디언트·유리·그림자·라운드 0). 액센트 1 = LX 블루 `#006DF7`(탐지 순간만 앰버 `#FFB633`). 회색 `#CCC`/`#686868`, 선 `#272727`/`#DDD`. 분석 뷰는 어두운 바닥 + 발광 데이터(kepler), 서사 페이지는 밝은 아틀라스(B안).
- **패널**: 떠 있는 HUD 스티커 금지. 오버레이는 이미지 안에 **헤어라인 벡터·코너 브래킷·캡션 `장소 · 날짜`** 로. CTA는 채운 버튼이 아니라 코너 브래킷 프레임.
- **모션**: 이징 하나 `cubic-bezier(0.15,1,0.3,1)`, 지속 500/750/1000/1250ms 사다리만. 숫자는 글자별 35–50ms 스태거로 현상. 텍스트 리빌은 `clip-path: inset(-5px 0)` 라인 마스크, 이미지 호버는 `inset(100% 0 0)→inset(0)` 1s. 호버 마이크로 180ms.
- **영상 처리**: 정사영상은 사진처럼(약한 무채화·대비), **선택적 채도** — AI가 본 폴리곤 안만 컬러 복원. 탐지는 축척이 안 보이면 "Acquired" 크롭 인셋으로 병치.
- **차트**: 축·격자 최소, 데이터 잉크만, 단일 액센트, 값은 카운트업/스윕으로 도착, 슬라이더와 같은 프레임.

## 5. 판정 규칙 (모든 화면에 적용)
1. 첫 프레임에 **실제 영상 사진**이 화면의 60% 이상인가
2. 5초 동안 아무것도 안 해도 **무언가가 실데이터 때문에** 움직이는가
3. 모든 인터랙티브 요소가 호버에 **물리적으로** 반응하는가(색 변화만은 실패)
4. 화면 전환이 **같은 지도의 카메라 이동**인가
5. 데이터가 나타날 때 **사건**(스캔·브래킷·카운트업)이 있는가
6. 색은 단색 바탕 + 액센트 1개, 노랑/적색은 탐지 순간에만
7. 헤드라인은 짧고 굵고 구체적(숫자·지명), 관리툴 어휘 금지
8. 차트는 값이 도착하는 순간이 있고 슬라이더와 동기화되는가
9. HUD의 모든 숫자가 **해설**인가(단위·범위·기준시점이 있는가) — 장식 숫자(예: '태양 직하점 10.9°')는 삭제. 데이터가 화면을 채우고 UI는 물러난다(vw-lab/KIOST 진단)
10. 화면당 움직이는 요소는 1개 + `● LIVE` 스탬프; 락온 3비트(브래킷 180ms → 확정 80ms → 라벨 120ms); 결손은 무채, 예측은 점선 고스트(FUI 조사)
11. 수치 규칙(살아있음 조사): 호버 `180ms cubic-bezier(.22,1,.36,1)`, 텍스트 인 `translateY(20px)→0` 600ms/60ms 스태거, 앰비언트 주기 ≥6s 위상 분산, 로더는 스피너가 아니라 3단 조립

## 6. 옵서버토리 악장 확정 — 워크플로우 화면 재구축(v3)으로 검증한 것

"2%" 판정을 받은 워크플로우 화면을 §4·§5로 전면 재구축하면서, **3악장 중 옵서버토리(어두운 무대 + 발광 데이터)** 의 세부를 아래로 고정한다. 다른 화면도 분석 뷰라면 이 표를 따른다.

| 항목 | 확정값 | 근거 |
|---|---|---|
| 바탕 | `#010102` 단색. 정사영상이 풀블리드 배경(화면의 100%) | §5-1 |
| 영상 처리 | 래스터 `saturation −0.58 · contrast +0.14 · brightness-max 0.86`, 주변 위성은 `−0.82 / 0.62` 로 더 눌러 무대로만 | 선택적 채도(§4) |
| 액센트 | **청록 `#0FA9A0` 한 계열만**(클래스 구분은 명도 램프). UI 는 전부 무채. 앰버 `#FFB633` 은 락온 순간 380ms 동안만 | §5-6, §5-10 |
| 발광 | 탐지 중심점에 **가산 혼합(`globalCompositeOperation:'lighter'`) 스프라이트**. z≥16.4 에서 0으로 내리고 실제 폴리곤에 자리를 넘긴다(밀도→개체 크로스페이드) | kepler Layer Blending |
| 유리 | **화면당 1개만 허용** — 하단 상주 타임라인 `rgba(36,39,48,.85)` + `blur(18px)`. 그 외 패널은 배경 없이 헤어라인 한 줄로만 구획 | kepler 시간필터 |
| 액자 | 노드·썸네일·크롭은 카드가 아니라 **1px 액자 + 바깥 위쪽 12px 캡션**. 면적의 70% 이상이 실제 픽셀이어야 한다. 코너 브래킷은 이미지 안쪽 6px, 호버·활성 시 40ms 스태거로 등장 | Frame-not-Card(D1), 장치 6 |
| 임계 컨트롤 | 슬라이더가 아니라 **실제 히스토그램 위의 끌 수 있는 마커**. 숫자는 항상 보인다. 통과=청록, 미달=무채(삭제 금지) | 장치 9, Palantir P1 |
| 숫자 | 화면당 초대형 하나(92~124px, Inter tabular) + 8~11px 캡션들. 값 변경 시 **글자별 40ms 스태거 현상** | §4, Vantor 4.4 |
| 결손 | 없는 자료는 **점선 무채 액자 + 이유 한 줄**. 대체 자료로 채웠으면 캡션에 그 사실을 쓴다("V-World 위성(이 시점 고해상 도엽 없음)") | §5-10 |
| 척도 | 모든 이미지에 헤어라인 스케일바 + **사람 척도 참조물**(비닐하우스 1동 54 m / 어선 1척 25 m) | 장치 8 |
| 심층 모드 | 진입 시 **밝은 면과 어두운 면이 칼로 그은 경계**로 만난다(좌 라이트 패널 / 우 다크 무대). 페이드·블러로 섞지 않는다 | 명암 교대(§2.1) |

추가로 확정된 것 하나: **진입 연출은 반드시 중단 가능해야 한다.** 활공 중 클릭·휠·키 입력이 들어오면 즉시 착지시킨다. 멈출 수 없는 연출은 "예쁜 영상"이고, 그것이 1차 목업 판정의 원인이었다.
