# Land-XI 프론트엔드 전면 개편 — 설계 스펙 (LX 플랫폼 1차)

작성일 2026-08-25 · 상태: 검토 대기

## 1. 목적과 범위

**목적.** 기존 프로토타입(https://mini531.github.io/namwon-smart-village/landxi7/)의 기능은 그대로 두고, 껍데기(디자인·배치·인터랙션)를 전면 개편한다. 대국민·비전문가가 처음 봐도 "혁신적인 Geo-AI 플랫폼"으로 와닿아야 하며, 목업이 아닌 실제 동작하는 HTML/CSS/JS로 구현한다.

**비전/모토(화면 문안에 그대로 사용).**
- 모토: **"LX 전 직원이 Geo-AI 전문가입니다"**
- 축: 노코드 · 워크플로우 기반 AI 모델 개발 · 전국단위 AI 실태조사
- 비전: **AI 기반 국토정보 통합조사**

**1차 범위 (LX 플랫폼 = 기존 `landxi7`).** 홈, 로그인, 대시보드, 프로젝트(목록·워크플로우 캔버스·하위 페이지), 데이터 관리, 분석 실행, XI 맵, 카드 발행 관리, 서비스 지원(공지·FAQ·문의·활용사례·매뉴얼), 서비스 관리(공지·문의·FAQ·사용자·지도 속성), 마이페이지.

**비범위.** 남원시(`namwon3`)·하천(`river`) 변형, 백엔드 연동, 실제 인증, 새로운 기능 추가. 기존 기능의 제거도 없다.

## 2. 기술 기반

- 빌드 도구 없는 정적 사이트: HTML + CSS(커스텀 프로퍼티) + ES Module JS. GitHub Pages/로컬 파일로 실행.
- 지도: **MapLibre GL JS v5** (CDN). 벡터 타일은 OpenFreeMap(`https://tiles.openfreemap.org/planet`) + 자체 스타일 JSON(`assets/map/style-landxi-light.json`). 글로브 투영, 3D 건물 돌출, pitch/bearing 카메라. 정사영상은 VWorld WMTS(Satellite/Hybrid) 래스터 레이어로 얹고 투명도 슬라이더로 전환. 타일 서버 불가 시(오프라인·아티팩트) 절차 생성 캔버스 폴백을 유지한다.
- 차트: ECharts 5 (기존 유지), 테마는 CSS 토큰에서 읽어 생성.
- 서체: Google Fonts — Gothic A1(700/800/900), IBM Plex Sans KR(400/500/600), IBM Plex Mono(500).
- 데이터: 기존 `assets/data/*.js` 목업을 그대로 옮기고, 지도에 필요한 항목(프로젝트 범위, 분석 결과, 카드 배포 기관, 시군구 커버리지)은 `assets/data/geo/*.geojson`으로 추가한다. 시군구 경계는 단순화된 GeoJSON을 포함한다.
- 상태: 기존과 동일하게 `localStorage`(로그인 플래그, 사용자 심볼, 최근 검색).
- 브라우저: Chrome/Edge 최신. 1280px 이상 데스크톱 우선, 1024px 이하에서 패널이 시트로 전환되는 최소 반응형.

## 3. 정보 구조와 쉘

### 3.1 쉘 레이아웃
```
┌64┬────────────────────────────────────────────────┐
│레│ 컨텍스트 바 48px: [LX 기관·팀] [브레드크럼] … [검색 /] [알림] [사용자] │
│일├──────────────┬─────────────────────────────────┤
│  │ 2차 컬럼 232 │ 콘텐츠 / 지도 캔버스              │
│  │ (필요 시)    │                                 │
│  ├──────────────┴─────────────────────────────────┤
│  │ 상태 눈금줄 36px (지도 화면): 좌표 · 축척 · 촬영일 · 모델    │
└──┴────────────────────────────────────────────────┘
```
- **레일(64px)**: 로고, `대시보드`, 그룹 `BUILD`(프로젝트·데이터·카드 발행), 그룹 `USE`(분석 실행·XI 맵), 하단 `서비스 관리`·`서비스 지원`·사용자 아바타(MY 플라이아웃: 마이페이지·로그아웃). 활성 = 왼쪽 3px Survey Blue 바 + 틴트 아이콘. 기존 9개 메뉴와 1:1 대응이며, 그룹 라벨은 역할 데이터(`AI_PERMISSIONS`)에 따라 숨길 수 있게 `data-role` 속성을 둔다(1차에서는 LX 관리자 고정).
- **컨텍스트 바(48px, 신설)**: 기관·팀, 브레드크럼, 커맨드 팔레트 트리거(`/`), 알림(기존 `.noti-*` 데이터 재사용), 사용자. 지도 화면에서는 유리(흰 82% + 블러)로 지도 위에 뜬다. 하단 눈금자는 페이지 로드 시 한 번 그려진다.
- **2차 컬럼(232px)**: 프로젝트 워크스페이스(Project/Data/Models/Deploy), 데이터 관리(업로드·완료·발행중·아카이브), 서비스 지원/관리 탭이 모두 이 한 패턴을 쓴다. 지도 화면에서는 접힘 상태로 시작하며 아이콘 스트립(40px)만 남는다.
- **푸터**: 문서 화면에서만, 정부 표준 링크(개인정보처리방침·이용약관·이메일무단수집거부·주소·고객센터·패밀리사이트)를 한 줄 회색 바로. 지도 화면에서는 상태 눈금줄 우측에 `ⓘ` 버튼으로 접근.

### 3.2 페이지 유형
1. **문서형** — 콘텐츠 최대폭 1440, 지도가 바탕에 흐리게(pitch 40°, 정지) 깔리고 흰 유리 카드가 올라감. 대시보드·프로젝트 목록·마이페이지·게시판.
2. **지도 캔버스형** — 지도가 전면이고, 좌측 플로팅 패널(392px)·상세 패널(392px)·하단 속성 드로어·우측 도구 스트립이 뜬다. 기존 배치를 유지하되 유리 스타일로 통일. 데이터 관리·분석 실행·XI 맵·카드 발행 관리·프로젝트 작업 화면.

### 3.3 공통 URL/딥링크
기존 파라미터를 그대로 지원: `?tab=`, `?domain=`, `?status=`, `?pid=`, `?job=`, `?embed=1`. `?embed=1`은 레일·컨텍스트 바·푸터를 숨긴다.

**서체·스케일.** Display Gothic A1, Body IBM Plex Sans KR(기준 14px, 행간 1.55), Data IBM Plex Mono(케이스/작업 번호, 좌표, PNU, 용량, 날짜). 스케일 12/13/14/16/20/24/32/44. 표·칩·캡션 13, 보조 12에서 멈춘다.

**형태.** 반경 6(컨트롤)/10(카드)/14(플로팅 패널). 테두리 1px. 엘리베이션 3단계(카드 `0 1px 2px` / 플로팅 `0 10px 30px 10%` / 모달 `0 24px 60px 18%`). 8px 그리드.

**시그니처 — 측량 눈금자.** `--rule` 그라데이션(10px 미세 눈금, 50px 긴 눈금)을 컨텍스트 바 하단·패널 헤더·KPI 타일 상단에 새긴다. 지도 화면 하단 상태 눈금줄은 줌에 따라 눈금 간격을 실제 축척에 맞게 재계산한다.

**모션.** 진입: 눈금자 드로잉 0.6s + 패널 순차 등장(80ms 간격). 카메라: `flyTo` 1.2s, 케이스 선택 시 pitch 45°. 앰비언트는 화면당 1개(홈 글로브 회전 / 대시보드 커버리지 펄스 / 지도 화면 스캔 스윕 없음). `prefers-reduced-motion`이면 앰비언트 정지, 카메라는 `jumpTo`.

## 5. 컴포넌트 (`assets/css/components.css`, `assets/js/ui/*.js`)

기존 4종 모달·5종 탭·2종 카드를 아래로 통합한다.
- **Button** primary/secondary/ghost/danger(outline), 크기 sm 30/md 38/lg 44. 기존 `.btn-p`, `.bp-btn`, `.btn-cta`는 이 클래스로 치환.
- **Pill** 상태 6색, 점 + 라벨. `.badge`, `.admin-pill` 대체.
- **Tabs** 하나: 세그먼트형(`role=tablist`). 패널 탭·admin-tabnav·left-tab·cmp-mode-tab 모두 이걸 사용하며 아이콘 유무만 다름.
- **Card / GlassPanel** 헤더(제목·카운트·우측 액션) + 본문. `.table-card`, `.glass-card` 대체.
- **Dialog** 하나(`<dialog>` 기반): 크기 sm/md/lg/full, 헤더·본문·푸터. `.modal-card`, `.pledge-box`, `.dh-action-modal`, `.notify-box`를 모두 대체. `NotifyUI.alert/confirm/toast` API는 유지하되 내부 구현만 교체.
- **Drawer** 우측 상세(392px)·하단 속성 드로어.
- **ListHeader 키트** 필터 칩 + 내 것/공유 토글 + 새로고침 + 검색 토글 → 접이식 검색 패널. 분석 실행·카드 발행·데이터 관리·게시판 공통.
- **DataTable** 13px, 라디오 행 선택, 페이지네이터(처음/이전/n/다음/마지막 + 페이지 크기 + 총 건수).
- **KPI Tile** 눈금자 + 라벨 + Display 숫자(카운트업) + 보조 문구. 워터마크 아이콘 없음.
- **CommandPalette** `/` 또는 검색창 클릭 → 프로젝트·카드·사용자·공지·주소/지번 통합 검색, 결과 선택 시 페이지 이동 또는 지도 `flyTo`.
- **MapShell**(`assets/js/map/shell.js`) MapLibre 초기화, 스타일 로드, 우측 도구 스트립(검색·배경지도·측정·그리기·내보내기·LX 레이어·AOI), 상태 눈금줄, 정사영상 투명도 슬라이더, 폴백 캔버스.
- **아이콘** 단일 SVG 스프라이트(`assets/icons.svg`), 크기 16/18/22. 이모지 아이콘 금지.

## 6. 화면별 스펙

각 화면은 "유지되는 기능" → "배치" → "인터랙션"으로 적는다.

### 6.1 홈 (`home.html`)
유지: 상단 내비(플랫폼 소개·활용 사례·문의하기·로그인), 히어로 CTA 2개, 4개 지표, 4단계 파이프라인, 전/후 비교, 3개 기능 소개, 서비스 라인업 13종, 활용 사례 2건(모달), 문의 폼(모달·검증·토스트), 정책 모달.
배치: 전면 지도가 페이지 전체 바탕(스크롤에 따라 카메라가 변함). 섹션은 유리 패널로 지도 위에 흐른다.
인터랙션:
- **글로브 진입**: 로드 시 글로브가 천천히 회전(앰비언트) → 1.5s 후 한반도로 `flyTo`. 스크롤 진행도에 따라 카메라가 전국(zoom 6) → 전북(9) → 남원 시가지(14, pitch 50°) → 정사영상 레이어 페이드인(zoom 16)으로 내려간다. 각 단계가 섹션(전국 실태조사 → 지자체 서비스 → 노코드 모델 → 탐지 결과)과 짝을 이룬다.
- **스캔 렌즈**: 히어로 구간에서 커서가 렌즈가 되어 렌즈 안에서만 AI 탐지 레이어가 보이고, 가까운 탐지의 서비스명이 태그로 뜬다. 클릭하면 서비스 라인업 섹션의 해당 칩으로 스크롤·하이라이트.
- **지표 카운트업**, 파이프라인 4노드는 화면 진입 시 선이 흐른다(워크플로우 캔버스와 같은 그래픽 언어).
- 전/후 비교는 드래그 스와이프(기존 자동 회전은 유지하되 사용자가 잡으면 멈춤).

### 6.2 로그인 (`login.html`)
유지: 아이디(이메일)·비밀번호·아이디 저장·아이디/비밀번호 찾기·계정 신청. 배치: 지도(글로브 정지 상태) 위 중앙 유리 카드. 로그인 성공 시 카드가 축소되며 대시보드로 전환(localStorage 플래그 동일).

### 6.3 대시보드 (`dashboard.html`)
유지: 공지 스트립, KPI 5(전체 사용자·발행 카드·카드 승인 대기·가입 승인 대기·미답변 문의), 백본 모델, 프로젝트 용량 차트, 7일 방문 차트, 스토리지 도넛, 승인 대기 목록, 사용자·콘텐츠 관리 타일.
배치(문서형, 지도 바탕): ① 페이지 헤더+공지 한 줄, ② 좌 400px **처리 대기 큐**(승인 대기+가입 승인+미답변 문의 통합, 대기 일수 정렬, 행 액션 검토/승인·거부/답변), 중앙 KPI 2×2(+"전체" 툴팁으로 5번째), 우 300px 백본·스토리지·프로젝트 용량, ③ 하단 **전국 커버리지** 카드(방문 차트·스토리지 도넛은 카드 안 탭으로 이동), ④ 사용자·콘텐츠 관리 타일 4개.
인터랙션: 큐 호버 → 지도에 관련 위치(프로젝트 범위/기관) 하이라이트, 클릭 → 카메라 이동 + 상세 드로어. KPI 호버 → 해당 상태만 남김. **전국 커버리지**: 시군구 코로플레스(실태조사 진행 지역 채움, 앰비언트 펄스 1개), 호버 시 과제·건수 툴팁, 클릭 시 XI 맵으로 이동(`?region=`).

### 6.4 프로젝트 (`ai-project.html`, `ai-project-*.html`)
유지: 검색·초기화, 목록(카드: 썸네일·이름·탐지 유형·작성자·날짜·라벨링/학습/구성원 수), 페이지네이터, 프로젝트 만들기, 워크스페이스 하위 페이지 전부(개요·파일 업로드·클래스 관리·라벨링·데이터셋·AI 학습·모델 등록·AI 분석·카드 발행 요청), 구성원 초대/내보내기, 삭제.
배치: 목록은 문서형(지도 바탕에 프로젝트 범위 폴리곤이 옅게). 워크스페이스는 2차 컬럼(Project/Data/Models/Deploy) + 콘텐츠.
인터랙션: 목록 카드 호버 → 지도에 그 프로젝트 범위 강조. **워크플로우 캔버스**(`ai-project-view`): 개요 페이지 상단을 노드 그래프로 — `데이터 → 클래스 → 라벨링 → 학습 → 평가 → 발행`. 각 노드는 해당 하위 페이지 링크이자 진행률 링(라벨링 n/n, 학습 회차, IoU), 완료된 구간은 선을 따라 흐르는 점선 애니메이션. 노드 클릭 = 페이지 이동, 노드 호버 = 요약 툴팁. 기존 개요 정보(설명·클래스·구성원·학습 결과)는 캔버스 아래 카드로 유지.

### 6.5 데이터 관리 (`dataset.html`)
유지: 4탭(업로드·완료·발행중·아카이브), 파일 유형 칩, 업로드 드롭존·큐·취소, 디스크 사용량·증량 신청 모달, 발행 5단계 스테퍼, 아카이브 검색·지도 미리보기·하단 행정정보 표. 하위 페이지 fetch-inject 방식은 폐기하고 한 페이지 안의 탭 섹션으로 통합(같은 DOM ID 체계 유지).
배치: 지도 캔버스형. 2차 컬럼 대신 좌측 플로팅 패널 안 세그먼트 탭.
인터랙션: 업로드 큐 항목 호버 → 지도에 그 파일의 범위 바운딩 박스. 아카이브 항목 클릭 → 카메라 이동 + 정사영상 투명도 슬라이더 자동 노출. 발행중 스테퍼의 현재 단계가 지도 위 범위에 스캔 라인으로 표시(해당 항목 선택 중에만).

### 6.6 분석 실행 (`analysis-ai.html`, `history*.html`)
유지: 3탭(실행·실행중·완료), 과제→모델→영상 순차 선택 카드, 실행 CTA, 진행 오버레이(단계·필지 진행·시작 시각·새로 분석/결과 보기), 실행중·완료 목록(칩·내 것/공유·검색 패널·카드), 상세 패널·수정·공유 설정, 결과 편집 툴바(이동·삭제·저장·취소), 하단 분석 결과 표, GPKG 다운로드, 과제별 결과 페이지.
배치: 지도 캔버스형, 기존 좌측 패널 + 상세 패널.
인터랙션: **분석 실행 = 지도가 채워짐** — 실행하면 진행 오버레이 대신(수치는 유지) 선택 범위의 필지가 `필지 진행 n/n`에 맞춰 순서대로 밝아지고 탐지 폴리곤이 그려진다; 완료 시 결과 요약 칩이 패널에 착지. 과제 선택 시 지도가 그 과제의 대표 지역으로 부드럽게 이동.

### 6.7 XI 맵 (`ximap.html`, `map-*.html`)
유지: 좌측 스택(AI 분석 결과/레이어 탭, 설정, 그룹·목록 보기), 상단 모드(기본·겹쳐보기·나란히보기), 우측 통계 스택, 범례, 관심 구역 그리기·저장, 우측 도구(검색·배경지도·측정·그리기·내보내기·LX 레이어), 하단 패널(공간정보·지역·분석 결과 탭·검색·표), 탐지 팝업·상세 모달(상태 스테퍼·이력), 비교 선택 모달, 보고서 발급 모달(`?embed=1` iframe), 모바일 FAB.
배치: 동일, 유리 스타일. 좌·우 스택은 한 번에 하나만 펼쳐지고(다른 쪽은 아이콘 스트립) 범례는 상태 눈금줄 위 칩 바로 이동.
인터랙션: **타임 스크럽** — 겹쳐보기/나란히보기를 시간축 슬라이더 하나로 통합: 기준·비교 시점을 눈금줄 위 트랙에서 고르고, 드래그하면 두 정사영상이 스와이프되며 신규 탐지(AI teal)·소멸(보류색)이 색으로 구분. 탐지 클릭 → 카메라 pitch 45° + 3D 건물 + 상세 드로어. 레이어 토글 시 해당 레이어가 페이드/드로잉. 분석 결과 vs 레이어 시각 구분: 탐지=teal 폴리곤, 행정 케이스=상태색 핀.

### 6.8 카드 발행 관리 (`admin-publish.html`, `ai-card.html`)
유지: 상태 칩(전체·대기·검토중·승인·반려), 목록·검색, 요청 상세(개요·구성원·라벨링·학습 결과·분석 결과 탭), 발행 처리(승인/반려·사유·이미지), 클래스 일괄 변경, 발행 카드 목록.
배치: 지도 캔버스형. 지도에는 요청 프로젝트의 분석 범위와 배포 대상 기관 위치.
인터랙션: **카드 발행 = 배포 애니메이션** — 승인 확정 시 카드 썸네일이 목록에서 떠올라 지도 위 권한 기관(남원시청·전라남도·LX)으로 날아가 착지하고 기관 핀이 켜진다. 반려 시 카드가 흔들리며 회색으로. 요청 호버 → 범위 강조.

### 6.9 서비스 지원·서비스 관리·마이페이지
유지: 각 탭과 게시판(검색·기간 버튼·표·페이지네이터·상세·등록/수정 RTE·첨부), 사용자 관리(승인/거부·로그인 이력·비밀번호 이력), 지도 속성 관리, 마이페이지(회원 정보·비밀번호 변경·디스크 사용량·증량 신청 이력·브랜드 심볼 업로드·정보 수정).
배치: 문서형, 2차 컬럼에 탭. RTE 툴바 아이콘은 스프라이트로 교체.
인터랙션: 특별한 것 없음(공통 진입 모션만). 사용자 관리에서 사용자 호버 → 소속 기관 위치가 바탕 지도에 표시.

## 9. 접근성·품질 기준
- 키보드: 레일·탭·다이얼로그·팔레트 전부 포커스 가능, `:focus-visible` 링 2px Survey Blue.
- 대비: 잉크/미스트 12:1, 유리 패널 위 본문은 항상 `--ink`. 상태색은 필+라벨로 색맹 대응.
- `prefers-reduced-motion` 준수(4장).
- 성능: MapLibre 1개 인스턴스/페이지, 문서형 화면에서는 `interactive:false` + 정지. 첫 화면 LCP 목표 2.5s(로컬).
- 검증: 각 페이지를 헤드리스 Chrome으로 1440×900 스크린샷 → 기존 페이지 스크린샷과 나란히 비교해 기능 누락 점검(기능 체크리스트는 6장 "유지" 항목에서 생성). 브라우저 콘솔 오류 0.
