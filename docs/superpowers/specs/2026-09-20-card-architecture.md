# 서비스 카드 구조 — 공통 틀 · 전용 모듈 · 지역 이식 (2026-09-20 발주자 구술)

3. "글로벌도 지자체도 **LX와 연계 체계**가 고려되어야 하고, **기본적인 구조는 비슷하게** 가야 한다"
4. "23년 남원시 생활환경 위험요소, 25년 영농관리 행정서비스, 26년 도로 안전관리, 27년 인파관리 … **디테일한 서비스를 공통 표준으로 하긴 어렵다. 기본 틀은 갖추되 필요한 세부 기능은 따로 만들어야 하는 핵심 어려움**이 있다"
5. "남원에 분기한 이 AI 서비스를 **또 다른 지자체에 이식**할 수 있도록 / **모듈형**도 고려되어야 하는 복잡함"

## 1. 세 겹 구조 (`landxi/assets/data/cards.js`)

```
MODULES ──┬─ CORE (공통 7)   모든 카드가 상속 = "기본 틀"
          └─ EXT  (전용 n)   그 서비스에만 있는 세부 기능 = "따로 만드는 것"
                  ↓ 조합
CARDS     카드 = 행정 업무 한 건을 처리하는 AI 분석 서비스 한 벌 (표준 틀)
                  ↓ 심기
DEPLOYS   배포본 = 카드를 특정 지역·연도에 심은 것 (남원 23·25·26·27 …)
```

**이식이란**: 카드는 그대로 두고 배포본의 `region · 경계 · 기준값 · 주기`만 갈아 끼우는 일. 다른 지자체로 옮기려면 같은 `cardId` 의 배포본을 하나 더 만든다. 여수 해양쓰레기(2025)가 남원 밖 첫 이식 사례다.

### 공통 모듈 7 (CORE_MODULES)
영상 수집·정사화 → AI 추론 실행 → 결과 검수·수정(LX 권한) → 지도 결과 열람 → 행정구역 통계 → 보고서 발급 → 권한·공유.
각 모듈은 이미 있는 화면에 대응한다(`dataset` `analysis-ai` `ai-project` `ximap` `stats-standard` `report-standard` `admin-users`) — 그래서 새 카드를 만들어도 화면을 새로 만들 필요가 없다.

### 전용 모듈 (EXT_MODULES) — 핵심 난제가 사는 곳
| 서비스 | 전용 모듈 | 상태 |
|---|---|---|
| 영농관리 | 필지 대장 대조 · 영농 주기 판정 · 비닐하우스 동수 집계 · 직불금 대상 검토 | 3 완성 / 1 설계 |
| 생활환경 | 폐기물 더미 규모 추정 · 소각 흔적 판별 · 민원 연계 · 현장 점검 동선 | 2 진행 / 2 설계 |
| 도로안전 | 노선 구간화 · 포장 상태 등급 · 다시점 대조 · 보수 우선순위 | 3 완성 / 1 설계 |
| 인파관리 | 시계열 밀도 · 혼잡 임계 경보 · 행사 구역 설정 | 3 설계 (2027) |
| 변화탐지 | 시점 쌍 정합 · 변화 유형 분류 · 무허가 대조 | 2 완성 / 1 설계 |
| 해양쓰레기 | 쓰레기 종류 분류 · 해안선 구간화 · 수거 계획 산출 | 1 완성 / 1 진행 / 1 설계 |

**규칙**: 전용 모듈을 공통으로 끌어올리지 않는다. 두 서비스 이상에서 같은 요구가 반복될 때만 공통 승격을 검토한다(예: `구간화` 가 도로·해안에서 반복 → 후보).

## 2. 분기 — 지자체 / 글로벌

같은 카드 문법·같은 화면. 다른 것은 맥락뿐이다.

| | 지자체 사업 | 글로벌 사업 |
|---|---|---|
| 행정 단위 | 읍·면·동 | 주 · 군(district) |
| 좌표계 | EPSG:5186 | EPSG:4326 |
| 영상 | 드론 · 항공 정사영상 | 위성 중심(드론 접근 제약) |
| 현재 | 운영 4 · 검토 1 · 준비 2 | 준비 2 (대상국 미정) |

**LX 연계 체계**(두 분기 공통): 모델 개발은 LX · 결과 품질 책임도 LX · 모델이 오르면 카드 버전이 오르고 배포본에 갱신이 간다 · 검증된 카드는 이식으로 퍼진다 · 문의는 서비스 지원으로.

**콘티 원칙**: 글로벌은 실데이터가 없다 — 수치를 지어내지 않고 `준비 중` + `gap` 한 줄로 둔다. 구조(분기 탭·배지·폼 필드·권한)만 진짜로 동작한다.

## 3. 화면에 나타나는 곳

- **분석 서비스**(`analysis-ai.html`) = 카드 진열대. 상단 `지자체 사업 / 글로벌 사업` 분기, 카드마다 대상·소관·주기·모듈 수·배포 지역.
- **카드 상세** = 묶은 AI 모델 + 공통 7 + 전용 n(완성/진행/설계) + 배포 지역 + **이식 필요 조건**.
- **카드 발행 관리**(`admin-publish.html`) = 프로젝트 결과를 카드로 승격. 발행 폼에 `대상 사업`·`전용 모듈`·`이식 가능` 필드.
- **프로젝트**(`ai-project.html`) = LX 작업실. 완료한 모델이 **어느 카드로 갔는지** 역추적(`cardNamesOfService`).
- **대시보드** = 분기별 카드 집계 + 남원 연도별 배포 현황.
- **지도·통계·보고서** = 배포본의 결과를 행정에 쓰는 자리.
