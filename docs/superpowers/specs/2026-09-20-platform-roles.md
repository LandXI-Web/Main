# Land-XI 역할·흐름 정의 (2026-09-20 발주자 구술, 이후 모든 화면의 전제)

발주자 원문:
- "카드 발행 관리는 **내가 잘 만들어진 AI 모델 분석 서비스를 카드 형태로 발행하는 기능**이다."
- "예를 들면 **남원시 영농관리 서비스 카드**, **생활환경 위험요소 탐지 서비스** 등등"
- "**LX에서 만든 서비스들이 지자체 · 글로벌사업 분기가 필요**하다"
- "이 서비스를 즉, **AI 분석 모델 개발 / 분석 결과 수정·삭제 등 이 기능들이 LX의 역할**인 거고"
- "**지자체나 글로벌 나라는 분석 결과를 행정에 잘 활용**하는 거지"

## 1. 두 역할, 한 플랫폼

| | **LX (한국국토정보공사)** — 만드는 쪽 | **지자체 · 글로벌 국가** — 쓰는 쪽 |
|---|---|---|
| 하는 일 | AI 분석 모델 **개발** · 학습 · 분석 실행 · **분석 결과 수정·삭제** · 품질 관리 | 발행된 **서비스 카드**로 분석 결과를 **행정에 활용** |
| 쓰는 화면 | 프로젝트(모델 개발 8단계) · 데이터 관리 · 카드 발행 관리 · 서비스 관리 | 분석 서비스(카드 목록·실행) · 지도 서비스 · 대시보드(뷰어) |
| 산출 | **서비스 카드** | 조사 결과 · 통계 · 보고서 |

LX가 만든 것이 카드가 되어 고객에게 건너간다 — **플랫폼의 축은 "모델 → 카드 → 행정 활용"** 이다.

## 2. 서비스 카드 = 이 플랫폼의 상품

"카드"는 잘 만들어진 **AI 분석 서비스 한 벌**이다: 학습된 모델 + 실행 방법 + 결과 표현(지도 레이어·통계·보고서) + 권한.
카드 이름은 기능명이 아니라 **행정 업무명**으로 읽힌다 — `남원시 영농관리 서비스`, `생활환경 위험요소 탐지 서비스`.
한 카드는 여러 탐지 모델을 묶을 수 있다(예: 영농관리 = 농지이용 + 비닐하우스 + 사료작물).

## 3. 분기 — 지자체 사업 / 글로벌 사업

발행 시 **대상 사업**을 고른다.

| | 지자체 사업 | 글로벌 사업 |
|---|---|---|
| 고객 | 시·군·구, 도, 중앙부처 | 해외 정부·기관(ODA·수출) |
| 다른 점 | 행정구역(읍면동)·법정 업무 주기·국내 좌표계(EPSG:5186) | 국가·지역 단위, 현지 언어/단위, 국제 좌표계, 위성 중심(드론 접근 제약) |
| 화면에 나타나는 곳 | 분석 서비스 목록의 **분기 탭/필터**, 카드의 **대상 배지**, 카드 발행 폼의 **대상 사업 선택**, 대시보드 집계 | 〃 |

**콘티 원칙 유지**: 글로벌 사업의 실적·국가명은 아직 실데이터가 없다 — 지어내지 않고 `준비 중` 또는 `시연` 표식으로 둔다. 구조(분기·필터·배지·폼 필드)만 실제로 동작하게 만든다.

## 4. 화면별 역할 재정의 (기존 원판과 충돌하지 않는 범위)

- **프로젝트** = LX의 모델 개발 작업실. 끝에 `카드 발행 요청`으로 나간다.
- **카드 발행 관리** = 요청을 검토·승인해 **서비스 카드로 발행**. 발행 시 **대상 사업(지자체/글로벌)** 과 권한을 정한다. 발행된 카드 목록이 곧 `분석 서비스`의 진열대.
- **분석 서비스** = 발행된 카드 목록(지자체/글로벌 분기) + 실행 + 결과. 고객이 가장 많이 쓰는 화면.
- **지도 서비스** = 결과를 행정에 쓰는 자리(지도·통계·보고서 발급).
- **데이터 관리** = 두 역할이 함께 쓰는 원천 영상·학습데이터.

## 5. 이 정의가 요구하는 수정 (2026-09-20 이후 작업 목록)

1. `services.js`에 **`scope: 'local' | 'global'`**(대상 사업)과 **카드 관점 필드**(행정 업무명·소관·주기) 추가. 기존 15종은 전부 `local`(남원 등 국내 실증) — 글로벌은 구조만 두고 `준비 중`.
2. **분석 서비스**: 상단에 `지자체 사업 / 글로벌 사업` 분기, 카드에 대상 배지.
3. **카드 발행 관리**: 발행 폼에 `대상 사업` 필드, 목록에 분기 필터·배지.
4. **대시보드**: 발행 카드 집계를 분기별로.
5. **프로젝트**: 모델 개발 결과가 어느 카드로 갔는지 역추적 링크.
