## 5. 정직 항목

1. **전역 추론이 체감상 빠르지 않다.** 남원 전역 1,064칩에 1,071초, 실측 1.0칩/초가 걸렸다. 워커는 해상도를 낮춘 칩(upsample 0.25)을 만들 때 4096² 원본 창을 통째로 읽은 뒤 줄인다(읽기 병목). 서버 견적 `eta_s`는 칩을 미리 올려 둔 벤치(20칩/초)로 계산돼 55초로 나왔다. 실제의 1/20이다. 그래서 화면의 결과 시간은 **같은 영상으로 끝난 최근 분석의 실측 속도**(`/jobs?state=done`의 `chips_per_wall_s` 중앙값)로 계산한다. 지금은 **약 18분**이 뜬다(1,069초 → 120초 이상은 분 표기). 기록이 없을 때만 서버 견적을 쓴다.
2. **(1차 기준 · 2차에서 바뀜 — §00 #1)** **영상은 편집본이다.** 대기 구간 세 곳을 잘랐다: 정문 → 도착 사이 약 4초, 전역 견적 약 11초(서버가 1,064칩 계획을 만드는 시간), 실행 → 첫 칸 약 14초(워커 준비). 잘린 곳 말고는 실시간이다. 차오름 구간(약 6.5초)도 실제 속도 그대로라 영상 끝에서 진행은 1%다. 다 찬 모습은 끝난 작업을 `?job=`로 다시 불러 찍은 스틸(`region-result`)이다. 그 작업의 실제 기록 이벤트를 다시 받아 그린 것이지 합성한 화면이 아니다.
3. 영상을 찍으려고 전역 작업을 두 번 더 시작했고, 녹화 뒤 바로 취소했다(`job_01M3GNYT…` 등). GPU는 게이트웨이 큐로만 썼고, 한 번에 한 작업만 돌렸다. 에이전트와 보고서(vLLM)는 추론 작업이 없을 때만 호출했다.
4. `/regions`(S-3)가 없어서 전국 시군구 목록과 경계는 `landxi/assets/data/geo/sigungu.geojson`(249개 · 코드 · 이름 · 도형)에서 읽는다. 기관 관할은 기관 이름을 이 목록에서 찾고, 없으면 K4 `loadRegions()`(배포 기록)로 대신한다. 지역 문자열 하드코딩은 0이다.
5. 필지 타일(`parcels-*`)의 PNU는 옛 시도 코드(전북 45)로, 실태조사 PNU(52)와 다르다. 그래서 시도 두 자리를 뺀 17자리로 맞춰 칠하고 누른다.
6. 제주(`jeju-2022`)와 김제 국산리(`kuksan-a68`)는 `POST /jobs/quote`에서 **서버 500**이 난다(영상 원본 경로 문제로 보인다). 이때 화면은 `지금은 견적을 낼 수 없습니다`로 끝나지만, CORS 없는 500이라 콘솔에 오류가 한 줄 남는다. 그래서 두 번째 지역은 익산 드론 영상으로 확인했다.
7. S-8(서버 shard 계획 · `too_large` · `power_budget`)은 작업 도중 서버 팀이 반영 중이었다(`SHARD_CAP infer 20000`). 화면은 두 사유 모두 문구로 받는다. 칩 수를 누르는 해상도 단계(1600칩 기준)는 아직 클라이언트 어댑터가 정한다. 서버가 계획을 내면 그 값을 따르면 된다.
8. 에이전트 답 본문의 수(예: `431건` = 모든 우선순위)와 HUD 수(85 = 우선순위 A)는 서로 다른 지표다. 답 본문은 K10 소관이고, 지도 동작이 끝나면 1.6초 뒤 닫힌다.
9. **첫 도착 수치는 가시 탭 조건이다.** 판정 환경에서 탭이 가려져 있으면(백그라운드 창 · 가려진 헤드리스 탭) 브라우저가 화면 프레임을 멈추고, MapLibre `load`가 첫 프레임을 기다리므로 `ready`가 늦어진다. 제품 결함이 아니라 측정 조건 차이다. 위 표는 모두 `visibilityState=visible`에서 쟀다.
10. 게이트웨이 끊김 판정은 **게이트웨이 프로세스를 끄지 않고** 브라우저에서 `/survey/*` 요청만 끊어 재현했다. 다른 화면 · 워크플로가 같은 게이트웨이를 쓰고 있고, 관문 `/me`까지 끊기면 K2 관문이 정문으로 돌려보내므로 xi-clean 화면 자체가 뜨지 않는다(이 경우는 키트 K2 소관).

## 6. 키트 요청(키트 팀 · 나는 고치지 않았다)

- **K1 셸** — 레일 아이콘이 고정 키 11종뿐이다. 도구 아이콘을 쓰려고 화면이 그린 뒤 svg를 덧칠한다(`patchRail`). `items[].svg`(또는 path)를 받게 해 주기를 요청한다. 또 이름과 역할이 같으면 역할 칩이 `LX 직원 · LX 직원`으로 중복된다. 화면에서 `dedupeRole()`로 막았지만, `roleText`가 `name === 역할`이면 역할만 내도록 키트에서 고치는 편이 맞다(다른 화면에도 같은 중복이 난다).
- **K6 bignum** — 허용 라벨 검사가 정확히 일치할 때만 통과한다. 명세 라벨 `현장 확인 필요 · {지역}`은 dev 모드에서 경고가 나서 라벨 요소에 지역을 따로 붙였다. 접두어 일치로 바꿔 주기를 요청한다. `set(env, {animate:false})` 옵션도 요청한다(지금은 생성 옵션뿐이다).
- **K16 CLI** — `frontDoor()`가 지금 정문(라디오 `who` + 라벨)에서 `getByRole('radio')` 클릭을 못 한다(span이 가로챈다). 그래서 CLI 대신 같은 `scan`/`collect`를 정문 로그인 뒤 페이지 안에서 불러 쟀다.
- **K10 cmdk** — 답 완료를 바깥에 알리는 이벤트가 없다(`kit:agent-done` 요청). 지금은 지도 동작이 오면 1.6초 뒤 닫는다.

## 7. 서버 요청

- 워커 읽기: upsample < 1일 때 원본 창 전체 대신 **오버뷰(decimated read, `out_shape`)**로 읽어 달라. 전역 추론 속도가 약 10배 이상 빨라질 것으로 추정한다. 이것이 Hyper Performance 장면의 병목이다.
- `eta_s`: 벤치 대신 `perf:shard_ms`(실측 · 읽기 포함)로 계산해 달라. upsample별로 따로 계산해야 한다.
- `/jobs/quote` 500(제주 · 국산리 영상): 봉투 오류(4xx)와 CORS 헤더로 응답해 달라.

## 8. 제안(구현은 명세대로 했다)
