## 0% 가 나온 원인 (규명)
1. **GPU 시간·분석 면적:** 계량이 작업을 **낸** 기관 id 로만 기록했다. 남원 영상 AI 분석은 전부 LX 가 대신 돌려서 `usage_events` 가 전부 `lx` 로 들어갔고(백필 전 gpu_s 8,186행·area 225행 전부 `lx`), 남원·광주전남은 0행이었다. 한도(hard)는 이미 있었으므로 % 가 0 인 것은 한도 문제가 아니라 사용량 0 때문이었다.
2. **저장 공간:** 폴더 크기를 `results/{기관 id}` 에서만 쟀는데, 실제 결과는 전부 `results/lx/…`·`vector/pmtiles/…` 에 있고 `results/namwon`·`results/gwangju-jeonnam` 폴더는 아예 없다. 올린 대장·실태조사 결과는 파일이 아니라 DB 행이라 잡히지도 않았다.

## 고친 것
