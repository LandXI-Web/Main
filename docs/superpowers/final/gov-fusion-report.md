## 4. 데이터 경로(서버 정본)
- 반입: 브라우저가 필지를 이은 뒤 `POST /t/{tenant}/survey/registry/import`(뜻을 고른 열만 · 성명 · 연락처 0 · 종류는 파일에서) → `POST …/{import_id}/confirm` → `GET …/{import_id}`가 `matched`가 될 때까지 기다린다. 지도 스윕과 서버 평가는 동시에 돈다.
- 결과: `GET /survey/findings?ledger={import_id}&rule=L1,L2,R1,R2,R4&limit=2000` 한 번(`by_rule` + 목록). 큰 숫자 L1(없으면 R1), 주차장 R4, 경작 흔적 없음 L2∪R2(대장 필지로 한정된 실태조사 규칙). 표의 `상태`와 필지 카드의 상태 · `현장 배정`은 같은 결과 한 건을 쓴다.
- 이어 열기: `GET …/registry?latest=1` → `GET …/{import_id}`. 이 창에 행 캐시가 있으면 대장 필지 전체를 옅게 깔고, 없으면 결과 필지만 칠한다.
- 결합률: 한 숫자. 이 창에 행이 있으면 브라우저 결합 ∪ 서버 결합, 새 기기에서는 서버 결합 + 서버가 조회 상한으로 못 본 행을 브라우저가 V-World로 확인한 값이다. 합이 정해지기 전에는 숫자 없이 `대장 필지 결합 확인 중`만 둔다.
- 대장 종류: 서버 최근 반입의 `kind` → (첫 반입) 파일 이름 · 열 → 기관 배포 카드. `ledger_schema`는 기관 세션이 읽을 경로가 없어(405 · 403, §0-4) 계약에 생기면 먼저 쓰도록 검사만 걸어 두었다.
- 바탕: V-World 위성 타일(외부) · 시군구 PMTiles(게이트웨이) · V-World 읍면동 경계(`/proxy/vworld/data`, 해안 칸만).

2. **K3 육지 마스크 바탕**: 이 화면의 `land.js`(바다 단색 · 시군구로 바다 · 내륙 · 해안 가르기 · 해안은 V-World 읍면동 경계 · 저줌 물빛 걷기 · 저줌 받침)를 K3 무대 옵션(`createStage(el, { base: 'land' })`)으로 옮겨 달라. 모든 지도 화면에 같은 남색 사각 문제가 있다. 지금은 화면이 `k-eox` `k-vw`를 숨기고 자체 층을 깐다.
3. **K6 허용 라벨**: `대장은 {대장 상태} · AI는 {AI 판독}`(§2.9 문구)이 `ALLOWED`에 없어 `?dev=1`에서 경고 1건이 난다.
4. **K10 `mountCmdk({ onSubmit })`**: 화면이 질문을 넘겨받는 훅이 없어 캡처 단계에서 `submit`을 가로챈다. 자리표 · 마스트 문구(`물어보기`)도 옵션으로 달라.
5. **K1 마스트 뒤쪽 칸**: `할 일 {n}`을 역할 칩 뒤 · `?` 앞에 둘 칸이 없어 DOM으로 끼웠다.
6. **K10 390 입력칸**: 긴 질문이 앞에서 잘려 보인다(입력 끝으로 스크롤됨). 두 줄 입력이나 글자 축소를 요청한다.

## 6. 서버 요청(우선순위 순)
1. **confirm마다 기관 '할 일'(배정 건)이 사라지는 동작**(판정관 관찰). `ledger.evaluate_rules`가 반입마다 이 기관의 L-* 결과를 `DELETE … state='open' AND NOT demo` 후 다시 넣고, `survey.findings`는 조회마다 `_maybe_revert_demo`를 부른다. 이 둘과 gov-report의 배정 건 사이의 관계는 이 화면에서 확인하지 못했다(배정을 누르지 않았다). 사람이 손댄 결과(assigned · inspected)와 그 이벤트는 반입이 바뀌어도 남아야 한다.
2. **V-World 조회 상한 300**(`VW_CAP`): 연속지적이 없는 관할(광주전남)은 786행 중 300행만 서버가 잇는다. 화면은 나머지를 브라우저가 V-World로 확인해 합치지만, 서버 기록에는 38.2%로 남는다. BOX 한 번에 여러 필지를 확인하거나 상한을 행 수에 비례하게 해 달라.
3. **반입 행 목록**(`GET …/registry/{import_id}?rows=matched`): 새 기기에서는 서버가 이은 행의 PNU를 받을 길이 없다. 그래서 광주전남 새 기기 지도에는 브라우저가 확인한 486필지만 칠해지고, 서버가 이은 300필지는 칠해지지 않는다(숫자는 786 · 100.0%로 같다). 남원은 결과 필지만 칠하고 대장 필지 전체 바탕은 칠하지 않는다.
4. **L2 대장 상태 값**: L2는 `상태`가 `경작 · 자경 · 임차`일 때만 걸린다. 지목(전 · 답)을 `상태`로 올린 농지대장에서는 0건이라, 화면은 `경작 흔적 없음(확인 필요)`을 L2∪R2로 센다. 규칙 정의 결정이 필요하다.
5. **시군구 코드**: `/regions`는 새 코드(광주전남 12xxx)를 주고 경계 타일 `sigungu.pmtiles`는 옛 코드(29 · 46)를 쓴다. 화면은 시도 이름 기준표로 둘 다 건다. `/regions`에 `prev_cd`를 실어 달라.
6. **`GET /registry/cards/{cid}/ledger_schema`(기관 세션 읽기)**: 지금은 `put`만 있어 405, `GET /registry/cards`는 기관 세션 403이다(2026-09-29 새 프로필 4회 실측). 판정 지적 4의 '경로가 살아 있다'는 반입 S-2 경로(import · confirm · latest · detail)에만 맞고 이 경로에는 맞지 않는다.
7. 이전 차수에서 이어지는 항목: `/feedback`의 `kind: imagery_request`, S-10 `ledger_*` 도구, 매칭 중 게이트웨이 헬스 막힘.

## 7. 정직 항목
1. **큰 숫자가 696 → 431로 바뀌었다.** 2차는 브라우저가 AI 판독 색인의 `bld_m2`(필지에 걸친 건물 전체 면적 · 서버 `a23_bld_m2`와 같은 695)로 셌다. 이번에는 서버 규칙 L1(`a23_bld_in_m2` · 필지 안 건물 면적 ≥ 33㎡)을 정본으로 썼다. 경작 흔적 없음도 1,376 → 1,309(R2)다. 한 반입의 숫자가 기기마다 같아졌다.
2. 서버 결과가 늦으면(올린 창 25초, 이어 열기 8초) 큰 숫자는 `—`로 두고, 서버가 끝나는 대로 그 자리에서 바꾼다. 측정 중에는 이 경우가 없었다.
3. 새 기기에서 Ctrl K는 결과 필지(L1 · R1 · R2 · R4 대상) 안에서만 센다. 분류(건물 · 주차장 · 경작 흔적 없음) · 지명 · 농업진흥 조건은 올린 창과 같은 값이다. 대장 필지 전체가 필요한 조건(예: 비닐하우스)은 올린 창보다 작게 나올 수 있다. 서버 요청 3이 해결되면 같아진다.
4. 저줌 물빛 걷기는 내륙 저수지도 바다색으로 칠한다. 물을 물색으로 보이게 두었다.
5. 해안 정밀 마스크는 해안 칸(z10)마다 V-World 데이터 API를 한 번 부른다(게이트웨이 캐시 7일). 내륙 · 먼바다 칸은 부르지 않는다.
6. 전국 화면에서 목표 타일을 받는 동안 약 2초 머문 뒤 비행한다. gov-fusion 첫 0.25–0.5초는 바다색만 있는 프레임이다.
7. **서버 쓰기가 있다.** 명세가 정한 반입(import · confirm)만 했다. 점검 · 녹화로 남원 약 12건, 광주전남 약 10건을 반입했고, confirm마다 서버가 이 기관의 open L-* 결과를 새로 갈아 넣었다. 현장 배정과 영상 반입 요청은 누르지 않았다.
8. GPU: Ctrl K 모델 호출은 게이트웨이 `/agent/runs`로만 했다(남원 질문 1문항당 1회). 직접 GPU 스크립트는 0회다.
9. 대장 표본은 기관 원본이 아니다. V-World 연속지적 속성을 대장 모양으로 뽑은 파일이다(`sample/*.xlsx`). 광주전남 표본 786행은 모두 화양면 이목리다.
10. 영상은 헤드리스 Chrome 녹화(1440×900)다. 처음 0.25초만 잘랐고, 아이디와 질문은 한 글자씩 입력했다.
11. **재녹화 · 재촬영**: 판정이 본 `gov-fusion.mp4`(09-27 20:32) · `1440-namwon-3-result.png`(20:25)는 `app.js` 마지막 수정(20:33)보다 앞선 빌드였다. 09-29에 스틸 68장 · 영상 2편 · 원자료를 모두 최종 빌드로 다시 찍었고, 그 뒤 `registry.js` · `app.js`에서 파일 이름 한 줄을 고쳐 **한 번 더** 전부 다시 찍었다. 이 보고서의 수치는 마지막 촬영의 원자료다.
12. 판정 지적 1 · 3 · 5 · 6은 이번에 코드를 바꾸지 않았다. 판정 시점 코드에 이미 들어 있었고, 최종 빌드에서 다시 잰 값만 적었다(§0).
