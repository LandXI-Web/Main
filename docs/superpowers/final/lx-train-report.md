### 요청(소유 밖, 4차)
- **키트 K12 `line()`**: `mark`(표시 회차 인덱스)와 `digits` 옵션이 필요하다. HTML 점(비율 고정)도 필요하다. 지금은 `preserveAspectRatio="none"` 때문에 SVG 원이 타원으로 보여서 lx-train이 원을 지우고 HTML 점을 덧댄다. 이 옵션이 들어오면 `drawCurve()`의 덮어쓰기를 걷어낸다.
- **키트 K6 `bignum`**: `unit:'ratio'`가 `%`로 매핑된다(`UNIT.ratio = '%'`). 0–1 비율에 `%`가 붙으므로 `ratio`는 단위 없음이 맞다. 지금은 화면이 `unit:''`을 넘긴다.
- **서버 S-2 `/survey/rules/{id}/stats`**: `precision.unit`은 `%`인데 모델 기록은 비율이다. 계약에서 한쪽으로 통일해야 한다. `checked`(현장 확인 수) 봉투도 있으면 좋다. 지금은 `by_state`에서 합산한다.

## 폴백(계약 준수 어댑터)
1. S-2 `/survey/rules/{id}/stats`가 없음 → 큰 숫자는 결손으로 둔다. 응답 형식은 `{precision: 봉투, checked: 봉투|n_checked}`로 가정했다(계약 v1.2가 다르면 `fieldPrecision()` 한 곳만 고치면 된다).
2. S-8 `kind:train`이 없음 → 위 오류 문구. 곡선은 `job.progress`의 `metrics.precision`(또는 `metrics/precision(M|B)`)을 읽는다.
3. `/registry/models/{mid}`에 `samples`가 없음 → `표본 —`. 봉투나 숫자가 들어오면 그대로 표시한다.
4. `/feedback?model=` 필터가 없음 → 전체 `/feedback`을 결과층 이름으로 묶는다(`tasks.json` `sets`).
5. S-3 `/regions`가 없음 → 키트 K4가 배포 기록으로 대신한다(광주전남·남원·익산 황등이 보임).
6. AXIS-Label 주소를 모름 → `tasks.json` `labelUrl`(`http://localhost:8010/`)로 새 창을 연다. **지금은 죽은 링크다.** `E:\Auto_Label_project\start_axis.bat`의 기본 포트 8000이 vLLM과 겹쳐서 띄우지 않았다.
