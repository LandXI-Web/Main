# 서비스 카드 모델 되돌리기 · 다시 학습 (데이터-1 · 데이터-2)

> 2026-10-07 · 근거: 확인 대장 'AI 학습 데이터 자산' **데이터-1 확인 · 데이터-2 확인(GPU 한 장씩)**.
> 숫자는 모두 이 PC 서버 기록 · 측정 파일에서 옮겼다(지어낸 값 없음). GPU 작업은 전부 게이트웨이 대기열 · GPU 0 한 장으로만 돌렸다.

## 한 장 요약
- **비닐하우스 · 건축물 · 주차장 카드를 원판 모델로 되돌렸다(새 판 2.0 · LX 관리자 결재 기록).** 같은 검증 묶음으로 다시 재니 시험 모델보다 원판이 크게 낫다(비닐하우스 0.27 → 0.91 · 건축물 0.45 → 0.89 · 주차장 0.25 → 0.87).
- **원판은 네 가지를 함께 찾는 모델이라, 카드가 찾는 분류만 결과로 남게 했다.** 예전 비닐하우스 카드 결과에는 건물 · 경작지 · 주차장이 섞여 있었다(함양 2,724곳 옆에 건물 20,232 · 경작지 18,530).
- **이미 분석한 6개 지역을 대기열로 하나씩 다시 분석했고, 카드 숫자가 서버 흐름대로 바뀌었다**(예: 건축물 원주 '현장 확인 필요' 60 → 37필지).
- **곤포사일리지 카드는 되돌리지 않았다 — 정해 주셔야 한다.** 원판 곤포 모델은 지금 카드의 규칙 '휴경·전용 의심'을 평가할 수 없어 서버가 새 판을 막는다. 점수 차이도 거의 없다(0.963 대 0.967).
- **데이터-2: 비닐하우스 다시 학습(24.6시간)은 같은 묶음 0.873으로 원판 0.906보다 낮아 등록 요청하지 않았다.** 건축물 학습은 GPU 메모리 한도로 멈췄고, 같은 이유(원판이 이미 배운 자료)로 다시 띄우기 전에 정해 주셔야 한다.

## 1. 같은 검증 묶음 — 시험 모델과 원판을 함께 잼
**검증 묶음(항공 25cm):** 항공 토지피복 학습 묶음(표 1의 1 · AI Hub 토지피복 정답 가공)의 시험 몫 가운데, 원판 학습 · 검증 몫과 '서비스 만들기' 표본에 같은 칸이 없는 19,515칸에서 3,000칸을 무작위로 골랐다(고정 씨앗 20261007). 지역 경상 1,172 · 전라 1,122 · 경기 671 · 제주 35칸. 정답 도형 건물 31,409 · 경작지 20,695 · 주차장 4,516 · 비닐하우스 2,027개.

## 4. 정해 주셔야 할 것 · 알게 된 것
1. **곤포사일리지 카드:** 원판 곤포 모델로 새 판을 만들면 서버가 '휴경·전용 의심은 이 모델이 찾지 않는 대상'이라며 막는다(지금 1.0 판은 이 점검이 생기기 전에 만들어졌다). ⓐ 규칙 없이 AI 분석만 하는 판으로 되돌림 ⓑ 지금 그대로 둠(점수 차이 0.004). 또 보령(지금 곤포 배포 지역)은 25cm 항공 영상뿐이라 드론 곤포 모델로는 분석이 안 된다 — 지금 보령 결과는 9-30에 4분류 원판으로 대신 돌린 것이라 곤포가 0곳이다.
2. **남원 비닐하우스는 원판으로도 적게 잡힌다(703곳).** 검증 묶음 점수(0.91)와 달리 남원 2023 영상에서는 하우스 단지를 많이 놓친다(9-24 시각 점검과 같은 결론). 시험 모델의 14,792곳은 대부분 다른 분류가 섞인 수였다. 이것이 데이터-2 비닐하우스 다시 학습의 이유다.
3. **남원 필지 대조 수가 바뀌지 않았다.** 남원은 기관 실태조사(전 규칙) 결과를 시군구 한 줄로 쓰고 있어, 비닐하우스 카드로 다시 분석해도 그 줄이 그대로다. 같은 시군구에 카드가 여럿이면 필지 대조 줄이 하나를 같이 쓴다 — 카드마다 따로 둘지 정해야 한다.
4. 화면의 '분석에 쓴 모델' 한 줄은 모델의 분류(4가지)를 그대로 보인다. 결과는 카드 분류만 남지만, 이 줄도 '찾는 분류'로 보이게 고칠지 정해 주세요.

## 5. 데이터-2 — 다시 학습 결과 (10-09 기준)
| 차례 | 학습 자료(표 1의 2 · 원본 하드링크 · 이동 0) | 장수 | 설정 | 결과 |
|---|---|---|---|---|
| 1 비닐하우스 | 항공 25cm 비닐하우스 정리본 27,605장 중 검증 묶음 칸을 뺀 27,247장 + 비닐하우스 없는 학습 칸 8,000장(헷갈림 줄이기) · 학습 33,485 · 검증 1,762 · 도형 164,683개 | 35,247 | 원판에서 이어 학습 · 1280 · 20바퀴 · 배치 8 | 10-07 18:34 → 10-08 19:11(24.6시간) · **같은 검증 묶음 0.873(정밀도 0.84 · 재현율 0.81) < 원판 0.906 → 등록 요청하지 않음**(모델은 '결과 확인 전'으로만 남음) |
| 2 건축물 | 항공 25cm 건물 정리본 105,528장 중 103,448장 + 건물 없는 칸 3,000장 · 학습 101,126 · 검증 5,322 · 도형 1,505,773개 | 106,448 | 같음 · 10바퀴 | **멈춤** — 배치 8은 시작하자마자, 배치 4는 2시간 뒤 GPU 워커 메모리 한도(약 22GB)를 넘어 실패. 다시 띄우지 않음(아래) |

- 전력: 학습 내내 GPU 0 한 장(최고 약 170W · 상한 200W), GPU 1은 약 28W. 두 장 동시 고부하 없음.
- **알게 된 것:** 분류별 정리본은 원판이 이미 학습한 항공 묶음의 일부다. 그 일부로 이어 학습하면 새 정보가 없어 원판을 넘지 못한다(비닐하우스 실측). 건축물 정리본도 같은 원판 학습 자료의 일부라 같은 결과가 나올 가능성이 크고, 학습에 약 2일 동안 GPU 워커가 묶인다(그동안 XI맵 실시간 · 카드 분석이 대기열에서 기다림). 그래서 다시 띄우기 전에 정해 주시기를 요청한다.
- **남원 비닐하우스를 실제로 늘리려면 자료가 달라야 한다:** 원판이 놓치는 것은 남원 2023 영상의 하우스 단지다(검증 묶음 점수는 이미 0.91). 결과 확인에서 사람이 고친 남원 하우스 도형 · 경기 · 제주 정답의 비닐하우스(원판 학습에 없던 지역 자료인지 먼저 확인) 같은 **원판이 보지 못한 자료**를 더해야 한다.
- 실행기 `02. 데이터/training/retrain/run_retrain.py` · 기록 `progress.json` · `run_retrain.log`. 실패한 건축물 학습 2건 · 비닐하우스 새 모델(결과 확인 전)은 기록으로 남겨 두었다.
