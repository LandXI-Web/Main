## 1. 참고 페이지에서 배운 것(문법만)
Playwright 로 1440 · 390 두 폭에서 0.25초 간격 캡처와 스크롤 단계 캡처, 스타일시트를 읽어 정리했다.
| 항목 | 참고 페이지가 하는 것 | 우리에게 가져올 것 |
|---|---|---|
| 첫 화면 | 광고 영상이 화면을 꽉 채우고 제목은 영상 안에 있다. 시작 단추가 0.3초에 작게 나타나(0.5배) 0.8초 동안 옆으로 늘어나며 글자가 뒤따라 켜진다 | 영상은 안 쓴다(우리 첫 화면은 지도·지구). **'먼저 모양, 뒤따라 글'** 순서만 — 표기 → 메뉴 → 제목 → 설명 → 단추 |
| 이름 글자 하나씩 | **마지막 장면**에서 회사 이름 다섯 글자가 0.1초 간격으로 하나씩 떠오른다(각 0.5초 · 30px 위로 · 화면에 들어올 때 한 번) | 첫 화면 표기 'LAND-XI PLATFORM' 16글자를 0.06초 간격으로(총 1.4초) · 마지막 장면 큰 표기도 같은 문법(안 ⓑ). 글자는 그림이 아니라 **진짜 글자**(원칙 95) |
| 장면 제목 | 글자마다 칸을 나누고, 줄 전체에 색 띠를 글자 모양으로 잘라 왼쪽에서 오른쪽으로 쓸어 드러낸다(배경 위치 -100% → 0) | 띠 색은 우리 먹색 한 가지로 — 가리개가 걷히는 느낌만(배운 것 ②). 전부가 아니라 강조할 장면 한두 곳 |
| 스크롤 안내 | 따로 없다. 대신 화면 위 알약 모양 메뉴 셋(AI탭 · 살펴보기 · 경험하기)이 내려가면 고정되고 지금 장면이 진하게 — 어디까지 왔는지 알려 준다 | 안내는 우리가 더 친절하게(마우스 그림 + 한 줄 · 처음 스크롤에 사라짐). 메뉴는 우리 위 표기 줄의 '서비스 · 활용 사례'에 **지금 보는 장면 밑줄**(배운 것 ③) |
| 장면 전환 | 바탕색이 흰 → 옅은 파랑 → 짙은 파랑 → 남색으로 서서히 바뀌고, 판이 붙은 채(sticky) 안의 카드가 바뀐다 | 우리는 이미 판 하나에서 카메라가 움직이고 한 구간 반전이 있다 — 그대로 |
| 마지막 장면 | 광고 띠 → 바닥글(전화 · 저작권) → **회사 이름 글자 하나씩** 으로 맺는다. '시작하기' 단추가 늘 떠 있어 끝에서도 다음 행동이 있다 | 끝을 비워 두지 않는다 — 안 ⓐ 모토 + 두 단추 + LX 한 줄 / 안 ⓑ 큰 표기 글자 하나씩 + 처음으로. 늘 떠 있는 단추는 우리 위 표기 줄의 로그인이 이미 그 역할 |
| 속도감 · 고급스러움의 이유 | 움직임 종류가 적다(떠오름 0.5초 · 늘어남 0.8초 · 쓸어 드러남 두 가지). 한 화면에 움직이는 것 하나. 순서가 늘 같다(모양 → 글). 큰 그림이 화면을 채우고 글은 짧다 | 우리 법전(움직이는 것 1개 · 750ms --e-cam · 스태거 120)과 같은 방향. 더할 것은 '순서'와 '여는 글자 · 닫는 글자' 둘뿐 |

## 3. 시안 설명(`mock/index.html` · 우리 글 · 우리 그림)
### ① 첫 화면 표기 등장(메인-1) — `new-hero-enter-mid-1440` · `new-word-b-mid-1440` · `new-hero-1440` · 영상 `new-hero-enter-1440.webm`
- 순서: 표기 글자(0.2초~ · 글자마다 0.06초 · 각 0.5초) → 메뉴(1.1초) → 제목 두 줄(0.9 · 1.02초) → 설명 세 줄(1.14~1.26초) → 단추(1.38초). 지구는 0.4초부터 1.2초 동안 1.04배 → 제자리로 또렷해진다.
- ⓐ 글자 하나씩 떠오름(추천 · 0.4em 아래서) / ⓑ 왼쪽에서 쓸어 드러남(1.1초 · 가리개만 걷힘 · 글자 색 그대로).
- 글자는 `<i>` 로 나눈 **진짜 글자** — 드래그 선택 · 복사 · 검색 모두 된다. 읽기 보조기는 `aria-label="LAND-XI PLATFORM"` 한 단어로 읽는다.
### ② 스크롤 안내(메인-2) — `new-hero-1440`(왼쪽 아래) · `new-hero-390`(가운데 아래)
- 글이 다 선 뒤 2.2초에 켜진다. PC: 마우스 그림(휠 점이 1.6초마다 내려감) + '휠을 내려 보세요'(14px 회색) — 글 기둥과 같은 왼쪽 선. 휴대폰(터치 기기): 손가락 그림 + '위로 밀어 보세요' 가운데.
- 처음 스크롤(휠 · 터치 · 키)에 0.38초로 사라지고 다시 안 나온다. 이미 내려온 상태(새로 고침)면 안 켜진다.
### ③ 마지막 장면(메인-3) — `new-fin-a-1440` · `new-fin-b-1440` · `-390`
- 공통: 지구가 또렷해지며(1초) 글이 뒤따른다. 빈 회색 칸 없이 바닥글이 바로 이어진다. '처음으로 ↑'는 연출 없이 바로 이동(원칙 95).
- ⓐ 마무리(추천): 모토 → 두 줄 문장(의미 단위 줄바꿈 · 휴대폰도 두 줄) → 로그인 · 서비스 보기 → 1.5초 뒤 '한국국토정보공사(LX)가 만들고 운영합니다' → 처음으로.
- ⓑ 다시 처음으로: 큰 표기 'LAND-XI PLATFORM' 글자가 0.07초 간격으로 떠오름(휴대폰은 'LAND-XI / PLATFORM' 두 줄) → 처음으로. 첫 화면과 같은 글자로 열고 닫는다.
### ④ 그 밖에 배울 것 셋(메인-4)
- 장면 제목 쓸어 드러남(둘째 장면에 적용해 둠 · `data-sweep`) · 지금 보는 장면의 메뉴 밑줄(화면의 35% 넘으면) · 첫 화면 지구 천천히 또렷해짐.
### 공통
- `prefers-reduced-motion: reduce` 면 모든 전환이 꺼지고 글이 바로 보인다(안내 그림의 움직임도 정지).
- 시안은 지도 대신 지구 사진(`globe-hero.webp`)과 서비스 카드 그림을 쓴다 — 구현은 v3 메인의 지도 무대 위에 같은 타이밍으로 얹는다(코드 수정은 확인 뒤).

## 5. 먼저 제안(원칙 57 — 채택은 사용자)
- PC 마지막 장면의 글이 안 켜지는 것은 시안과 별개로 **지금 메인의 결함**이다 — 확인과 무관하게 바로 고치는 것이 맞지 않을까(구현 담당 · 창 축소 조건 + 판 여유 한 화면).
- 휴대폰 마지막 문장의 글자 단위 끊김도 같이(두 줄 `<span>` 으로 의미 단위 줄바꿈).
