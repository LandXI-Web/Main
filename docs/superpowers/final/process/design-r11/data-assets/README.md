## 한 장 요약
- **지금 서비스 카드 4개(비닐하우스 · 건축물 · 주차장 · 곤포사일리지)는 '학습 흐름 시험'으로 만든 모델을 쓰고 있다.** 표본 60~200장으로 3바퀴만 돈 모델이라 검증 점수가 비닐하우스 0.66 · 건축물 0.56 · 주차장 0.40이다. 같은 PC에 15만 장으로 학습한 원판 모델(검증 0.89)과 남원 드론 2천 장으로 학습한 곤포 모델(0.97)이 이미 있다. **학습 없이 원판으로 되돌리는 것이 가장 싸고 큰 개선이다.**
- **비닐하우스 25cm 전용 재학습 자료는 충분하다.** 항공 25cm 비닐하우스 사진 27,605장 · 도형 166,710개 + 정답에 비닐하우스가 따로 있는 경기 · 제주 토지피복 정답. 조각 문제는 모델이 아니라 묶기(GEO-1 설계)로 푼다.
- **변화 탐지 학습 자료가 새로 확인됐다.** 도시 건물 변화(두 시점 4만 장) · 수변구역 변화(항공 · 위성 · 레이더) · 국립공원 변화(드론 · 위성). 지금 '국토 변화' 카드는 학습 모델 없이 지수 계산만 한다.
- **새 서비스는 '자료 + 실제 결과'가 함께 있는 것부터:** 석면 슬레이트 지붕 · 태양광 · 사료작물 재배 확인 · 하천구역 건물 점유(전국 결과 있음) · 바닷가 점유(전북 · 전남 결과 있음).

## 먼저 제안 — 이런 것도 필요하지 않을까요?
- **모델마다 '학습 자료 출처 · 이용 조건' 한 줄을 모델 카드에** — 해외 기관에 서비스를 열 때 LX 관리자가 반출 가능 여부를 바로 판단한다.
- **'서비스 만들기' 시험 모델에 '시험' 표시** — 이번처럼 시험 모델이 실제 카드에 붙는 일을 막는다(LX 관리자 승인 화면에 검증 점수 · 학습 장수 함께).
- **결과 확인에서 고친 도형을 학습 자료로 쌓기** — LX 직원이 고친 만큼 다음 학습이 좋아진다(지금 표본 대장과 연결).
