# 바깥에서 올린 영상을 LX AI 서버에서 돌려도 되나 — 정부 보안 기준 검토

> 2026-10-10 · 지위: **검토(코드 수정 0 · 사용자 확인 전)**. 확인 대장 항목 없음 — 문서 · 제안만.
> 사용자(10-10): "외부에서 타인이 분석하고 싶은 영상을 올려서 우리 내부 AI 서버에 전송해서 돌린다는게 정부시스템 보안 가이드라인에따라 가능한 영역인지도 검토해줘"
> 관련 결정: 영상은 이용자가 우리 쪽에 올린다(원칙 88) · 내보내는 것은 AI 분석 결과이고 영상은 아니다(원칙 69) · API로도 분석을 맡긴다(원칙 54 · 174).
>
> **이 문서는 법률 자문이 아닙니다.** 공개된 법령 · 지침 원문을 읽고 정리한 것이며, 최종 판단은 LX 정보보안처와 국가정보원 보안성 검토로 받아야 합니다.

## 0. 한 줄 결론
**조건부 가능.** 2026년 5월 1일 국가정보원 지침이 바뀌면서 '업무망 · 인터넷망 분리' 조항이 지워지고, 정보의 중요도(기밀 · 민감 · 공개)에 따라 지키는 방식으로 바뀌었습니다. 그래서 "인터넷으로 받은 영상을 내부 AI로 분석"하는 것 자체를 막는 조항은 없습니다.
다만 **지금 구조(개인 개발 PC를 해외 사업자 터널로 바깥에 연 것)는 실제 기관 영상을 받는 운영에 그대로 쓸 수 없습니다.** 운영 전에 국정원 보안성 검토, 인터넷 쪽 업로드 서버와 내부 AI 영역의 분리, 검사 뒤 내부로 넘기는 장치, 공간정보 보안 규정에 따른 취급이 필요합니다.

## 2. 질문별 답

### ① 외부 기관 · 개인이 인터넷으로 올린 영상을 LX 내부 AI 서버에서 처리하는 것 자체가 되나
- **된다(조건부).** 바뀐 지침은 망분리 조항(제40조)을 지우고, "공개 등급 시스템은 인터넷과 통신하거나 인터넷에 둘 수 있다"(제39조의5 ③), "민감 정보는 같거나 높은 등급 시스템에서 처리하되, 국가망 보안체계(N2SF) 가이드라인 통제를 지키면 낮은 등급에서도 처리 가능"(제39조의3 ①)으로 정했습니다.
- 국정원 'AI 보안 가이드북'(2025-12-10)도 구축 유형을 '내부망 전용', '내부망 AI의 외부망 연계', **'대민 서비스용 AI의 내부망 연계'** 셋으로 나눠 대책을 냅니다 — 우리 경우가 셋째 유형으로, 금지가 아니라 대책 대상입니다(가이드북 본문은 직접 읽지 못함 — 보도 기준).
- **개인**이 올리는 것은 더 조심: 공개제한 공간정보를 받는 쪽이 아니라 LX가 '받아 처리'하는 것이지만, 개인이 가진 영상이 공개제한이면 그 개인이 정당하게 가진 것인지(보안심사를 거쳐 받은 것인지) 확인할 길이 필요합니다. 처음에는 **서비스를 받는 기관만**(이미 정한 범위)으로 두는 것이 맞습니다.

### ② 영상 종류별 보안 처리 · 공개 심사 의무
| 영상 | 분류(공간정보 세부분류기준 별표 1) | 올리기 전에 필요한 것 | Land-XI가 할 일 |
|---|---|---|---|
| **지자체 보유 항공 · 드론 정사영상** | 군사 · 국가보안시설이 보이면 **비공개**. 지운 흔적이 남았거나, 좌표가 있고 30m보다 정밀하면 **공개제한**. 25cm보다 정밀한 항공사진은 공개라도 제공 기록 필요 | 기관이 보안처리(보안시설 삭제)를 끝냈는지. 지도 · 측량용 사진에는 군사시설 · 비공개 사항 표시 금지(공간정보관리법 시행령 제15조) | 공개제한으로 취급(관련자만 · 기록 · 국외 반출 금지). '보안처리 끝남' 확인 없으면 받지 않음 |
| **민간 드론** | 같은 기준 | 보호구역 안 군사시설 촬영 금지(공공기관 공공사업은 관할 부대 승인 시 예외). 촬영 금지 시설이 있을 수 있는 곳은 촬영 4일 전(근무일) 국방부 허가(드론 원스톱). 사람이 찍히면 개인정보 보호법의 이동형 영상기기 규칙 | 촬영 허가 여부 확인란. 촬영 뒤 공개 전 보안 검토 절차가 따로 있는지는 **확인 못 함** |

- 공개제한 공간정보를 **받으려면** 원래 관리기관의 보안심사가 필요합니다(국가공간정보 기본법 제34조 ② · 제35조의2). **LX는 그 보안심사를 하는 전문기관**입니다(같은 법 시행령 제24조의2 ① 제1호 · LX 공간정보 보안심사 안내). 다만 기관이 자기 영상을 분석 맡기는 경우가 '제공'에 해당해 심사를 받아야 하는지, '처리 위탁'으로 보는지는 **확인 못 함** — 보안 부서 질문 4번.

### ⑤ 결과(AI 분석 도형)만 내보내는 것의 보안 성격
- **영상을 내보내는 것보다 훨씬 가볍지만, 자동으로 '공개'는 아닙니다.** 국가공간정보 기본법은 공개제한 정보 "또는 그 정보를 활용하여 생산한 공간정보를 제3자에게 제공할 때의 보안관리"를 심사 항목으로 둡니다(제35조의2 ① 제2호). 국토지리정보원 규정도 '원시자료를 이용하여 생산한 성과물'을 접근 권한 관리 대상에 넣습니다(제8조 ② 제4호).
- 도형 결과(필지별 판정 · 변화 구역)는 영상과 달리 '해상도' 기준이 바로 맞지 않습니다. 다만 **군사 · 국가보안시설의 명칭 · 속성 자료는 비공개**(별표 1 '기타 공간정보')이므로, 보안시설을 가리키는 결과는 내보내면 안 됩니다.
- 결론: 결과는 **받는 기관 관할 안 · 그 기관에만**(이미 정한 범위) 내보내고, 보안시설 주변 결과를 빼는 방법은 보안 부서와 정합니다(우리는 보안시설 위치를 가질 수 없음 — 질문 12번).

## 3. 대안 구조 둘
| | ⓐ 인터넷 쪽 업로드 서버 → 검사 → 내부 AI로 한 방향 전송(추천) | ⓑ 기관 안(또는 국가 클라우드)에 분석 장치를 두고 결과만 받기 |
|---|---|---|
| 모양 | 공개 등급 영역 업로드 서버(LX 데이터센터 또는 목록에 있는 국내 클라우드)가 받음 → 악성코드 · 형식 · 다시 쓰기 · 보안처리 확인 · 지문 → 국정원 검증 제품으로 내부 AI 영역에 한 방향 전송 → AI 분석 → **결과 도형만** 공개 영역으로 되돌림 → 기관 화면 · API | 기관 폐쇄망(또는 국가정보자원관리원 같은 정부 시설)에 GPU 장치 + Land-XI 분석 모듈. 영상은 기관 밖으로 나가지 않고, LX는 모델 갱신과 결과 도형만 주고받음 |
| 좋은 점 | 지금 결정(이용자가 올림 · API로 맡김 · 결과만 내보냄)을 그대로 지킴. 한 곳에서 전국 · 해외 기관을 받음. AI를 LX가 계속 다듬음 | 공간정보 보안 · 국외 반출 · 개인정보 걱정이 가장 적음. 폐쇄망 기관도 쓸 수 있음 |
| 어려운 점 | 보안성 검토 · 망연계 장비 · 운영 서버 마련(시간 · 예산). 큰 영상(TB)은 디스크 전달이 여전히 필요 | 기관마다 장비 · 설치 · 모델 갱신 부담. '영상은 이용자가 우리 쪽에 올린다'와 다름 → 사용자 결정 필요. 기관 간 비교 · 전국 결과 쌓기가 어려움 |

**추천: ⓐ를 기본으로, ⓑ는 폐쇄망 · 비공개 자료 기관용 선택지로만.** 그리고 둘 다보다 먼저 — **영상을 받지 않는 길(LX 보유 영상 · 영상 API 범위만 지정)을 맨 앞에** 둡니다. 외부 영상이 오가지 않으니 보안 부담이 가장 적고, 전국 수시 변화 서비스는 원래 이 길입니다(원칙 136 · 171).

## 5. 먼저 제안(이런 것도 필요하지 않을까요?)
1. **보안 확인서 한 장(기관에 주는 것)** — 지자체 보안담당관이 "Land-XI에 올려도 되나"를 물을 때 내밀 문서(보안성 검토 결과 · 보관 기간 · 결과만 내보냄 · 접속 기록). 누가: 기관 정보보안 담당 · 왜: 기관 쪽 승인이 없으면 공무원이 올리지 못함.
2. **올린 영상의 지움 증명** — 30일 뒤 지운 기록(무엇을 · 언제 · 지문)을 기관 관리자 화면에서 보고 내려받음. 누가: 기관 관리자 · 왜: 감사 때 "맡긴 영상이 어디 남아 있나" 질문에 답.
3. **보안시설 범위 빼기 규칙을 보안 부서와 함께** — 결과를 내보낼 때 빼야 할 범위를 LX 보안 부서가 관리하는 방식으로. 누가: LX 정보보안처 · 왜: 결과 도형도 비공개 대상이 될 수 있음.

## 6. LX 정보보안처 · 국정원 보안성 검토에 물을 것(그대로 보내도 됩니다)
> Land-XI는 LX가 운영하는 GeoAI 분석 서비스입니다. 지자체 등 서비스를 받는 기관이 드론 · 항공 · 위성 영상을 인터넷으로 올리면(화면 또는 API), LX AI 서버가 분석하고 결과 도형(필지별 판정 · 변화 구역)만 그 기관에 돌려줍니다. 원본 영상은 분석 끝 30일 뒤 지웁니다. 아래를 여쭙습니다.

1. 이 서비스는 「국가 사이버보안 기본지침」(2026-05-01) 제15조 제1항 제20호(다른 기관 시스템 연동) · 제23호(인공지능 활용)에 따른 국정원 보안성 검토 대상입니까? 국토교통부를 거치는 절차와 걸리는 기간은 어떻게 됩니까?
2. 올라오는 영상(좌표가 있는 드론 · 항공 정사영상 — 공간정보 세부분류기준상 '공개제한')과 AI 결과 도형을 LX는 업무정보 등급(기밀 · 민감 · 공개) 중 어디로 분류합니까? AI 서버는 어느 등급 영역에 두어야 합니까?
3. 인터넷 업로드 서버 → 내부 AI 영역 전송에 LX가 쓰는 망연계(한 방향 전송) 장비, 악성코드 검사, 파일 무해화 표준이 있습니까? 수십 GB짜리 GeoTIFF에도 적용됩니까?
4. LX 자체 공간정보 보안관리규정이 있습니까? 기관이 분석을 맡기며 보낸 공개제한 영상을 LX가 받는 것이 '제공'(보안심사 필요)입니까, '처리 위탁'입니까? 취급자 지정 · 복제 대장 · 보관 기간(우리 안 30일) 기준은?
5. 해외 사업자(Cloudflare) 터널 · CDN을 거쳐 영상을 받는 것이 '민간 클라우드 이용'(제24조의4 도입 가능 목록)이나 '공개제한 공간정보 국외 반출'에 해당합니까? 운영 때는 LX 공식 회선 · 도메인으로 옮겨야 합니까?
6. 운영 서버 위치로 LX 데이터센터 · 국가정보자원관리원 · 보안인증(CSAP)을 받은 국내 클라우드 중 무엇이 허용됩니까?
7. 접속 기록(제55조, 1년 이상)에 결과 내려받기 · API 호출까지 넣어야 합니까? LX 보관 기준은?
8. 지자체 공무원이 공개제한 영상을 LX가 운영하는 외부 웹 · API로 보내는 것이 기관 쪽 규정(제66조 업무자료 공식 소통 수단)에 맞으려면 LX가 기관에 어떤 증빙을 주어야 합니까?
9. 영상 속 사람 · 차량에 대해 LX는 개인정보 처리 수탁자가 됩니까? 기관과 맺을 위탁 문서(개인정보 보호법 제26조) 서식이 있습니까?
10. 민간 드론 영상은 국방부 항공촬영 허가 외에 공개 · 제공 전 별도 보안 검토가 필요합니까? 허가 여부를 LX가 확인할 방법은?
11. 국정원 'AI 보안 가이드북'(2025-12)의 '대민 서비스용 AI 시스템의 내부망 연계' 체크리스트를 LX가 적용한 사례나 사본이 있습니까?
12. AI 결과 도형만 내보낼 때도 '공개제한 정보를 활용하여 생산한 공간정보'(국가공간정보 기본법 제35조의2 제1항 제2호)로서 보안관리 대상입니까? 보안시설 주변 결과를 빼는 방법은 누가 어떻게 정합니까?
13. 해외 기관이 자기 나라 영상을 올리고 결과를 받아 가는 경우, 국내 결과를 해외 기관에 주는 경우에 각각 걸리는 규정이 있습니까?

## 8. 확인 못 한 것
- Cloudflare 터널이 '도입 가능 목록'의 민간 클라우드에 해당하는지, 해외 사업자 망 통과가 공개제한 공간정보 국외 반출에 해당하는지.
- 기관이 분석을 맡기며 보낸 영상을 LX가 받는 것이 '제공'(보안심사)인지 '처리 위탁'인지.
- LX 자체 공간정보 보안관리규정 · 사이버보안 세부지침의 내용(공개되어 있지 않음).
- N2SF 가이드라인 · AI 보안 가이드북 본문(보도와 요약으로만 확인).
- 상용 위성 판매사 이용 조건, 민간 드론 촬영 뒤 공개 전 별도 검토 절차.
- 기관 쪽(지자체) 규정에서 외부 웹 업로드를 허용하는 조건.
