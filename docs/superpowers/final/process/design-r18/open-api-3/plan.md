## 2. 1차 고침 — 키를 기관 공유에서 떼기 · 결과 조회 경로 정리 · 약 5일
**무엇**
- DB(그때 빈 다음 번호): `api_applicants`(구분 internal · lx_service · external · 기관 · 부서 · 시스템 이름 · 담당자 · 전화 · 메일 · 목적 · 상태) · `api_keys` 에 `applicant_id` · `scope`(전국 / 시도 · 시군구 코드 목록 / 나라) · `rights`(read · read_analyze) · `sources` · `area_once · area_day · area_month` · `allow_ips` · `callback_url` · `hook_secret_ref` 더함, `tenant_id` 는 비울 수 있게(기관 신청자일 때만). `cards.api_id`(영문 이름 — building · farm …) · `cards.api_sources`(분석할 수 있는 원천).
- **서비스 결과 장부** `service_results`(card_id · 서비스 판 · 지역 칸(읍면동 코드) · source · year · job_id · 만든 날 · 대체됨) — 작업이 끝날 때 한 줄씩, 지난 결과는 `space_guides.sets` 와 끝난 작업에서 채움(지금 파일 영상 결과는 source `lx` · 그 영상 연도).
- 외부 창구 새 주소: `/v1/me` · `/v1/services` · `/v1/services/{서비스}` · `/coverage` · `/results`(region · bbox · source · year · kind · since · cursor · crs) · `/results/search`(도형) · `/summary` · `/exports/{geojson|shp|parcels}` · `/v1/usage`. 결과 줄 모양은 1차 `_props` 에 source · year · emd_cd · analyzed_at 더함. 1차 주소(`/v1/results` 등)는 지움(결정 API3-1차키 ⓐ일 때 — 켜진 키 0).
- `_auth`: 공유 판정 → 키 범위 · 권한 · 원천 판정. 범위 밖 = 404.
- 화면: LX 관리자 '배포 → API' 탭을 **신청자 묶음 × 서비스 줄**로(키 만들기 서랍에 범위 · 권한 · 원천 · 넓이 한도 더함). 기관 관리자 '받은 API 키'는 그 기관이 신청자인 키만.
- **완료 기준**
  1. 서비스 공유를 켜고 꺼도 키 호출 결과가 바뀌지 않음(기관 공유와 떨어짐).
  2. 범위 '전라북도' 키 → 남원 결과 200 · 광주전남 결과 404(상대 값 0건). 범위 밖 bbox · 도형도 404.
  3. 받은 수 = 장부 수 = XI맵 · 기관 화면 같은 시점 수(남원 + 다른 시도 한 곳, 차이 0). bbox 조회 오류 0.
  4. `source` · `year` 로 거른 결과의 원천 · 연도가 모두 맞음 · 응답마다 출처 표시.
  5. 1차 시험 7개 중 남는 것(발급 · 섞지 않음 · 형식 셋 · 폐기 · 기간 끝 · 한도 · 기록 수) 통과 + 새 시험.
  6. 응답에 내부 이름 0(작업 번호 · 파일 경로 · 장비 이름 금지어 검사).
- **시험**: 자동(GPU 0) — 범위 판정(시도 · 시군구 · bbox 걸침 · 도형) · 권한(조회 키로 분석 주소 403) · 원천(LX 보유를 외부 키로 404) · 장부 채우기 결과 수 대조 · 쪽 끝까지 받은 수 = total · 좌표계 바꿔 넓이 차 0.1% 안.
- **작업량**: 서버 3일(장부 · 채우기 1.5 포함) · 화면 1일 · 시험 · 실증 1일.

## 3. 2차 — 분석 호출(영상 원천 입력 분석 길 · 작업 · 상태 · 알림) · 약 11일
**무엇**
1. **영상 원천 장부(0.5일)** — `imagery` 표에 파일 없는 원천 행: `remote:ngii-aerial:{연도}`(UTM-K 타일 · 연도 층 · 2011–2025) · `remote:vworld`(웹 메르카토르 19단계 · 최신) — footprint = 전국, layer = 호출 사양 · 속도 · 출처 문구. 키 값은 `.env` 에서만.
2. **원천 읽기기(3일)** — `workers/` 에 칸(지금 칩 단위)마다 그 자리 타일을 불러 이어 붙이고 좌표를 맞춰 분석에 넘김 · 디스크에 남기지 않음 · 원천별 속도 조절(Redis 토큰 통) · 다시 받기 · 빈 타일 = 가림/없음 → `gaps`. 영상 파일과 같은 입력 모양이라 추론 코드는 그대로. **XI맵 다시 짜기(XI맵-1 ⓐ)가 같은 엔진** — 그쪽이 먼저 만들면 이 칸 0.5일(잇기만).
3. **적합도(1일 + GPU 한 장 밤 1회)** — 서비스마다 원천별로 같은 자리 결과를 파일 영상 결과와 비교(10-09 방식)해 `cards.api_sources` 를 채움. 지금 기대: 건축물 · 경작 · 주차장 열림, 비닐하우스는 재학습(영상API-3 ⓐ 순서) 뒤.
4. **범위 · 견적(1일)** — 행정구역 코드(시군구 · 읍면동 경계) · bbox · GeoJSON 검사(꼭짓점 · 넓이 · 나라 밖 · 키 범위) → 넓이 · 칸 수 · 예상 시간(부르기 + GPU) · 남은 넓이 한도 · 장부에 이미 있는 비율.
5. **분석 호출 · 상태(1.5일)** — `/analyses/estimate` · `POST /analyses`(같은 요청 막는 열쇠 24시간 · `reuse` 면 장부에 있는 칸은 빼고 없는 칸만 작업) · 상태 사람 말 · 취소 · 결과. `POST /jobs` 를 함께 써서 작업 행 · 대기열 · 전력 규칙 그대로, `options.via='api'` · `options.source/year` · 우선순위 가장 낮음 · API 작업 전체 1건.
6. **한도 넘는 분석(0.5일)** — 결정 API3-분석승인 ⓐ: 넓이 한도 안 = 바로, 넘으면 결재함 `api_held` 한 줄 → 승인/반려 → 상태 · 알림.
7. **알림(1.5일)** — 발송기(서명 HMAC · 1분 · 5분 · 30분 · 2시간 · 6시간 · 24시간 · 보낸 기록) · 키 줄에 '알림 마지막 성공/실패'.
8. **시험 · 실증(2일)**.
- **완료 기준**
  1. 영상 파일이 없는 시군구(등록 영상 64곳 밖) 한 곳의 2㎢를 `ngii-aerial 2025` 로 호출 → 끝 알림 → 결과가 XI맵 같은 자리 · 같은 원천 · 연도에 같은 수로 보임(결정 API3-결과장부 ⓐ일 때). 디스크에 남은 영상 0.
  2. 같은 본문 · 같은 열쇠 세 번 → 작업 1건. 같은 조건 다른 열쇠 → `reused_share` 1.0 · GPU 0 · 1분 안 끝.
  3. 넓이 한도 초과 → 413 + 나눌 읍면동 목록 · 하루 한도 초과 → `held` → 관리자 승인 → 돎 · 반려 사유 = 상태 = 알림.
  4. 비닐하우스 + `vworld` → 422 `unfit_source`(적합도 표 그대로). 가림 지역 칸 → `gaps` 에 적히고 실패가 아님.
  5. API 분석이 도는 동안 화면에서 누른 읍면동 분석 첫 결과 10초 안 · 두 장 동시 고부하 0 · 언어 모델 그대로.
  6. 알림 받는 쪽을 끄면 다시 보낸 기록이 쌓이고 켜면 옴 · 서명 확인 성공.
  7. 원천 호출 속도가 정한 값을 넘지 않음(호출 기록으로 확인).
- **실증**: 서로 다른 시도 두 곳(영상 파일 있는 곳 1 · 없는 곳 1) · 2025 · 2021 두 해 · 랜디에어를 흉내 낸 시험 키(LX 다른 서비스 구분) · GPU 한 장.
- **작업량**: 약 11일(엔진을 XI맵과 나누면 약 6일 + 밤 GPU 1회).
- **먼저 정할 것**: `vworld_analysis` 켜기 · 국토지리정보원 호출 길(키 없는 지도 화면용 길 vs 공식 오픈 API 키) — 영상API-2와 같은 사용자 결정. 정해지기 전에는 `ngii-aerial` 만, 또는 둘 다 '시범'으로.

## 7. 확인 못 한 것
- 국토지리정보원 연도별 호출 길은 공식 안내 문서가 없는 지도 화면용 길(10-09 검토) — 운영 호출량 · 약관은 정식 확인 전.
- 브이월드 약관의 '저장 · 복제 제한'이 분석 결과(영상이 아닌 도형)를 쌓아 남에게 주는 데 걸리는지.
- 랜디에어의 실제 연동 방식(그쪽 서버가 고정 주소인지 · 알림을 받을 수 있는지) — 신청 때 확인.
- 지금 `jobs.card_id` 가 비어 있는 작업이 많을 수 있음(이 PC의 시험 DB 연결로는 확인 못 함) — 장부 채우기는 `space_guides.sets` 와 배포(deploy_id)로 서비스를 찾는 길도 둔다.
