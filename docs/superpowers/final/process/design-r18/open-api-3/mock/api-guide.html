두 가지 API

GET결과 조회

이미 만든 AI 분석 결과를 범위 · 영상 연도로 골라 받습니다.
GeoJSON · SHP · 필지 엑셀.

curl -H "Authorization: Bearer $LANDXI_KEY" \
 -G https://api.land-xi.dev/v1/services/building/results \
 -d region=45190 -d year=2025

POST분석 호출

범위와 영상 원천을 정하면 그 자리 영상을 불러 분석합니다.
끝나면 알림 주소로 알려 드립니다.

차례 기다림→영상 부르는 중→AI 분석 중→끝
curl -X POST -H "Authorization: Bearer $LANDXI_KEY" \
 https://api.land-xi.dev/v1/services/building/analyses \
 -d '{"area":{"bbox":[127.38,35.40,127.41,35.42]},
      "imagery":{"source":"ngii-aerial","year":2025}}'
