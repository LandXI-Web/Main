**정리** — 다섯 중 Land-XI 가 모델과 결과를 쥐고 있는 것은 **영농관리(모델)와 해양쓰레기(결과)** 둘이다. 생활환경·영농관리의 **운영 화면은 외부 시스템**이고, 도로안전은 **설계 시안**이며, 관광인파는 **아직 아무것도 없다**. 그래서 "Land-XI 가 100% 만들어 뿌리는 구조가 아니다"라는 사용자 말이 실제와 맞다 — 제공 방식을 나눠야 한다(concept.md).

## 1. 도로안전 관리(2026) — 공개 대시보드 분석
주소: https://mini531.github.io/namwon-smart-village/namwon3/dashboard.html · 캡처 `shots/road-*.png`

### 1-1. 무엇인가
- 이름은 **Namwon GeoVision**. 바닥에 남원시 마크 + LX 마크, "AI 서비스 고객센터 063-713-1218". 옛 Land-XI 자산의 '남원시 GeoVision 플랫폼'과 같은 이름 — 3년차(도로안전) 사업의 **기관 분기 플랫폼 시안**으로 보인다.
- **자료가 화면 파일 안에 고정된 시안**이다(케이스 목록·분석 이력이 화면 자료 파일에서 읽힘, 서버 호출 없음). 그래서 기능 구조는 신뢰할 수 있지만 숫자는 실제 결과가 아니다.
- 메뉴 아홉: **대시보드 · 데이터 관리 · 분석 실행 · AI 분석 지도 · 보고서 · 통계 · 서비스 지원 · 서비스 관리 · 알림 · MY**.

### 1-3. 이 시안이 말해 주는 것
1. 기관 분기 플랫폼은 **연차 사업이 쌓이는 그릇**이다 — 3년차 화면에 1·2년차 과제가 그대로 들어 있다. 우리 '남원 누적' 모형(concept.md)과 맞는다.
2. 기관이 **영상을 올리고 분석을 직접 실행**한다(과제 선택 → 영상 → 실행). LX 가 돌려 주는 것이 아니라 기관 담당자가 자기 자료로 돌린다. 저장 공간이 기관 단위로 할당·증량된다.
3. 결과의 행정 가공(케이스 · 조치 상태 · 회차 · 관심 구역 알림)이 화면의 중심이다 — 옛 명세의 '기관 행정 가공은 기관 몫'이 그대로 구현돼 있다.
4. 입력이 **정사영상 + 차량 블랙박스** 두 갈래 — Land-XI 의 XI맵(정사영상)만으로는 블랙박스 흐름이 없다. 도로안전을 ⓐ 로 가져오려면 차량 영상 입력 경로가 필요하다.

## 2. 영농관리(2025) — 로그인 화면만
주소: https://jeonnam-ai.kr:18443/auth/nw/login · 캡처 `shots/farm-1-login.png` · **로그인은 시도하지 않았다**(계정 없음).

- 제목 "남원 AI 플랫폼", 왼쪽 그림 위 "NAMWON GEOVISION PLATFORM". 남원시 마크 + LX 마크, 문의 063-713-1218(평일 09–18시). 회원가입 · 아이디 찾기 · 비밀번호 찾기(아이디는 이메일).
- 소개 카드 넷: **사료작물 정보 분석**("이탈리안 라이그라스(IRG), 호밀, 옥수수, 수단그라스 등 4종의 사료작물을 학습한 모델로, 각 작물의 재배지를 자동 탐지하고 필지 단위로 면적과 위치를 정량 분석") · **농지 활용 분석** · **비닐하우스 정보 분석** · **방치 쓰레기 정보 분석**.
- 주소가 남원시 것이 아닌 별도 도메인(포트 18443)이고, 화면 부품 이름이 한 업체 틀로 통일돼 있다 → **외부(수행사) 서버에서 운영되는 시스템**으로 보인다. 정확한 운영 주체·계약 형태는 **사용자 확인 필요**.
- 사용자 원문의 "사료작물 8종"과 로그인 화면·모델의 "4종(IRG·호밀·옥수수·수단그라스)"이 다르다 — **확인 필요**(생육기·생산기를 나눠 8종인지, 추가 작물이 있는지).
- 로그인 뒤 화면은 보지 못했으므로 기능 목록은 알 수 없다. 다만 3년차 시안(1절)의 분석 과제 목록에 같은 이름(사료작물 생육기·생산기, 곤포사일리지, 비닐하우스, 농지 활용, 방치 쓰레기, 적치물)이 들어 있어 **같은 계열 시스템의 다음 해 판**으로 읽힌다.
