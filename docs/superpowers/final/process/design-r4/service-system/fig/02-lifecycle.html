서비스 생애 — 연차 사업이 쌓여 기관 플랫폼이 된다

한 서비스가 태어나서 유지되는 일곱 단계. 아래는 남원시 예 — 해마다 사업이 하나씩 붙고, 앉은 서비스는 계속 갱신된다.

1

연차 사업 수주

기관이 원하는 업무 하나(예: 도로안전)

영업 · 기관
2

프로젝트

영상 올리기 → 라벨링 → 학습 → 결과 확인. 프로젝트장이 1차 소유

LX 직원
3

모델 + 규칙

무엇을 세고 나누나, 어떤 기준과 비교하나(기본 · 표준 양식 · 맞춤)

LX 직원
4

서비스 카드 발행

관리자 승인(반려 사유 남김). 버전이 붙는다

LX 관리자
5

기관 분기 제공

기관 플랫폼 홈에 카드가 놓인다. 부서는 자기 카드만

기관 관리자 · 부서
6

유지 · 갱신

새 영상마다 다시 분석, 정확도 지켜보기, '실제와 다릅니다' 받기, 재학습 지시

LX 관리자 (→ 프로젝트장)
7

다음 해 사업

새 업무가 붙거나(누적) 같은 서비스가 범위를 넓힌다(확대)

영업 · 기관 · LX
