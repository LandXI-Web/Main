## 1. 실제 서비스 — 지금 어디서 돌고 있나(한 줄씩)
| 서비스 | 한 줄 |
|---|---|
| 생활환경(2023) | 방치쓰레기·불법소각장·방치폐가 — 지금은 **외부 운영 시스템** 안에 '방치 쓰레기 정보 분석'으로 이어짐. Land-XI 엔 모델·결과 없음 |
| 영농관리(2025) | 경작·비경작 · 비닐하우스 · 사료작물 · 곤포 — 운영 화면은 **외부 시스템(남원 AI 플랫폼, 로그인 필요)**, **모델 5종은 Land-XI 안에 있음** |
| 도로안전(2026) | 포트홀 · 차선 · 도로시설 파손 — **공개 설계 시안**(Namwon GeoVision, 자료가 화면에 고정). 정사영상 + 차량 블랙박스. Land-XI 엔 포트홀 모델 없음 |
| 관광인파(2027 예정) | 교통혼잡 · 인파혼잡 — **아무것도 없음**(모델 개발 전, 설계만) |
| 전남 해양쓰레기(2025 → 2027 확대) | 해안 쓰레기 종류별 — **Land-XI 안에 결과 있음**(여수 항공 2025 · 드론 2026). 외부 시스템 없음 |

→ 다섯 중 Land-XI 가 쥔 것은 영농관리(모델)·해양쓰레기(결과) 둘. 나머지는 외부·시안·없음. **"100% 우리가 만들어 뿌리는 구조가 아니다"가 실제와 맞다.** 자세히: `real-services.md` · 캡처 `shots/road-*.png` `shots/farm-1-login.png`.

## 2. 제공 방식 네 갈래(그림 `shots/sys-1-four-ways.png`)
| 갈래 | 기준 | 운영·유지 |
|---|---|---|
| **ⓐ 분기 카드** — Land-XI 가 만들어 뿌림 | 모델이 LX 안에 있고 다른 지역에도 심을 수 있다 | LX(모델·화면·갱신·재학습) · 기관은 쓴다 |
| **ⓑ 연결** — 기존·외부 시스템을 링크/임베드/결과 자료 받기로 잇는다 | 이미 돌고 있는 시스템이 있다 · 입력이 우리 흐름에 없다(블랙박스) | 그 시스템 주체 · LX 는 연결 등록과 모델 공급만 |
| **ⓒ 맞춤** — 연차 사업 맞춤 개발 · 일회성 분석 보고서 · 파트너 | 모델이 없다 · 새 입력 종류 · 특수 대장(대장 비교 3층의 '커스텀') | 사업 기간 LX 프로젝트 → 끝나면 결과만 남기거나 ⓐ 로 승격 |
| **ⓓ API** — 기관·외부 시스템이 결과를 가져가거나 분석을 맡김 | 기관 자기 시스템에 넣고 싶다 · 화면 불필요 | LX(표준 안내·키·한도·기록) · 호출은 기관. 표준·범위·구현은 `../open-api/`(오퍼스) |
네 갈래 모두 같은 서버 · 같은 작업 흐름 · 같은 계정 범위 · 같은 기관 한도. 판별 순서와 생애(연차 사업 → 프로젝트 → 모델 → 카드 발행(관리자 승인) → 기관 제공 → 유지·갱신(관리자) → 다음 해)는 `concept.md`, 남원 누적 그림 `shots/sys-2-lifecycle-namwon.png`.

## 3. 역량 결론(`capacity.md`)
- **병목은 GPU 가 아니라 사람과 저장.** 25cm 항공 기준 시군구 전역은 GPU 한 장으로 약 10분(순수 추론 · 추정, 실측 20 칩/초 기준). 결과 확인 표본(20건 이상)과 드론 원본(시점당 1–2TB, 이 PC 남은 1.9TB)이 먼저 막힌다.
- **GPU 는 한 장 규칙으로 한 줄 대기열** — 드론 1.5cm 전역 재분석(남원급 약 44시간 · 추정)과 재학습이 겹치는 달만 GPU 병목.
- 그래서 지금은 **상시 서비스 = 25cm 항공 기반, 드론 전역 = 사업 단위 예약**. 동시 기관 수: 항공 기반은 수십 기관(한계는 확인 인력), 드론 전역은 월 3–5건(추정).
- **A100 두 대(8장)**가 붙으면 학습·추론 분리 · 드론 전역 하루 2–3건 · 드론도 상시 — 노드 등록 흐름(코어 C6)과 원본 보관 서버가 조건. 사람 병목은 그대로.
- 측정 필요: 읽기 포함 벽시계 처리량 · 재학습 1회 GPU 시간 · 한 사람 표본 확인 처리량 · LX 직원 수 · 1TB 올리기 소요.

## 4. 새 지자체 온보딩(`onboarding.md` · 그림 `shots/sys-3-onboarding.png`)
카드는 그대로, 그 지역의 **영상 · 필지 · 대장 · CI** 만 새로. 여섯 단(업무 정하기 → 기관 만들기 → 영상 올리기 → 지역에 적용 → 결과 확인 → 공개·가입) 중 넷은 화면 안 자동, 사람 시간은 '결과 확인'. 기관 영상이 없어도 등록된 항공 영상으로 첫 결과. 전남 해양쓰레기 확대 = 같은 카드에 해안 한 줄.
