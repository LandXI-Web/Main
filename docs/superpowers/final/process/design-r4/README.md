## 시안 이름 규칙
- `shots/now-…png` = 지금(기존 캡처를 그대로 복사 · `now-4-various` `now-L1-three` 는 기존 캡처를 모은 것) · `shots/new-…png` = 바뀐 뒤(시안) · `…-three.png` = 세 장 나란히(Land-XI · 남원 · 광주전남).
- 시안 안 노란 번호표는 설명용이며 실제 화면에는 없다. 왼쪽 아래 검은 도장이 어느 플랫폼 화면인지 말한다.

## 확인 못 한 것(정직)
- 기관 분기 시안의 담당자 이름·부서 이름(농정과 · 환경과 · 건설과 · 관광과 · 해양수산과)은 서버 계정 자료가 없어 **예시 표기**다. 서비스 이름·연도는 옛 포털 자산 그대로.
- 영상 파일 이름(`남원시_드론정사영상.tif` 등)은 예시. 읽은 값(25cm · 2025년 · 중부원점)은 기존 등록 화면 기본값과 서버 요약의 영상 표기에서 가져왔다(실제 파일에서 읽은 값은 아님).
- 오탐 메모 문장("지난달 창고를 철거했습니다")은 흐름을 보이기 위한 예시 문장이다.
- AXIS-Label 은 서버를 띄우지 않고 정적 파일만 임시로 내주어 **로그인 화면까지만** 찍었다(안쪽 작업 화면은 못 봄). 옛 라벨링 작업공간은 개발 서버(:4173)에서 로그인 표시를 넣어 찍었다.
- 확인 요청 페이지 생성은 하지 않았다(오케스트레이터 몫 · `LX_CONFIRM_ITEMS=design-r4/confirm-items.json LX_CONFIRM_ROUND=4 LX_CONFIRM_EXTRA=design-r4/shots`).
- 대장 매칭 테마 조사는 다른 에이전트 몫으로 다루지 않았다. 서비스 제공 체계(무엇을 Land-XI 가 만들어 뿌리고 무엇은 연결하는지)도 다른 기획 에이전트 몫 — 여기는 모습 시안만.
