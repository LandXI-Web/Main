# 외부 연동 API — 구현 계획

> 2026-09-30 · 지위: **사용자 확인 전 계획**(코드 수정 0 · GPU 실행 0 — 코어 3차가 서버 파일을 고치는 중). 확인되면 코어 3차가 끝난 뒤 단계 순서대로 만든다.
> 공정: 평가(이 문서 1절) → 기획(범위·가이드·이 계획) → 개발(단계별) → 실증(두 지역 + 무작위 한 지역, 바깥 주소, 명령줄 없이 관리자 화면에서 키 발급) → 서비스(안내 페이지·운영 기록).

## 1. 평가 — 지금 있는 것(코드 읽기 + 로컬 호출로 확인)
- 게이트웨이(내부 API) 요청 종류 **163개**(내부 API 목록에서 뽑음). 화면용이라 결과·작업·필지·실태조사·보고서·타일 서명·사용량·감사 기록이 이미 있다. 외부 API 는 이것을 **다시 만들지 않고 얇은 창구**로 감싼다.
- 인증은 화면 로그인 토큰(24시간, LX·기관 따로)뿐 — **기계용 키 없음.**
- 기관 격리는 DB 행 보안(기관 id)으로 잘 돼 있다(작업·탐지·실태조사·필지·대장·사용량). 결과 세트·타일 서명·동적 영상 조각은 관할 확인이 있다.
- 사용량 장부(분석 시간·분석 면적·저장·동시 작업·AI 도우미 토큰)가 실측으로 쌓인다. **요청 수 칸이 없고, 전송량은 '미계량'.**
- 비동기 작업은 대기열 + 실시간 스트림(화면용)만 — **알림(웹훅) 없음.** 큰 파일 조각 올리기는 학습 표본 올리기에만 있다(8MB 조각 · 이어 올리기).

### 평가에서 나온 원칙 위반 3건 — 확인 없이 먼저 고칠 것(이미 확인된 사용자 원칙 위반)
| # | 무엇 | 확인 방법 | 왜 문제 |
|---|---|---|---|
| 1 | **바깥 주소에서 내부 API 목록 전체가 열린다** — 공개 관문이 `/api/…` 를 통째로 넘겨 API 문서 화면과 요청 목록(163개)이 바깥에서 보인다 | 공개 관문(바깥 주소가 닿는 문)에 로컬로 두 주소를 불러 둘 다 200. 바깥 주소로 직접 부르지는 않았다(바깥 주소도 이 관문을 지남) | 개발 정보 노출 금지 원칙 · 공격 표면 |
| 2 | **필지 조회가 로그인 없이 전국 어디든 답한다**(지번·지목·면적·공시지가) | 로그인 없이 남원 한 점을 불러 200 | 계정 범위 밖 0 원칙(게스트는 범위가 없음) |
| 3 | **기관 계정의 분석 견적·등록에 관할 확인이 없다** — 시군구 전역·그린 범위 모두 영상·모델만 고르고 관할은 보지 않는다(코드 읽기 · 실제 호출은 하지 않음: 견적이 분석 기계에 모델을 미리 올리므로) | 코드 읽기 | 계정 범위 밖 0 원칙. 외부 API 가 이 경로를 그대로 쓰면 바깥 시스템이 다른 지역을 분석시킬 수 있다 |
→ 0단으로 묶는다(아래). 코어 3차가 같은 파일을 고치는 중이라 3차 담당과 순서만 맞춘다.

## 3. 단계
### 0단 — 원칙 위반 3건 고치기(확인 불필요 · 반나절~1일)
- 공개 관문: 모든 바깥 입구에서 내부 API 목록 두 주소를 404.
- 필지 조회: 로그인 필수 + 관할 안만(LX 는 전국).
- 분석 견적·등록: 기관 계정이면 관할 가드(범위가 관할을 벗어나면 거절 · 시군구 코드가 관할 밖이면 거절).
- **완료 기준**: 바깥 주소에서 두 주소 404 · 로그인 없는 필지 조회 401 · 남원 계정으로 여수 전역 분석 견적 → 거절(분석 기계 사용 0) · 남원 계정으로 남원 견적은 그대로.

### 1단 — 결과 보기 API + 키 발급 화면(약 5일)
- 서버: 키 · 관할 가드 · 읽기 10개(서비스 · 지역 · 요약 · 조각 결과 · 필지 목록 · 필지 하나 · TileJSON · 지도 조각 · 보고서 목록·파일 · 사용량) · 요청 수 한도 · 요청 기록 · 전송량 계량 · 외부 전용 API 목록.
- 관리자 화면: 기관 서랍 'API 연동' 칸(아래 4절).
- **완료 기준(측정 가능)**
  1. LX 관리자 화면에서 키 발급 → 첫 호출 성공까지 **명령줄 0**, 5분 안.
  2. **관할 밖 0**: 기관 둘(남원 · 광주전남)의 키로 서로의 지역·결과·필지·지도 조각·보고서를 부르는 교차 조합 전부 404, 응답 본문에 상대 기관 값 0건.
  3. **숫자 한 출처**: 같은 시각 외부 요약 = 기관 화면 = 내부 요약 — 남원·여수 + 확인자가 고른 한 지역, 차이 0.
  4. 폐기한 키 → 5초 안에 401.
  5. 1분 한도를 넘기면 429 + 다시 시도할 때 · 관리자 화면 'API 요청' 수가 1분 안에 늘어남.
  6. 외부 요청 수 = 요청 기록 수(빠짐 0).
  7. 외부 응답에 내부 이름 0 — 금지어 자동 검사(표 이름 · 파일 경로 · 드라이브 문자 · 장비 이름 · 내부 작업 흐름 용어).
  8. 결과 1,000행 한 쪽이 2초 안(게이트웨이 기준) · 커서로 끝까지 받은 수 = 전체 수.
- **시험**: 자동 시험(분석 기계 0) — 키(없음·틀림·끝남·폐기·권한 없음·IP 밖) · 교차 관할 · 숫자 대조 · 페이지 끝까지 · 한도 · 기록 수 · 금지어. 실증 — 바깥 주소로 두 지역 + 무작위 한 지역, 가이드의 curl·Python 예제를 그대로 돌림.

### 2단 — 분석 맡기기 + 알림(약 5일)
- 서버: 영상 조각 올리기(이어 올리기 · 파일 정보 자동 읽기 · 관할 밖 거절) · 미리 적재 없는 견적 · 등록(중복 방지 열쇠 · 우선순위 3번째 · API 칸 1개 · 동시 작업 합산) · 상태 · 결과 · 취소 · 메모 한 줄 · 웹훅(분석 끝/실패 · 새 결과 공개 · 서명 · 6번 재시도 · 보낸 기록).
- 관리자 화면: 키 서랍에 '알림 보낸 기록' 한 줄(마지막 성공·실패) · 대기열 표에 'API' 표시.
- **완료 기준**
  1. 2GB GeoTIFF 를 올리다 끊고 이어 올려 성공 · 받은 파일 해시 = 보낸 파일 해시.
  2. 관할 밖 범위 영상 → 파일을 읽는 단계에서 거절(분석 기계 사용 0).
  3. 같은 중복 방지 열쇠로 세 번 등록 → 작업 1개.
  4. API 분석이 도는 동안 화면에서 누른 읍면동 분석의 **첫 결과 10초 안 유지** · 전력 기록에서 동시 고부하 1장.
  5. 끝나면 알림이 옴 · 서명 확인 성공 · 받는 쪽을 일부러 끄면 재시도 기록이 쌓이고 켜면 알림이 옴.
  6. 같은 작업 번호가 기관 화면 결과 · LX 관리자 대기열 · 기관 사용량에 같이 보임(관리-생산-서비스 한 흐름).
  7. 한도 넘은 기관의 등록 → 정책대로(순서 낮춤 또는 거절).
- **시험**: 자동 시험은 분석 기계 없이(대기열까지만). 실증은 GPU 한 장 규칙을 지켜 작은 드론 영상 1개(관할 안) + 관할 밖 1개, 해양쓰레기(광주전남) + 영농(남원).

### 3단 — 외부 개발자 안내 페이지(약 2.5일)
- 이 가이드 초안을 페이지로(사용자 말 · 줄바꿈 규칙 · 밝은 톤) · 외부 API 목록 · curl/Python 예제 · 오류표 · 바뀐 점 목록 · '시험 키'(그 기관 실제 데이터 · 읽기만 · 한도 낮음 · 30일).
- 기관 분기 플랫폼 기관 관리자의 'API 연동' 보기(키 이름 · 마지막 사용 · 급할 때 폐기 · 기록 내려받기 · 새 키 요청 → LX 관리자 결재함).
- **완료 기준**: 처음 보는 개발자(이 설계를 모르는 다른 모델 에이전트)가 **안내 페이지만 보고 30분 안에** 첫 결과를 받음 · 페이지 PC·모바일 캡처에서 줄바꿈 규칙 통과 · 내부 코드 0.

| 칸 | 보이는 것 | 누를 것 |
|---|---|---|
| 키 목록 | 한 줄 = 이름(예: 도로안전 시스템) · 할 수 있는 일(결과 보기 / 분석 맡기기) · 마지막 사용 · 끝나는 날 | [폐기] — 확인 카드 한 번 |
| 이번 달 사용 | 기존 기관 한도 막대(분석 시간·분석 면적·저장)에 **API 몫을 옅게** 겹쳐 표시 + 'API 요청 n회' 한 줄 | 없음 |
| 새 키 만들기 | 시트에 입력 **3개**: 이름 · 할 수 있는 일(두 칸: 결과 보기 / 분석 맡기기) · 서비스(기본 = 이 기관 전체) · 접힌 '더 보기'(끝나는 날 · 알림 받을 주소 · 허용 IP) | [만들기] → 키를 **한 번만** 보여 줌 + [복사] + "이 창을 닫으면 다시 볼 수 없습니다" |

- 결재를 두지 않는다 — 키는 LX 관리자가 직접 만들고 바로 쓴다(승인·반려는 꼭 필요한 것만). 기관이 새 키를 원하면 3단의 '새 키 요청'이 결재함에 한 줄로 온다.
- 상태 말은 공통 사전 그대로: 쓰는 중 · 끝남 · 폐기됨.
