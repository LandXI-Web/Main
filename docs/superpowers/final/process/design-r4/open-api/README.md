# 외부 연동 API — 한 장 요약

> 2026-09-30 · 지위: **사용자 확인 전 설계**(코드 수정 0 · GPU 실행 0). 어느 플랫폼: **둘 다** — 키·한도·사용량은 Land-XI(LX 관리자 화면), 쓰는 쪽은 기관의 다른 시스템.
> 사용자 원문(09-30): "우리 서비스를 API 방식으로 호출하여 결과를 가져가거나, 실제 API 형태로 분석을 던지고 주고받는 구조도 고민이 필요하다. 표준 가이드도 필요하고, 어느 범위까지 가능한 영역인지도 정해야 한다. 그리고 구현해야 하고."

## 한 줄
**API 는 기관 분기 플랫폼의 '기계용 창구'다.** 사람이 화면에서 보는 결과를 같은 관할 · 같은 서비스 · 같은 한도 안에서 다른 시스템이 직접 받아 가거나, 영상을 맡겨 분석을 받는다. 화면보다 넓게 열리는 것은 없다.

덧붙임 — 이 창구의 약속(서비스·관할·결과 모양)이 굳으면 **기관 분기 플랫폼(예: 남원 GeoVision)도 같은 창구 위에 얹을 수 있다.** 그러면 새 지자체 분기는 모습(CI·몇 가지 기능)만 바꾸는 일이 된다 — 서비스 제공 체계 설계와 함께 맞출 것(이번 확인 항목에는 넣지 않음).

## 핵심 셋
| | 정한 것(기본값 — 바꾸려면 말씀만) |
|---|---|
| **인증** | 기관(또는 부서)별 **API 키**. 화면 로그인과 완전히 따로(키로 화면 못 들어감 · 로그인 토큰으로 API 못 부름). 키는 만들 때 한 번만 보이고 한 방향 암호로만 저장. 묶이는 것 = 기관 · 할 수 있는 일(결과 보기 / 분석 맡기기) · 서비스 · 끝나는 날(1년) · 선택으로 허용 IP · 알림 주소. 폐기하면 5초 안에 거절. LX 관리자가 기관 서랍에서 만들고, 기관 관리자는 급할 때 폐기 |
| **주소** | 바깥 `https://api.land-xi.dev/v1/…` · 내부 `/api/ext/v1` — **화면용 내부 API 와 분리**(화면 쪽이 차수마다 바뀌어도 바깥 약속은 그대로 · 내부 이름·관리자 기능이 새지 않음 · 문서도 외부 경로만). 같은 서버·같은 DB·같은 기관 격리를 그대로 쓰는 얇은 창구. 같은 버전 안에서는 더하기만, 빼거나 바꾸면 v2 · v1 은 최소 12개월 유지 |
| **비동기** | 영상 조각 올리기(8MB · 이어 올리기 · 해상도·촬영일·범위는 파일에서 자동으로 읽음) → 견적(분석 기계 사용 0) → 등록(202 · 중복 방지 열쇠) → 상태 조회(30초에 한 번 이하) 또는 **알림(웹훅 · 서명 · 6번 재시도)** → 결과(GeoJSON · 페이지). API 분석은 화면 분석 뒤 순서 · Land-XI 전체에서 한 번에 1건 · 등록 뒤 24시간 안 약속 |

형식은 한 벌: 숫자는 '값·단위·근거·기준 시점·출처'로(화면과 같은 값) · GeoJSON(경도·위도, 필요하면 국내 좌표계) · 시각은 시간대 포함 · 커서 페이지 · 오류는 코드 한 벌 · 모든 결과에 '참고자료' 표시. 관할 밖은 읽기 404(있다는 사실도 안 알림) · 분석 범위가 조금이라도 벗어나면 거절.

## 사용자 결정이 필요한 갈림길
1. **누구에게 여나** — ⓐ 서비스를 받는 기관(계약·협약)만, 그 기관 관할·서비스 안에서(추천: 계정 범위 밖 0 원칙과 그대로 맞음) · ⓑ ⓐ + 다른 공공기관에도 요약 숫자·지도 조각은 신청·승인으로(필지·조각 모양은 계약 기관만).
2. **분석 맡기기의 한도와 비용** — ⓐ 기관 한도 안에서 따로 비용 없이, 화면 작업 뒤 순서(추천) · ⓑ 한도를 넘는 양은 맡긴 넓이·시간 기록으로 따로 정산 · ⓒ 처음엔 분석 맡기기를 열지 않고 결과 보기만.
3. **결과를 어느 수준까지** — ⓐ 조각·필지 모양까지 + '결과 확인 전/확인됨' 표시(추천: 기관 화면과 같은 수준) · ⓑ 결과 확인을 마친 것만 모양까지, 확인 전은 숫자만 · ⓒ 숫자·지도 조각·보고서만(모양 파일 없음).

## 확인 못 한 것
- **바깥 주소(https)로는 부르지 않았다** — 공개 관문과 게이트웨이를 이 PC 안에서만 불렀다.
- **기관 분석 등록의 관할 누락은 코드 읽기로만 확인** — 실제로 불러 보지 않았다(견적이 분석 기계에 모델을 미리 올리는 경로라 GPU 금지 조건에 걸림).
- 벡터 지도 조각을 QGIS·ArcGIS 에 실제로 띄워 보지 않았다(지금 결과 지도 파일에서 한 장씩 꺼내는 경로는 새로 만들 것).
- 드론 영상 1㎢ 당 분석 시간은 모델 처리 속도 기록으로 **추산**만 했다(드론 실측 기록 없음).
- 한도 초기값(요청 수·넓이·등록 수)은 제안이다 — 지금 기관 한도 초기값처럼 운영하며 조정.
- 남원 도로안전 · 영농관리 기존 시스템의 실제 연동 방식(그쪽이 부르는 쪽이 될 수 있는지)은 확인하지 않았다 — 그쪽 개발사와 확인 필요.
