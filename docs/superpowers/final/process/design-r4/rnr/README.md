## 누락 상위 10 (자세히 → `gaps.md`)
1. 계정·기관·부서 체계가 통째로 없음 — 기관 만들기 · 첫 기관 관리자 · 부서 · 가입 신청·승인 · 부서 서비스만 보기 · 비밀번호 바꾸기
2. 프로젝트와 프로젝트장이 없음 — 소유·판단(공개 요청·적용 요청·재학습)의 주인이 설 자리가 없음
3. 학습데이터 구축이 반쪽 — 라벨링은 별도 도구 새 창, 라벨 검수는 보기·빼기만, 클래스 관리 없음
4. 서비스 공개 결재가 없음 — 확정과 반대로 직원이 바로 서비스를 만들고 그 직원이 승인자로 적힘
5. 데이터 올리기가 반쪽 — 영상은 '경로' 글자 칸, 지역을 화면이 먼저 정함, 행정 자산은 양식만, 기관 영상·공유 영상 없음
6. 'AI가 잘못 봤어요' 한 바퀴가 없음 — 신고 96건이 쌓이기만 하고 처리·답이 없음
7. 관할 밖 0이 덜 됨 — 남원시 계정 검색에 '여수시'가 뜸, 광역은 전체 합계 없이 강진군으로 저절로 감
8. 공개 뒤 관리와 재학습의 주인이 없음 — 운영 중 모델도 아무 직원이 '학습 시작'
9. 외부 연동 API 가 전부 없음(설계 진행 중)
10. 만들지 않기로 한 '시정명령·이행강제금·배정'이 기관 화면에 남음

## 확인 못 한 것 (정직)
- **GPU 를 쓰는 실행은 누르지 않았다**(학습 시작 · 전역 분석 · 이번 계절 분석 · 보고서 초안 · 말로 묻기 전송 · 결합 실행). 그 줄은 9월 30일 실증 기록으로 판정했다. 배포 롤백·단계 올리기도 누르지 않았다(버튼만 확인).
- **부서 사용자·열람자 계정이 없다**(서버에 부서 칸이 없고 열람자 계정도 만들어진 것이 없음). 부서 사용자 줄은 기관 담당자 계정으로 대신 봤다.
- 해외 기관은 키르기스 농업부 한 곳만 봤다.
- 학습 흐름(모델 등록 요청 · 서비스 만들기 ⑤)과 결재함 일부는 **코어 3차가 지금 고치는 중**(저장 전 파일)이라 결과가 바뀔 수 있다 — 그래서 '부분'으로 두었다.
- 별도 라벨 도구(AXIS-Label) 안의 기능(자동 라벨 등)은 열어 보지 않았다 — Land-XI 와 연결되는지만 봤다.
- 바깥 주소(app·admin·gov)는 이번에 열어 보지 않았다(개발 주소만).
