# 기능 대조 — 역할마다 '하는 일' 한 줄씩, 지금 되는가 (2026-09-30)

> R&R 표(`rnr.md`)의 하는 일 82줄을 지금 플랫폼과 한 줄씩 맞춰 봤다. 지위: 사용자 확인 전 점검 기록. 코드는 고치지 않았다.

## 판정 기준
| 판정 | 뜻 |
|---|---|
| **있음** | 화면에서 끝까지 된다(누를 곳이 있고 결과가 나온다) |
| **부분** | 화면만 있다 · 서버만 있다 · 외부 도구로 넘어간다 · 명령줄·파일 손작업이 필요하다 · 지금 개발 중이라 끝까지 확인 못 했다 |
| **없음** | 화면도 서버도 없다 |
| 만들지 않음 | 사용자가 만들지 않기로 한 것(현장 확인 배정 · 공문 · 시정명령). 화면에 남아 있으면 '남아 있음'으로 적는다 |

## 어떻게 확인했나
- **화면**: 이 PC 개발 주소에서 로그인 폼으로 들어가(세션 주입 0) 눌러 봤다 — LX 직원(`lx-staff`), LX 관리자(`lxadmin` · LX 관리자), 기관(`lxadmin` · 남원시 · 광주전남특별시 · 키르기스 농업부), 영업(`lx-sales`), 게스트. 1440×900. 시트·서랍·탭은 열고, 저장·실행 버튼은 GPU 를 쓰지 않는 것만 열어 봤다.
- **서버**: 게이트웨이 기능 목록(경로 163개)과 역할별 권한 표를 맞췄다. 관할은 기관 계정의 로그인 세션으로 관할 밖 지역을 직접 불러 봤다(여수 의심 필지 0건 · 지역 상세 거절 · 다른 기관 사용량 거절 · 지역 목록 256곳은 내려옴).
- **누르지 않은 것**(GPU · 규칙): 학습 시작 · 전역 분석 · 이번 계절 분석 · 보고서 초안 · 말로 묻기 전송 · 결합 실행 · 배포 롤백. 이 줄들은 9월 30일 실증 기록(`docs/CORE.md` 상태 추적)으로 판정하고 '지금 모습'에 적었다.
- 캡처: `shots/now-staff-train-drawer.jpg`(학습 서랍 — 라벨 열기·학습 시작) · `now-admin-approval.jpg`(결재함 — 다른 지역 적용·사유·반려/승인) · `now-gov-action-leftover.jpg`(기관 조치 기록 — 시정명령 남음) · `now-gov-search-outside.jpg`(남원시 계정 검색에 여수시) · `new-rnr-matrix.png`(매트릭스).
- 코어 3차가 같은 시간에 화면·서버를 고치고 있어(학습 흐름·결재함 등 저장 전 파일) 그 줄은 **부분**으로 두었다.

## 서버가 지금 아는 역할 — R&R 표와의 차이
| R&R 역할 | 서버 역할 | 차이 |
|---|---|---|
| LX 관리자 | LX 관리자 | 같음 |
| LX 직원 · 프로젝트장 | LX 직원 | **프로젝트장 권한 없음**(프로젝트 자체가 없음) |

| 기관 관리자 | 기관 담당자 | **부서·사용자를 관리하는 권한 없음** |
| 부서 사용자 | 기관 담당자 · 열람자 | **부서 칸 없음** — 모든 기관 계정이 모든 서비스를 봄. 열람자 계정은 만들어진 것이 없음 |

| 외부 시스템(API) | 없음 | **키·범위·한도가 없음** |
| 게스트 | 로그인 없음 | 가입 신청 경로 없음 |
