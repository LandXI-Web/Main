# 외부 연동 API 다시 붙이기 — 한 장 요약

> 2026-10-10 · 지위: **사용자 확인 전 정리**(코드 수정 0). 확인 대장 '10-10 외부 연동 API 다시 살림'(원칙 174).
> 사용자(10-10): "분석결과? 분석하기? API도 고려해야 한다. 이전에 언급한 사항인데 어디에도 안보이네"

## 한 줄
**기관에 공유된 분석 서비스 하나 = 그 기관이 API로 쓸 수 있는 서비스 하나 = 키 하나.**
키를 든 기관의 다른 시스템은 그 서비스의 결과를 가져가고(지난 결과까지), 영상을 올려 분석을 맡깁니다(관리자 승인 뒤). 화면보다 넓게 열리는 것은 없습니다.

![API 키와 분석 서비스(시안)](shots/api-key-map-1440.png)

## "API 키랑 분석 서비스랑 같은 거야?" — 아닙니다
- **분석 서비스** = 무엇을 분석하나(예: 영농관리). LX 직원이 배포 신청 → LX 관리자 승인 → 관리자가 기관에 공유.
- **API 키** = 그 공유된 서비스를 기관의 **다른 시스템**(예: 남원 영농관리 시스템)이 화면 없이 쓰는 출입증. 공유된 서비스마다 하나.
- 비유 — 서비스는 통장, 키는 그 통장에 연결한 카드. 카드를 잃어버리면 카드만 멈추고, 공유(통장)를 거두면 카드도 못 씁니다.

## 이번에 붙인 것(새 구조 위에서)
- **분석 맡기기는 새 길을 만들지 않습니다.** 지금 있는 기관 '분석 요청'(결재함 한 줄 · 관리자 순번 · 급함 · 보류 · 조각 올리기 20GB · 무상)에 '들어온 곳: API' 표시만 더합니다.
- **결과 가져오기**는 기관 화면 내려받기(관할 안만 자름)와 같은 값을 씁니다 — 숫자 한 출처.
- **사용 현황**: '배포 → 사용 현황' 표에 'API 호출' 열과 'API로 맡긴 분석'을 더합니다. 기관 한도는 같은 장부(새 칸 'API 호출(하루)').
- **감사 기록**: 모든 호출(누가 · 무엇을 · 언제 · 몇 건). 키 만들기 · 폐기는 사람이 화면에서(OTP가 붙으면 OTP 뒤).
- **주소 분리**: `api.land-xi.dev/v1` 만 바깥 API. 화면 주소에서는 외부 API 길을 막고, API 주소에서는 화면용 내부 API를 막습니다.

지난 설계에서 그대로 쓸 것 · 바뀐 것 · 버릴 것 표는 [plan.md](plan.md) 2절.

## 먼저 제안(원칙 57)
1. **새 결과 알림** — 공유된 서비스에 새 시점이 생기면 키에 적힌 주소로 알림. 매달 가져가는 기관 시스템(도로안전 · 영농관리)이 날짜를 맞춰 묻지 않아도 됨. (1단에 포함)
2. **시험 키** — 기관이 맡긴 개발사가 연동을 만드는 동안 쓰는 읽기 전용 30일 키. 실제 키를 개발 PC에 두지 않게. (2단)
3. **키 끝나기 30일 전 알림** — 기관 관리자 화면과 메일 한 줄. 1년 뒤 기관 시스템이 갑자기 멈추는 일을 막음.
4. **XI ChatGEO 읽기 질문 API(나중)** — 기관 시스템이 "이번 달 확인이 필요한 필지 몇 곳?"을 말로 물음. 같은 분석 기계를 써서 지금은 닫고, 한도 장부(토큰)가 선 뒤 후보로.
