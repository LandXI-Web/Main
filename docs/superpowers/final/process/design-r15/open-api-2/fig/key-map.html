쉽게 — 통장과 카드

공유된 분석 서비스는 통장, API 키는 그 통장에 연결한 카드입니다.

카드를 잃어버리면 카드만 멈추고 통장은 그대로입니다.

공유를 거두면 카드도 쓸 수 없습니다.

사람과 시스템은 따로 들어옵니다

사람은 화면 로그인(아이디 · 비밀번호 · OTP).

시스템은 키. 키로는 화면에 못 들어가고, 화면 로그인으로는 API를 못 부릅니다.

한도와 기록은 하나

API로 쓴 것도 화면과 같은 기관 한도에 합산되고, 관리자 '사용 현황'에 함께 보입니다.

모든 호출은 누가 · 무엇을 · 언제로 남습니다.
