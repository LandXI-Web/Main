## 남은 것
1. **처음 밤이 첫 실제 실행** — 낮에는 시험 칸만 돌렸다. 내일 아침 장부(runner.log · 관리자 한 줄)로 실제 속도 · 실패를 보고 하룻밤 예상을 실측으로 바꾼다(화면 값은 첫 칸 뒤 자동으로 실측).
2. **영상 이용 범위 · 호출 한도 정식 확인**(국토지리정보원) — 아직 안 됨. 호출이 막히면 칸이 failed 로 쌓이고 관리자 줄이 주황으로 바뀐다.
3. 소하천 원본(공개)으로 바꾸기 — 계정 로그인 한 번이 필요(사용자 조치).
4. 농지 둘레는 WorldCover 2021(10m) 기준 — 0.05㎢ 미만 외딴 밭은 빠진다. 연속지적 지목(전 · 답 · 과수원)으로 바꾸면 더 정확.
5. 낮은 줌 면은 격자(200m · 80m) — 객체 모양은 줌 11부터. 결과 객체는 데이터베이스에 두지 않으므로 '그 자리 고치기'는 전국 결과 객체에는 아직 안 붙는다.
6. 시험 표시 작업 줄(jobs 표 2줄)은 시험 표시로 남음(숫자 · 화면 0).

## 제안 — 이런 것도 필요하지 않을까요?
1. **아침 한 줄 보고** — 누가 왜: LX 관리자. 밤사이 끝난 읍면동 · ㎢ · 실패 칸을 아침 알림 한 줄로(관리자 대시보드 알림). 실패가 쌓이면 바로 알 수 있다.
2. **기관 화면에 '우리 지역 농지 결과'** — 누가 왜: 기관(남원 · 광주전남). 전북 · 광주전남이 먼저 끝나므로, 기관 지도 서비스에 자기 관할 결과 면을 바로 보여 주면 농지 이용실태조사 대상 고르기에 쓸 수 있다(공유 승인 뒤).
3. **XI ChatGEO 로 진행 묻기** — 누가 왜: LX 관리자 · 직원. "전국 농지 어디까지 했어?"에 진행 장부와 같은 숫자로 답하고 그 자리로 날아감.
