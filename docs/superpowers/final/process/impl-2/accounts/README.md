# 계정 — 가입 신청 · 아이디/비밀번호 찾기 · 로그인 가운데 창 (구현 2차)

> 10-01 사용자: "로그인 창에서 계정 찾기·신청 하면 오른쪽이 뜨는데 그냥 창이 하나 중간에 뜨는 걸로... 그래서 가입 신청과 아이디 비밀번호 찾기 등 기능을 만들자." · "아이디가 메일 주소 체계로 되어야 하거든"
> 확인 대장: 계정·기관을 관리자 화면에서 만들기·승인·비밀번호 재설정·잠금(1차 — 확인) · 기관 사용자 가입 신청 + 승인(2차 — 확인)
> 10-01 구현 확인 답: "이 창구는 LX 직원만 이용하는 창구다" → Land-XI 로그인의 창은 LX 직원용. 기관용 신청·찾기는 같은 부품을 기관 로그인이 부른다.
> 상태: **구현 확인 대기** — 아래 주소에서 직접 열어 보고 완료 / 다시를 정해 주세요.

## 한 줄
로그인의 '계정 찾기 · 신청'을 누르면 **오른쪽 서랍 대신 화면 가운데 창**이 뜹니다. 창 안 탭 셋: **가입 신청 · 아이디 찾기 · 비밀번호 찾기**. 신청과 비밀번호 재설정 요청은 **관리자 계정 화면**에서 승인 · 반려하고, 임시 비밀번호로 들어온 사람은 **새 비밀번호를 정해야** 들어갑니다.

## 보안 기본(개인정보의 안전성 확보조치 기준 — 일정 횟수 틀리면 접근 제한)
- 같은 아이디로 비밀번호를 **5번 틀리면 그 계정 10분 잠금** — 화면에 "비밀번호를 여러 번 틀려 10분 동안 잠겼습니다". 잠긴 동안은 맞는 비밀번호도 받지 않습니다. 관리자가 계정 화면에서 풀 수 있습니다.
- **실패한 로그인도 모두 기록**(아이디 · 시각 · 입구 · 접속 주소 · 까닭). 비밀번호 값은 어디에도 남기지 않습니다. 관리자 계정 화면 '로그인 실패' 탭에서 봅니다.
- 로그인 없이 부르는 신청 · 찾기는 접속 주소마다 횟수를 제한합니다(가입 신청 한 시간 20번 · 아이디 찾기 · 비밀번호 찾기 10분 10번).
- 비밀번호 찾기는 계정이 있든 없든 같은 답 — 있는 메일 주소를 알아내는 데 쓰이지 않게.
- 2차 인증(OTP)은 확인 대기라 만들지 않았습니다.

## 시험 결과
- 서버 시험 10건 통과: 신청 → 승인 → 로그인(메일 대소문자 무관) · 입력 검증 · 관리자 입구 신청 거절 · 접속 주소마다 신청 횟수 제한 · 반려 사유 필수 · 아이디 찾기 가림 · 찾기 횟수 제한 · 재설정 → 임시 비밀번호 → 바꾸기 강제(세션 없음 · 약한 비밀번호 · 같은 비밀번호 · 한 번만) · 기관 관리자는 자기 기관만 · LX 관리자는 전부 · 관리자 잠금 · 5번 틀리면 10분 잠금(주소가 바뀌어도) · 실패 기록(비밀번호 값 0) · 관리자가 풀기.
- 화면 시험 10건 통과: 세 입구 × PC · 휴대폰 가운데 창 · 탭 셋 · Esc · 바깥 · × · 빈 칸은 서버로 보내지 않음 · 임시 비밀번호 → 새 비밀번호 → LX 직원 대시보드 · LX 관리자 계정 화면 · 관리자 아닌 계정 거절 · 기관 관리자 계정 화면은 한 기관만.
- 금지어 검사: 가운데 창(세 입구 · 모든 탭) · 계정 화면 0건 · 화면 오류 0.
- 시험 계정은 시험 안에서 만들고 끝에서 지웠습니다. 옛 계정은 바꾸지 않았습니다.
