# 구현 2차 · 검토 요청 · 메시지 · 알림 — 구현 확인 대기

> 2026-10-01 · 어느 플랫폼: **기관 화면**(할 일 판정 카드 · 기관 첫 화면 필지 카드 · XI맵 필지 카드)과 **Land-XI 화면**(LX 직원 · LX 관리자) · 서버
> 근거(사용자가 확인한 것만):
> - 확인 요청 6차 '검토 요청' — "'AI가 잘못 봤어요'가 아니라 '검토 요청' 기능으로. 메모를 간단하게 남겨 꼭 AI 가 아니더라도 메시지를 전달할 수 있게. 이런 주고받는 부분도 LX 관리자가 알아야 한다"
> - 확인 요청 6차 '알림은 담당 프로젝트장 + LX 관리자' — "프로젝트장이 받더라도 LX 관리자는 같이 알아야 한다. LX 관리자는 모든 걸 감시하고 보조 지원하는 역할도 크다"
> - 확인 요청 4차 '오탐 알리기' — "그 서비스를 담당하는 직원도 매칭되어야"
> - 원칙: 사용자에게 짐을 넘기지 않는다(메모 한 줄) · 받는 사람을 정한다 · LX 관리자는 다 보고 돕는다 · 검토 요청 = 짧은 메시지 · 계정 범위 밖은 없다

## 한 줄
**기관 담당자가 필지 카드에서 '검토 요청'을 누르고 메모 한 줄(안 써도 됨)을 보내면, 그 서비스를 맡은 LX 직원과 LX 관리자의 화면 머리 알림 칸에 숫자가 서고, LX 가 한 줄(+ 판정 선택)로 답하면 기관 담당자의 알림 칸에 답이 온다.**

## 무엇을 만들었나
| 누가 | 어디서 | 무엇 |

| 기관 담당자 | 할 일(판정 카드) · 기관 첫 화면(대장 × AI 필지 카드) · XI맵(필지 카드) | **검토 요청** 버튼 한 개 → 메모 한 줄(안 써도 됩니다) → **LX 담당자에게 보내기**. 이유 고르기 · 사진 · 분류 입력 없음. 카드 아래 '받는 사람'이 저절로 적힌다(이 서비스 담당 LX 직원 ○○○ / LX 관리자) |
| 기관 담당자 | 화면 머리 **알림 칸** → **내가 보낸 요청** | 내가 보낸 요청 목록 — 상태 **보냄 → 확인 중 → 답변** · 메모 · LX 답과 판정 · 대화에 한 줄 덧붙이기 |
| LX 직원 | 화면 머리 **알림 칸** → **기관에서 온 요청** | 내가 담당하는 서비스로 온 요청만 · 답할 것 / 답한 것 · 대화 한 건에 **저절로 붙은 것**(영상 조각 · 필지 · 대장 지목과 면적 · AI 분석 결과와 영상 시점) · 한 줄 답 + 판정(**맞음 · AI 오류 · 모름**, 고르지 않아도 됨) |
| LX 관리자 | 화면 머리 **알림 칸** · LX 관리자 대시보드 왼쪽 메뉴 **검토 요청** | **모든 기관의 요청과 대화**를 함께 본다(받는 사람 표시) · 담당 직원이 없는 요청은 관리자가 받고 답한다 · 담당이 있어도 관리자가 거들어 답할 수 있다 |
| 서버 | — | 요청 하나 = 짧은 대화 · '**AI 오류**' 판정은 지금까지 오탐 신고가 쌓이던 자리에 재학습 표본 한 줄로 이어 쓴다(기존 기록은 지우지 않음) · 같은 사람이 같은 필지로 답을 받기 전에 또 보내면 새 요청이 아니라 그 대화에 한 줄이 붙는다 |

- 화면 말: '검토 요청' · '내가 보낸 요청' · '기관에서 온 요청'. **'오탐 신고' · 'AI가 잘못 봤어요' 표기 0**(기관 화면 · 대화 · 알림 모두).
- 메일 알림은 만들지 않았다(확인되지 않음). 알림 칸은 30초마다 · 화면으로 돌아올 때 · 보내고 답할 때 바로 다시 센다.
- 기다림 · 빈 화면 · 문제 표시는 모든 화면과 같은 세 모양(막대 + 불러오는 중 · 회백 카드 한 줄 · 다시 시도).

## 받는 사람 — 누구에게 가나
1. 그 필지의 AI 결과가 어느 서비스 것인지 서버가 정한다(화면이 넘긴 서비스 → 그 필지의 실태조사 규칙 → 결과 층).
2. 그 서비스 카드의 **담당**: 그 카드를 낸 프로젝트의 **프로젝트장** → 카드의 담당 칸 → 그 카드를 공개 · 다른 지역 적용 요청한 LX 직원.
3. 담당이 없으면 **LX 관리자**가 받는다.
4. 어느 쪽이든 **LX 관리자는 모든 요청 · 대화를 본다**(알림 칸 숫자도 관리자에게 함께).
- 지금 자료로는: 남원 '휴경·전용 의심' 필지(영농관리 행정서비스) → **LX 직원 김도윤** · '무허가 건축 의심' 필지(생활환경 위험요소 탐지 서비스) → 담당 직원이 없어 **LX 관리자**.

## 계정 범위 밖 0
- 기관은 **자기가 보낸 요청만** 본다(같은 기관의 다른 담당자 것도, 다른 기관 것도 열리지 않는다 — '없는 요청'과 같은 답).
- 요청은 **관할 필지만** — 관할 밖 필지 번호 · 위치로 보내면 '없는 필지'와 같은 답(있다는 사실도 알리지 않는다).
- LX 직원은 내가 담당하는 요청만, LX 관리자는 모두. 영업 계정에는 알림 칸 · 검토 요청이 없다.

## 확인 방법(계정 lxadmin — 비밀번호는 대화로만)
1. **https://gov.land-xi.dev** → 기관 **남원시**로 로그인 → 위 **XI맵** → 왼쪽 **규칙**에서 '휴경·전용 의심' → **목록** → 필지 하나 → 카드의 **검토 요청** → 메모 한 줄(안 써도 됨) → **LX 담당자에게 보내기**. (할 일 화면의 판정 카드 · 기관 첫 화면의 필지 카드에도 같은 버튼)
2. **https://app.land-xi.dev** → 로그인(LX 직원) → 위 **알림 칸(종 모양)** 숫자 → 그 요청 → 오른쪽에 저절로 붙은 영상 조각 · 대장 · AI 결과 → 판정 하나(선택) + 한 줄 → **답 보내기**.
   (lxadmin 은 app 주소에서 LX 직원 화면으로 들어가지만 관리자 계정이라 모든 요청이 보인다. '담당 직원만 보는' 모습은 LX 직원 계정으로.)
3. **https://admin.land-xi.dev** → 로그인 → 위 **알림 칸** 숫자 · 왼쪽 메뉴 **검토 요청** → 모든 기관의 요청 · 받는 사람 · 답.
4. 다시 **gov.land-xi.dev**(남원시) → 위 **알림 칸** 숫자 → 그 요청 → LX 답과 판정 · 상태 '답변' · 한 줄 덧붙이기 · **내가 보낸 요청 전체**.

## 시험
- 서버 시험 8개 통과: 요청 만들기(메모 없이도) · 받는 사람(프로젝트장이 먼저 · 카드 담당 직원 / 없으면 LX 관리자) · 같은 필지 다시 보내면 그 대화에 붙음 · 관할 밖 필지 · 위치 거절 · LX 계정 · 로그인 없음 · 영업 계정 거절 · 기관은 자기 요청만(같은 기관 다른 담당자 · 다른 기관 0) · LX 직원은 담당만 · 관리자는 모두 · 알림 수(새 요청 → 담당 · 관리자 +1, 담당이 열면 담당만 −1, 답 → 기관 +1, 기관이 열면 −1) · 답 · 판정(AI 오류 → 재학습 표본 한 줄 · 답 받은 요청은 '열린 기관 신고' 수에서 빠짐) · 기관이 덧붙이면 다시 '보냄' · 화면 말에 '오탐' · '잘못 봤' 0. 함께 돈 관할 · 요약 시험 21개도 통과(요약 시험은 요약 숫자를 1분 보관하므로 검토 요청 시험 바로 뒤에 돌리면 1분 전 값과 비교해 어긋난다 — 따로 돌리면 통과).
- 화면 흐름 시험 1개 통과: 기관 lxadmin(남원시 · gov 입구) → XI맵 필지 → 검토 요청 → LX 관리자(admin 입구) 알림 칸 · '검토 요청'에서 그 요청과 받는 사람 → LX 직원(app 입구) 알림 칸 → 대화 → 'AI 오류' + 한 줄 → 기관 알림 칸 → 내가 보낸 요청에 답 · 판정 · '답변'. 로그인은 폼 입력만, 시험이 만든 요청은 끝에서 지움.
- 금지어 검사: 기관에서 온 요청(LX 직원 · LX 관리자) · LX 관리자 대시보드 · 할 일 · XI맵 — 0건 · 화면 오류 0.

## 남은 것 · 확인 못 한 것(정직하게)
- **프로젝트장 연결**: 받는 사람은 '그 카드를 낸 프로젝트의 프로젝트장'을 먼저 본다(프로젝트 화면이 쓰는 같은 판정). 프로젝트로 묶인 서비스(비닐하우스 · 곤포사일리지 · 주차장 · 건축물)는 그 프로젝트장이 받고, 카드 아래에 '이 서비스 담당 프로젝트장 ○○○'으로 적힌다. 영농관리 · 생활환경 카드는 아직 프로젝트와 이어지지 않아 공개 · 적용 요청 기록으로 담당 직원을 찾는다(영농관리 = 김도윤 · 생활환경 = 없음 → LX 관리자).
- **담당 다시 정하기**(담당이 떠났을 때 관리자가 다른 직원에게 넘기기) 화면은 만들지 않았다 — 확인된 범위 밖.
- 기관 첫 화면 · 서비스 고르기 화면(다른 갈래가 만드는 중)에는 '내가 보낸 요청' 메뉴 칸을 넣지 않았다. 알림 칸의 '내가 보낸 요청 전체'로 연다(주소에 review=all 을 붙이면 바로 열린다 — 그 갈래가 메뉴로 이으면 된다).
- LX 직원 대시보드의 왼쪽 단계에는 '기관에서 온 요청' 칸을 넣지 않았다(다른 갈래 파일). 알림 칸 → '기관에서 온 요청 전체'로 간다.
- 해외 기관 화면에는 검토 요청 버튼을 넣지 않았다(그 화면은 이 갈래 밖). 알림 칸은 해외 기관에도 영어로 선다.
- 대화의 '영상 조각'은 그 필지 둘레의 위성 영상 위 필지 경계다. 기관이 본 드론 · 항공 정사영상 그 장면 그대로는 아니다.
