> 근거(확인된 것만): 확인 요청 6차 기관 한 흐름 "일단 진행" · 기관별 메인(구조화된 틀) · 마크·이름·색은 기관 관리자 직접 + LX 관리자도 · 5차 남원 서비스 선택 흐름 · 4차 기관 분기 흐름 ·

## 무엇이 바뀌었나
1. **기관별 메인(로그인 전)** — 모든 기관이 같은 틀: 상단 바(마크 · 플랫폼 이름 · 서비스 소개 · 이용 방법 · 문의 · 로그인) → 머리(기관 이름 · 두 줄 머리 · 설명 · 그 기관 모습의 로그인) → 우리 기관 AI 분석 서비스(켜진 서비스 카드 · 상태) → 이용 방법 3단 → 바닥(대표전화). 기관은 주소가 정하므로 기관 고르기 없음. 로그인 아래 '가입 신청 · 아이디 · 비밀번호 찾기'는 계정 갈래의 같은 창(그 기관 하나로) · 임시 비밀번호로 들어오면 새 비밀번호 정하기 창.
2. **서비스 선택 → 서비스 대시보드 → 기존 기관 화면** — 로그인하면 서비스 선택(하나뿐이면 그 서비스로 바로). 대시보드 = 큰 숫자 하나(현장 확인 필요 · 없으면 AI 탐지) · 할 일(결과 확인 대기 + 점수 높은 필지 셋) · 최근 결과(AI 분석 결과 기준일 · 등록된 영상). 탭 '결과 보기 · 필지 대조 결과 · 보고서'는 지금 있는 기관 화면으로 서비스를 붙여 넘긴다. 광역 기관만 '광역 전체 / 시·군·구' 한 칸이 더 있다. 결과가 없는 서비스는 '첫 결과 전', 다음 해 사업은 '내년'(숫자를 지어내지 않음).
3. **로그인 뒤 머리 · 메뉴** — 서비스 선택 · 지도 · 할 일 · 보고서 화면 모두 머리에 기관 마크와 플랫폼 이름. 왼쪽 메뉴 = 내 서비스 · 내가 보낸 요청(검토 요청 목록) · 기관 정보(기관 관리자).
4. **기관 정보 고치기** — 마크 그림(PNG · JPG · WebP · 1MB 이하 · 가로세로 64–2048픽셀) · 마크 글자 · 플랫폼 이름 · 약칭 · 기관색 두 가지 · 머리 두 줄 · 설명 세 줄 · 서비스마다 한 줄 소개 · 대표전화. 기관색은 대비 검사를 통과해야 저장된다(흰 바탕에서 읽히는지 · 검정에 가까운지 · 연한 바탕이 너무 짙은지 · 두 색 차이). 저장하면 메인에 바로 반영. 고칠 수 있는 사람 = 그 기관의 관리자 + LX 관리자(서버가 확인). 서비스 목록은 LX 관리자만.

## 남은 것(정직하게)
- 기존 기관 화면(지도 · 할 일 · 보고서)은 아직 서비스를 가려 보여 주지 않는다 — 넘겨준 서비스 표시를 읽어 그 서비스만 보이게 하는 것은 그 화면 갈래에서. 지도 화면 왼쪽 목록에는 LX 가 돌린 다른 서비스(비닐하우스 · 국토 변화)도 보인다.
- 기관 서비스 목록(남원 넷 · 광주전남 하나)은 처음 값으로 넣었다. LX 관리자 화면에서 목록을 바꾸는 칸은 아직 없음(서버는 LX 관리자만 받는다).
- 자체 도메인(요청 기관만)은 설정 칸만 있다(연결 · 인증서는 나중).
- 해외 기관 메인은 영어 틀로 열리지만 소개 글은 비어 있다(기관이 채운다).
