## 이런 것도 필요하지 않을까요?
- **긴 요청은 나눠 답하기**: 실태조사 요청(C19)처럼 '목록 + 법령 + 표'를 한 번에 묻는 말은 칸마다 정해진 답(의심 필지 틀 · 조문 원문 · 보고서 단추)을 차례로 붙이면 돌릴 때마다 같은 모양이 됩니다(누가: 보고서에 옮겨 적는 공무원).
- **관리자 전용 질문의 거절 문장 한 가지로**: '서버 · GPU · 사용량'은 직원 · 기관에게 "이 계정에서는 볼 수 없습니다 — LX 관리자 화면에서 봅니다"로 통일하면 C35 가 닫힙니다(누가: 권한 경계를 확인하는 보안 점검).
- **도구 설명 줄이기**: 지시문 + 도구 설명이 문맥의 절반(7.4K)을 씁니다. 화면별로 쓰는 도구만 내놓으면 답이 빨라지고 넘침 여유가 커집니다(누가: 느림을 겪는 모든 사용자).
