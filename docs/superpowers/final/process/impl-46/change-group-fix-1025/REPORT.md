# 국토 변화 · 산사태 — 12분류 묶음 공식 이름 기준으로 바로잡음 (10-25 사용자 "응 고쳐")

## 1. 무엇이 틀렸나
변화 엔진(`server/change/detect.py`)이 다른 과제의 묶음(`geoai_roadland/src/characterize_idle.GROUP`)을 빌려 썼다.
그 묶음은 **나지(10)를 경작에**, **비대상지(0)를 '나지초지'에**, **주차장(2)을 건물에**, **가로수(4)를 경작에** 넣는다.
그래서 산사태 '산림 → 나지'는 실제로는 '산림 → 비대상지'를 셌다.

`characterize_idle` 원본은 고치지 않았다(도로공사 과제의 cover_full · loc_pass · sam_* 스크립트가 쓴다 · Land-XI 안에서는 change 엔진만 썼음).

## 2. 새 묶음(change 엔진 안 · 공식 이름 AI 허브 토지피복 라벨)
| 묶음 | 공식 분류(번호) | 예전 |
|---|---|---|
| 건물 | 건물(1) | 건물 · 주차장 |
| 도로 | 주차장(2) · 도로(3) | 도로 |
| 경작 | 논(5) · 비닐하우스(6) · 밭(7) | 가로수 · 논 · 비닐하우스 · 밭 · **나지** |
| 산림 | 활엽수림(8) · 침엽수림(9) | 같음 |
| 수역 | 수역(11) | 같음 |
| 나지 | 나지(10) | '나지초지' = **비대상지(0)** |
| 제외(변화 판정 안 씀) | 비대상지(0) · 가로수(4) | — |

주차장을 도로 쪽에 둔 근거: 주차장은 포장면이라 '포장 확대'(나지 · 경작 → 도로)에 드는 것이 맞고, 건물에 두면 새 주차장이 '신축'으로 잡힌다.
또 U-Net 이 포장면을 해마다 흔들어 잡는 것을 막으려고 도로 ↔ 건물 전이를 세지 않는 규칙(change-2)이 이미 있어, 주차장 ↔ 건물 흔들림도 같이 빠진다.
