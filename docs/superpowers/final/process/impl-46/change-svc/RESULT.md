## 직원이 아직 혼자 못 하는 것(솔직히)
1. 밖에서 학습한 모델(ap25)을 장부에 올리고 승인받는 일 — 화면 · 길 없음(1번 막힘).
2. 대상지를 기관에 공유하는 일 — 기관 공유는 지금도 '프로젝트에 묶인 대상지'만 가고, 카드에서 올린 대상지는 기관 화면에 안 감(대상지별 공유 화면 없음 · 서버 API 만).
3. 등록 영상(내 영상 · 공유 데이터)으로 비교한 결과는 지도 위 두 시점 가르기가 없음 — 폴리곤 칸의 두 시점 그림으로만 견줌(국토지리정보원 해끼리는 가르기 그대로).
4. 대상지 이름 바꾸기 · 지우기 · 다 쓴 시험 대상지 정리 화면 없음.
5. 같은 구역선 · 같은 두 해의 끝난 결과를 이어 붙인 회차는 새 작업 줄 없이 결과만 생김(예전부터의 동작) — 지도 서비스 목록에는 원래 작업 줄 하나로 보임.

## 제안(만들지 않음 · 채택은 사용자)
- **대상지 관리 칸**(국토 변화 카드 안): 대상지 이름 바꾸기 · 보관 · 기관 공유 체크 — 누가: LX 직원 · 왜: 카드에서 대상지를 직접 올리게 되면서 시험 · 중복 대상지가 쌓이고, 도로공사 같은 기관에 어떤 구간을 보여 줄지 직원이 정해야 함.
- **등록 영상 두 시점 가르기**: 공유 데이터 · 내 영상으로 비교한 결과도 지도에서 좌우로 갈라 보기 — 누가: 판정하는 직원 · 왜: 드론 · 자체 촬영 영상은 국토지리정보원 해와 시기 · 해상도가 달라 결과를 같은 영상 위에서 봐야 판정이 맞음.
