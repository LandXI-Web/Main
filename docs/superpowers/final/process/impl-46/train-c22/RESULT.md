## 막힌 곳
1. **판에서 '이 PC 학습 묶음'(farm-v2 같은 dataset.yaml)으로 학습한 모델이 추론 · 배포 신청에 안 나온다.**
   - 원인: 추론 · 배포 신청의 모델 목록(server/landxi_api/release.py `project_models`)이 '프로젝트에 이어진 올린 학습 표본(smp_)'으로 만든 모델만 센다. 묶음으로 학습한 모델은 표본 id 대신 묶음 경로가 들어가 빠진다. 10-13 운영 판도 같은 이유로 이 프로젝트 추론 화면에 안 나온다.
   - 고칠 길(제안 · 확인 뒤): 학습 작업에 적힌 프로젝트(options.project_id)로 만든 모델도 목록에 넣는다. 고치면 게이트웨이를 다시 띄워야 한다. 이번에는 시험 모델이 배포 신청 화면에 오르지 않도록 고치지 않고 남겼다.
2. **평가를 시작하는 화면 단추가 없다.** 판의 '추론' 블록은 '학습이 끝나면 추론합니다'라고 하지만 실제로 저절로 돌지 않는다. 이번에는 같은 대기열 길(/jobs, 검증만)로 두 번 넣었다. → 학습이 끝나면 같은 검증 묶음 평가를 저절로 넣는 것이 필요.
3. **판 기본 학습 설정에 학습률 덧값이 없다.** 이어 배우기를 짧게 돌리면 첫 반복이 크게 떨어진다(64 %). 판의 학습 설정 블록에 '이어 배우기(낮은 학습률)'가 필요.
4. **새 모델 이름이 '새 모델 학습 날짜'로 붙는다** — 이 프로젝트에 업무 이름이 비어 있어서. 이번에는 DB 에서 '경작지 시험 학습 2026.10.22'로 이름만 바꿈.
5. 판 서랍이 열려 있으면 '다시 돌리기' 단추를 덮는다(서랍을 닫아야 누름) · 학습 그래프 오른쪽 아래 끝값(76 %)에 XI ChatGEO 단추가 겹친다(원칙 309).
6. 판에서 고를 수 있는 학습 데이터는 '올린 표본(200장 이하)'과 '지난 학습에 쓴 묶음'뿐 — 큰 묶음의 일부만 골라 학습하는 길이 없다.

## 바꾼 것(되돌림 포함)
- server/config/pools.yaml `train_share` true → **false 로 되돌림**(저장소와 같은 값).
- server/config/retention.yaml: `training/farm-v2` 를 30일 정리 대상에서 뺌(이번 시험 · 지난 판의 비교 기준 묶음). 다시 넣으려면 목록에 더한다.
- 모델 1개(후보) · 학습 결과 폴더 1개(87 MB) · 평가 결과 파일 2개가 생김. 운영 모델 · 기관 공유 · 배포 신청 · 승인은 손대지 않음. 게이트웨이 · 작업기 다시 띄우지 않음.
