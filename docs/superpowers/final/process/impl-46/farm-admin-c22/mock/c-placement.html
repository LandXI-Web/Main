3. 규칙 다섯 줄(디자인 법전 §6-1 초안)

자리는 다섯 개뿐

왼쪽 위 판 · 오른쪽 도구 열 · 오른쪽 기둥 · 아래 가운데 대화 · 왼쪽 아래 결과 카드. 떠 있는 요소는 이 다섯 자리 중 하나를 선언한다. 자리 없는 떠 있는 요소는 만들지 않는다.

한 자리에는 하나

같은 자리에 둘이 열리면 앞것은 닫히거나 접힌다(서랍 ↔ 지도 위 통계 ↔ 대화 서랍). 모달만 예외(위에 덮지만 뒤는 흐리게 · 동시에 1).

대화는 틈에 선다

XI ChatGEO 입력 · 답 띠는 다른 자리 사이의 가장 넓은 빈 틈에 서고(280~680), 틈이 모자라면 결과 카드 → 왼쪽 위 판 순으로 접는다. 답 띠는 줄이지 않는다.

휴대폰은 시트 하나

640 아래에서는 오른쪽 기둥 · 왼쪽 위 판 · 대화가 모두 아래 시트 하나로 모인다(높이 3단). 지도 위에는 입력 한 줄과 도구 열만 남는다.
