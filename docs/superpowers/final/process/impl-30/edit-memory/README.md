## 남은 것
1. **전국 작업기는 다음에 다시 켤 때 새 마무리 코드를 씁니다.** 지금 도는 작업기(10-14 아침 시작)는 옛 코드라, 그 사이 다시 도는 칸에서는 저절로 적용은 되지만(작업기 마무리) 칸 숫자에 지운 객체가 함께 세이고 고친 객체 줄이 지워집니다. 지금 실제(시험 아닌) 전국 결과 고치기는 0건이라 영향은 없습니다. 멈춤 → 다시 켬 한 번이 필요합니다(설정 변경이라 제가 하지 않았습니다).
2. 전국 결과 칸은 '경작지 v2' 프로젝트 학습 데이터로 셉니다. 그 프로젝트에는 서비스 카드가 없어 XI 재학습 줄(서비스별)에는 나오지 않습니다 — 학습은 프로젝트 학습 화면에서.
3. '다시 잡은 곳'은 그 판의 새 결과가 나온 뒤에만 나옵니다(전국 결과 · 서비스 재분석). 아직 새 결과가 없는 판의 신청서에는 줄이 없습니다.

## 제안 — 이런 것도 필요하지 않을까요?
1. **'다시 확인' 자리 모아 보기** — 누가 · 왜: LX 직원. 새 연도 영상으로 다시 분석하면 '이전에 지운 자리'가 여러 곳 생깁니다. XI맵에서 그 자리들을 한 번에 넘겨 보며 '지움 그대로 · 이번엔 맞음'을 고르면 연도가 바뀐 곳 확인이 빨라집니다.
2. **새 판 시험 범위 자동 고르기** — 누가 · 왜: LX 관리자. 배포 신청 전에 지운 자리가 많은 작은 범위를 골라 새 판을 한 번 돌리면, '다시 잡은 곳'이 신청서에 늘 들어갑니다.
