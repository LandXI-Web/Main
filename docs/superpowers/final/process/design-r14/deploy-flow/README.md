## 5. 제안(원칙 57 — 채택은 사용자)
1. **승인된 판이 기관에 자동으로 바뀌지 않게** — 기관이 쓰는 중인 판을 관리자가 '새 판으로 바꾸기'로 올리고, 결과 이력에 '2.0 → 2.1 바뀐 날'이 남으면 기관 담당자가 결과 차이를 설명할 수 있다.
2. **기관 쪽 '새로 공유됨' 알림** — 공유되면 기관 관리자에게 알림 한 줄(요청함과 같은 길) · 기관 관리자가 부서에 배정(space_assign)해야 부서 사용자에게 보인다는 안내.
