## 2. 한 틀(ⓐ · ⓑ 공통 규칙)
그림(3:2 · 한 장 · 합성 없음 · 없으면 같은 틀에 "결과 장면이 아직 없습니다" 한 줄) + 상태 배지(그림 왼쪽 위 한 자리 · 운영 · 시범 · 첫 결과 전) → 윗줄: 분야 · 입력 영상 → 이름 → 한 줄 소개("~을 찾습니다" · 24자 이내) → 큰 숫자: AI 분석 결과 n 필지/건 ✓ + 지역 · 기준일 / 없으면 같은 자리에 "—" + 한 줄("결과 수 집계 전 · 지역" 또는 "첫 결과 뒤 표시") → 아래 칸: 쓰이는 곳 · 걸리는 시간(없으면 "첫 분석 뒤 표시") → 버튼 자리: [이 카드로 분석] + 자세히 / 할 수 없으면 같은 크기 회색 칸에 까닭 한 줄.
- 셈 단위 규칙: 필지 대조가 있는 카드 = 필지, 없는 카드 = 건.
- 판 번호 · 담당은 카드와 상세에서 뺀다(서비스 카드 관리에만).
- ⓐ 세로(그림 위 · 4열 · 아래 칸 둘) / ⓑ 가로(그림 옆 · 2열 · 아래 칸 셋 = 찾는 것 추가 · XI맵 '이 영상에 이 분석' 작은 카드로 그대로 줄어듦).
- 상세: 목록 카드와 같은 순서(그림 → 윗줄 → 이름 → 소개 → AI 분석 결과(지역별 표) → 이 카드의 조건 → 영상과 결과) · 오른쪽 '이 카드로 분석'은 그대로.
