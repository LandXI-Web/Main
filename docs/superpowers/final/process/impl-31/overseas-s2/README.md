지금까지 해외 바탕은 EOxCloudless(비상업 CC BY-NC-SA · 상업은 EOX 유료 계약)였습니다. 이번에 **Copernicus Sentinel-2 L2A 원 자료로 직접 만든 구름 없는 모자이크(10 m)** 로 바꿨습니다. 무료이고 상업 이용도 됩니다(출처 표기 조건).

## 만든 방법 — `bake_s2.py`
1. **장면 고르기:** AWS 공개 Sentinel-2 L2A COG를 Earth Search STAC에서 찾았습니다(키 · 계정 · 메일 없음). MGRS 칸 × 궤도(무자료 비율 10 % 단위로 묶음)마다 구름이 적은 장면을 나라 판은 3장, 구역 판은 6장 골랐습니다. 궤도별로 고르지 않으면 궤도 끝 칸에 빈 쐐기가 남아서 이렇게 고쳤습니다.
2. **구름 가림:** 장면 분류(SCL)를 써서 구름(8 · 9) · 권운(10) · 구름 그림자(3) · 포화(1) · 무자료(0)를 뺐습니다. 식생 · 맨땅 · 물 · 눈 · 어두운 곳은 그대로 씁니다.
3. **중앙값 합성:** 참색(TCI)을 웹 지도 좌표(EPSG:3857)로 바로 다시 투영해 화소마다 중앙값을 냈습니다. 늘 구름인 곳은 있는 관측 전부의 중앙값으로 채웠습니다. 나라 판은 COG 내부 축소판(80 · 160 m)만 읽어 받는 양을 줄였습니다.
4. **밝기 맞춤:** 나라 판에서 띠별 0.5 % 값을 검은 점으로 잡고, 감마 0.88 · 채도 1.12를 적용했습니다. 같은 나라 고줌 판도 같은 값을 써서 줌을 바꿔도 톤이 튀지 않습니다. 국내 브이월드 영상과 비슷한 밝고 따뜻한 참색입니다.
5. **조각:** 가장 높은 줌에서 256 조각(WebP 86)을 만들고, 아이 조각 넷을 합쳐 낮은 줌을 만들었습니다. 자료가 없는 칸은 투명 처리해 밑 바탕이 비치게 했습니다.

다시 굽기: `python bake_s2.py [kg kg-chuy mm mm-meiktila]`(gcs 환경). 같은 판을 다시 구워도 밝기 값은 meta.json에 있는 그대로 씁니다.

## 바꾼 곳 (코드 한 곳)
- `landxi/v3/kit/stage.js` — 지도 무대 공통 바탕입니다. `meta.json`의 판마다 `k-s2-{판}` 층을 국내 바탕(k-vw) 바로 위 · 자체 영상과 결과 아래에 얹습니다(범위 · 줌은 판이 정함 · 지역 고정값 0). 판이 화면에 보일 때만 지도 오른쪽 아래에 **"Contains modified Copernicus Sentinel data 2025–2026"** 을 표시합니다. meta가 없으면(정적 배포) 그냥 건너뜁니다.
  - 무대를 쓰는 화면 전부(XI맵 · 메인 · 해외 첫 화면 등)에서 위 해외 범위는 새 바탕으로 보입니다. 국내 바탕과 국내 화면은 범위 밖이라 그대로입니다.
