## 한 줄
**로그인한 모든 화면의 오른쪽 아래 같은 자리에 둥근 버튼이 있고, 누르면 그 위로 'XI ChatGEO' 채팅창이 열린다. 지도를 보면서 말로 묻고 이어서 대화하며, 답에는 지도 동작 · 숫자 · 차트 · 법령 원문 · 내려받을 파일이 그대로 들어간다. 위쪽 '물어보기' 버튼과 'Ctrl K' 글자는 없앴고, 단축키(Ctrl · ⌘ K)는 그대로 열린다.**

## 마스코트 — 바꾸는 곳은 한 곳
- 지금은 **LX 심볼**(LX 한국국토정보공사 로고의 'LX' 마크)을 버튼 · 머리 · 답 옆 세 자리에 쓴다. 새로 그린 후보(설계 6차 시안의 그림)는 쓰지 않았다.
- 표정 세 자리(기본 · 생각 중 · 답함)가 따로 있고 지금은 같은 그림이다. **랜디 원본(정사각 그림 셋)을 받으면 마스코트 설정 한 곳의 세 줄만 바꾸면** 모든 화면의 버튼 · 머리 · 답 옆이 함께 바뀐다.

- 규칙: 지도에 그리는 동작은 **화면이 실제로 그린 것을 확인한 뒤에만** '그렸습니다'라고 둔다. 그 화면이 처리하면 그 화면의 확인을, 아니면 채팅이 직접 그리고 보이는지 잰다. 확인되지 않으면 그 문장을 '그리지 못했습니다'로 바꾼다.
- 휴대폰에서는 지도에 그린 뒤 시트를 내려 지도가 보이게 한다(버튼으로 다시 연다).

## 막다른 말 없애기 — "그 지도 동작은 아직 할 수 없습니다"
- 답이 '할 수 없습니다'류로 끝나면 그 아래에 **이유 한 줄 + 할 수 있는 것 두세 개(누르면 바로 묻는다)**를 붙인다. 지도가 있는 화면: '이 화면 지도에서는 이동 · 확대 · 축소 · 기울이기 · 영상 층 켜고 끄기를 할 수 있습니다' + 지도 확대해 줘 · 3D로 기울여 줘 · 어느 지역에 어떤 결과가 있어? / 지도가 없는 화면: **XI맵에서 크게 보기**(가장 가까운 일) + 그 역할의 추천 질문 둘.
- 지도 동작이 안 됐을 때(더 확대할 수 없음 · 지도 없음)도 같은 '이렇게 해 볼 수 있습니다' 덩이가 붙는다.
- 재현 '지도를 흑백으로 바꿔 줘' → ![](img/after-fix-deadend-1440.png). 고치기 전에는 '그 지도 동작은 아직 할 수 없습니다.' 한 줄로 끝났다.
- 자세한 대화 규칙(무엇을 대신 해 줄지)은 페블이 설계 중 — 확인 요청으로 올라온다. 이번에는 고장과 막다른 말만.

## 확인 방법(계정 lxadmin · LX 직원 test@lx.or.kr — 비밀번호는 대화로만)
1. **https://app.land-xi.dev** → 로그인 → 오른쪽 아래 둥근 버튼 → 추천 질문 하나 → 답(✓ 단계 · 숫자 · 표 · 차트) → 닫기. 키보드 Ctrl K(맥 ⌘ K)로도 열리고 Esc 로 닫힌다. 위쪽에 '물어보기'가 없다.
2. 같은 창에서 프로젝트 · XI맵으로 옮겨 버튼을 누르면 앞 대화가 그대로 있다.
3. '남원시 현장 확인 필요 필지 지도에 보여 줘' — 첫 화면에서는 지도에 점이 찍히고, 프로젝트 목록(지도 없음)에서는 '그리지 못했습니다' + 표 + XI맵에서 크게 보기.
4. **https://admin.land-xi.dev** → 분석 대기열 요약 · 기관별 사용량(차트). **https://namwon.land-xi.dev** → 남원시로 로그인 → 농지 전용 근거 조문(원문 인용) · 보고서 초안(내려받기).
5. 휴대폰으로 같은 주소 → 오른쪽 아래 버튼 → 아래 시트.
6. 로그아웃하고 메인 소개 · 로그인 화면 → 버튼 없음.

## 시험
- 화면 흐름 시험(로그인 폼 입력 · 세션 주입 없음): 세 입구(LX 직원 · LX 관리자 · 남원시 기관) × PC · 휴대폰 — 첫 화면에 위쪽 물어보기 0 · Ctrl K 글자 0 · 버튼 보임 · 누르는 것과 겹침 0 → 버튼 → 채팅창(PC 380 × 560 · 휴대폰 아래 시트 72%) → 추천 질문 셋 → 질문 → 답 블록 → 금지어 0(창 열린 채) → 닫기 → 단축키로 열림 · Esc 로 닫힘 → 다른 화면에서 같은 자리 · 대화 이어짐 → 화면 오류 0 · 로그인 전 화면(메인 소개 · 로그인 · 기관 메인)에 버튼 없음 · 단축키로도 안 열림. **이 PC 59 / 59 통과 · 바깥 주소(app · admin · namwon.land-xi.dev) 57 / 57 통과**(결과 기록은 이 폴더).
