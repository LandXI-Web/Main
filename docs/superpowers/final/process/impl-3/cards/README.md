- ④ 자리는 부품 모양까지만 만들었다(기관 공간 화면은 다음 작업). 캡처의 2차 카드 글은 모양 확인용이며 실제 서비스가 아니다.
- 같은 부품을 LX 직원 대시보드의 '서비스 장면'도 쓴다(다른 작업이 붙였다).

## 남은 것
- 기관 공간 화면 자체(④ 자리)는 다음 작업(분기 공간 1단) — 이번에는 카드 모양까지.
- 기관 카드의 '담당 부서' 칸은 서비스별 담당 부서 정보가 서버에 없어 비워 두었다(사업 연도 · LX 담당만).
- 건축물 카드의 장면: 시안의 산청 장면은 밖으로 내보낼 수 없는 항공영상이 바탕이라 쓰지 않았다 → 회백 판. 원주 결과 장면을 '결과 장면 올리기'로 넣으면 채워진다.
- 장면이 없는 카드 8장(곤포사일리지 · 주차장 · 건축물 · 생활환경 · 도로 · 인파 · 산림 · 해외 둘).
- 갤러리는 카드 목록이라 첫 화면 글 · 버튼 예산(300자 · 8개)을 넘는다(글 약 560자 · 칩 포함 단추 18) — 설계 때 '카드당 60자'로 재자는 제안이 있었고 아직 확인 전.

## 이런 것도 필요하지 않을까요?
- **분석이 끝나면 결과 장면 자동 후보** — 누가: LX 직원(카드 담당). 왜: 장면 없는 카드가 8장이다. 분석이 끝난 지역의 결과 조각을 서버가 잘라 '고를 수 있는 장면'에 넣으면 고르기만 하면 된다.
- **기관 카드의 담당 부서** — 누가: 기관 사용자 · LX 직원. 왜: 원칙 102(기관 쪽 담당자도 보인다). 서비스마다 기관 안 담당 부서를 기관 관리자가 한 칸 적으면 카드 ③과 LX 요청함에 같이 보인다.
- **오래 걸리는 분석은 한 번 더 확인** — 누가: LX 직원. 왜: 남원 비닐하우스처럼 시군구 전역이 2시간 넘게 걸리는 경우가 있다. 걸릴 시간이 1시간을 넘으면 '분석 시작' 전에 한 줄 확인.
