## 3. 꼬리표 색 점
지도 위 통계 꼬리표(읍면동 이름 · 숫자) 이름 앞에 색 점. 한 업무 통계면 그 클래스 색(사용자가 고른 색 — `kit/colors.js` colorState 의 값이 먼저), 모든 업무 통계면 그 곳의 지도 색. 색 칸에서 바꾸면 `recolor()`가 꼬리표 점도 바로 다시 칠한다. 그림: `after-1920-stats-step1.png` · `after-1920-stats-step2.png`.

## 4. 색-공유 '내 화면만' — 확인만(변경 없음)
고른 색은 브라우저 저장소(`lx.colors.v1.{사람}.{화면}.{층}`)에만 있고, 보고서(`POST /ximap/report.hwpx`)는 서버가 준 사양(spec)만 보내며 기관 공유(배포)에도 색은 들어가지 않는다. 다른 사람 · 다른 화면 · 기관 XI맵에는 새지 않음.
