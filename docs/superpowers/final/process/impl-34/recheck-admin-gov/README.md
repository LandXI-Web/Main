## 2. 안 되던 것 · 고친 것

1. **인프라 · 배포 탭이 20~30초 멈춤** — 기관 사용 현황(`/ops/tenants`)을 부를 때마다 결과 폴더 전체 크기 · 기관 DB 행 크기를 새로 세어(20초), 30초 갱신마다 겹쳐 쌓였습니다. 서버가 미리 세어 두고(게이트웨이 켜질 때 · 60초 지나면 뒤에서 다시 셈 · 동시에 와도 한 번만 셈) 바로 줍니다. 한도를 바꾸면 다음 요청은 새로 셉니다. 배포 → 사용 현황도 같은 값을 씁니다.
2. **사용 현황 탭이 몇 초 빈 화면** — 표가 오기 전 '불러오는 중'(원칙 212)을 보이고, API 호출 열 값은 함께 부릅니다. 지금은 0.5초 안에 뜹니다.
3. **작업 목록이 6.9MB** — 관리자 화면은 작업 범위 도형을 쓰지 않아 빼고 받습니다(870KB). 작업마다 따로 묻던 진행 값도 한 번에 묻습니다.
4. **인프라 '최근 24시간 작업'이 500으로 멈춰 있음**(목록 500건 상한) — 서버가 센 수(2,309)를 씁니다.
5. **XI ChatGEO '운봉읍 무허가 건축 의심 필지'가 '해당 지역 데이터가 없습니다'** — 이름 때문이 아니었습니다. 모델이 읍면동('운봉읍')을 지역 칸에 넣어 시군구를 못 찾았습니다. 화면 지역(관할) 시군구의 읍면동이면 그 읍면동으로 읽습니다 → 431필지 · 상위 5곳 지도 표시. 기관 쪽 '운봉읍 … 몇 곳'은 시군구 전체 숫자로 바로 답하던 길을 타지 않고 그 읍면동 · 규칙 숫자로 답합니다.
6. **개선 후보** — 이미 답하는 후보(11줄)에 '이대로 반영'(답 문구 붙이기) 대신 '지금 됩니다'. 정기 개선 바퀴가 판을 올릴 때 '고치기 전에도 답하던 후보'를 함께 싣습니다.
7. **한 단어 줄 3곳** — 기관 한 곳 최근 기록 · 개선 후보 · 기관 보고서의 문장 끝 줄바꿈을 막았습니다(1280 · 1366 · 1440 · 1920 모두 0).

## 3. 규칙 이름 통일 — '무허가 건축 의심' → '농지 위 건물'

- 규칙 정의(R1) · 서버 규칙 이름 · DB(실태조사 결과 16,130행 · 규칙 표 · 승인 요청 1건) · 화면 견본 데이터 · 보고서 초안 → 모두 '농지 위 건물'. 실태조사 보고서 초안(운봉읍)에 '농지 위 건물' 26회 · '무허가' 0회.
- XI ChatGEO 답: 규칙 코드('R1', '(R1)')를 빼고, 옛 이름이 답에 나오면 '농지 위 건물'로 씁니다.
- 질문 알아듣기: '무허가 건축 의심' · '불법 건축'으로 물어도, '농지 위 건물'로 물어도 같은 규칙(R1). '대장 농지 위 건물'(L1)과는 섞지 않습니다.

## 이런 것도 필요하지 않을까요?

1. **기관 화면 시작 호출 한 번으로** — `/me` · 기관 정보 · 기관 색 · 메뉴를 한 응답으로 주면, 지자체 담당자가 화면을 열 때마다 1초 넘게 빨라집니다(바깥 주소 왕복이 0.3초라 차례로 부를수록 느림).
2. **느린 화면 알림** — 관리자 인프라에 '최근 하루 3초 넘은 화면'을 한 줄로 두면, 오늘처럼 20초 멈춤을 사용자보다 먼저 압니다.
3. **행정정보와 비교 도형 미리 만들어 두기** — 대장을 올릴 때 한 번 만들어 두면 담당자가 매번 기다리지 않습니다.
