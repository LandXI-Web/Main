# R-D5-1. 오탐 신고 — 기관 이용자 중심으로 (다시 기획)

> 지위: 사용자 확인 전 제안(확인 요청 2차 D5-1 "보류 → 다시 기획"). 코드는 고치지 않았다.
> 사용자 원문(09-30): "오탐 신고는 지자체 직원이나 실제 서비스 이용자인데 화면과 내용은 LX 중심으로만 되어 있다. UI/UX 통일성." · 원칙 46 "신고·요청 기능은 실제로 쓰는 사람(기관 이용자) 중심 화면으로."
> 2차 설계의 LX 쪽 처리(신고함 → 건별 판정 → 표본·기준값·대장 확인으로 자동 분기)는 **받는 쪽 요약**으로만 남기고, 이 문서는 기관 부서 사용자의 화면과 말을 먼저 세운다.

## 1. 누가, 어떤 상황에서
- **남원 GeoVision 농정과 담당자**(부서 사용자). 자기 서비스 '농지이용 전수조사'의 의심 필지 목록을 보다가, 대장을 확인하거나 현장을 다녀와서 **"이 필지는 AI 결과와 다르다"** 고 알게 된 순간.
- 이 사람에게 필요한 것: ① 지금 보고 있는 필지에서 **30초 안에** 알리기 ② 내가 알린 것이 어떻게 됐는지 **한 곳에서** 보기 ③ 답이 오면 **알림 한 줄** ④ 같은 이유의 필지 여러 건을 **한 번에**.
- 이 사람에게 필요 없는 것: 신고 번호 · 접수 담당자 이름 · LX 내부 처리 단계 · 재학습·표본·기준값 같은 LX 말.

## 2. 기관 화면의 말(용어)
| 자리 | 지금(LX 말) | 제안(기관 담당자 말) |
|---|---|---|
| 필지 카드 버튼 | 오탐 신고 | **실제와 다릅니다** |
| 판정 3택 중 하나 | 대장과 같음 | 대장과 같음(AI 결과와 다름) — 고르면 아래 안내 한 줄 "이 필지는 LX 에 '실제와 다름'으로 전달됩니다" |
| 내 목록 | 내 신고 | **내가 알린 필지** |
| 상태 3단 | 접수 → 확인 중 → 처리 결과 | **전달됨 → LX 확인 중 → 답변** |
| LX 쪽 이름 | 신고함 · 오탐 신고 | 그대로(LX 직원 화면에서만) |
- 용어는 갈림길(§8 ②)로 확인받는다 — '오탐 신고'를 기관에도 그대로 쓸지, 기관은 '실제와 다름'으로 부를지.

## 3. 기관 흐름 — 화면 순서대로
### 3-1. 알리기(30초)
1. 어디서: 서비스 작업 공간의 **의심 필지 목록 → 필지 카드**(대장 값 · AI 결과 · 영상 조각이 나란히) · 결과 지도의 필지 카드 · XI맵 필지 카드 — 세 곳 모두 같은 카드, 같은 버튼(공통 P-3 서랍).
2. 버튼 **'실제와 다릅니다'** 를 누르면 카드 안에 작은 시트:
   - 왜 다른가(하나 고름, 담당자 말로):
     - **실제로는 대장대로입니다**(AI 가 잘못 봤음)
     - **대장이 최신이 아닙니다**(대장이 오래됨 — 우리 쪽에서 갱신할 것)
     - **기준이 너무 엄합니다**(이 정도는 위반이 아님)
     - **계절·일시적입니다**(수확·공사 등 시점 문제)
   - 사진(선택 · 현장 사진 여러 장) · 메모 한 줄(선택)
   - 1차 버튼 **'LX 에 전달'** → 토스트 "LX 에 전달했습니다" (공통 P-2 문형 `{동작}했습니다`)
3. 필지 · AI 근거 · 영상 조각 · 대장 값은 자동으로 붙는다(담당자가 적지 않는다).
4. 판정 화면에서 '대장과 같음'을 고르면 같은 시트가 열린다(이유는 '실제로는 대장대로'가 기본으로 골라져 있고 바꿀 수 있음). 저절로 전달되지 않는다 — **'LX 에 전달'을 눌러야 간다**(2차 설계의 '자동 접수'를 바꿈: 담당자가 모르는 새 신고가 되지 않게).
5. 여러 건 한 번에: 의심 필지 목록에서 체크 → '실제와 다릅니다' → 이유 하나 → 전달. 사진은 건별로 못 붙이고 메모만.

### 3-2. 내가 알린 필지(한 곳)
- 서비스 작업 공간 탭 하나 **'내가 알린 필지'**(기관 메인이 아니라 서비스 안 — 원칙 38 메인은 공통 기능만). 표: 지번 · 이유 · 보낸 날 · 상태 칩(전달됨 / LX 확인 중 / 답변) · 답변 한 줄. 행 = 우측 서랍(내가 보낸 것 · LX 답변 · 근거 조각).
- 부서 사용자는 자기 부서 것만, 기관 관리자는 기관 전체(부서 열 추가).
- 빈 상태: "아직 알린 필지가 없습니다"(공통 P-5 · 행동 없음).

### 3-3. 답변(LX 가 처리하면 기관에 보이는 말)
| LX 판정 | 기관 담당자가 보는 답변 | 그 필지는 |
|---|---|---|
| 맞는 탐지 | "확인 결과 AI 결과가 맞습니다" + 근거 조각(영상·날짜) | 할 일에 그대로(현장 확인 필요) |
| AI 가 잘못 봄 | "AI 오류로 확인했습니다 — 다음 분석부터 반영됩니다" | 할 일에서 빠짐 · 의심 필지 표시 지움 |
| 기준이 엄함 | "기준값을 조정합니다(적용되면 알림)" | 할 일에서 빠짐 |
| 대장 갱신 | "대장 갱신을 확인해 주세요" | 할 일에 '대장 확인' 칩으로 남음 |
| 계절·일시적 | "다음 시점 분석에서 다시 확인합니다" | 할 일에서 빠짐(다음 시점에 다시) |
- 답변이 오면 기관 메인 알림 한 줄("산동면 대기리 615 — 답변이 왔습니다") → 누르면 그 서랍.
- 30일 안에 답이 없으면 상태는 'LX 확인 중'으로 남고 LX 직원 첫 화면 다음 할 일에 "기관 답변 대기 n건"이 뜬다(기관에 독촉 버튼은 두지 않는다).

### 3-4. 광역 · 해외
- 광역 기관: 같은 화면에 시군구 열 하나 더. 해외: 같은 화면 영문(이유 4택도 영문).

## 4. LX 받는 쪽(요약 · 2차 설계 §3-2 유지)
- 서비스 관리(⑥) '신고함' — 프로젝트(R-D3) 6단에 묶임. 표(기관 · 지번 · 이유 · 사진 · 보낸 날 · 상태) → 행 서랍(영상 조각 시점 비교 · AI 근거 · 대장 값 · 기관 메모·사진) → 판정 3택 **맞음 / 오탐 / 모름** + 오탐이면 원인 4택(기관이 고른 값 기본).
- 판정 뒤 자동 갈림: AI 잘못 봄 → 재학습 표본 · 기준 엄함 → 기준값 조정 제안(결재) · 대장 갱신 → 기관 답변 · 계절 → 다음 시점 재분석 예약. 판정과 동시에 §3-3 답변이 기관에 간다(직원이 답변 문장을 따로 쓰지 않는다 — 판정이 곧 답변, 메모 한 줄은 덧붙일 수 있음).
- '기관 신고' 숫자 = 열린 '실제와 다름' 건만(영상 등록 요청 등 제외 — 숫자 한 출처).

## 5. 통일 패턴 적용표(P-patterns.md)
| 장면 | 패턴 |
|---|---|
| 필지 카드 · 알리기 시트 | P-3 서랍 안 시트 · 1차 버튼 1 |
| 내가 알린 필지 표 · 서랍 | P-3 목록→서랍 · P-4 상태 칩 3단(잉크 농도) |
| 전달·답변 알림 | P-2 토스트 `{동작}했습니다` · 알림 한 줄 |
| 빈 상태 · 불러오는 중 · 실패 | P-5 · P-6(막대만) · P-7(인라인 한 줄 + 다시 시도) |
| 여러 건 한 번에 | 표 체크 + 하단 띠 버튼(P-3 표 규칙) |

## 6. 구현 계획(확인 뒤)
1. 서버: '실제와 다름' 접수(이유 4택·사진·메모·여러 건) · 상태 3단 · LX 판정 → 답변 종류 자동 · 기관 알림 · 할 일 제외 규칙 · 부서 범위(원칙 39) · 집계는 열린 건만.
2. 기관 화면: 필지 카드 버튼 + 시트(세 곳 같은 부품) · 판정 '대장과 같음' 연결 · '내가 알린 필지' 탭 · 알림 · 광역 열 · 영문.
3. LX 화면: 신고함(프로젝트 6단) · 판정 3택 + 원인 · 자동 갈림.
4. 실증: 남원 농정과 계정으로 3건(이유 다르게, 1건은 사진) + 여러 건 1회 → LX 판정 → 기관 상태·답변·할 일 변화 · 광주전남(시군구 열) · 해외(영문) 각 1건.

## 7. 완료 기준
- 필지 카드에서 '실제와 다릅니다' → 전달까지 30초 · 클릭 3번 이내.
- LX 판정 → 30초 안에 기관 '내가 알린 필지' 상태·답변 변경 + 알림 1줄 · 'AI 오류' 필지는 할 일에서 빠짐.
- 세 진입점(판정·결과 지도·XI맵)이 같은 시트 · 같은 말.
- 기관 화면에 LX 말(재학습·표본·기준값·신고함) 0.

## 8. 확인받을 것
1. **R-D5-1** — 기관 담당자 중심 흐름(필지 카드 → 이유 4택 → LX 에 전달 → 내가 알린 필지 → 답변 5종 → 할 일 반영) · 자동 접수 대신 '전달' 버튼 — 확인 / 보류 / 반려.
2. **R-D5-1-갈림길** — 기관 화면의 말: ⓐ 기관은 '실제와 다릅니다 · 내가 알린 필지'(LX 만 '오탐 신고') / ⓑ 기관도 '오탐 신고'로 통일.
