## 공통 패턴 핵심 규칙(P-patterns §2 요약)
1. 파일 올리기는 키트 드롭존 하나(끌어 놓기 · 여러 파일 · 진행 막대 · 멈춤/취소 · 실패 한 줄) — 경로 글자 칸·기본 input 0.
2. 승인/반려는 결재 시트 하나(누가·무엇을·왜 → 승인 1차 · 반려 2차 → 반려 사유 필수) · 완료는 `{동작}했습니다` 토스트 · 판정 3택도 같은 시트의 변형(즉시 저장 0).
3. 목록→상세는 표 행 → 우측 392 서랍(×·Esc) — 떠 있는 카드·고정판·팝오버 0.
4. 상태는 칩 사전 한 벌(잉크 농도 3단, 조치 필요만 빨간 글자) · 같은 뜻 같은 말.
5. 빈 상태 = 회백 카드 + 문장 1 + 행동 1 · 불러오는 중 = 막대 1 + 글자(그림 0) · 오류 = 그 자리 한 줄 + 다시 시도(콘솔만·빈 상태로 대신 0) · 되돌릴 수 없는 동작은 확인 카드.
