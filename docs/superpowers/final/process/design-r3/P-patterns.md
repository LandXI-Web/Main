# P. 공통 화면 패턴 — 같은 일은 같은 모양·같은 말 (UI/UX 통일성)

> 지위: 사용자 확인 전 제안. 원칙 43(09-30, 확인 요청 2차 답 거의 전 항목 "UI/UX 통일성도 검토한다") · 원칙 42(뜻 없는 그림 금지) · 원칙 46(반려에는 사유). 코드는 고치지 않았다.
> 근거: v3 화면 16개와 키트(`landxi/v3/kit`)를 읽고, 로그인 폼으로 들어가 1440×900 캡처 33장(`shots/`)을 찍었다. 같은 일을 화면마다 **다르게** 하고 있는 곳을 먼저 모으고(§1), 패턴마다 **하나로 정하는 규칙**(§2)을 표로 세웠다. 이 표가 확인되면 D1·D2·D3·D4 구현과 R-D2·R-D3·R-D5·R-D7 이 모두 이 규칙을 쓴다.

## 0. 한 줄
**화면은 조합만 한다.** 아홉 가지 일(올리기 · 승인/반려 · 목록→상세 · 상태 · 빈 상태 · 불러오는 중 · 오류 · 지역 · 확인 대화)은 키트 부품 하나씩으로만 그리고, 문구는 사전 한 벌에서만 가져온다. 자체 카드·자체 칩·자체 문장은 0.

## 3. 상태 사전(P-4) — 화면이 코드가 아니라 이 표에서 가져온다
| 대상 | 상태(순서대로) | 농도 |
|---|---|---|
| 올린 파일 | 올리는 중 → 올라옴 → 지도에 올림 → 보관 · 실패 | 잉크·잉크·잉크·회 · 빨강 글자 |
| 프로젝트 단계 | 1 데이터 올리기 … 6 서비스 관리(스텝퍼) | 완료 잉크 · 현재 액센트 · 대기 헤어라인 |
| 서비스 | 만드는 중 → 공개 대기 → 공개 · 반려됨 · 중지됨 | 회 · 잉크 · 잉크 · 빨강 글자 · 점선 |
| 결재 | 대기 중 → 승인됨 · 반려됨 | 회 · 잉크 · 빨강 글자 |
