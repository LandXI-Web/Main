## 4. 권하는 제작 방식
1. **뼈대 = 실제 화면 녹화(①) + 우리 지도 연출(②) + ffmpeg 편집(③)** — 크레딧 0 으로 장면 1~8 전부 가능. 영상 생성(④)은 장면 2의 실사풍 '구름 뚫고 내려오는' 1~2컷에만 선택지로 두고, **쓸지는 사용자가 결정**(쓰면 컷당 50크레딧 안팎 · 승인 뒤 정확히 그 수만).
2. **한 타임라인 · 두 벌 출력**: 편집 목록(장면 · 시작 · 길이 · 자막 문안 · 시각)을 파일 하나로 두고 ffmpeg 가 (가) 무자막 마스터 (나) 자막 번인판을 같은 타임라인에서 뽑는다. 아이템 1 · 2 · 3 은 **낱개 클립(자막 유 · 무 각각)**으로도 따로 내보내 VIP 설명 때 골라 틀 수 있게 한다. 자막 파일(.srt)도 따로 둔다.
3. **길이 · 해상도**: 본편 **2분 ~ 2분 30초**(도입 20초 · 플랫폼 30초 · 성과 20초 · 아이템 3 × 20초 · 미래상 15초) · **1920×1080 · 30fps**. 4K는 화면 녹화를 2배 배율로 찍으면 3840×2160 이 되지만 지도 타일 해상도가 따라오지 않아 **1080p 를 권함**(필요하면 4K는 뒤에 추가 녹화).
4. **음악 · 내레이션**: 저장소에 음원이 없고 옛 홍보영상 음악은 권리가 확인되지 않아 **쓰지 않음**. 음악은 사용자(LX 보유 음원) 제공 또는 무음. 내레이션은 음성 합성 외부 서비스를 쓰지 않고 **사용자 녹음 제공** 또는 무자막판은 설명자가 말하는 전제(VIP).
5. **톤**: 밝은 톤(design/system-v2.2-toss.md) · 화면 글자 표준 단계 · 자막은 화면 아래 한 줄 · 의미 단위 줄바꿈(규칙 9) · 내부 지표 0.
