## 1. 한 장 — 구조 2차
```
왼쪽 메뉴 넷        내 서비스 ─ 서비스 카드(현황) + 최근 이력(모든 서비스 · 시간순) + 이번 달
                    요청하기 ─ 탭 셋: 분석 요청 · 촬영 요청 · 보낸 요청
                    기관 정보(관리자) ─ 모습 · 소개 글 · 배경 사진(보기만) · 기록       ※ 담당자 표 없음
                    계정 ─ 사람 · 부서 · 볼 수 있는 서비스
서비스 한 장 탭 다섯  현황 · 결과 지도 · 필지 목록 · 이력 · 통계·보고서
  현황      결과 장면 위 큰 숫자 하나 · 읍면별 · 네 시점  |  이 결과는 · 현장 확인 예정 · LX와 주고받은 검토 요청(+ LX 담당 이름)
  결과 지도  지도 위 '보고 있는 결과' 카드 · '이 영상으로 분석 요청' 버튼 · 필지 카드(확인 결과 적기 · LX에 검토 요청)
  이력      결과 공개 · 확인 기록 · 검토 요청 · 분석 요청 · 촬영 요청 · 내려받기 — 날짜순 한 줄기 · 거르기 · 엑셀
  통계·보고서 상태별 다섯 숫자 · 읍면별 표(39곳) · 월별 확인 기록 · 보고서 만들기 · 자료 내려받기
머리의 종   새 결과 · 검토 답 · 요청 결과(+ 메일 한 줄 — N-1 알림 ⓑ)
```
'우리 공간' 메뉴는 없다(원칙 110). 거기 있던 네 가지(결과 설명 · 내려받기 · 알림 · 부서 배정)는 §3 비교 그림으로 다시 여쭌다.

## 3. 네 가지의 자리 — 두세 안과 추천(`new-compare-n-1440`)
기준 = 공무원이 쓰는 순서 ① 결과 보기 → ② 확인 · 메모 → ③ 보고 · 내려받기.
| 무엇 | ⓐ | ⓑ | ⓒ | 추천 · 이유 |
|---|---|---|---|---|
| 결과 설명 | 현황 '이 결과는' 카드 + 지도 '보고 있는 결과' 카드(같은 세 줄 · 자세히는 서랍) | 결과 지도 옆 패널만 | '결과 자료' 탭 하나(설명 + 내려받기 + 이력) | **ⓐ** — ①단계 두 자리(현황 · 지도)에서 바로, 글은 세 줄로 고정 |
| 내려받기 | 통계·보고서 탭 한 곳(보고서 만들기와 함께 · 지도 카드의 '내려받기'는 이 탭으로) | 현황 카드 아래 + 지도 카드(설계 8차) | 결과 지도에서만 | **ⓐ** — ③단계 한 곳 · 현황 카드가 가벼워짐 |
| 새 결과 알림 | 머리의 종 + 내 서비스 띠 | 종 + **메일 한 줄**(알림에만 · 계정에서 끄기) | 서비스 카드에 점만 | **ⓑ** — 공무원은 매일 들어오지 않는다 · 메일은 2차 인증이 아니라 알림(원칙 89) |
| 부서 배정 | 계정 화면 — 사람마다 '볼 수 있는 서비스' | 기관 정보 — 서비스마다 보는 부서 | 배정 없음 | **ⓐ** — 계정 만들 때 부서와 함께 · 기관 정보에 표를 두지 않음(기관-7) · 원칙 38 |

## 4. 필지 메모 — 서버 기록과의 짝(새 칸 0)
서버(`survey_findings.state · verdict · note · planned_for` · `survey_finding_events`)에 이미 있는 것을 화면 말로만 바꾼다. 지금 남원시에 21건이 적혀 있다(9.27 15건 · 9.29 6건 — 이력 탭 시안의 줄들).
| 화면 버튼 | 서버 | 이력에 보이는 말 |
|---|---|---|
| 맞음 | 확인 끝(closed) · 판정 '의심 맞음'(match) 또는 기존 기록의 '위반' | "— 맞음 · 메모 '…'" |
| 아님 | 오탐(dismissed · 사유 = 메모) 또는 확인 끝 + 판정 '오탐'(match_fp) → 재학습 재료로 LX에 저절로 전달 | "— 아님 · 메모 '대장과 같음'" |
| 현장 확인함 | 다녀옴(inspected) + 다음 확인 날짜(planned_for) · 판정은 메모 | "— 현장 확인 예정 10.04 · 메모 '…'" |
| 메모 한 줄 | note(500자) | 그대로 |
- 기관 담당자(manager)만 적을 수 있다(지금 서버 규칙 그대로). 종결 뒤에는 바꾸지 못하므로 '맞음 · 아님'을 누르면 저장 전에 한 번 묻는다(구현 메모).
- 영농관리 화면의 분류 이름은 '휴경·전용 의심'. 지금 서버 기록의 규칙 이름(2023년 실태조사 규칙)은 이력 줄에 쓰지 않고 주소 · 결과 · 메모만 보인다.

## 5. LX 관리자 두 기능(+ 촬영-4) · 기관-10
- **담당 지정**(기관-11 = 촬영-4): 기관 서랍 표 한 장 — 서비스마다 LX 담당 직원(비면 관리자가 받음) · 맨 아래 '촬영 요청' 담당(직원 또는 관리자 직접). 받는 쪽 규칙은 원칙 63 · 114 그대로: 못 읽는 파일 · 검토 요청 · 분석 요청 · 촬영 요청 모두 그 담당 → 없으면 LX 관리자(관리자도 함께 본다 · 원칙 72). 기관 화면에는 그 서비스의 LX 담당 이름만(대시보드 오른쪽 카드). 기관 정보의 '서비스별 우리 담당자' 표는 없앤다(기관-7).
- **기관 메인 배경 사진**(기관-12): 같은 서랍 — 그 기관에 공유한 영상 · 결과 장면 가운데 고르거나 올림 · 미리 보기 · 로그인 전 화면이라 가로 1,600 이하로만 저장(원본은 내주지 않음 — 9/24 결정과 맞춤). 기관 관리자 화면에는 보이기만.
- **기관-10**: 화면은 한 줄(묶음 제목 · 배지 없음). 2차 서비스는 13차 분기-1 ⓐ(개발자가 올리고 관리자 승인)와 어긋나므로 ⓐ 2차 없음 · ⓑ 2차도 LX가 만들어 올림 · ⓒ 그대로 두되 화면 구분만 없앰 가운데 고르시도록 올렸다.
