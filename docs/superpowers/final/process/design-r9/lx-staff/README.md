## 6. 정직
- 서버의 네 프로젝트가 모두 같은 모양(⑥ 서비스 관리 · ④ 비어 있음)이라 띠 · 목록 시안이 한 가지 상태만 보여 준다. 새로 만든 직후는 '예시'로 그렸고, 중간 상태(③ 학습 중 등)는 그리지 않았다.
- 아카이브 고르개의 '내가 올린 0' · '위성 · 그 밖 5' 칩 이름은 서버 영상 목록의 종류를 내가 묶은 것이다(서버에는 역할 · 출처 · 해상도만 있음). 구현 때 서버가 종류를 내주면 그 이름으로.
- '③ 어디에 쓰나'는 옛 자산에 없던 칸(6차 흐름 1단계 '사업 · 목적'에서 가져옴 · 선택). 필요 없으면 빼도 흐름은 같다.
- 세는 방식 둘(하나씩 세기 / 윤곽까지 따기)은 서버 모델 종류(seg · obb)와 1:1로 잇는 것을 전제로 했다. 지금 서버 모델은 거의 seg 다.
- K-3 ⓑ(위 막대 없앰)를 고르면 단계 화면 안에서 띠가 안 보이므로 막대는 단계 화면 안에서만 남기는 것으로 그렸다.
- GPU 실행 · 코드 수정 · 서버 쓰기 호출(만들기 · 올리기)은 하지 않았다. 서버는 읽기만.
