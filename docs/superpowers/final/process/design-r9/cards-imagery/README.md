### 1-2. 카드 ⑥ 자리 규칙(사다리) — 네 자리 공통
```
위 줄(큰 숫자)   ① 현장 판정 정확도   29% ✓ AI 정확도        작은 글: 현장 판정 24건 기준 · 2026.09.29
                 ↓ 20건 미만이면
                 ② 학습 검증 정확도   67% ~ 학습 검증 정확도  작은 글: 학습 때 검증 표본 기준 · 2026.09.30 · 현장 판정 전
```

### 2-4. 길 셋 + 추천(`mock/view.html?v=join`)
| 길 | 어디에 | 얻는 것 | 잃는 것 |

**추천 = ⓑ + ⓒ.** LX 쪽은 'AI 분석이 먼저'(원칙 45)이므로 직원이 결합을 누르지 않는다. 데이터 올리기는 "영상 4시점 있음 ✓ · 행정 자료 있음 ✓ · 필지 단위 결과 준비됨 · 10.01" 세 줄로 줄고(시안 아래 '지금 / 바뀐 뒤' 두 판), 결합률은 개발자 서랍으로 내려간다. 서비스 카드 조건에 '필지 대조 있음/없음'이 있어 어느 카드가 결합을 받는지 서버가 안다.
