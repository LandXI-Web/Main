# 설계 5차 · 기관 분기 흐름(design-r5/gov-flow) — 한 장 요약

> 2026-09-30 · Fable 5.1(기획·UI/UX). 지위: **사용자 확인 전 제안**(코드 수정 0 · GPU 실행 0 · 코어 3차와 파일 겹침 0). 확인 요청 4차 답(docs/CONFIRM.md) 중 기관 분기 항목 넷 — G1(기관별 메인 → 로그인 → 서비스 선택 → 대시보드 → 서비스별 기능, 마크·이름·색) · U2(영상 올리기의 앞뒤 과정 · 위계) · F1(알림의 받는 사람) · 대장-2(기관 대장은 요구사항 커스텀) — 를 **흐름 먼저(원칙 61)** 로 다시 냈다. 화면 시안은 그 흐름의 한 칸으로만 보인다.
> 방법: 흐름 그림은 HTML(`fig/`) → 1440 폭 전체 캡처. 화면 시안은 실제 키트(`landxi/v3/kit/kit.css` · 토큰 · 서체)를 그대로 불러 HTML(`mock/`) → 1440×900 캡처(메인은 전체). 기관 CI(남원 초록 · 光全 파랑 · 플랫폼 이름 · 문의처)는 옛 포털 자산 `landxi/assets/data/brand.js` 값 그대로. 숫자는 4차 시안과 서버 요약에서 쓴 값(남원 영농 AI 탐지 2,098필지 · 판정 대기 3건 · 기준일 2026.06.08 · 2025년 드론영상 · 2023년 항공영상)만 썼고, 수수료·기간 숫자는 넣지 않았다.

## 1. 기관 분기 한 흐름(`flow.md` · 그림 `shots/flow-1-onestop.png`)
**기관별 메인 → 로그인·가입 신청 → 서비스 선택 → 서비스 대시보드 → 서비스별 기능 → 다음 해 사업** — 여섯 칸, 단계마다 왜 · 누가 · 넣는 것 · 나오는 것 · 다음 단계.
1. 기관별 메인(로그인 전 · 스크롤 소개) — 마크·이름·색·우리 시 서비스 4개 · 이용 방법 → 로그인/가입 신청
2. 로그인 · 가입 신청 — 부서 고르기 → 기관 관리자 승인(반려 사유) → 내 부서 서비스만 보이는 계정
3. 서비스 선택 — 농정과 = 영농관리 카드 하나 + 공통 넷(알림 · 내가 알린 필지 · 분석 의뢰 · 계정) · 하나뿐이면 건너뜀
4. 서비스 대시보드 — 큰 숫자 하나 · 기준/비교 영상 고르기 · 할 일 · 최근 도착 · 내 의뢰·알린 필지
5. 서비스별 기능 — 결과 보기 · 필지 대조 결과 · 보고서 · 내려받기(동의 창 · 기록) · AI가 잘못 봤어요(→ 담당 프로젝트장 → 답) · 우리 영상으로 분석 의뢰
6. 다음 해 사업 — 새 카드가 메인 소개와 서비스 선택에 추가 → 1로
기관 관리자 한 줄: 로그인 → 부서 만들기 → 부서별 서비스 켜기 → 가입 승인 → 활용 현황 → 기관 정보.

## 2. 기관 영상 → AI 분석 의뢰(`request.md` · 그림 `shots/flow-2-request.png`)
'영상 올리기'가 아니라 **'우리 영상으로 분석 의뢰'** — 기관 넷(영상: LX 공유 영상 불러오기 또는 우리 영상 파일 놓기 → 어느 서비스로(내 부서 서비스만) → 비용·기간(LX 수수료 체계에 따름 · 접수 때 견적 · 숫자 지어내지 않음) → 의뢰) · LX 셋(그 서비스 담당 프로젝트장 접수/반려 → LX AI 서버에서 분석 → 표본 확인) · 기관 하나(결과가 서비스 대시보드에 새 시점으로 도착). 상태는 접수 대기 → 접수됨 → 분석 중 → 결과 도착(또는 반려·사유). **기관 화면에 '분석 실행' 버튼은 없다.** LX 공유 영상은 1번 칸의 첫 자리.

## 3. 기관별 메인·브랜드(`brand.md` · 그림 `shots/new-main-two.png`)
남원 · 광주전남 두 장 — 배치·메뉴·카드·버튼은 같고 **마크 · 플랫폼 이름 · 기관색(진한 1 + 연한 1, 대비 검사) · 메인 소개 글 · 서비스 목록(그 기관 실제 사업) · 행정단위 말 · 문의처 · 보고서 머리**만 다르다. 바꿀 수 없는 것: 배치 · 메뉴 이름·순서 · 부품 · 서체 · 흐름 · 서비스 안 탭. 누가 바꾸나(기관 관리자 직접 / LX 관리자 등록)는 확인 항목.

## 4. 알림의 받는 사람(F1 다시)
'AI가 잘못 봤어요'와 분석 의뢰 → **그 서비스 카드를 발행한 LX 프로젝트장(없으면 LX 관리자)** → Land-XI '기관에서 온 것'에서 판정(맞음 · AI 오류 · 모름)/접수 → 기관 '내가 알린 필지' · '내 의뢰'에 답. 흐름 그림 아래 칸과 시안 `new-dashboard-parcels-flag.png` · `new-lx-inbox.png` · `new-flagged.png`.

## 7. 시안 이름 규칙
`shots/flow-*.png` = 흐름 그림 · `shots/new-*.png` = 바뀐 뒤(시안) · `shots/now-*.png` = 지금(4차 캡처를 그대로 복사) · `*-two.png` = 두 장 나란히. 시안 안 노란 번호표와 검은 도장은 설명용이며 실제 화면에는 없다.

## 8. 확인 못 한 것(정직)
- 담당자 이름(박서연 · 이준호 · 김도윤) · 부서 사용자 수 · 영상 파일 이름과 읽은 값은 **예시 표기**(서버 자료 없음).
- 수수료 항목·금액 · 기간 산정 규칙 · 접수 뒤 대기열 방식(자동/예약)은 모름 — 화면에는 "수수료 체계에 따름 · 접수 때 견적"만.
- LX 공유 영상을 누가 정하나(5차 '역할-4') · 남원 기존 두 화면의 자리(5차 '체계-2')는 5차 답에 따른다.
- 광주전남 확대 사업의 대상 해안·연도 미확인 — 카드에 지역을 적지 않았다.
- 확인 요청 페이지 생성은 하지 않았다(오케스트레이터 몫 · `LX_CONFIRM_ITEMS=design-r5/gov-flow/confirm-items.json LX_CONFIRM_EXTRA=design-r5/gov-flow/shots`). `design-r5/lx-flow/` 는 다른 에이전트 몫으로 손대지 않았다.
