## 0. 한 줄
**기관별 메인 → 로그인(가입 신청·승인) → 서비스 선택(내 부서 서비스만) → 서비스 대시보드 → 서비스별 기능 → 다음 해 사업.** 여섯 칸이 한 줄로 이어지고, 모든 기관 화면은 이 여섯 칸 중 하나에 들어간다. 남원시 농정과는 예시이며 어느 기관·어느 부서에도 같은 틀이다.

## 2. 기관 관리자의 한 줄
**로그인(같은 문, 관리자 아이디) → 부서 만들기 → 부서별 서비스 켜기(농정과 ↔ 영농관리 짝만 짓기) → 가입 신청 승인 / 반려(사유 한 줄) → 활용 현황(결과 열람 기록 · 내려받기 기록 · 분석 의뢰 내역 · AI 서버 이용) → 기관 정보(마크 · 이름 · 색 · 소개 글 · 문의처).** 시안 `new-admin.png`.
- 기관 관리자가 **하지 않는 일**: 기관 만들기 · 한도 정하기(LX 관리자) · 모델 · 분석 실행 · AI 결과 고치기(LX 직원). 기관 관리자는 모든 부서의 서비스를 볼 수 있다.
- '기관 정보'의 **바꾸기를 누가 하나**(기관 관리자 직접 / 기관이 내면 LX 관리자가 등록)는 확인 항목(`brand.md` 3절).

## 3. 알림·의뢰가 가는 길 — 받는 사람이 정해져 있다(F1 다시)
```
부서 사용자 ─ 'AI가 잘못 봤어요' + 메모 한 줄 / 우리 영상 분석 의뢰
   → 그 서비스 카드를 발행한 LX 프로젝트장(없으면 LX 관리자) — Land-XI '기관에서 온 것'
   → 판정(맞음 · AI 오류 · 모름) / 접수(수수료·기간) · 반려(사유)
   → 기관 '내가 알린 필지' · '내 의뢰'에 답이 붙고 알림 한 줄
```
- 기관 담당자는 **누구에게 가는지 몰라도 된다** — 카드 아래에 "받는 사람: 이 서비스 담당 LX 프로젝트장 ○○○"이 저절로 적힌다(`new-dashboard-parcels-flag.png`).
- LX 쪽 시안 `new-lx-inbox.png`: 의뢰와 알림이 **같은 받은 곳**에 들어오고, 판정이 곧 답이다. 'AI 오류'는 다음 학습 표본으로 쌓인다(재학습 판단은 발행 전 프로젝트장 · 발행 뒤 관리자 — 원칙 51).
- 기관 '내가 알린 필지' 시안 `new-flagged.png`: 표 한 줄(필지 · 서비스 · 내 메모 · 보낸 날 · 답) + 오른쪽에 주고받은 말 두 칸.

## 4. 광역 기관(광주전남)은 어디가 다른가
- 메인·로그인·서비스 선택·대시보드 틀은 같다. 다른 것은 **대시보드 첫 화면이 광역 전체 합계**로 열리고, **시·군·구는 사용자가 고른다**(화면이 대신 고르지 않음 — 2차 답 D4-광역).
- 계정 범위 밖은 서버가 내주지 않는다(검색 제안 · 지도 · 영상 · AI 도우미 모두).

## 6. 확인 못 한 것(정직하게)
- 담당자 이름(박서연 · 이준호 · 김도윤)과 부서 사용자 수(2 · 3 · 1)는 **예시 표기**다(서버 계정 자료 없음). 서비스 이름·연도·숫자(2,098 · 판정 대기 3건 · 기준일 2026.06.08 · 대표전화)는 옛 포털 자산과 4차 시안에서 쓴 값 그대로.
- '서비스가 하나뿐인 부서는 서비스 선택을 건너 대시보드로' — 사용자 확인 필요(항목 1 안에 적음).
- 필지 대조 결과의 기본 비교를 지적(지목)으로 둔 것은 4차 답 "실태조사 목적으로 필지 번호와 필지 대조 결과 출력"을 따른 것이고, 기관 대장과의 비교는 커스텀 영역으로 남겨 두었다.
