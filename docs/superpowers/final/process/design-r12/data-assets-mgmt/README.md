## 3 · '빠짐없이 그렸나'(자산-2)
문제: 비닐하우스만 그린 그림과 건물만 그린 그림을 합쳐 학습하면, 비닐하우스 그림 속 건물이 '건물 아님'으로 학습된다.

| 방법 | 하는 일 | 사람 몫 |
|---|---|---|
| 선언 | 올릴 때 클래스마다 '이 그림 묶음에서 이 클래스를 빠짐없이 그렸다 · 아니다'. 원래 라벨 목록에 있던 클래스는 기본 '빠짐없이' | 한 번 누름 |
| 자동 대조 | 그 클래스 표준 모델을 돌려, 모델은 찾았는데 라벨이 없는 곳 = '빠진 의심' 목록(작업 대기열 GPU 한 장) | 의심 목록만 봄 |
| 표본 점검 | 관리자가 무작위 20장을 봄 | 20장 |
| 학습 때 | '빠짐없이'가 아닌 층은 그 클래스를 함께 학습할 때 그 그림을 뺀다 | 없음 |

## 6 · 이용 조건 · 내려받기(원칙 133)
```
직원: 불러오기 창 '내려받기 요청'(쓸 곳 · 기간 한 줄)
  → LX 관리자: 공유 데이터 › 내려받기 요청(이용 조건 함께 보임) — 승인 / 반려(사유)
  → 승인: 기한 있는 받기 1회(받은 사람 · 판 · 때가 남음) · 반려: 사유가 요청한 사람에게
  → 기록: 학습 데이터 한 건의 '내려받은 기록' + 감사 기록
```
- 플랫폼 안 재사용(불러오기 · 학습 · 분석)은 승인 없이 바로. 이용 조건은 목록 · 불러오기 창 · 결재 화면에 같은 말로 붙는다.
- 이용 조건 첫 값: 48묶음 중 38 확인 필요(AI Hub 가공 22 · 공개 묶음 12 · 출처 추정 1 · AI Hub 바탕 표본 3) · LX 자체 10 확인됨.
