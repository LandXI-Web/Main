# 설계 12차 · AI 학습 데이터를 자산으로 관리하기

> 2026-10-07 · 사용자 말: "이것 뿐만 아니라 시스템에 AI학습데이터를 자산으로 관리하는 부분도 필요한데." (원칙 131)
> 설계만 했다. 코드 수정 0 · GPU 0 · 원본 자산 이동 · 변경 0. 숫자는 설계 11차 자산 대장(표 1)과 이 PC · 서버 기록에서 직접 센 값이다.
> 시안: `landxi/proto/review/data-assets/` (목록 `index.html` · 한 건 `detail.html`) · 캡처 `shots/`

## 한 장 요약
- **학습 데이터 한 건 = 클래스 목록이 같은 라벨 묶음 하나.** 대장 27줄을 이 기준으로 나누면 **48건**이 된다(표 4).
- **판(버전)으로 관리한다.** 모델이 쓴 판은 잠기고, 라벨을 고치면 새 판이 생긴다. 앞 판은 지우지 않는다. 그래서 어느 모델이 어느 판으로 학습했는지 늘 되짚을 수 있다.
- **고친 것이 쌓이는 길을 연다.** AI 결과가 맞는지 보기(결과 확인)에서 고친 도형과 기관이 알린 오탐이 '다음 판에 담을 것'으로 모인다. 지금 서버에는 기관 오탐 알림 **105건**이 열린 채 쌓여 있고, 라벨로 옮기는 길은 아직 없다.
- **이용 조건을 자산마다 정한다.** 48건 중 **38건은 약관 원문을 아직 못 봐 '확인 필요'** 상태다. 해외 기관 서비스에 쓰기 전에 LX 관리자가 정해야 한다.
- **화면은 LX 직원 메뉴 '데이터' 안에 '학습 데이터' 탭 하나.** 목록과 한 건, 두 화면이다. 프로젝트의 '학습데이터 구축' 단계는 이 목록에서 고르거나 새로 올린다.

## 먼저 제안 — 이런 것도 필요하지 않을까요?
- **학습 데이터 저장 용량을 프로젝트 용량과 따로 셈** — 15만 장 묶음이 직원 할당을 다 먹지 않게(원칙 66). 누가: LX 관리자 인프라 화면.
