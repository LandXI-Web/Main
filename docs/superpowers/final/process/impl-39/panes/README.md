# 칸 크기 조절 — 모든 나뉜 칸(원칙 263 · 2026-10-15)

사용자 원문: "지금 대시보드 결과 보면 왼쪽 지도와 오른쪽 통계 칸이 고정이 되어 있다? 이런 것들이 창을 조율할 수 있는 유연한 UI/UX가 되어야 한다. 이런 조건들은 모든 영역이어야 하고."
원칙 231(창 크기 고정)은 '내용 때문에 저절로 출렁이지 않게'로 좁혀 읽음 — 끈 뒤 크기는 px 로 고정되고, 창(모달) 크기는 그대로 둔다.

## 쓰는 법

```js
import { panes } from '/landxi/v3/kit/panes.js';     // CSS 는 kit.css 가 함께 부름(따로 쓰면 panes.css 를 link)
// 그리드 화면: CSS 는 그대로 두고 한 줄만 더함 — .x[style*="--side"]{grid-template-columns:minmax(0,1fr) var(--side)}
const p = panes(sideEl, { edge: 'left', key: 'side', cssVar: '--side', min: 320, max: 720, otherMin: 480, below: 961, map });
// flex · 지도 위 떠 있는 카드: cssVar 없이 — 칸 자체 width/height 를 정함
panes(cardEl, { edge: 'right', key: 'card', host: stageEl, container: stageEl, min: 280, max: 560 });
```

| 옵션 | 뜻 |
|---|---|
| `edge` | 손잡이 자리. 왼쪽 칸이면 `right`, 오른쪽 칸이면 `left`, 위 칸 `bottom`, 아래 칸 `top` |
| `key` | 칸 이름. 저장 열쇠 = 사람 · 화면 주소 · 칸 이름(브라우저). 저장이 막혀도 그 방문 동안은 동작 |
| `cssVar` · `varHost` | 그리드 화면은 이 변수로 폭을 넘김(기본 부모에). 없으면 칸의 width/height |
| `min` · `max` · `otherMin` | 칸 최소 · 최대 · 나머지 칸 최소(px · `null` = 제한 없음) — 넘침 · 겹침 방지 |
| `map` | 크기가 바뀌면 `resize()` 할 지도(함수 · 배열 가능) |
| `collapse` | 접기 · 펼치기 단추(기본 켬 · 기존 꺾쇠 아이콘 · 짧은 손잡이는 Enter 로만) |
| `below` | 이 화면 폭 미만은 손잡이 없이 화면 기본 배치(그 화면이 한 줄로 쌓이는 폭에 맞춤 · 기본 760) |
| `host` · `container` · `fixed` · `z` | 손잡이 붙일 곳 · 크기 범위 기준 · 화면에 붙은 칸 · 겹침 순서 |

- **기본 크기 = 화면 CSS 그대로.** 저장 값이 없으면 부품은 칸 크기를 건드리지 않는다(지금 보던 모양으로 시작). 두 번 누르기 = 기본 크기로.
- 키보드: 손잡이에 Tab → ← → (위아래 칸은 ↑ ↓) 16px · Shift 64px · Home 최소 · End 최대 · Enter 접기/펼치기.
- 새 문구 없음 — 손잡이 title/aria 는 '칸 크기', 단추는 '접기' · '펼치기'(이미 쓰던 말).
- 공용 서랍(`kit/panel.js drawer`)에 붙여서 서랍을 쓰는 모든 화면(44곳 호출)이 같이 바뀜 — 왼쪽 가장자리 손잡이 · 사람 · 화면별 기억 · 휴대폰 시트는 그대로.
