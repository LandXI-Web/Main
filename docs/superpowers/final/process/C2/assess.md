## 5. 기획 단계로 넘길 우선순위(평가 결론)
1. **지어낸 동작 차단 + 지도 제어 도구**: `map_zoom`·`map_layer`·`map_view(pitch/bearing)`·`map_region(결과 없어도 이동)`를 추가한다. 동작 도구가 없으면 "할 수 없다" 한 줄만 낸다. `{{unv}}` 자리표를 화면에 그대로 내보내지 않는다.
2. **gov-fusion 가로채기 해소**: 대장 필터로는 대장 열 조건이 있는 질문만 보낸다. 나머지(의심 몇 건 · 보고서 · 법령 · 차트)는 서버 에이전트로 보낸다. '의심 필지 몇 건?' 은 `survey_stats` 로 답한다.
3. **분석 실행 도구**: 전역 분석 · 실태조사 적재를 확인 카드로 연결하고, 대기열·전력 검사를 거친다. 결과 차트 블록(읍면동 막대)을 추가한다.
4. **보고서 말로 → docx**: 대상 지역 = 현재 지역(`운봉읍` 기본값 제거). docx 의 개발 문구를 없애고 시도 이름을 하나로 맞춘다.
5. **RAG**: 공개 법령 원문(농지법·건축법·국토계획법·산지관리법·농지이용실태조사 요령)을 로컬에 두고, bm25(+선택 임베딩)로 색인한다. `law_search` 로 조·항·시행일을 인용한다. 반입은 관리자 화면 버튼으로 한다.
6. **VLM**: `crop_tiles` + `vlm_describe` 를 만든다(엔진 준비 완료). 필지 카드에 '영상 설명' 을 붙이고 `AI 의견 · 근거 아님` 꼬리표를 단다.
