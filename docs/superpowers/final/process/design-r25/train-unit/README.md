## 선택지(다시)
- **ⓐ 고치면 저절로 (추천)** — 직원 손이 안 가고(원칙 203 · 확인 기록 없음), 섞인 틀림은 재학습 뒤 정확도 비교에서 걸러져 배포되지 않는다. 조각 안이 복잡하면 화면이 "옆 것도 봐 주세요" 한 줄만 띄운다.
- **ⓑ '다 봤음'을 눌러야**

## 제안 — 이런 것도 필요하지 않을까요?
1. **ⓐ로 가되, 한 칸에 고친 것이 둘 이상이면 그 칸을 먼저 쌓기** — LX 직원 · 관리자. 여러 번 손이 간 칸은 사람이 그만큼 본 칸이라 믿을 만하고, 그런 칸부터 학습에 넣으면 ③의 위험이 줄어든다.
2. **데이터하우스(직원 메뉴 '데이터')에서 '내가 고쳐서 쌓인 n장'을 칸 그림으로 보여 주기** — LX 직원. 고친 것이 어디에 어떻게 쌓였는지 보여야 ⓐ의 '저절로'가 체감된다(24차 결정 2 ⓐ 와 한 몸).
