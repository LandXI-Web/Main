# 구현 23차 · 직원 프로젝트 — 진행 현황 카드 · 새 프로젝트 한 창

사용자 지시(10-12): "1. 프로젝트 진행 현황은 분석서비스 카드 처럼 만든다. 2. 새 프로젝트 생성 아이콘을 누르면 이름을 입력하고 이후 여러 단계가 산발적으로 이뤄져 있는데.... 한 창에서 해결하는게 안되냐?? … 결국 프로젝트 명 쓰고. 설명(필수 아님)란 있고. 영상 업로드, 구성원 초대를 시작해서 바로 학습데이터 구축 화면으로 전환할 수 있는거 아닌가." → 원칙 219 · 220(지시 · 바로 구현).

바깥 주소 https://app.land-xi.dev · LX 직원 로그인 폼 · 그림은 모두 PC 1440 · 찍은 시각은 파일 이름 끝(HHMM) · `run.json`.

## 2. 바뀐 것

**프로젝트 진행 현황 = 분석 서비스 카드와 같은 틀** (`a1-cards`)
- 분석하기 카드 CSS(`.k-sc` · `.la-ac` · 칩 `.la-chips` · 한 페이지 `.la-view` 2 · 4 · 6 · 8장 · 페이지 `.la-pager`)를 그대로 불러 씁니다. 더한 것은 단계 줄 · 사람 줄뿐.
- 카드 = 그림(서비스가 있으면 분석하기 카드와 같은 결과 장면 · 없으면 이은 영상 · 대상 지역 영상 썸네일 · 없으면 '그림 없음') → 이름 → 설명(없으면 무엇을) → 여섯 칸 막대 + '지금 n 단계 · n/6' → **학습 데이터 n장 · AI 모델 정확도** → 대상지 → 구성원 · 마지막 활동 → 열기 · 프로젝트 →.
- 카드를 누르면 그 프로젝트의 지금 단계 화면. 남은 일이 있으면 그림 오른쪽 위에 그 한 줄(빨강 글자), 남은 일 있는 카드가 앞.
- 거르기: 묶음 탭(그대로) · 단계 칩 6(예전 흐름도 대신 · `?stage=` 그대로라 대시보드 단계 링크도 그대로) · 찾기.
- 숫자 한 출처: 단계 · n/6 · 남은 일 = 대시보드 진행 현황과 같은 서버 값(GET /projects). 정확도 = 분석하기 카드 덱 값(89 · 96%) · 서비스 전이면 그 프로젝트 모델 기록. **학습 데이터 n장 = 학습 화면 '학습 이력' 맨 위 줄과 같은 값**(비닐하우스 2026 = 35,247장 · 서버 시험이 대조).

**새 프로젝트 = 한 창** (`a2-new-window` → `a3-label-carry` → `a4-label-done` · `new-project-10s.mp4`)
- 왼쪽: 이름(필수) · 설명(선택) · 무엇을(하나) · 구성원(LX 계정 찾기 · 여러 명) / 오른쪽: 영상 — '파일 올리기'(데이터 올리기와 같은 조각 올리기 · 끌어 놓기 · 여러 파일 · 진행 막대) 또는 '데이터하우스에서 고르기'(썸네일 · 찾기 · 여러 장). 1440×900 에서 스크롤 없이 한 창.
- 대상지는 **영상 자리에서 저절로**(고른 영상 = 그 시군구 · 올린 영상 = 등록되면). 영상 없이 만들 때만 시군구 · 해외 지역 고르기 칸이 보입니다(지역 하드코딩 0).
- '만들기' 한 번 → 바로 그 프로젝트 **학습데이터 구축**. 올리는 중이면 파일을 이 브라우저 보관함에 맡기고 넘어가, 단계 막대 밑 한 줄('영상 파일 올리는 중 · 1/2' + 막대)에서 서버가 받은 자리부터 이어 올리고 → 등록 → 대상지가 정해지면 '영상 1장을 등록했습니다 · 대상지 남원시'(단계 막대도 데이터 올리기 완료로 바뀜). 다른 단계 화면으로 가도, 브라우저를 다시 열어도 그 프로젝트 화면에서 이어 갑니다. 끊기면 '다시 시도'.
- 옛 주소(`lx-project/?new=1` — 대시보드 빈 화면의 '새 프로젝트')는 같은 한 창으로 열립니다.

## 4. 서버

- `POST /projects` — `description`(선택) · `members`(여러 명) · `imagery`(데이터하우스 영상 → 대상지) · `from_upload`(올리는 중 — 대상지 비운 채)
- `POST /projects/{id}/imagery` — 등록된 영상을 잇고 그 자리 지역을 대상지에 더함(프로젝트장 · 구성원)
- `GET /projects/imagery` — 고르기 목록(이름 · 지역 · 연도 · 종류 · 썸네일 · 경로 0)
- 목록 줄에 `pic` · `train_n` · `acc` · `people` · `card` · `description`
- 마이그레이션 `0050_project_desc.sql`(projects.description · 되돌리기 down 있음). 영상 ↔ 프로젝트는 기존 project_links(kind 'imagery')
- 고친 고장: 새 프로젝트가 같은 업무의 옛 학습 기록(프로젝트 표시 없던 학습)을 자기 학습 이력으로 보이던 것 — 이제 같은 업무의 가장 먼저 만든 프로젝트만(`project_train.py` · 학습 화면과 카드 같은 규칙)
