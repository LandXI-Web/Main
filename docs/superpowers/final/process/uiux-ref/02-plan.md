## 2. 순서(공정)
1. 사용자 확인(CONFIRM 10) → 확인된 번호만 아래로.
2. UX-17·UX-18(문서·규칙) → UX-15·UX-16(검사기) → 화면 항목(UX-1·4·7 먼저, 나머지는 Sonnet 반복).
3. 화면마다: 기획서 한 장 → 토큰·부품으로 구현 → 글 검수(copy-review) → 캡처(1440·390) → Fable 판정 → CONFIRM '구현 확인 대기'.
