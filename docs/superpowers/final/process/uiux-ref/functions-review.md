## 4. 데이터 올리기 — 깊이 재검수(첫 사례)

**원래 의도·목표(근거)**
- 옛 데이터 관리(`landxi/proto/dataset.js` · `ds-data.js`): "두 역할이 함께 쓰는 원천 영상·학습데이터"(specs `platform-roles.md` §4). **지역을 고르는 칸이 없었다** — 지역은 파일에 딸린 속성(파일명·좌표), 공유 대상 기관 목록이 있었다. 기능: 드래그·다중·1TB·일시정지·재개·취소 · 완료 → 레이어 발행 4단 · 실패 조치(좌표계 지정·원본 다시 올리기) · 아카이브·메모·기관별 공유 권한 · 디스크 증량.
- 09-20 스펙: 지역은 **배포본의 속성**(card-architecture §1 "이식 = region·경계·기준값·주기만 갈아 끼움", two-tier §3 "영상은 현지 확보").
- 최종 명세 §2.4: "고른 지역에 영상과 대장 형식이 갖춰졌는지 보고 없는 것을 등록" · 공통 규칙 "지역 = URL `?region=` 또는 세션 기관" · §4-6 "**첫 카메라는 전국, 지역은 URL·세션·선택으로**".
- 즉 세 기록 모두 **직원이 지역을 정한다**(또는 앞 화면에서 넘긴다). 화면이 지역을 고르는 근거는 없다. 자동 선택은 구현 보고서(`docs/superpowers/final/lx-ingest-report.md:37` "빈 localStorage → 첫 화면 = 남원시(배포 8 동률: 남원·곡성·구례 → 의심 필지 20,868 인 남원)")에서 생긴 구현 편의다.

**지금 동작(화면·코드)**
- 도착 0.5초: 검색창에 '남원시'가 미리 채워짐(A-ingest-500) → 0.7초 뒤 남원 카메라·서랍(A-ingest-5000). 주소는 `?region=52190` 으로 바뀜.
- `lx-ingest/app.js:345-355` 첫 지역 = URL → 최근 지역(localStorage `lx_kit_recent_regions`) → `firstRegion`(의심 필지 있음 → 배포 수 → 영상 → 의심 수 정렬) → `setTimeout(pick, 700)`.
- `app.js:337-343` 지도 아무 곳 클릭 → 그 시군구로 바뀜. `pick()` 은 최근 지역에 저장하지 않음(콤보로 고른 것만 저장).
- 레일: lx-console 의 '데이터 올리기' 링크에 지역 없음(`lx-console/app.js:14`) · lx-deploy 는 6단 점검의 링크만 `?region=` 을 붙이며 그 값이 5자리 코드가 아니라 **프로필 키**일 수 있음(`lx-deploy/data.js:77`) · lx-review 는 지역을 정한 뒤에야 레일에 붙임(`lx-review/app.js:464·508`).

**"구례군 → 남원시" 재현 시도** — 새 브라우저에서 도착 0.3초 뒤 콤보로 구례군을 고르자 3.6초 동안 구례군이 유지됐다(S1-03 trace). 이 한 번의 시도로는 되돌아감이 재현되지 않았다. 코드상 가능한 경로(수정 금지, 추정):
1. **700ms 타이머 경쟁** — 타이머가 취소되지 않아, 사용자가 0.7초 안에 구례를 고르면 뒤이어 `pick(남원)` 이 실행돼 덮어씀(나중 호출이 이김).
2. **레일이 지역을 안 넘김** — 앞 화면에서 구례를 보고 있어도 lx-console·lx-deploy·lx-train 레일은 지역 없이 ingest 로 보냄 → 최근 지역 또는 firstRegion(동률이면 남원).
3. **지역 코드 형식 불일치** — lx-deploy 가 프로필 키를 넘기면 `app.js:352` 매칭 실패 → 최근/firstRegion 으로 떨어짐. 서버 `/regions` 유무에 따라 목록 키가 프로필/5자리로 달라져 최근 지역도 매칭 실패.
4. **상자 겹침** — '오늘' 칸·lx-review 의 `regionAt` 은 "겹치는 상자 중 가장 작은 것"이라 남원 필지가 이웃 구례 상자에 먼저 걸릴 수 있음 → 카메라 구례 → PNU 로 남원 재판정 → 레일에 남원 → ingest 남원.
5. **지도 클릭** — 구례 상자로 날아간 화면에 남원도 보이므로 서랍 밖 클릭 한 번에 남원으로 바뀜.
6. **동률 깨기 환경 의존** — V-World 대체 목록엔 `n_findings` 가 없어 동률이면 정렬 순서로 정해짐.

**재기획안(CONFIRM 12 → FR-7 · FR-1 · FR-20)** — 도착 = 전국 판 + 빈 검색창 + 안내 한 줄 · 자동 선택 0 · 지역이 정해지는 길 3개(앞 화면 `?region=` · 검색 · 지도 클릭) · 레일 6단 모두 5자리 코드 `?region=` 일관 · 지역 옆 출처 한 줄(FR-25) · 영상 등록은 파일 드롭존(FR-1) · 결합 완료 뒤 다음 행동(FR-20). **완료 기준**: 새 브라우저·앞 화면 상관없이 도착 지역 = 전국 / 검색·클릭 외 지역 변동 0 / 6단 레일 왕복에서 지역 유지 / 구례·남원 두 지역 + 확인자가 고른 한 지역으로 실증 / 영상 파일 1개를 화면에서 올려 '있음'으로 바뀜.

## 6. 정직 항목
- GPU 를 쓰는 실행은 누르지 않았다(전역 분석·학습 시작·AI 도우미 전송·보고서 초안). 그 기능의 '됨/안 됨'은 C2·C1 3차 기록을 따른다.
- 시나리오는 자동화된 클릭이라 사람 손의 속도·경로와 다르다. '구례군 → 남원시' 되돌아감은 이번 한 번의 시도에서 재현되지 않았고, 원인 6개는 코드로 추정한 것이다.
- 결재함 '불러오는 중'은 1.2초 관찰이다. 더 기다리면 뜰 수 있으나 관리자 첫 단계로는 늦다.
- 기관 대장 결합 결과는 10초 관찰이다(그 안에 '마쳤습니다' 토스트와 '결과 없음'이 동시에 보인 것은 사실).
- 옛 화면·명세 조사는 별도 탐색 결과를 옮긴 것이라 줄 번호는 2026-09-30 기준이다.
