## 4. 제안 — 이런 것도 필요하지 않을까요?
1. **영상 카드의 '결과 없음' 줄에 '이 영상으로 분석 요청' 글 단추** — 누가 왜: LX 직원. 2020 항공처럼 결과가 없는 영상을 고르면 조회 대신 분석을 걸 수 있어야 현황판이 비어 있지 않다(영상 API 읽기기가 생긴 뒤).
2. **조회 뒤 '최근 고친 것' 한 줄** — 누가 왜: 프로젝트장. 전국판에서 누가 어디를 고쳤는지 한 줄로 보이면 학습 자료가 쌓이는 것이 체감된다(원칙 182 뒷면).
3. **두 사람이 같은 객체를 다르게 고치면 '판단이 다름' 표시** — 누가 왜: 학습 품질. r17 위험 1 과 한 몸 — 학습에서 빼고 프로젝트장이 본다.
