## 한 줄
**학습 탭은 설명 글이 아니라 판이다 — 왼쪽 블록 일곱을 끌어다 놓고 선으로 잇는데, 처음부터 기본 흐름(학습 데이터 → 기반 모델 · 학습 설정 → 학습 → 평가 → 배포 신청)이 놓여 있어 직원은 학습 데이터만 고르고 '밤에 돌리기'를 누르면 되고, 아래에는 이 흐름으로 만든 판의 계보가 남는다.**

## 왜 이 방향(판정 근거)
- 지금 학습 화면(review-r15)은 왼쪽 카드 한 장 + 오른쪽 서랍에 글(기반 모델 고르기 · 학습 실행 · 결과 · 등록)이고, 원칙 181 설명 칸을 더해도 '읽는 화면'이다. 사용자는 "작업 흐름"을 말했다 — 데이터 · 모델 · 설정 · 평가가 **눈에 보이는 블록과 선**이면 "학습은 무슨 모델? 뭘로 배우나? 어떻게 재나?"(원칙 181)가 글 없이 그림 자체로 답이 된다.
- **쉬운 시작**(3): 블록 도구는 빈 판에서 시작하면 어렵다. 기본 흐름이 이미 놓여 있고 '학습 데이터를 고르세요'만 파랗게 빛나면 직원은 한 번 고르고 한 번 누른다. 고급(추론 시험 · 설정 펼침)은 더할 때만.
- **진화 틀과 한 몸**(4 · 원칙 182): '학습 데이터' 블록 안에 'XI맵에서 고친 것 · 새 묶음 0칸'이 늘 보인다 — 고친 칸이 쌓이면 같은 흐름을 다시 돌리는 구조라 설계 17차 뒷면 한 바퀴의 ④ 다시 학습 ⑤ 비교 ⑥ 배포 신청이 바로 이 판이다.
- **판 계보**(2): 흐름 아래 '이 흐름으로 만든 판' 띠가 원판(서비스 중) → 이 흐름의 판 → 다음 판을 잇는다. 실제 기록으로 그리니 "나아진 판만"이 실제로 어떻게 막히는지(비닐하우스 87% · 주차장 40%) 보인다.
