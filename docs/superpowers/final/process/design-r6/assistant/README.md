# 설계 6차(design-r6/assistant) — AI 도우미를 지도 오른쪽 아래 마스코트 채팅으로

> 2026-10-01 · Fable 5.1(기획·UI/UX). 지위: **사용자 확인 전 제안**(코드 수정 0 · GPU 실행 0 · 영상 생성 크레딧 0). 사용자 원문(10-01): "물어보기는 상단이 아니라 지도 우측 하단에 Land-XI 마스코트를 배치하고, 클릭하면 채팅창 형태로 뜬 상태에서 채팅 형태로 vLLM 서비스를 제공하는 걸로 바꾸자." → 원칙 82.
> 방법: 저장소에 마스코트가 없음을 확인(브랜드 자산은 워드마크 · LX 마크 · 민트 구 · 태그라인만)하고 **원본 SVG 후보 셋**을 새로 그렸다. 채팅창은 5차와 같이 실제 키트(`landxi/v3/kit/kit.css` · 토큰 · 서체)를 불러 HTML 시안으로 만들었고, '지금' 화면은 로그인 폼으로 들어가 찍었다. 숫자 · 이름 · 읍면 값은 **예시**다.

## 2. 채팅창 시안(`mock/chat.html` · 그림 `shots/new-*.png`)
| 부분 | 시안 |
|---|---|
| 자리 | 지도 판 **오른쪽 아래** 24 · 마스코트 버튼 56(흰 원 · `--elev-map`) · 범례 · 축척은 왼쪽 아래라 겹침 0 · 지도 조작 버튼은 키트가 숨김. 닫혀 있을 때 '물어보기' 꼬리표 한 줄 |
| 열림 | 버튼 위로 **380 × 560** 흰 카드 16 · `--elev-3` · 지도는 어두워지지 않음(지금은 뒤를 어둡게 함) · 휴대폰(≤640)은 **아래에서 올라오는 전체 폭 시트**(높이 72%) |
| 머리 | 마스코트 32 · 'Land-XI 도우미' · 보조 한 줄 '말로 지도 · 분석 · 보고서' · 닫기 |
| 대화 | 내 말 = 오른쪽 잉크 말풍선 · 도우미 답 = 왼쪽 흰 말풍선 + 마스코트 24(답함 표정). 답 안 블록은 **지금 AI 도우미 그대로** — 지도 동작 확인(✓ 남원시로 이동 · 결과 층 켬) · 숫자(서버 값만 · 추정은 호버 한 줄) · 표/차트(막대 `--ai`) · 법령 인용(조문 · 개정일) · 내려받을 파일 · 확인 카드(쓰기 도구는 실행/취소 — 5차 그대로) |
| 생각 중 | 머리와 말풍선의 마스코트가 '생각 중' 표정 · 점 셋 + **무엇을 하는지 한 줄**('남원시 결과를 찾고 있습니다') · 6초 넘으면 '서버 응답이 늦습니다' |
| 추천 질문 | 역할별 셋 — LX 직원: 결과 확인 대기 필지 보여 줘 · 이 지역 최근 분석 결과 · 보고서 초안 만들어 줘 / LX 관리자: 오늘 결재 대기 · 기관별 사용량 · 분석 대기 상황 / 기관: 우리 시 현장 확인 후보 · 이 필지 근거 법령 · 보고서 초안 |
| 입력 | 높이 44 · 포커스 링 액센트 · 보내기 잉크 채움 · 게스트는 비활성 + 한 줄(지금 그대로) |
| 없애는 것 | 화면 위쪽 '물어보기' 버튼 · 'Ctrl K' 표기(단축키 자체는 갈림길) |

- 지금과 다른 점 한 줄: **한 번 묻고 닫는 바 → 지도를 보면서 이어 가는 대화.** 앞 답을 기억하는 것(`prev_run`)은 지금 코드에 이미 있어 그대로 쓴다.
- 법전과 다르게 둔 값: 채팅창 안쪽 여백 16(법전 지도 위 카드 24 — 말풍선이 들어가는 창이라 좁힘) · 말풍선 라운드 16/4. 확인 뒤 법전 6장(지도 위 패널) 에 '대화 시트' 한 줄로 올린다.

## 3. 어느 화면에 두나 — 갈림길(확인 요청 채팅-2)
- 지도 있는 화면: LX 직원 첫 화면 · XI맵 · 기관 화면 · LX 관리자 현황 → 지도 판 오른쪽 아래.
- 지도 없는 화면(데이터 올리기 · 학습 · 결과 확인 · 결재 등): ⓐ 모든 화면 같은 자리(제안) / ⓑ 지도 화면에만.
