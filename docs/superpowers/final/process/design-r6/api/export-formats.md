## 0. 한 줄
**여섯 가지(+ 엑셀)를 줄 수 있다.** 모든 형식에 **모양 · 결과 종류 · 신뢰 · 결과 확인 표시 · 시점 · 서비스 버전**이 붙고, **영상 · 개인정보 · 내부 값 · 관할 밖**은 빠진다. 지금 서버에 **이미 있는 것**은 요약 숫자이고, **바탕이 있는 것**은 GeoJSON(경위도 조회) · 결과 지도 파일(서명 주소)이며, **새로 만들 것**은 SHP · GeoPackage · 필지 CSV/엑셀 · 좌표계 고르기 · 지도 조각 한 장씩 꺼내기 · 결과 확인 표시와 서비스 버전 붙이기다.

## 1. 형식 한눈에
| 형식 | 누가 · 어디에 쓰나 | 들어가는 것 | 좌표계 | 크기 · 나눠 받기 | 지금 서버 |
|---|---|---|---|---|---|
| **GeoJSON** | 웹 지도 · 기관 개발 시스템 | 결과 조각(폴리곤) + 속성(2절) | 경위도(기본) · 국내 평면 넷 · UTM-K 중 고름 | 바로 받기 한 쪽 1,000개(약 1.2–2.6MB) · 시군구 전역은 파일로 | **반쯤** — 경위도 조회는 있음(결과 조각 조회 · 한 번 최대 1만 개 · 건너뛰기 방식). 좌표계 고르기 · 이어 받기 열쇠 · 확인 표시 · 버전은 **새로** |
| **SHP(zip)** | 시군구 GIS 담당(QGIS · ArcGIS) — 공무원이 가장 많이 쓰는 형식 | 조각 층 + 필지 층(두 벌) · 좌표계 파일 · 열 설명 표 | 국내 평면(기본) · 경위도 | 파일로만 · 형식 한계 한 파일 2GB · 열 이름 10자 | **새로** — 서버는 SHP 를 읽기만 함(대장 올리기). 쓰는 도구는 서버에 있음 |
| **GeoPackage** | GIS 담당 — SHP 한계(열 이름 · 한글 · 2GB) 없이 한 파일 | 조각 층 · 필지 층 · 요약 표 · 열 설명 표를 한 파일에 | 국내 평면(기본) · 경위도 | 파일로만 | **새로** — 서버는 읽기만 함(필지 자료) |
| **CSV · 엑셀(필지)** | 실태조사 담당 — 필지 목록을 엑셀로 결재 · 현장에 | 필지 한 줄씩(3절) · 모양 없음(선택: 필지 가운데 점 좌표) | (가운데 점만) 경위도 · 국내 평면 | 파일로 · 엑셀 한 장 100만 줄 한계 | **새로** — 필지 결과는 지도 모양으로만 있고(한 번 2,000건), CSV 로 주는 곳은 식생 지수 결과뿐 |
| **벡터 지도 조각(MVT)** | 도청 GIS · 웹 지도가 자기 지도 위에 결과 층을 띄움 | 조각 모양 + 최소 속성(결과 번호 · 종류 · 신뢰 · 결과 확인) · 줌 10–17 | 웹 지도 좌표계 고정 | 조각 단위로 받으니 한도는 요청 수(1분 1,200장) | **반쯤 있음** — 결과마다 벡터 지도 파일 한 개와 12시간 서명 주소가 **이미 만들어짐**. 한 장씩(줌/가로/세로) 꺼내 주는 길은 **새로** |
| **요약 숫자(JSON)** | 행정 포털 · 대시보드 · 2차 서비스 | 종류별 개수 · 면적 · 읍면동별 · 확인이 필요한 필지 수 · 확인 전/확인됨 나눔 · 시점 · 서비스 버전. 숫자마다 값 · 단위 · 근거 · 기준 시점 · 출처 | — | 작음(바로) | **있음** — 대표 수치 한 출처 · 읍면동별 · 종류별 집계. 바깥 모양으로 옮기기만(출처 문장을 사람 말로) |
| (참고) 보고서(Word) | 행정 포털에 첨부 | 읍면동 실태조사 보고서 | — | 파일 | **있음** — API 에서는 뒤 단계 |

| 요청 번호 | API 로 맡긴 분석이면 그 요청 번호 | 새로 |

**결과 확인 표시의 뜻**
- **확인 전** — AI 가 찾은 그대로. 분석이 끝나면 바로 이 표시로 나간다(5차 답 API-4 ⓐ).
- **확인됨** — 그 결과 묶음이 LX 결과 확인(표본 확인 기준 통과)을 마쳤다.
- **고침** — 사람이 모양이나 종류를 고친 조각(고친 뒤 값으로 나감).
- 사람이 **지운** 조각은 결과에서 빠지고 '지운 목록'으로만 알린다 — 외부 시스템도 따라 지우게.
- '바뀐 것만' 받기(지난번 받은 날 이후)는 **새로 나온 것 · 표시가 바뀐 것 · 지운 것** 세 묶음으로 준다.

## 3. 필지 CSV · 엑셀의 열
필지 번호 · 지번 주소 · 읍면동 · 지목 · 필지 면적 · AI 가 본 것(종류) · 겹친 면적 · 필지 대비 비율 · 신뢰(평균) · 확인이 필요한 까닭 한 줄(실태조사 규칙이 있는 서비스) · 기관 판정(판정 전 · 현장 확인함 · 종결 · AI가 잘못 봄) · 대장 대조(대장을 올린 기관만 — 대장의 지목 · 상태 칸과 AI 가 본 것) · 촬영 시기 · 서비스 버전 · 결과 확인.
- 열 이름은 한국어가 기본(공무원이 엑셀로 바로 봄), 개발용으로 영문 이름을 고를 수 있다. 파일에 '열 설명'을 같이 넣는다.
- **엑셀이 19자리 필지 번호를 망가뜨린다**(1.23E+18 처럼 바뀌고 끝자리가 0 이 됨). 그래서 엑셀 파일은 필지 번호 칸을 글자로 고정하고, CSV 는 글자로 읽히게 적고 안내 한 줄을 넣는다.
- 한글은 UTF-8(엑셀이 알아보는 표시 포함). 옛 GIS 를 위해 SHP 는 한글 방식을 고를 수 있다(UTF-8 / 옛 한글 방식).

## 5. 크기 한도 · 나눠 받기 — 실제 결과로 잰 크기
| 무엇 | 잰 값(2026-10-01) |
|---|---|
| 시군구 전역 결과 한 번 | 조각 약 13만 개 → **GeoJSON 160–225MB**(조각 한 개 약 1.2–2.6KB) |
| 같은 결과의 벡터 지도 파일 | 약 73MB |

| 받는 방법 | 한도(초기값 — 관리자가 바꿈) | 쓰는 때 |
|---|---|---|
| **바로 받기(쪽 나눔)** | 한 쪽 최대 1,000개 · 응답 30초 안 · 다음 쪽 열쇠(받는 동안 새 결과가 생겨도 빠지거나 겹치지 않음) | 매달 '바뀐 것만' · 필지 하나 · 작은 범위 |
| **파일로 받기** | 형식 · 범위 · 좌표계를 적어 요청 → 준비되면 알림 → 기한 있는 주소(24시간)로 받음 · 파일 하나 1GB 넘으면 **읍면동별로 나눠** 한 묶음(zip) · 만든 파일은 7일 뒤 지움(다시 만들 수 있음) | 시군구 전역 · SHP · GeoPackage · 엑셀 |
| **지도 조각** | 키당 1분 1,200장 · 주소 12시간 | 자기 지도에 띄우기 |
| **한 달 내보낸 양** | 기관 한도 안(남원시 50GB · 광주전남 30GB) — **지금은 재지 않고 있음 → API 부터 실제로 잰다** | 시군구 전역 GeoJSON 한 번 약 0.2GB |

- 요청 수: 키당 1분 60회(이전 설계 그대로). 넘으면 잠시 멈춤 + 다시 해도 되는 때.
- 전송은 압축해서 보낸다(GeoJSON 은 크게 줄어듦 — 줄어드는 비율은 재지 않음).

## 7. 내려받기 정책(원칙 59 — 동의 · 범위 · 기록)
- **동의**: 키 신청 때 기관 관리자가 '이용 약속'(개인정보를 붙이지 않음 · 기관 밖 재배포는 기관 책임 · 모든 요청 기록)에 한 번 동의 — 기록에 남음.
- **범위**: 그 키의 서비스 · 그 기관 관할만.
- **기록**: 모든 내보내기를 누가(키 · 쓰는 시스템) · 무엇을(형식 · 범위 · 몇 건) · 언제로 남긴다(열람 · 내려받기 기록 채택). 기관 관리자 · LX 관리자가 같은 기록을 본다.

## 8. 추천 — 만드는 순서
1. **먼저(1단)**: GeoJSON(좌표계 고르기 포함) · 필지 CSV/엑셀 · 요약 숫자 — 지금 있는 결과 조회 위에 모양만 입히면 된다. 개발 시스템 · 공무원 엑셀 · 대시보드 세 부류가 바로 쓴다.
2. **다음(4단)**: SHP(zip) · GeoPackage · 지도 조각 한 장씩 — 파일로 받기(준비되면 알림)가 선 뒤에. 쓰는 도구는 서버에 이미 있다.
3. 보고서(Word)는 있는 것을 목록 · 파일 주소로만 연다(뒤 단계).
