# 외부 연동 API — 다시 설계(5차 답 반영) · 한 장 요약

> 2026-10-01 · 지위: **사용자 확인 전 설계**(코드 수정 0 · GPU 실행 0). 어느 플랫폼: **둘 다** — 신청은 기관 분기 화면(기관 관리자), 승인 · 한도 · 보관은 Land-XI(LX 관리자), 키를 쓰는 쪽은 기관의 다른 시스템.
> 사용자 원문(10-01, 확인 요청 5차) — API-1(보류): "분석 서비스마다 API 키가 발급되고 API 키는 접속 - 분석하기 - 분석결과 가져오기(기존 결과도 마찬가지)이다. 분석된 결과 중 영상은 아니고 AI 분석 결과 폴리곤이나 shp 이나 .geojson 등 가공하여 내보내기 같은 범위일 것 같다. 다만, 상대방이 자기 영상을 보내는 과정이 좀 고민이 필요할 것 같다." · API-2(보류): "조금 더 고민이 필요." · API-3(확정 ⓐ): "무작위로 시작하는 개념은 아니고 관리자에게 요청하는 개념이다. 관리자는 이걸 확인하고 승인 반려 처리해야 한다." · API-4(확정 ⓐ): "가능한 옵션이 어떤 형태로 제공할 수 있는지 더 검토해야겠다."

## 한 줄
**키 한 개 = 기관 × 분석 서비스.** 기관 관리자가 신청하고 LX 관리자가 결재함에서 승인한다. 키로 하는 일은 셋 — **접속 확인 · 분석 맡기기 요청(LX 관리자 승인 · 반려를 거침) · 결과 가져오기(지난 결과 포함)**. 내주는 것은 **AI 분석 결과(모양까지 + 결과 확인 표시)**이고 영상은 주지 않는다.

## 다섯 가지 — 무엇을 정했나(기본값 · 바꾸려면 말씀만)
| | 정한 것 | 자세히 |
|---|---|---|
| **1. 키 흐름** | 발급 단위 = 기관 × 서비스 · **신청 = 기관 관리자**(서비스 · 쓰는 시스템 이름 · 이용 약속 동의, 세 칸) · **발급 = LX 관리자 결재**(지금 결재함에 종류 'API 키 신청') · 키는 기관 관리자 화면에 **한 번만**(LX 관리자도 보지 않음) · 1년 · 폐기 5초 · 교체는 7일 겹침 | [flow.md](flow.md) |
| **2. 요청 → 승인 · 반려** | 요청은 곧바로 돌지 않는다. 서버가 **자동 검사 일곱**(관할 · 적용 지역 · 넓이 · 한도 · 영상 · 중복 · 쌓인 대기)으로 먼저 거르고, 통과분만 **결재함에 한 줄**. 관리자는 **근거 넷**(범위 · 넓이 · 예상 분석 시간 · 한도 남은 양)과 범위 지도를 보고 승인 / 반려(사유 필수). 반려 사유는 **API 응답 · 알림 · 기관 관리자 화면** 세 곳으로. 5 업무일 결정이 없으면 '기한 지남'(저절로 승인 없음) | [request-approve.md](request-approve.md) |
| **3. 상대 영상 받기** | **크기와 있는 곳으로 고른다** — LX 가 가진 범위면 영상 없이(먼저) · 상대 저장소가 있으면 **주소만 알려 주고 LX 가 가져감(기본)** · 작은 것(20GB 이하)만 조각 올리기 · 100GB 넘거나 밖으로 못 내보내면 디스크로 직접 전달. 어느 방법이든 **승인 먼저, 받기 나중**(반려분 저장 0) · **분석 끝 30일 뒤 지움**(결과는 남음) · 맡긴 영상 칸 400GB · 기관당 200GB(기관 저장 한도 안) — 값은 설정 한 곳 | [imagery-in.md](imagery-in.md) |
| **4. 내보내기 형식** | **여섯 + 엑셀**: GeoJSON(좌표계 고름) · SHP(zip) · GeoPackage · 필지 CSV/엑셀 · 벡터 지도 조각 · 요약 숫자. 모두 모양 · 종류 · 신뢰 · **결과 확인 전 / 확인됨 / 고침** · 시점 · 서비스 버전이 붙고, 영상 · 개인정보 · 내부 값은 빠짐. 지금 서버: 요약 숫자는 **있음**, GeoJSON · 지도 조각은 **바탕 있음**, SHP · GeoPackage · 필지 CSV 는 **새로**(쓰는 도구는 서버에 있음) | [export-formats.md](export-formats.md) |
| **5. 누구에게 여나(API-2)** | **추천 ⓐ 서비스를 받는 기관만, 서비스별로.** 기관이 맡긴 사업자 · 개발사도 그 기관 키로(쓰는 시스템 이름에 업체 표시 · 책임은 기관) + 읽기만 되는 시험 키. ⓑ 다른 공공기관에 요약 공개는 결과 확인 체계가 선 뒤 **나중 후보**(원래 기관 동의 + 확인된 숫자만). ⓒ 개발사 직접 키 · 누구나 쓰는 공개 API 는 **열지 않음**(관할 밖 0 이 깨짐) | 아래 |

## 구현 단계(이전 약 13일 → 약 23일)
| 단계 | 무엇 | 작업량 | 완료 기준 한 줄 |
|---|---|---|---|
| 1단 | 키(신청 → 결재 → 한 번 보기) + 접속 확인 + 결과 가져오기(지난 결과 · 바뀐 것만 · 좌표계) + GeoJSON · 필지 CSV/엑셀 · 요약 | 약 6일 | 화면만으로 신청 → 승인 → 첫 결과 10분 안 · 교차 관할 · 다른 서비스 '없음' · 숫자 화면과 같음 |
| 2단 | 분석 맡기기 요청 → 자동 검사 → 결재(근거 넷) → 대기열 + 알림 — **LX 가 가진 영상 범위만** | 약 5.5일 | 요청만으로 AI 서버 사용 0 · 자동 반려 일곱 경우 · 반려 사유 세 곳 같은 글 · 같은 번호가 기관 · 관리자 화면에 |
| 3단 | 상대 영상 받기(주소 가져가기 · 조각 올리기 · 디스크 전달 연결) + 맡긴 영상 칸 · 30일 지움 · 설정 한 곳 | 약 6.5일 | 반려분 저장 0 · 내부 주소 막힘 · 30일 뒤 지움과 기록 · 설정만 바꿔 한도 변경 |
| 4단 | SHP · GeoPackage · 지도 조각 한 장씩 · 파일로 받기 + 개발자 안내 페이지 · 시험 키 | 약 5일 | QGIS 에서 개수 · 한글 · 좌표계가 화면과 같음 · 처음 보는 개발자 30분 안 첫 결과 |

## 먼저 맞춰야 할 것
- **기관 화면의 '우리 영상으로 분석 의뢰'(6차 확인 대기)**는 "담당 프로젝트장 접수 · 수수료 안내", 이번 API 요청은 "LX 관리자 결재 · 한도 안 비용 없음"(5차 확정)이다. 같은 일이 길 두 개로 규칙이 다르지 않게 — **한 건 모양 · 한 규칙**(한도 안 = 비용 없이 관리자 결재 · 한도를 넘거나 촬영이 필요하면 수수료 의뢰)으로 합치기를 추천(확인 요청 항목 2).
- 결재 한 건의 모양은 6차 '결재 한 건 — 근거 넷'과 같은 틀로 맞췄다. 6차 답이 바뀌면 여기도 바꾼다.

## 확인 못 한 것(정직하게)
- **문서만** 만들었다 — API 도, 화면도 만들지 않았고 바깥 주소로 불러 보지 않았다.
- **회선 속도를 재지 않았다** — 영상 보내는 시간 표는 이론값이다(이 PC 의 내려받기 · 올리기 속도는 모름).
- 드론 해상도 분석 시간(1㎢ 에 약 50–70초)은 이전 설계의 **추산 그대로**다(드론 실측 없음). 시안의 '약 4–5분'도 그 추산이다.
- 결과 크기(시군구 전역 약 13만 조각 → GeoJSON 160–225MB · 지도 파일 약 73MB)는 LX 결과 파일 몇 개로 잰 값이다. 서비스마다 조각 모양이 달라 다를 수 있고, 압축률은 재지 않았다.
- SHP · GeoPackage 는 **쓰는 도구가 서버에 있다는 것만** 확인했다(만들어 QGIS 에 띄워 보지 않음).
- 공공 클라우드 저장소(국내 업체)의 서명 주소 모양은 확인하지 않았다 — 1차는 'https 로 열리는 기한 있는 주소'만 받는다.
- 맡긴 영상 칸(400GB · 기관당 200GB) · 한 건 한도(20GB · 100GB) · 보관 30일 등은 **초기값 제안**이다(영상 보관 디스크 남은 공간 약 1.9TB 기준).
- 결재함 시안은 구현 1차 결재함 캡처를 보고 같은 틀로 그린 그림이다. 시안의 이름(최민정 · 김도윤)과 한도 남은 양(9시간 12분)은 **예시**다.
