# 외부 연동 API — 구현 계획(5차 답 반영판)

> 2026-10-01 · 지위: **사용자 확인 전 계획**(코드 수정 0 · GPU 실행 0). 이전 계획(설계 4차 · 약 13일 · 0–3단)을 5차 답(API-1 서비스별 키 · API-3 요청 → 관리자 승인 · API-4 모양까지 + 확인 표시 · 상대 영상 보내기 고민)에 맞게 고쳤다.
> 공정: 평가(1절) → 기획(flow · request-approve · imagery-in · export-formats · 이 계획) → 개발(단계별) → 실증(바깥 주소 · 두 기관 + 확인자가 고른 한 곳 · 명령줄 없이 화면만 · 로그인 폼으로만 · GPU 한 장) → 서비스(안내 페이지 · 운영 기록).

## 3. 단계
### 1단 — 키와 결과 가져오기(약 6일)
- **서버**: 키 표(기관 × 서비스 · 쓰는 시스템 이름 · 끝 네 자리 · 한 방향 암호 · 끝나는 날 · 허용 주소 · 알림 주소 · 상태) · 키 확인(5초 기억 — 폐기가 5초 안에 먹게) · 결재 종류 'API 키 신청'(승인 = 키 만들기 → 기관 관리자 화면에 한 번) · 접속 확인 · 결과 가져오기(지난 결과 포함 · 바뀐 것만 · 이어 받기 열쇠 · 좌표계) · 요약 숫자 · 필지 CSV/엑셀 · 결과 확인 표시 · 서비스 버전 · 요청 기록 · 요청 수 한도 · 내보낸 양 재기 · 외부 전용 목록 · 바깥 입구(API 주소는 `/v1` 만 넘기고 나머지 없음).
- **화면**: LX 관리자 결재함에 종류 하나(서랍 틀 그대로) · 관리자 기관 서랍에 'API 연동' 한 줄(키 목록 · 폐기) · 기관 관리자 'API 연동' 칸(신청 세 칸 · 한 번 보기 · 폐기 · 기록).
- **완료 기준(측정 가능)**
  1. **명령줄 0**: 기관 관리자 신청 → LX 관리자 승인 → 기관 관리자 한 번 보기 → 첫 결과까지 화면만으로 10분 안.
  2. **관할 밖 0**: 남원 · 광주전남 키로 서로의 결과 · 필지 · 요약 · 파일을 부르는 조합 전부 '없음' · 응답에 상대 기관 값 0건. 같은 기관의 **다른 서비스** 결과도 '없음'.
  3. **숫자 한 출처**: 같은 시각 외부 요약 = 기관 화면 = 내부 요약(남원 · 여수 + 확인자가 고른 한 곳) — 차이 0.
  4. **지난 결과**: 한 키로 그 서비스의 모든 시점을 받고 시점별 개수 = 기관 화면.
  5. **바뀐 것만**: 조각 하나를 고치고 하나를 지운 뒤 받으면 고침 1 · 지움 1 · 나머지 0.
  6. **좌표계**: 같은 조각을 경위도 · 국내 평면으로 받아 면적 차이 0.1% 안.
  7. **엑셀**: 19자리 필지 번호 칸이 글자형(자동 시험).
  8. 폐기 → 5초 안 거절 · 1분 한도 넘으면 잠시 멈춤 · 요청 수 = 기록 수(빠짐 0) · 내보낸 양이 장부에 쌓임.
  9. 바깥 응답에 내부 이름 0(금지어 자동 검사: 작업 번호 모양 · 조각 번호 · 파일 경로 · 드라이브 문자 · 장비 이름).
  10. 1,000개 한 쪽 2초 안(서버 기준) · 끝까지 받은 수 = 전체 수.

### 2단 — 분석 맡기기 요청 · 결재(LX 가 가진 영상 범위만) + 알림(약 5.5일)
- **서버**: 요청(범위 · 영상 방법 '범위만' · 메모 · 같은 요청 막는 열쇠) · 자동 검사 일곱 · 결재 종류 'API 분석 요청'(근거 넷을 요청 때 계산해 결재 기록에 담고, 결재 때 다시 계산해 달라졌으면 표시) · 승인 → 대기열(화면 작업 뒤 · API 분석 한 번에 1건 · 동시 작업 합산) · 반려 → 세 곳 · 기한 5 업무일 · 취소 · 상태 · 알림 발송(서명 · 6번 다시 · 보낸 기록).
- **화면**: 결재 한 건 서랍(근거 넷) + 표 아래 범위 지도 · 대기열 표 'API' 표시 · 할 일 칸 '승인 대기 n건' · 기관 관리자 '분석 요청' 목록.
- **완료 기준**
  1. 요청 → 결재함 한 줄 5초 안 · **요청만으로 AI 서버 사용 0**(전력 기록).
  2. 자동 검사 일곱 경우(관할 밖 · 적용 안 된 지역 · 넓이 초과 · 한도 초과 · 영상 없는 범위 · 중복 · 대기 5건) 모두 그 자리 반려 + 사유 한 줄 · 결재함에 안 뜸.
  3. 사유 없는 반려는 못 보냄 · 사유가 API 상태 · 알림 · 기관 관리자 화면 **세 곳에 같은 글**로.
  4. 승인 → 분석 → 결과: 같은 요청 번호가 기관 화면 새 시점 · LX 관리자 대기열 · 기관 사용량에 같이 보임(관리-생산-서비스 한 흐름).
  5. API 분석 중 화면에서 누른 읍면동 분석 첫 결과 10초 안 유지 · 두 장 동시 고부하 0.
  6. 알림 받는 쪽을 끄면 다시 보낸 기록이 쌓이고 켜면 옴 · 서명 확인 성공.
  7. 시계를 당겨 5 업무일 → '기한 지남' · 저절로 승인 0.

### 3단 — 상대 영상 받기 + 맡긴 영상 칸(약 6.5일)
- **서버**: ① 주소로 가져오기(키마다 등록한 저장소만 · 내부 주소 금지 · 넘겨주기 안 따라감 · 이어 받기 · 한 건 100GB) · ② 영상용 조각 올리기(학습 표본 방식을 넓힘 · 승인 뒤에만 열림 · 한 건 20GB) · 받은 뒤 검사(위치 정보 · 관할 · 요청과 대조 · 서비스 해상도 기준) · ③ LX 직원 영상 등록에 '요청에 붙이기'(복사 없이 연결한 채 분석 포함) · 맡긴 영상 칸(전체 · 기관당 · 한 건) · 보관 기간 자동 지움(30일 · 24시간 · 7일) · 보관 연장 결재 · 지운 기록 · **설정 한 곳**.
- **화면**: LX 관리자 설정 한 장(맡긴 영상 칸 · 보관 기간) · 기관 한도 막대에 '맡긴 영상' 옅게 · LX 직원 영상 등록 '요청에 붙이기' · 기관 관리자 '보관 연장 요청'.
- **완료 기준**
  1. ① 5GB 영상을 받다 끊고 다시 → 받은 곳부터 · 파일 지문 같음.
  2. ① 내부 주소(이 PC · 사설망) · 등록 안 된 저장소 → 받기 전에 거절.
  3. ② 끊고 이어 올려 성공 · 20GB 넘게 적은 요청 → 요청 때 반려.
  4. 관할 밖 범위 · 요청과 다른 촬영일 · 위치 정보 없는 파일 → 받은 뒤 '실패(사유)' + 24시간 안 지움 · AI 서버 사용 0.
  5. **반려된 요청의 영상 저장 0**(①②는 승인 전에 받지 않음).
  6. 시계를 당겨 30일 → 영상 지움 · 결과 · 요청 기록 · 영상 정보는 남음 · 지운 기록이 기관 관리자 화면에.
  7. 맡긴 영상 칸 · 기관당 한도를 넘는 요청 → 자동 검사에서 반려.
  8. 설정 값을 바꾸면 다음 요청부터 그대로(코드 수정 0 — A100 · 새 저장 장치 대비).

### 4단 — 파일 내보내기 확장 + 개발자 안내(약 5일)
- **서버**: 파일로 받기(준비되면 알림 · 24시간 주소 · 1GB 넘으면 읍면동별 · 7일 뒤 지움) · SHP(zip) · GeoPackage · 지도 조각 한 장씩 + 조각 안내(그 기관 결과 파일에서만) · 보고서 목록 · 시험 키(그 기관 실제 결과 · 읽기만 · 한도 낮음 · 30일).
- **화면**: 개발자 안내 페이지(사용자 말 · 밝은 톤 · 상대 경로) · 기관 관리자 '시험 키 신청'.
- **완료 기준**
  1. 결과를 SHP · GeoPackage 로 받아 QGIS 에 띄움 — 개수 · 한글 · 좌표계가 화면과 같음.
  2. 시군구 전역(약 13만 개) 파일이 읍면동별로 나뉘어 받아지고 합친 수 = 전체 수.
  3. 지도 조각을 웹 지도에 띄웠을 때 관할 밖 조각 0.
  4. 처음 보는 개발자(이 설계를 모르는 다른 에이전트)가 안내 페이지만 보고 30분 안에 첫 결과 · 첫 요청.
  5. 안내 페이지 PC · 휴대폰 캡처에서 줄바꿈 규칙 통과 · 내부 코드 0.

| 기관 화면의 '우리 영상으로 분석 의뢰'(6차) | 확인 대기 | 한 건 모양 · 규칙을 합칠지 함께 결정(request-approve.md 6절) |
| LX 영상을 기관마다 열기(5차 확정 — 관리자가 고름) | 확정 · 구현 전 | 2단 '범위만' 요청이 이 규칙에 기댐 — 없으면 지금 영상 공유 규칙으로 |
| 광주전남 한도 | 지금 분석 넓이 한도를 넘어 있음(구현 1차 기록) | 2단 실증에서 광주전남 요청은 **자동 반려가 정상** — 한도 값은 결재로 조정 |

## 6. 시험 · 실증
- **자동 시험(AI 서버 0)**: 키(없음 · 틀림 · 끝남 · 폐기 · 다른 서비스 · 허용 주소 밖) · 교차 관할 · 숫자 대조 · 바뀐 것만 · 좌표계 · 엑셀 칸 · 자동 검사 일곱 · 반려 세 곳 · 기한 · 주소 가져오기 막기(내부 주소 · 넘겨주기) · 이어 올리기 · 보관 지움 · 금지어.
- **실증**: 바깥 주소로, 남원 · 광주전남 + 확인자가 고른 한 곳 · 명령줄 없이 화면(두 사람: 기관 관리자 · LX 관리자) · 로그인 폼으로만 · 분석은 게이트웨이 대기열로 한 건씩(두 장 동시 고부하 0) · 가이드 예제를 그대로 돌림.
