10월 1일 7차 답으로 기관 한도는 없어집니다. 그래서 이 '한도 변경' 결재도 없어지지만, 규칙(요청한 계정 ≠ 결재하는 계정)은 그대로 남아 직원 자원 요청 · 장비 설정 바꾸기 · 서비스 공개에 쓰입니다.

왜 나누나

한 사람이 요청하고 승인까지 하면 아무도 확인하지 않은 것과 같습니다. 0 하나를 더 쓴 실수도, 한 사람의 판단만으로 기관 자원이 바뀌는 일도 두 번째 사람이 막습니다. 공문서에서 기안자와 결재권자를 나누는 것과 같은 뜻입니다.

무엇을 가르나

계정을 가릅니다. 같은 사람이 계정 둘을 쓰면 막지 못하므로, 정식 오픈 때는 사람마다 계정 하나로 정리합니다(지금은 시범 계정이 사용자 한 분 것).
