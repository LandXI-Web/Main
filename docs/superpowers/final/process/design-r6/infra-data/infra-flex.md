## 0. 한 줄
장비 · GPU 수 · 전력 예산 · 저장 위치 값이 **설정 한 곳에 모여 있지 않고 코드 · 실행 스크립트 · 화면 · 저장소 밖 설정까지 31곳**에 흩어져 있다(기관 만들기에 걸리는 7곳을 더하면 38곳). 특히 **전력 규칙이 '장비 구분 없이 전체에 하나'**라서 A100 서버를 붙이면 그 서버의 GPU 까지 이 PC 의 '동시 1장' 규칙에 묶인다. A100 이관 때 "설정만 바꾸면" 되려면 ① **장비 대장 한 장**(장비마다 GPU 수 · 동시 고부하 한도 · 장당 전력) ② **장비별 전력 판정** ③ **저장 위치 한 장**(서비스 저장소 · 원본 보관소 목록 · 경보선) — 셋을 모으고 모든 코드 · 화면 · 스크립트가 그것만 읽게 한다. 값은 지금 A6000 그대로 둔다.

## 3. 한 곳으로 모을 것 — 무엇을
| 한 곳 | 담는 것 | 누가 읽나 | 바꾸는 곳 |
|---|---|---|---|
| **① 장비 대장** | 장비마다: 이름 · 사는 곳(이 PC / IDC) · GPU 수 · 메모리 · **동시 고부하 한도 · 장당 전력 상한 · 판정선** · 이 장비의 작업 묶음(분석 / 학습 / 언어 모델) · 작업 크기 등급 · 상태(연결 / 끊김 / 대기) | 작업기 · 대기열 · GPU 상태 수집기 · 전력 판정 · 관리자 화면 · AI 도우미 · 기동 스크립트 — **모두 이것만**(코드 상수 · 글자 찾기 0) | 관리자 화면 '장비 · 저장 설정' → **다른 관리자 결재** |

| **③ 저장 위치 한 장** | 서비스 저장소 · **원본 보관소 목록**(여러 곳 — 드라이브 · 보관 서버) · 임시 자리 · 보관소마다 경보선 · 올리기 한도 | 서버 전체 · 저장 수집기 · 경보 · 기동 스크립트 | 관리자 화면 → 결재 |

| **⑤ 언어 모델 자리** | 어느 장비의 몇 번 GPU | AI 도우미 · 언어 모델 켜기 · 전력 판정 | 장비 대장의 '언어 모델' 묶음 |
| **⑥ 입구 주소 이름** | app · admin · gov(+ 기관별 주소 — 갈림길 1) | 화면 · 관문 · 서버 허용 목록 | 한 곳(지금 화면 표 — 서버도 그것을 읽게) |

원칙: **값은 한 곳, 바꾸는 것은 관리자 화면(두 사람 결재), 코드는 읽기만.** 화면에는 GPU 제품명 · 경로 · 포트를 쓰지 않는다 — 장비 이름 · '고부하 n/m' · '여유 n TB' 만(원칙 11).
