## 1. 1차·2차 서비스 — 경계 요지(`relation.md` · 그림 `shots/rel-1-marine.png`)
- **1차** = LX 가 영상에서 보이는 것을 찾아 세고 나눈 AI 분석 결과(해양쓰레기 탐지 — 해안별 위치·종류·양·시점). **2차** = 기관이 그 결과에 자기만 가진 자료·모델(해류·바람)을 합쳐 만드는 업무 서비스(해양쓰레기 예측 지도 — 어느 해안에 언제 얼마나 쌓일지).
- **경계 = 표준 결과 형식 한 장**(위치·종류·양·시점·신뢰도·버전). 1차 출구가 곧 2차 입구. 모델·영상·회차가 바뀌어도 형식은 같다.
- **여섯 질문**: 모델 소유(1차 LX / 해류·바람은 바깥 제공자, 결합 규칙은 전남) · 운영(1차 프로젝트장→관리자 / 2차 전남 담당 부서) · 계산 위치(**갈림길 1**) · 자료 방향(LX → 전남 한 방향, 전남 → LX 는 '잘못 봤어요'만) · 갱신(1차 공개 = 알림 이벤트 → 카드 알림 + 키에 등록한 받는 주소 → 전남이 가져가 재계산) · 책임(탐지 = LX, 예측 = 전남 + 제공자 — 2차 화면의 '입력 1차 기준 시점'이 가른다).
- **해류 모델은 누가 가지고 있나 — 확인 필요.** 옛 자산(09-20)은 "해양 물리의 영역 · 밖에서 받는다 · 산출은 아직 없다"까지만.

## 2. 일반화한 틀(`relation.md` 7절 · 그림 `shots/rel-2-frame.png`)
| 서비스 | 1차(LX) | 2차(기관) | 2차에 더 들어가는 것 |
|---|---|---|---|
| 해양쓰레기 | 해안 쓰레기 종류별 위치·양 | 예측 지도 · 수거 배치 | 해류·바람(바깥) · 수거 기록 |
| 영농관리 | 필지별 경작·비경작 · 비닐하우스 · 사료작물 | 직불금 대상 검토 · 휴경 관리 | 농업경영체 등록정보 · 신청 명단 |
| 도로안전 | 포트홀·도로시설 파손 위치·크기 | 보수 우선순위 · 조치 상태 | 노선·구간 · 교통량 · 보수 기록 |
규칙 다섯: 보이는 것까지가 1차 · 경계는 형식 한 장 · 기관 자료는 기관 안에서 · 갱신은 알림으로 · 책임은 기준 시점으로 가른다.

## 3. [문서] 와 [화면] 가르기(그림 `shots/rel-3-screens.png`)
