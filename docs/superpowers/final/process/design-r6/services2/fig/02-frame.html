1차·2차 서비스 — 일반화한 틀 한 장 문서 · 둘 다

어느 서비스든 같은 자리에서 끊는다: 1차는 영상에서 보이는 것을 세고 나눈 결과(LX), 2차는 그 결과에 기관만 가진 자료·모델을 합쳐 업무 판단·계획을 만드는 것(기관). 경계는 표준 결과 형식 한 장이고, 1차 새 공개가 2차 재계산의 신호다.

서비스1차 — LX 가 내는 것경계 — 표준 결과 형식2차 — 기관이 결합해 만드는 것2차에 더 들어가는 자료·모델(누가)2차가 다시 도는 때틀리면 누구 몫

생활환경남원 · 모델 없음 방치쓰레기 더미 · 소각 흔적 · 방치 폐가의 위치·규모 위치 · 종류 · 규모 · 촬영 시점 · 신뢰도 · 버전 민원 연계 · 현장 점검 동선 — 접수 민원과 겹치는 곳, 순회 순서 민원 접수 기록 · 점검 인력(환경과) 1차 새 촬영 공개 · 민원이 들어올 때(기관) 탐지 = LX · 점검 판단 = 환경과
1보이는 것까지가 1차영상에서 보이는 성질(쓰레기·작물·구멍)만 1차. 소유·신청·민원처럼 안 보이는 것과 합치는 순간 2차.
2경계는 형식 한 장1차 출구 = 2차 입구 = 표준 결과 형식. 시점·신뢰도·버전이 꼭 들어가야 나중에 "어느 입력으로 계산했나"가 남는다.
3기관 자료는 기관 안에서2차에 들어가는 대장·모델·기록은 LX 로 오지 않는다(계정 범위 밖 0). 예외는 갈림길 1-ⓑ(LX 서버에서 계산)일 때만.
4갱신은 알림으로1차 공개 = 이벤트. 카드 알림 한 줄 + 서비스별 키에 등록한 받는 주소. 2차를 자동으로 돌릴지 사람이 누를지는 기관이 정한다.
5책임은 기준 시점으로 가른다2차 화면에 '입력 1차 기준 시점 · 버전 · 계산 시점'을 항상 표시. 1차 오류는 LX(재학습), 2차 판단은 기관.

문서로 정할 것 문서

  • 여섯 질문 답(모델 소유 · 운영 · 계산 위치 · 자료 방향 · 갱신 · 책임)과 위 규칙 다섯
  • 표준 결과 형식 한 장(서비스마다 열 이름은 다르되 시점·신뢰도·버전은 공통)
  • 2차가 네 갈래 중 어디인가 — 전남이 계산하면 연결(ⓑ), LX 서버가 계산하면 맞춤(ⓒ) → 카드(ⓐ)
  • 해류 모델 소유·조달·갱신 주기 확인 목록

화면으로 만들 것 기관 분기 Land-XI

  • 기관 서비스 선택에 '우리 도가 운영하는 서비스' 카드 자리(2차) — 입력 1차 · 기준 시점 · '다시 계산 필요' 표시
  • 기관 알림 한 줄 "해양쓰레기 탐지 새 결과 — 예측 지도 다시 계산 필요"
  • 기관 관리자의 연동 키 칸에 '새 결과 알림 받는 주소' 한 칸(API 설계와 이어짐)
  • Land-XI 서비스 관리에 '이 결과를 쓰는 2차 서비스' 한 줄 — 관리자가 갱신 배포할 때 어디에 영향이 가는지

직불금·보수 우선순위·민원 연계는 옛 자산의 서비스 부품 목록에 '기관 몫(행정 가공)'으로 이미 적혀 있던 것을 2차로 옮겨 적은 것이다. 숫자는 넣지 않았다.
