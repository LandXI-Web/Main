LX 직원 — 회사 OTP 를 Land-XI 에 붙이는 네 길 문서 · Land-XI

회사 OTP 가 무엇인지(앱·실물 토큰·통합 로그인)와 그 인증 서버가 회사 밖에서 닿는지에 따라 길이 갈립니다. 어느 길이든 직원이 하는 일은 같습니다 — 로그인 때 회사 OTP 번호 한 번.

A

회사 통합 로그인으로 들어가기

통합 로그인(SSO) · SAML / OIDC
Land-XI 로그인에 'LX 통합 로그인' 버튼
↓
회사 로그인 화면 — 회사 비밀번호 + 회사 OTP
↓
Land-XI 로 돌아와 사번·이름·부서를 받아 입장

받아야 할 것

  • 통합 로그인 연결 정보(주소·서명 인증서)
  • Land-XI 돌아올 주소 등록(메인·관리자 입구 두 곳)
  • 넘겨받을 항목: 사번·이름·부서·메일
  • 시험 계정 2개 · 정보보안 부서 승인

안 되는 경우

  • 회사 통합 로그인이 사내망 PC 에서만 열림 → 직원 브라우저가 두 곳을 다 열 수 있어야 함
가장 편함 — 비밀번호도 회사 것 하나. 회사에 통합 로그인이 있을 때
B

인증 서버에 번호만 물어보기

RADIUS 또는 업체 확인 API
Land-XI 로그인 — 아이디·비밀번호 다음 회사 OTP 6자리
↓
Land-XI 서버가 회사 OTP 서버에 "이 사람, 이 번호 맞나요?"
↓
맞다 → 입장 · 아니다 → 다시

받아야 할 것

  • 인증 서버 주소·포트 · 방식
  • 공유 비밀값 또는 확인용 키 · 연동 규격 문서
  • Land-XI 아이디 ↔ 회사 아이디 맞추는 규칙
  • 방화벽 허용(Land-XI 서버 → 인증 서버) · 시험 계정 2개

안 되는 경우

  • 인증 서버가 사내망 전용 → 지금 Land-XI 서버에서 닿지 않음 → 운영 서버를 LX 전산센터로 옮길 때 연결
흔한 방식 — 재택근무 VPN 이 회사 OTP 를 쓰는 방식과 같음
C

회사 앱이 표준 방식일 때
처음 한 번 — 회사 OTP 앱으로 Land-XI QR 비추기
↓
앱에 'Land-XI' 줄이 생김
↓
로그인 때 그 줄의 6자리

받아야 할 것

  • 회사 앱이 'QR 로 다른 서비스 추가'를 허용하는지
  • 정보보안 부서가 업무 외 등록을 허용하는지

안 되는 경우

  • 회사 전용 방식 앱이면 불가
  • 회사 서버와 연결되는 것은 아님(퇴사해도 자동으로 안 막힘)
서버 연결 없음 — 앱만 회사 것. D 와 사실상 같음
D

연결 전까지 — Land-XI OTP 앱

표준 OTP 앱(구글 OTP 등)

↓
로그인 때 6자리
↓
회사 OTP 가 연결되면 A·B 로 바꿈

받아야 할 것

  • 없음 — Land-XI 안에서 끝남
  • 기관 입구와 같은 모양 · 같은 말

안 되는 경우

  • 회사 규정이 '사외 시스템은 회사 OTP 만'이면 A·B 가 나올 때까지 임시로
