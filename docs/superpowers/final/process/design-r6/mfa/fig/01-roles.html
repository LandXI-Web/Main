지금(시범 단계) 할 것

  • 관리자 권한 계정에만 OTP 앱 2차 인증을 켭니다(세 입구 모두)
  • 틀린 비밀번호 5번이면 그 계정 10분 잠금 · 실패도 기록
  • LX 정보보안 부서에 회사 OTP 연결 방법을 여쭙니다(여쭐 것 7)
  • 공무원 인증(정부 OTP·모바일 공무원증)을 LX 가 붙일 수 있는지 행정안전부에 여쭙니다

정식 오픈 때 할 것

  • 모든 사람 계정에 2차 인증 필수
  • LX 직원은 회사 OTP(연결되면), 기관은 OTP 앱
  • 임시 공통 비밀번호를 계정별 비밀번호로 바꾸고 처음 로그인 때 등록
  • 새 기기 로그인 · 초기화 · 잠금은 본인 메일로 알림

쓰는 사람이 하는 일은 셋뿐

  • 처음 한 번 — 휴대폰에 OTP 앱 설치 → QR 비추기 → 6자리 확인 → 복구 코드 보관(약 2분)
  • 로그인 때 — 6자리 한 번(하루 한 번꼴, 관리자는 로그인마다)
  • 휴대폰을 바꾸거나 잃으면 — 복구 코드로 들어가 다시 등록, 없으면 관리자에게 초기화 요청
