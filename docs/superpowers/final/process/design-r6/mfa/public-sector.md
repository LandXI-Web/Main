# 공공 부문 기준 — 행정·공공기관 정보시스템의 2차 인증은 어디까지 요구되나

> 2026-10-01 · Opus 5.5 · 지위: **사용자 확인 전 제안**(코드 수정 0). 공개 자료로 확인한 범위만 적고, 확인 못 한 것은 5절에 따로 적었습니다. 행정·조달 문서화가 목적이 아니라 **Land-XI 로그인을 어디까지 지켜야 하는지** 정하는 근거입니다(원칙 19).

## 3. 지금 Land-XI 와 기준 사이의 빈 곳
| 기준이 요구하는 것 | 지금 | 정식 오픈까지 |
|---|---|---|
| 외부 접속 때 안전한 인증수단 | 비밀번호만(세 입구 모두) | 모든 사람 계정 2차 인증 필수 · 관리자 권한은 지금부터 |
| 몇 번 틀리면 접근 제한 | 접속 주소마다 10분 20번(계정별 제한 없음) | 계정마다 5번 → 10분 잠금 + 본인 메일 알림 · 관리자가 풀 수 있음 |
| 접속 기록 | 성공한 로그인만 기록 | 실패 · 잠금 · 2차 인증 등록 · 초기화도 기록, LX 관리자가 봄(열람·내려받기 기록 채택과 함께) |
| 관리자 보호 | 관리자 입구도 비밀번호만 · 관리자 한 명 | 로그인마다 2차 인증 · 관리자 두 명 이상 · 나중에 패스키 선택 |
| 계정별 비밀번호 | 임시 공통 비밀번호(시범 단계 결정 — 원칙 30) | 계정별 비밀번호 + 첫 로그인 때 바꾸기 + 2차 인증 등록 |
| 외부 연결 키 | 설계 중(서비스별 키) | 키는 2차 인증 대상이 아님 — 대신 서비스별 · 보낼 수 있는 주소 제한 · 사용 기록 · 키를 만들고 보는 화면은 관리자 2차 인증 뒤 |

## 4. 정식 오픈 최소선(한 장)
1. 모든 사람 계정 2차 인증(OTP 앱 · LX 는 회사 OTP 연결되면 회사 OTP).
2. 계정마다 5번 실패 잠금 · 실패도 기록.
3. 관리자 권한은 로그인마다 2차 인증 · 관리자 두 명 이상.
4. 비밀번호 재설정은 메일 링크 + 2차 인증.
5. 새 기기 로그인 · 초기화 · 잠금은 본인 메일로 알림.
6. 휴대폰 분실 초기화는 가까운 관리자, LX 관리자는 모두 지원(원칙 72) — 모두 기록.

## 5. 확인 못 한 것
- 국가정보보안기본지침의 원격 접속·인증 조항 원문(공개 범위가 제한됨).
- 행정기관 및 공공기관 정보시스템 구축·운영 지침(행정안전부 고시)에 사용자 인증 강도를 정한 조항이 있는지 — 본문 파일을 열어 보지 못함.
- 국가망 보안체계 가이드라인 1.0 의 인증 영역 세부 항목(다중 인증을 어느 등급부터 요구하는지).
- LX 내부 정보보안 규정(사외 시스템 인증 규칙).
- LX(공공기관)가 정부 OTP · 행정전자서명 검증 · 모바일 공무원증 로그인 연계를 신청할 수 있는지.
- Land-XI 가 ISMS-P 등 인증 대상에 드는지(LX 판단).
