|---|---|---|---|---|---|---|

## 2. LX 직원 — 회사 OTP 연동(`lx-otp.md` · 그림 `shots/mfa-2-lx-otp.png`)
- **반영할 수 있습니다.** LX 가 쓰는 OTP 의 이름·방식은 공개 자료로 확인하지 못했고, 공공기관에서 흔한 형태는 모바일 OTP 앱 · 조달 등록 2차 인증 제품 · 통합 로그인 · 재택근무 VPN 연계입니다.
- **네 길**: A 회사 통합 로그인으로 들어가기(가장 편함) · B Land-XI 서버가 회사 OTP 서버에 번호만 물어보기(VPN 과 같은 방식) · C 회사 OTP 앱에 Land-XI 추가(앱이 표준 방식일 때) · D 연결 전까지 Land-XI OTP 앱.
- **내부망 전용이면**: D 로 시작 → 운영 서버를 LX 전산센터로 옮길 때 B · 또는 방화벽 한 줄 허용 · 또는 A 가능 여부 확인.
- **사용자께 여쭐 것 7**: ① OTP 이름과 모습(앱 화면 사진 한 장) ② 어디에 쓰나(VPN · 그룹웨어 · 메일 · 업무 포털) ③ 통합 로그인이 있나 ④ 집·출장지에서도 되나 ⑤ 관리 부서·담당자 ⑥ 다른 시스템이 붙인 사례·연동 문서 ⑦ 직원 아이디 체계(사번 · 메일 아이디).
- **정보보안 부서에서 받을 것**: 서버 주소 · 방식 · 연동 규격 문서 · 공유 비밀값 또는 키 · 시험 계정 2개 · 방화벽 허용 · 승인 절차 · 장애 때 비상 로그인 규칙.

## 3. 기관 — 구글 OTP 같은 표준 OTP 앱(`totp.md` · 그림 `shots/mfa-3-totp.png` · `shots/mfa-5-login.png` · 지금 `shots/now-gov-login.png`)
- **활용할 수 있고 기관 쪽 기본으로 권합니다.** 표준 방식 앱이면 무엇이든(구글 OTP · 마이크로소프트 인증 앱 등), 무료, 업체 계약·문자 비용 없음, 해외도 같음.
- **처음 한 번(약 2분)**: 앱 설치 → QR 비추기 → 6자리 확인 → 복구 코드 10개 보관. **로그인 때**: 아이디·비밀번호 다음 6자리 한 장(하루 한 번꼴). **휴대폰 분실**: 복구 코드로 혼자, 없으면 부서 사용자 → 기관 관리자 · 기관 관리자 → LX 관리자가 본인 확인 뒤 초기화(기록 · 본인 메일 알림). LX 관리자는 모두 도울 수 있음(원칙 72).
- **공무원 환경**: Land-XI 는 인터넷 PC 에서 열고 OTP 는 휴대폰이라 망 구분과 무관. 개인 휴대폰 업무 인증은 모바일 공무원증(227개 지자체) · 원격근무 스마트폰 인증으로 이미 익숙. 휴대폰을 못 쓰면 실물 OTP 토큰. 기관별 앱 설치 규정은 확인 필요.
- **대안**: 공무원이 이미 가진 정부 OTP · 모바일 공무원증 — LX 가 연계 신청할 수 있는지 행정안전부 확인이 먼저(갈림길 2).

## 4. 메일 2차 인증 판단(`email.md` · 그림 `shots/mfa-4-compare.png`)
**2차 인증으로 쓰지 않고 알림·재설정 보조로만.** 메일 비밀번호만 알면 코드도 받고(국제 지침: 메일은 2차 인증 수단으로 쓰지 말 것), 늦게 오거나 스팸함, 공무원 메일은 밖에서 열 때 또 로그인. **문자도 쓰지 않음** — 유심 복제·번호 가로채기(2025년 4월 통신사 유심 정보 유출 사건), 건당 비용·번호 보관, 해외 어려움. 메일은 비밀번호 재설정 링크(그 뒤에도 2차 인증) · 새 기기 로그인 · 초기화 · 잠김 · 가입 승인 알림에만.

## 5. 공공 기준 요지(`public-sector.md`)
- **개인정보의 안전성 확보조치 기준 제6조 제2항**: 외부에서 개인정보처리시스템에 접속하면 "인증서, 보안토큰, 일회용 비밀번호 등 안전한 인증수단" · **제5조**: 몇 번 틀리면 접근 제한. Land-XI 는 세 입구 모두 인터넷이라 **정식 오픈 때 전 계정 2차 인증**이 맞음.
- ISMS-P 2.5.3 · 2.6.6(강화된 인증 · 원격 접근) · 한국인터넷진흥원 권고(2024-11-26, 외부 접속 업무 시스템은 반드시 2차 인증) · 국가망 보안체계 가이드라인 1.0(2025-09-30, 등급별 통제 — 인증 세부 원문 확인 못 함) · 정부원격근무서비스 관행(인증서 + 복합인증) · 국제 지침(2025년 8월, 비밀번호 + OTP 앱 = 2단계, 메일 불가, 문자 제한).
- 한 줄씩: 행정전자서명 인증서(가능하나 인증서 이동 불편·해외 불가) · 정부 OTP(연계 신청 + 연결망 허용, LX 신청 가능 여부 확인) · 모바일 공무원증(민간 SaaS 연계공통기반 경유 — 민간 서비스 대상, LX 운영 시스템 가능 여부 확인) · 공동인증서(권하지 않음) · 간편인증(국민 대상용, 범위 밖) · 디지털원패스(2025-12-30 종료).
