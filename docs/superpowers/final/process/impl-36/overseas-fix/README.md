# 구현 36 · 해외 첫 화면 고침(해외첫화면-고침)

브리핑 확인: (1) **고장 고침만 · 새 문구 0** — 영어 화면 문구는 그대로이고, 기다릴 때는 키트에 이미 있는 가운데 'Loading'만 씁니다(원칙 157 · 212 · 230). (2) **재검수 · 시간 재기**(원칙 251) — 해외 화면 기능을 한 바퀴 눌러 '됨 / 안 됨'과 걸린 시간을 남겼습니다. (3) **서버 규칙** — 게이트웨이만 두 번 다시 켰습니다(10:01 · 10:26, 전후 health ok). 워커 · 전국 작업기는 건드리지 않았고, 바깥 주소는 로그인 폼으로만 열었습니다.

그림: `shots/`(바깥 주소 https://kgz-agri.land-xi.dev 을 해외 기관 로그인 폼으로 연 PC 1440). 파일 이름 끝 네 자리가 찍은 시각(10-15)입니다. 고치기 전 모습은 설계 30차 `design-r30/overseas/shots/now-org-kgz-1440-0947.png`입니다.

## 1. 원인

세 증상('Checking…'이 남음 · 큰 숫자 자리가 빔 · 'Run this season' 꺼짐)은 고장 하나가 아니라 **느린 첫 화면**이었습니다. 서버 호출 실패, 주소 오류, 응답 형식, 권한 문제는 없었습니다(모두 200). 0947 그림은 열고 9초 뒤에 찍어서 셋이 아직 안 끝난 순간이었습니다.

| 증상 | 원인 |
|---|---|
| 큰 숫자 자리가 빔 | 작황 하락 숫자는 브라우저가 위성 원값 타일 약 130장(경작지 판정 30 · 달별 지수 96)을 Planetary Computer에서 직접 받아 계산합니다. 한 장에 평균 1.3초 걸려, **지역에 닿은 뒤 약 11초** 동안 숫자 자리가 비어 있었습니다. 기다린다는 표시도 없었습니다. |
| 숫자가 볼 때마다 다름 | 많이 부르면 PC가 CORS 머리 없는 오류를 돌려줍니다. 그러면 타일 몇 장이 빠지고, 빠진 채로 계산돼 **같은 지역 · 같은 계절인데 117.9와 100.2 km²**가 나왔습니다(숫자 한 출처 위반). |
| 'Checking…' · Run 꺼짐 | 실행 견적을 **지역으로 날아가는 비행이 끝난 뒤에야** 물었습니다. 그래서 착지 뒤 2–3초 동안 'Checking…'이 남고 Run이 꺼져 있었습니다. 견적에는 시간 한도도 없어서, 서버가 답을 안 주면 'Checking…'이 계속 남을 수 있었습니다. |
| (EOX 교체와의 관계) | 바탕 영상 교체(세계 바탕 판 · Sentinel-2 해외 판)는 원인이 아니었습니다. 타일은 모두 받아졌고 오류는 0이었습니다. |

## 2. 고친 것

- **미리 시작:** 착지할 지역을 데이터 받는 즉시 정합니다. 결과 계산과 실행 견적을 글로브 · 비행(약 7초)과 겹쳐 시작합니다. 사용자가 지역을 누를 때도 견적을 비행 전에 묻습니다(`landxi/v3/global/app.js`).
- **서버 중계 · 보관:** 새 길 `GET /api/v1/proxy/pc/data/…`를 만들었습니다. 로그인한 사람만 쓸 수 있고, 허용 주소는 Planetary Computer의 data 타일 두 컬렉션(esa-worldcover · sentinel-2-l2a)뿐입니다.
  - 429 · 5xx가 오면 다시 시도합니다.
  - 받은 타일과 '자료 없음'은 30일 보관합니다.
  - 화면은 이 길이 있으면 이 길로 받고, 없으면(정적 배포) 예전처럼 직접 받습니다(`server/landxi_api/proxy.py` · `landxi/v3/global/ndvi-tiles.js`).
- **빠진 타일 처리:** 화면도 타일마다 최대 4번(0.4 · 1.2 · 2.4초 쉬고) 다시 받습니다. 끝내 못 받은 타일 수를 셉니다. 빠진 타일이 있는 결과는 보관하지 않습니다.
- **결과 보관:** 한 번 잰 결과(값 · 지도 그림)를 이 브라우저에 둡니다. 같은 작업 · 지역 · 계절 · 모자이크면 다음부터 바로 나옵니다.
- **다른 계절 미리 재기:** 지역에 닿으면 끝난 작업이 있는 다른 계절도 뒤에서 하나씩 미리 잽니다. 계절을 바꾸면 바로 나옵니다.
- **견적:** 1분 안에 받은 같은 견적은 다시 묻지 않습니다(계절을 오갈 때). 20초 안에 답이 없으면 'Checking…'에 멈추지 않고 기존 한 줄 'Queue is busy · try again shortly'로 넘깁니다. 늦게 온 다른 지역의 답은 버립니다.
- **기다림 표시:** 숫자를 계산하는 동안, 그리고 글로브가 서기 전(로그인 확인 · 배포 받기)에 키트의 가운데 'Loading'을 띄웁니다(원칙 212 · 새 문구 0).
- 서버 시험: `server/tests/test_pc_data_tile.py`(로그인 필요 · 허용 주소만 · 재시도 뒤 보관 · 204 보관 · 404는 빈 타일 · 5xx는 502) — 기존 프록시 시험과 함께 13개 통과(`pytest.txt`).

## 5. 검증
- 콘솔 오류 0(점검 네 번 모두).
- e2e: `v3-integration` 해외 기관 · 지자체 공무원 로그인 → 첫 화면 2개 통과.
- 서버 시험 13개 통과(`pytest.txt`).
- `tools/check/words.mjs`: 화면 금칙어 0 · 화면 오류 0으로 통과했습니다(44개 화면).
- `tools/check/numbers.mjs`: 같은 이름 숫자 모두 같음으로 통과했습니다.
- 주의: words.mjs는 해외 화면을 돌지 않습니다. 해외 기관을 넣어 돌리면(`--tenant kgz-agri`) 국내 기관용 '내 서비스' 칸을 기다리다 실패합니다. 이것은 검사기 쪽 한계입니다.

## 6. 남은 것 · 제안(채택은 사용자)
- **열고 지역에 닿기까지 약 10초** — 대부분 기존 비행 움직임입니다. 기관 사용자는 매일 같은 지역을 보므로, 두 번째부터는 글로브를 건너뛰고 바로 지역으로 열면 어떨까요? 이미 있던 화면이라 묻고 바꿉니다.
- **지역이 통째로 빨갛게 칠해짐**(설계 30차에서 본 '군 전체가 한 색') — 고장이 아닙니다. 올린 구역 대장과 어긋난 구역을 칠하는 층이 Season 탭에서도 켜져 있어서입니다. 이 칠이 작황 하락 화소(청록)를 가립니다. 대장 칠은 Register 탭에서만 보이게 할까요?
- **처음 계산하는 지역 · 계절은 약 6초** — 서버가 작업(Run)이 끝날 때 그 지역 타일을 미리 받아 두면, 첫 방문도 바로 나옵니다.
- **나라 축척에서 영상 경계가 보임** — Sentinel-2 해외 판의 오른쪽 · 아래 끝이 세계 바탕(500 m)과 네모 선으로 갈립니다(`10-country`). 판 범위를 넓히거나 경계를 흐리게 할지 정해야 합니다.
- **XI ChatGEO 답의 정확도** — "How much cropland dropped…"에 작황 하락 km²가 아니라 NDVI 평균으로 답했습니다. 해외 도구에 '작황 하락' 답을 붙이면 어떨까요?
- **검사기에 해외 화면 넣기** — words.mjs와 numbers.mjs가 해외 첫 화면도 돌게 하면, 이번처럼 재검수에서 빠지지 않습니다.
