## 남은 것
1. **워커 재시작 전까지 새 결과는 옛 방식**(1px 네모로 모음)으로 구워집니다 — 전국 작업기 칸 사이에 워커를 다시 켜면 새 방식. 해외 작업기를 다른 에이전트가 다루는 중이라 이번엔 켜지 않았습니다.
2. **이미 구운 전국 결과 칸 파일 2,938개**(10-15 이후 · 옛 가벼운 조각)는 다시 굽지 않았습니다. XI맵은 줌 11 부터 객체라 칠 규칙만으로도 굵게 보이지만, 줌 11 · 12 의 아주 작은 객체 일부는 아직 1px 네모로 모여 있습니다. 한가할 때 CPU 로 다시 구우면 됩니다(파일 하나 1~3초 · 전체 1~2시간).
3. 10-15 이후 다른 직원이 만든 서비스 결과 중 LX 직원 지도 서비스 목록에 없는 것은 이번 대상이 아니었습니다(같은 도구로 다시 굽기 가능).
4. 증거 스크립트의 XI맵 단계가 멈추던 일은 화면 문제가 아니라 시험 도구가 지도 객체 전체를 돌려받으려 한 탓이었습니다(고침 — `jumpTo` 결과를 돌려받지 않음).
