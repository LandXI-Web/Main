## 1. 한 줄
**기관 메뉴에서 '우리 공간'을 없앤다.** 거기 있던 네 가지는 공무원이 이미 가는 자리로 옮긴다 — 결과 설명과 내려받기는 **서비스 대시보드와 결과 지도 안**으로, 새 결과 알림은 **머리의 종 하나**로, 부서 배정은 **기관 정보의 담당자 표**로. 피드백(검토 요청 · 답)은 지도의 필지 카드에서 보내고 대시보드에서 주고받은 것을 본다. 서버의 공간(가벼운 칸 · 결과 설명서 판 · 기록)은 그대로 두고 **메뉴와 화면만** 바꾼다 — 구현 3차에서 만든 서버 쪽은 버리지 않는다.

- 탭은 다섯 그대로(현황 · 결과 지도 · 필지 목록 · 행정정보와 비교 · 보고서). '이 결과 설명' · '내려받기'를 탭으로 더 두는 길(일곱 탭)도 있어 N-1 선택지 ⓑ로 둔다 — 탭이 늘면 공무원이 어디를 눌러야 할지 다시 헷갈려 추천하지 않는다.
- 숫자는 한 출처: 현황 큰 숫자 1,035(현장 확인 필요)와 '이 결과는'의 2,098(판정한 필지 · 경작지 1,291 · 비경작지 807)은 둘 다 서버 값이고 뜻이 다르다(현장 확인 필요 ⊂ 판정한 필지). 카드에 "판정한 필지"라고 적어 헷갈리지 않게 했다.
- LX 관리자 쪽 '기관 공간' 탭(N-4)은 이 변경과 무관 — 그대로.

## 5. 점검
- 캡처 10장(`new-rehome-*.png` · 1440 · 390 · 390-full · 서랍 연 모습) — 가로 넘침 0(기관 정보 휴대폰에서 카드 제목 옆 긴 설명이 한 줄로 고정돼 넘쳤던 것 → 줄바꿈 허용) · 금지어 0 · 한 단어 줄 없음(측정기의 '3건 · 2건'은 제목 옆 작은 글 오판).
- 쓴 그림은 8차와 같다(남원 2025 드론영상 결과 크롭 · 지금 XI맵 캡처). 알림 글 · 검토 답 글 · 기록 줄은 예시.

## 6. 확인 못 한 것
- 결과 지도의 '보고 있는 결과' 카드는 지금 XI맵의 왼쪽 위 '결과 시점' 카드(분석 의뢰 화면에 있는 것)와 합치는 자리다 — 실제 구현은 그 부품을 넓히면 된다.
- 종 목록(새 결과 · 검토 답 · 의뢰 결과)이 지금 서버 알림과 한 줄기인지는 구현 때 확인.
- '보는 사람' 열은 부서 사용자 계정이 있어야 채워진다(지금 남원시 · 광주전남에 부서 사용자 계정 없음 — 구현 3차 메모와 같음).
