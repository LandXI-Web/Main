## 2. 무엇을 바꿨나 — 한 벌의 규칙
1. **실제 영상과 결과만 그림으로.** 결과가 있는 서비스(영농관리)는 실제 결과 장면(2025년 드론영상 위 휴경·전용 의심 필지 윤곽)을, 아직 없는 서비스는 기관색 연한 판에 '첫 결과 전 · 영상이 들어오면 분석합니다'처럼 **시작 시기만** 적는다. 일러스트 0.
2. **기관 화면 메뉴를 하나로** — 내 서비스 · 분석 의뢰 · 보낸 요청 · 기관 정보(기관 관리자만) · 계정. 모든 기관 화면이 같은 메뉴, 휴대폰은 아래 탭 다섯.
3. **기관 모습은 기관 것으로** — 머리는 기관 마크 · 플랫폼 이름 · 사람(부서 · 이름). 기관 색은 마크 · 현재 메뉴 표시 · 상태 칩 · 1차 버튼 · 서비스 얼굴 판에만. 바닥엔 기관 이름 · 대표전화 · "AI 분석 · 모델 개발과 갱신 — LX".
4. **카드 한 벌 그대로** — 결과 장면 · 상태 · 사업 연도와 부서 · 이름 · 한 줄 · 결과 예시(업무 결과만) · 조건 두 칸 · 1차 버튼. 메인 · 내 서비스 · 분석 의뢰(작은 판) · 기관 정보 미리 보기에 같은 부품.
5. **공무원 말로** — 형식 · 해상도 · 좌표계 · 용량 글자 0. "덕과면 일대 영상 1장 · 2024년 7월에 찍은 영상입니다 — 분석할 수 있습니다 ✓" 한 줄. 못 읽으면 "이 파일은 영상으로 읽지 못했습니다" + 'LX 담당자에게 보내 확인받기' 버튼 하나.
6. **숫자는 한 출처** — 1,035(현장 확인 필요 · 남원시)와 결과 날짜 2026.06.08만 서버 값. 읍면별 숫자 · 알림 · 할 일 · 사람 이름은 예시로 표시(시안 도장).

## 6. 확인 못 한 것(정직하게)
- 남원시 부서 이름(농정과 · 환경과 · 건설과 · 관광과)과 사람 이름(박서연 · 최민재 · 김도윤 · 이수진)은 **예시**다 — 기관 관리자가 기관 정보에 적는 값이고 실제 화면은 서버 값만 쓴다.
- 읍면별 숫자(운봉읍 212 …)는 합이 1,035가 되게 만든 예시다. 서버에 읍면별 집계가 있는지는 구현 때 확인.
- 채팅 답 글은 **모양을 보이는 예시**다 — 실제 답은 XI ChatGEO(vLLM)가 만든다. 장면 조각은 지금 XI맵 캡처에서 잘라 썼다.
- 메인 바탕에 실제 영상을 흰빛으로 눌러 쓴 것은 로그인 전 화면이라 '게스트에 고해상 영상 금지'(9월 24일 결정)와 부딪힐 수 있어 **기관-2로 묻는다**(ⓑ면 바탕도 뺀다).
