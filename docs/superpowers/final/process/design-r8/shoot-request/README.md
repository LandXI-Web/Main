## 3. 계산 규칙 — 확정된 것과 확인할 것
**확정(사용자 10-01 · 원칙 106)** — 기준 넓이 0.25㎢ · 군 지역 3,471,000원 · 시 지역 3,551,000원 · 구 지역 3,656,000원 · 출처 국토교통부 고시 제2025-896호(드론지적측량 수수료).
**설계로 정한 것** — 군·시·구는 기관이 아니라 **그린 범위가 든 시군구**로 서버의 행정구역(시군구 경계 252)에서 정한다(광주전남 계정이 강진에 그리면 군, 여수에 그리면 시, 광주 북구에 그리면 구). 화면의 금액은 모두 **'대략 · LX 확인 뒤 확정'**이고, 확정 금액은 LX 담당이 답할 때 적는다(대략 금액이 미리 들어 있음).

### 예시 계산 — 남원시(시 지역) 덕과면, 두 방식(`shots/new-fee-rule-1440.png`)

|---|---|---|
| 1.5㎢(시안 화면의 예 — 일부러 나눠떨어지는 값) | 6칸 × 3,551,000 = **21,306,000원** | 6.0칸 × 3,551,000 = **21,306,000원**(같음) |

## 4. 설정 한 곳(원칙 106) — 고시가 바뀌면 여기만
지금 서버는 값을 `server/config/*.yaml` 한 곳에 두고 파일이 바뀌면 다시 읽는다(분석 의뢰 · 영상 표준이 그렇게 되어 있음). 수수료도 같은 방식으로 **`server/config/fees.yaml`** 하나를 둔다(구현 때 만든다 — 지금은 초안).

```yaml
# 촬영 수수료 — 국토교통부 고시 제2025-896호(드론지적측량 수수료). 고시가 바뀌면 이 파일만 고친다(화면 · 코드에 금액 0).
drone_shoot:
  notice: "국토교통부 고시 제2025-896호"      # 화면에 '국토교통부 고시 기준'으로만 보임
  effective_from: null                        # 고시 시행일(사용자 확인 뒤)
  unit_km2: 0.25
  per_unit: { gun: 3471000, si: 3551000, gu: 3656000 }
  region_type_of: "sgg"                       # 군·시·구 = 그린 범위가 든 시군구(기관이 아님)
  general_gu: null                            # 일반구(천안시 서북구 등)를 'si' 로 볼지 'gu' 로 볼지 — 촬영-3
  rounding: null                              # ceil(올림) | prorate(비례) — 촬영-2
  min_units: null                             # 최소 칸 수 — 촬영-3
  vat: null                                   # included | excluded — 촬영-3
  straddle: null                              # 둘에 걸칠 때 — larger_share | higher_price — 촬영-3
  volume_discount: []                         # 넓을수록 깎는 구간 — 촬영-3(없으면 빈 칸)
  analysis_fee: null                          # 촬영 뒤 AI 분석 추가 금액 — 촬영-3(없으면 0)
```

- **서버 셈 한 곳** — 화면은 범위(도형)만 보내고 `넓이 · 시군구 종류 · 칸 수 · 금액 · 고시 이름`을 받는다(견적 한 줄). 화면 어디에도 금액 숫자를 적지 않는다(같은 이름 같은 값 — 사용자 규칙 3).
- **대략 → 확정** — 의뢰에는 '대략 금액(셈 당시 설정의 사본)'이, LX 답에는 '확정 금액'이 따로 남는다. 고시가 바뀌어도 옛 의뢰의 금액은 바뀌지 않는다.
- **관리자 화면에서 고치기(제안-3)** — 원스톱(원칙 24)에 맞게 LX 관리자 '설정 → 수수료'에서 고시 번호 · 금액을 화면에서 고치면 이 파일에 저장되게. 바뀐 기록(누가 · 언제 · 전 값)을 남긴다.

## 7. 확인 못 한 것(정직하게)
- **고시 원문은 보지 못했다.** 숫자는 사용자가 주신 세 금액뿐이다. 고시의 '기준면적 0.25㎢'가 촬영만인지 측량 성과(도면 등)까지인지, 끝수 · 최소 · 부가세 조항이 고시에 있는지는 원문을 받으면 그대로 옮긴다(촬영-2 · 촬영-3이 바뀔 수 있음).
- **서버에 촬영 의뢰 종류가 없다.** 지금 의뢰 표는 분석 의뢰만(상태 확인 대기 → 분석 준비 → 분석 중 → 결과 도착 · 반려), 결재함 종류도 '분석 의뢰'까지다. 구현 때 의뢰 종류 '촬영'(상태 접수 → LX 답 → 진행 → 촬영 중 → 영상 공유 → 분석)과 견적 한 줄, 영상 등록에 '어느 의뢰로 찍었나' 한 칸이 새로 든다.
- **범위 그리기 부품** — 지금 XI맵 도구 복원 항목(FR-22 측정 · 관심 구역)이 확인 대기라, 그리기 부품은 구현 때 그 부품과 한 벌로 만든다(따로 만들지 않음).
- 날짜(10.01 · 10.02 · 11월 둘째 주 · 11.12) · 사람(박서연 · 김도윤) · 보낸 의뢰 목록은 **예시**다. 읍면동 이름(덕과면 · 사매면 · 보절면 · 산동면 · 운봉읍 · 주천면 · 송동면)은 서버 읍면동 경계의 실제 이름이다.
- 390 전체 캡처(`-390-full`)는 아래 고정 탭을 뺀 그림이다(실제 화면에서는 탭이 아래에 고정).
