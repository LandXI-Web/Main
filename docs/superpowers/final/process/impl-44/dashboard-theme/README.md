## 2. 테마 고르기(대시보드-테마)

| 테마 | 모습(모두 밝은 톤 · 규칙 3-4 검정 톤 없음 · 글자 바닥 14 그대로) | 그림 |
|---|---|---|
| 기본 | 지금 그대로 — 회백 바탕 위 흰 카드 16 · 선 · 그림자 0 | `theme-basic-1440` |
| 부드러운 | 카드 24 · 흰색에서 옅은 하늘빛으로 아주 조금 물든 면 · 숫자 칸에 옅은 바탕 · 제목 600 | `theme-soft-1440` |
| 또렷한 | 1px 선 · 모서리 8 · 머리 아래 선 · 제목 800 · 보조 글자 진하게(대비 높임) · 더 보기 밑줄 | `theme-sharp-1440` |
| 촘촘한 | 안쪽 여백 12/16 · 머리 24 · 목록 줄 21px · 큰 숫자 대신 보통 숫자 — 같은 칸에 더 많은 줄 | `theme-dense-1440` |

- 어디서: 수정 중 도구 줄 '모양 고르기' 옆 **'테마'**. 목록에 작은 견본 · 이름 · 한 줄 설명 · '지금 테마'. **목록 위에 손을 올리면(또는 초점) 대시보드에 바로 입혀져 미리 보고**, 누르면 저장, 벗어나면 지금 테마로 돌아간다 — `theme-menu-1440` · `theme-preview-soft-1440`(손만 올림 · 저장 테마는 아직 기본 · run.log "미리 보기 data-theme=soft · 저장 테마=basic" → "손 내림 data-theme=basic").
- 저장: 사람마다 서버 사용자 설정(같은 `PUT /me/prefs/dash.lx-console` 의 `theme` 칸) + 브라우저 사본. 새로 열어도 유지(run.log "새로 열기 … 테마 유지=dense"). '처음 모양으로'는 배치와 함께 기본 테마로.
- 공용 부품: `kit/dashgrid.js` 의 `themes: [{ id, label, desc }]` · `.dg[data-theme=…]` · `ctx.theme`. LX 관리자 · 기관 첫 화면이 같은 부품을 쓰면 같은 테마 고르기가 따라온다.

## 4. 제안

1. **공휴일 빨강** — 공공데이터포털 '특일 정보 API'(한국천문연구원) 를 서버가 하루 한 번 받아 연도별 표로 두고 `/me/agenda` 에 `kind: holiday` 로 내려 주면 달력이 같은 빨강 + 이름('개천절')으로 표시. 지자체 공무원이 가장 먼저 찾는 표시. 키 신청이 필요해 사용자 확인 뒤.
2. **LX 관리자 대시보드에 같은 부품** — 테마 · 표시 방식까지 그대로 따라온다(열쇠만 `dash.ops-core`).
3. **테마를 기관 화면에도** — 기관 첫 화면은 기관 상징색(CI)이 있어 '부드러운' 테마의 물든 색을 CI 로 바꾸는 변형 하나면 된다.
