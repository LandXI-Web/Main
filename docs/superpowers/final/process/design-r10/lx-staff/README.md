### 1-4. 홈에 '대시보드'가 없었다
지금 홈은 **목록의 축소판**(프로젝트 3줄 · 요청 숫자 셋 · 서비스 장면 넷)이라 "프로젝트가 몇 개, 할 일이 몇 개, 서비스가 어디서 몇 개 도나"가 **숫자로 한눈에** 서지 않았다. 숫자 띠(지금 할 일 · 내 프로젝트 · 운영 중 서비스 · 다시 학습할 서비스)를 두 방향 모두 맨 위에 둔다.

### 1-5. 뿌리 하나
**단계 화면 · 단계 막대 · 단계 띠 · 단계 칩이 서로 다른 자리에서 같은 말을 하고, 할 일과 상태가 섞여 있었다.** 방향 A는 그중 '지금 할 일 하나'만 남기고 나머지를 접고, 방향 B는 단계 자체를 '일의 목록 여섯 줄'로 바꿔 한 자리에서 보고 한다.

## 4. A와 B는 무엇이 다른가 — 고르실 때
| | A 덜어내기 | B 일의 목록 |
|---|---|---|
| 프로젝트 한 장에서 '지금 어디'를 아는 법 | 지금 할 일 한 칸 + 단계 6 칩 한 줄 | 여섯 줄 중 펼쳐진 줄 |

| 새 프로젝트 | 한 장 세 칸 + 보관함은 창 | 네 줄 체크리스트, 보관함은 줄 안 |
| 잘 맞는 사람 | 한 번에 하나만 보고 싶은 사람 · 휴대폰 | 전체 흐름을 한 장에서 훑고 그 자리에서 처리하고 싶은 사람 |
| 구현 난이도 | 낮음(지금 부품 재배치 + 접기) | 중간(4단계 표본 보기 · 6단계 지도 · 재학습을 줄 안에 넣는 부품) |
**섞는 길(ⓒ)**: 홈 · 목록은 A(한눈에 + 지금 할 일 하나), 프로젝트 한 장 · 새 프로젝트는 B(여섯 줄 · 네 줄). 어디를 섞을지는 메모로.
