## 5. 기관-10 — 2차 서비스 변수 검토(`variables-2nd.md` · `mock/fig-2nd.html`)
핵심만(표 전체는 `variables-2nd.md` §2 열일곱 변수):
- **바뀐 것**은 올리는 사람(개발자 → LX 직원)뿐. 공간 방식(가벼운 칸 + 필요한 기관만 상자) · 결과 설명서 · 카드 한 벌은 13차 그대로.
- **변수가 갈리는 축은 둘** — 공통 비교 기능으로 되나(설정만 / 코드 상자) · 바깥 자료가 있나(없음 / 있음 — 제공처 · 주기를 기관이 책임). 광주전남 예측 지도 = 코드 상자 + 바깥 자료, 남원 직불금 표 = 설정만 + 바깥 자료 없음.
- **비용 선**: 설정만 = 유지관리 수수료 안 · 코드 상자 · 바깥 연결 = 연차 사업으로 별도. 금액은 LX 답에서 사람이(촬영-3 ⓐ와 같은 원칙).
- **1차 갱신 때**: 2차 카드에 '다시 계산 대기' — 설정만은 자동 · 코드는 LX 담당 확인 뒤. 형식이 바뀌는 회차(여수 종류 1 → 8)는 공개 전 알림.
- **버전**: 2차 판 = 1차 회차 + 자료 날짜. '입력 … 기준' 한 줄을 카드 · 이력 · 보고서에 고정.
- **미리 정해 둘 것 열 가지**(§3) · **추천 흐름 여섯 칸**(§4 · 그림) — 요청 받기(요청하기 '맞춤 서비스' 한 줄) → 검토(점검표 여덟 칸) → 만들기(LX '2차 프로젝트') → 공개(승인 · 카드) → 갱신('다시 계산 대기') → 유지 · 끝(연 1회 점검 · 30일 뒤 지움 · 두 기관 이상이면 1차로 승격).
- 갈림길: ⓐ 추천 흐름대로 · ⓑ 요청은 사업 협의로만 받고 화면에는 결과 카드만.

## 8. 확인 못 한 것(정직하게)
- 'LX맵'을 어디까지 켜 둘지(기본 켬 / 기본 끔) — 시안은 필지를 눌렀을 때 켜지는 모습. 지도 전체에 늘 켜면 축척이 작을 때 글자가 겹친다 — 구현 때 축척 한계를 둔다.
- V-World 지역지구 층은 도시지역 · 관리지역 · 농림지역 · 자연환경보전지역 네 층을 따로 물어야 한다(필지마다 한 층만 답함). 농업진흥 · 보호구역은 서버 적재 정본에만 있다(V-World 층 이름을 못 찾음 — 두 필지 모두 값 없음).
- 시안의 지도 바탕은 공개 위성 영상(서버 타일 사다리). 실제 화면 바탕은 2025년 드론영상이라 더 선명하다.
- 해류 · 바람 예보의 제공처 · 주기, 직불금 명단의 실제 열, 코드 상자의 자원 숫자 — 7차와 같이 미확인(`variables-2nd.md` §6).
- 관리자 기관 화면의 '이번 달 보낸 요청 0'은 분석 · 촬영만 센 것. 검토 요청 수는 이번에 읽지 않아 넣지 않았다(구현 때 서버 값).
