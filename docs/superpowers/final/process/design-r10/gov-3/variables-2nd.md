## 0. 한 줄
1차 = LX가 만든 AI 분석 서비스(예: 해양쓰레기 실태조사 · 영농관리). 2차 = 그 결과에 기관 자료를 더해 만드는 기관 맞춤 서비스(예: 해양쓰레기 예측 지도 · 직불금 대상 검토 표). **2차도 LX가 만들어 올린다**는 결정으로 변수의 절반(누가 올리나 · 누가 점검하나 · 품질 책임)은 LX 안으로 들어왔고, 남는 변수는 **기관마다 다른 요구 · 자료 · 바깥 자료 · 비용 · 1차 갱신과의 관계**다. 아래 표는 그 변수를 실제 예 둘에 대 보며 "미리 정해 두면 흔들리지 않는 것"을 뽑은 것이다.

## 1. 전제 — 바뀐 것과 그대로인 것
| | 13차 분기-1~4(확정) | 18차 기관-10 ⓑ 뒤 |
|---|---|---|
| 올리는 사람 | 기관이 맡긴 개발자(또는 LX) → LX 관리자 승인 | **LX 직원**(프로젝트장) → LX 관리자 승인. 외부 개발사가 끼면 LX에 넘겨 LX가 올림 |
| 공간 | 모든 기관 가벼운 칸 + 코드가 필요한 기관만 상자(분기-3 ⓒ) | 그대로 |
| 화면 | 2차는 기관 플랫폼 틀 안에 카드 한 벌(분기-4 ⓐ · 원칙 93) | 그대로 — 'LX가 제공' · '우리 도가 만든' 구분 없이 한 줄(기관-10) |
| 결과 설명서 | 1차 공개 때 저절로(분기-2) | 그대로 — 2차의 입력 근거 |
| 지금 구현 | 분기 공간 1단(가벼운 칸 · 결과 설명서 · 관리자 기관 공간 목록 — 구현 확인 3차 N-4 완료) | 올리기 화면이 아직 없음 → 이 문서 확인 뒤 범위를 정함 |

## 2. 변수 표 — 실제 예 둘로
기준: 광주전남 **해양쓰레기 예측 지도**(1차 = 해양쓰레기 실태조사 서비스 · 지금 광주전남에 공개된 결과 AI 탐지 1,857건 · 2025년 항공영상 · 2026.06.08 분석) · 남원 **직불금 대상 검토 표**(1차 = 영농관리 행정서비스 2판 · 판정한 필지 2,098 · 2025년 드론영상). 숫자는 서버 값, 나머지는 사업 상황을 가정한 예.

| 4 | **바깥 자료** | 누가 · 어떤 형식 · 어떤 주기로 주는지 LX가 모른다 | 해류 · 바람 예보 — 제공처 · 주기 **확인 필요**(7차에서도 미확인) | 없음 | 바깥 자료는 **기관이 주소 한 곳 + 책임자**를 적어 준다. 끊기면 2차 카드에 '자료 끊김' 표시, LX가 고치지 않는다 |
| 5 | **개인정보** | 명단에 이름 · 연락처가 섞여 온다(원칙 59 · S-8 채택) | 수거 기록에 작업자 이름 가능 | 신청자 이름 · 주소 | 올리는 순간 서버가 가림(S-8). 2차 결과 · 보고서 · 내려받기에는 가린 값만. **보관 기간은 그 해 검토 끝까지**(기관이 더 짧게 정할 수 있음) |

| 8 | **비용** | 유지관리 수수료 안인지, 별도 사업인지 애매(원칙 60) | 코드 상자 + 바깥 자료 연결 = **별도(연차 사업)** | 설정만 = 수수료 안 | 선: **설정만 = 유지관리 수수료 안 · 코드 상자 · 바깥 연결 = 별도 사업**. 금액은 화면이 아니라 LX 답에서 사람이(촬영-3 ⓐ와 같은 원칙) |

| 11 | **1차 갱신 때 다시 계산** | 자동으로 돌리면 틀린 표가 기관에 바로 보인다 | 코드 상자 → 자동으로 돌리기 위험(형식 변화) | 설정만 → 자동이 자연스러움 | 1차 새 회차 공개 → 2차 카드 **'다시 계산 대기'** 표시. **설정만 = 자동 · 코드 상자 = LX 담당 확인 뒤 공개**. 기관 자료를 새로 올려도 같은 길 |

| 16 | **책임** | 2차 결과로 처분하면 누가 책임지나(원칙 40) | 예측(언제 어디에 쌓일지) = 도 + 계산 방식 · 탐지(어디에 무엇이) = LX | 대상 여부 = 농정과 · 판정(경작인가) = LX | 카드에 한 줄: **"AI 분석 = LX · 해석 · 처분 = 기관"**. Land-XI는 보고서까지 |
| 17 | **폐기** | 사업이 끝난 2차가 쌓이면 잡동사니(원칙 85) | 사업 끝 → 상자 · 예측 결과 · 해류 자료 지움 | 그 해 검토 끝 → 명단 지움 · 표는 보고서로 | 기관 관리자 '끄기' 요청 → 30일 내려받기 → 지움. 본체 · 다른 기관 영향 0 |

## 3. 미리 정해 둘 것 — 열 가지
1. **받는 길 하나** — 요청하기 메뉴에 '맞춤 서비스' 한 줄(무엇을 · 어떤 자료로 · 언제까지 · 누가 보나). 큰 건은 연차 사업 협의로 가되 같은 요청 번호로 잇는다.
2. **판단 기준 = 변수 점검표 여덟 칸** — 자료 형식 · 바깥 자료 · 개인정보 · 1차 의존 · 공간 방식 · 비용 · 일정 · 다른 기관 확장. LX 담당이 채우고 관리자가 '할 수 있다 · 협의 필요 · 안 한다'로 답.
3. **만드는 자리 = Land-XI '2차 프로젝트'** — 입력은 1차 서비스 결과 + 기관 자료. 생산 단계는 1차 프로젝트와 같은 틀이되 학습 단계가 없다(설정 또는 코드 → 시험판 → 공개 요청).
4. **두 방식만** — 설정만(공통 비교 기능) · 코드 상자. 셋째 방식은 만들지 않는다.
5. **비용 선** — 설정만 = 유지관리 수수료 안 · 코드 상자 · 바깥 자료 연결 = 연차 사업으로 별도. 금액은 LX 답에서 사람이.
6. **갱신 규칙** — 1차 새 회차 → 2차 '다시 계산 대기'. 설정만 자동 · 코드 상자는 LX 담당 확인 뒤. 형식이 바뀌는 회차는 공개 전 알림.
7. **버전 표기** — 2차 판 = 1차 회차 + 자료 날짜. '입력 … 기준' 한 줄을 카드 · 이력 · 보고서에 고정.
8. **개인정보** — 올리는 순간 가림(S-8) · 보관은 그 해 검토 끝까지 · 2차 결과에는 가린 값만.
9. **책임 한 줄** — AI 분석 = LX · 해석 · 처분 = 기관. 카드 설명에 고정 문구.
10. **끝내기** — 기관 관리자 요청 → 30일 → 지움. 두 기관 이상이 원하면 1차로 승격.
