# 화면 최적화 — LX 관리자 · 기관 · 메인 화면 (원칙 248 · 10-14)

사용자 원문(10-14): "지금 화면별로 맞춤 최적화를 해야될 것 같다. 여백 공간이 너무 많고. 해상도에 따라 안이쁘게 보이는 것도 너무 많다. 이건 기본으로 최적화하여 구현해야 하는 범위이다. 직원, 관리자, 기관 화면 모두 체크한다."
직원 화면(impl-32/fit-staff)에 이어 **LX 관리자 화면 · 기관 화면(남원) · 메인(로그인 없이)** 을 같은 규칙으로 고쳤습니다. 직원 화면에 남아 있던 XI ChatGEO 둥근 단추 문제도 함께 고쳤습니다.

- 찍은 방법: 바깥 주소를 로그인 폼으로 한 번씩 들어가 세션을 유지했습니다(LX 관리자 — app.land-xi.dev · 남원 기관 관리자 — namwon.land-xi.dev · 메인 · 로그인 · 남원 기관 메인은 로그인 없이). 화면 37개 × 해상도 5(1280×720 · 1366×768 · 1440×900 · 1920×1080 · 2560×1440)를 고친 전 · 후로 찍고 쟀습니다(`shoot.mjs` · 측정 `measure.part` · 비교 `cmp.js` · 측정값 `metrics-before.json` · `metrics-after.json` · 칸별 표 `problems.txt`).
- 잰 것: 가로 넘침 · 화면 밖으로 나간 칸 · 내용 폭(화면 판 폭 대비 %, 80% 미만 = 가운데 좁은 띠) · 제목 3줄 이상 · 한 단어만 남은 줄 · 격자 열 수 · XI ChatGEO 단추가 단추 · 링크 · 입력을 덮는지. 겹침은 캡처를 눈으로도 봤습니다.
- 그림 전체(370장)는 저장소 밖에 두고, 아래 대표 그림만 넣었습니다.

## 4. XI ChatGEO 둥근 단추(공용 부품 — 직원 · 관리자 · 기관 모두)

- 원인: 단추가 자리를 비킬 때 '누르는 것'을 그 한가운데 점으로만 확인해서, **화면 아래 가장자리에 반쯤 걸친 단추 · 링크(한가운데가 화면 밖)를 못 보고 그 위에 앉았습니다.**

## 9. 이런 것도 필요하지 않을까요?

1. **XI ChatGEO 단추가 비킬 자리가 없을 때 왼쪽 메뉴 아래 빈칸으로** — 카드가 꽉 찬 화면(직원 대시보드 1280)에서 단추가 카드 그림 위에 놓입니다. 왼쪽 메뉴 아래는 늘 비어 있어 그쪽으로 옮기면 어떤 화면에서도 내용을 가리지 않습니다(정해진 '오른쪽 아래' 자리를 바꾸는 일이라 먼저 여쭙니다).
2. **관리자 배포 '사용 현황' 탭 처음 열 때 빈 화면** — 표가 몇 초 늦게 떠 그동안 아무것도 없습니다. '불러오는 중' 한 줄을 두면 고장으로 오해하지 않습니다.
3. **잠깐 끊긴 서버 응답에 로그아웃되지 않게**(직원 화면 때와 같음) — 측정 중 게이트웨이 502 몇 초에 기관 화면도 로그인으로 떨어졌습니다. 401 일 때만 로그인으로 보내면 기관 담당자가 일하다 튕기지 않습니다.
4. **기관 서비스 대시보드 2560 의 큰 그림 높이** — 폭이 넓어지며 첫 그림이 화면 절반 높이가 됩니다. 넓은 화면에서 그림 높이에 상한을 두는 안을 시안으로 보여 드릴 수 있습니다.
