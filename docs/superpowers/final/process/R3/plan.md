## 3. 작업 사이 계약 (고칠 때는 이 절을 따른다)
- **3.1 동작 끝 신호**
  - 화면이 지도 동작을 처리하면 `kit:agent-action-done {op, ok, reason?}` 을 낸다.
  - 실패하면 `ok:false` 와 함께 사용자 말 한 줄을 `reason` 에 담는다(예: '더 확대할 수 없습니다').
  - r3-route 는 한 run 의 동작이 모두 `ok:false` 이면 답 끝을 실패 문장으로 바꾼다.
  - XI맵(r3-xi)·해외 화면(r3-global)·첫 화면(r3-fusion)은 각자 `ok` 를 정직하게 낸다.
- **3.2 가드 결과 그대로**
  - 도구가 `{"status": "no_data"|"outside"|"not_found", "text": "...", "next": "..."}` 를 돌려주면, r3-route 의 runner 는 `text`(+`next`)를 그대로 답으로 쓴다. 모델이 바꿔 말하지 못하게 한다.
  - 관할 안인데 결과가 없으면 "해당 지역 데이터가 없습니다", 관할 밖이면 "이 기관의 데이터가 아닙니다"다(기존 `say()` 문구).
- **3.3 영상 범위**
  - r3-xi 의 분석 도구와 견적 결과는 다음 값을 봉투로 준다: `coverage`(0–1, 측정), `emd_covered`(영상과 겹치는 읍면동 수), `emd_total`.
  - 답·진행판·확인 카드는 이 값만 쓴다. 지어낸 비율은 0이다.
- **3.4 확인 카드 제목** — 확인 카드 도구 결과에 `title`(예: '산청군 AI 분석 실행 · 영상이 있는 곳만')이 있으면 명령 바가 그 글자를 그린다. r3-xi 가 `title` 을 채우고 r3-route 가 그린다.
- **3.5 법령 질문 판정**
  - `LAW_ASK`(조문·조항·법·법령·시행령·근거·위반·처벌·원상회복 등)가 맞으면 r3-route 의 `ledger_route`·요약 직행은 이 질문을 건너뛴다. 판정 함수는 r3-route 가 소유한다.
  - 법령 도구 결과(원문)는 숫자 가드에서 뺀다. `basis: "law_text"` 봉투나 도구 이름으로 가린다.
- **3.6 확장 라우터**
  - `landxi_api/main.py` 의 확장 라우터 목록(`for _name in ("law",)`)에 r3-train 이 `"training"`, `"global_data"` 를 한 번에 넣는다.
  - 모듈이 없으면 건너뛰는 지금 동작은 그대로 둔다.
- **3.7 숫자 한 출처** — 같은 이름의 숫자는 모든 화면에서 같은 값이다.
  - 의심 필지 = `survey_sgg.findings`
  - 대장과 AI 가 어긋난 필지 = 대장 대조 결과
  - 모델 성능 = 학습 끝 검증(측정) 값
