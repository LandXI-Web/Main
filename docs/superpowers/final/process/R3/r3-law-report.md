## 할 일
1. **M9 본 조문 먼저**
   - 제목을 비교하기 전에 띄어쓰기와 조사('의'·'에 관한')를 없애 맞춘다("개발행위의 허가" = "개발행위허가").
   - 점수가 같으면 법 > 시행령 > 시행규칙 > 지침·요령 순으로 올린다.
   - 시행령·시행규칙이 1순위일 때는 '함께 볼 조문'에 모법 본 조문을 넣는다.
   - 조문을 지어내지 않는 규칙('법령 데이터에 없습니다')은 그대로 둔다.
2. **영어 법령 질문** — 영어 질문은 주요 용어 사전(farmland lease → 농지 임대차, development permit → 개발행위허가 등, 로컬 표)으로 한국어 검색어를 만들어 찾는다. 답은 영어 요약 + 조문 원문(한국어) 인용이다.
3. **M10 보고서 가드**
   - 보고서 도구는 관할 안이지만 결과가 없으면 `{"status":"no_data","text":"해당 지역 데이터가 없습니다","next":"XI맵에서 {지역} AI 분석을 먼저 실행하세요"}`, 관할 밖이면 `status:"outside"` 를 돌려준다(plan 3.2).
   - 관할 판정은 기관 관할 시군구 목록으로 한다(해남·나주·담양 = 광주전남 관할 안).
4. **M15 공문 초안**
   - '공문'·'협조 요청'·'시행문'을 요청하면 보고서가 아니라 공문 초안 docx 를 만든다. 양식은 plan 4절 기본값이다.
   - 숫자(대상 필지 수 등)는 도구 결과 봉투에서만 쓴다.
   - 내려받기 블록은 기존 파일 블록을 쓴다.
5. **M16 docx 사용자 말**
   - 표제·목록·꼬리표에서 규칙 코드(R1–R6·L1 등)를 없애고 규칙 이름으로 쓴다.
   - 상위 10건은 필지 기준으로 중복을 없앤다(plan 4절 기본값).
   - 개발 문구 검사 목록에 규칙 코드 패턴 `\b[RL]\d\b` 를 더한다.
6. **보고서 화면**(`gov-report`)
   - 머리는 고른 시군구 이름이다(시도가 아님).
   - '할 일' 표와 오른쪽 상세는 고른 시군구의 필지만 보여 준다.
   - 첫 문장에서 지역 이름이 겹치지 않게 한다('도암면의 도암면' 0).

## 완료 기준 (측정 가능 · 화면만으로 · 두 시도 이상 · 계정 광주전남·남원(전북))
- M9: 두 계정에서 "개발행위허가 대상 조문은?"·"산지전용허가 기준 조문은?"·"농지 전용 신고 조문은?"·"농지 처분의무 조문은?"을 묻는다. 1순위가 각각 「국토계획법」 제56조·「산지관리법」 제18조·「농지법」 제35조·「농지법」 제10조다. 새 질문 2개(확인자가 고름)도 본 조문이 1순위다. 색인 밖 질문 4개는 여전히 "법령 데이터에 없습니다"다.
- 영어: "Which article of the Farmland Act covers farmland lease?" → 「농지법」 제23조 인용 + 영어 답.
- M10: 광주전남 해남·나주·담양, 전북 1곳(결과 없는 시군구) 보고서 요청 → 모두 "해당 지역 데이터가 없습니다" + 다음 할 일 한 줄. "기관의 데이터가 아닙니다" 0. 관할 밖(남원 계정에서 전주·여수) → "이 기관의 데이터가 아닙니다".
- M15: 두 시도에서 "○○ 현장 조사 공문 초안 써 줘" → 공문 docx 내려받기(파일 이름·양식은 기본값대로, 대상 필지 수 = 화면 값).
- M16: 두 시도 보고서 docx 에서 규칙 코드 0건, 같은 필지 중복 0건. 인용 [1] = 요청 지역(회귀 0).
- 보고서 화면: 강진·구례를 고르면 머리가 시군구 이름이고, 할 일 표에 다른 시군구 필지가 0건이다.
- `test_r3_law_report.py` 에 위 순위·가드·공문 테스트가 있고 녹색이다.
