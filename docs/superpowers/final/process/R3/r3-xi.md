## 할 일
1. **M11 COG 지역 범위 분석**
   - `analyze.js` 의 `pickImagery()` 가 등록 영상(COG)도 후보로 넣게 하거나, 읍면동·그린 범위 경로도 전역 분석처럼 서버 견적(`/jobs/quote`)에 영상·모델 선택을 맡긴다. 둘 중 하나로 구현하고 이유를 보고서에 적는다.
   - 영상과 겹치지 않는 범위만 '영상 등록 필요'다.
2. **M12 범위 정직화**
   - 견적·작업 결과에 `coverage`·`emd_covered`·`emd_total` 을 봉투로 준다(plan 3.3). 읍면동 수는 영상과 겹치는 읍면동만 센다.
   - 에이전트 답(`analyze.py`), 확인 카드 `title`(plan 3.4), 진행판은 plan 4절 기본 문장을 도구 값 그대로 쓴다.
   - 영상이 시군구를 거의 다 덮을 때(95% 이상)만 '전역'이라고 한다.
   - 영상이 없는 나머지에는 한 줄과 '영상 등록'(LX 직원만)을 붙인다.
3. **M13 규칙 코드** — `app.js:647`·`673` 에서 이름이 없으면 규칙 코드를 보이지 않는다. 이름표(`/survey/rules` 이름)를 먼저 받아 쓰고, 끝내 없으면 그 줄을 숨긴다.
4. **확인 카드 지역 이름** — 분석 실행 도구 결과 `title` 에 지역 이름과 범위 문장을 담는다.
5. **읍면동 이동** — '옴천면으로 이동'·'시천면 보여 줘'가 읍면동 경계로 간다(`map.py` + XI맵 처리). 시군구 이름이 겹치면 현재 시군구 안에서 먼저 찾는다.
6. **동작 끝 신호**(plan 3.1) — XI맵이 처리한 지도 동작마다 `ok`·`reason` 을 정직하게 낸다. 최대 확대에서 더 확대, 층이 없는데 끄기 같은 경우는 `ok:false` 다.
7. **3D 유지** — 전역 분석을 시작해도 사용자가 기울인 3D 상태를 유지한다.

## 완료 기준 (측정 가능 · 화면만으로 · 서로 다른 시도 두 곳 이상)
- M12: 영상이 일부만 덮는 시군구 2곳(경남 산청 + 다른 시도 1곳, 예: 충남 보령·경북 문경)에서 LX 직원이 말로 전역 분석을 실행한다. 답·확인 카드·진행판 세 곳에 같은 범위 문장이 나온다. 읍면동 수 = 영상과 겹치는 읍면동 수(DB 대조), 비율 = 작업 `coverage` 값이다. 영상이 덮지 않는 곳을 '전역'이라고 부른 문장은 0이다.
- M11: COG 등록 지역 2곳(서로 다른 시도)에서 결과 읍면동 막대 누르기 → '이 범위 분석' → 결과 1건 이상. 그린 범위 1회 → 결과 1건 이상. '영상 등록 필요' 0(영상 안쪽).
- M13: 전국 화면·시군구 화면에서 규칙 코드 글자가 0건이다.
- 확인 카드에 지역 이름이 보인다. '옴천면으로 이동'(광주전남)과 '시천면 보여 줘'(경남)가 읍면동 경계로 간다.
- 회귀: 여주·보령·문경·함양·보은 영상 층이 그려진다. 새 결과의 읍면동 칸 빈칸 0. GPU 두 장 동시 100 W 초과 0회(csv).
- `test_r3_xi.py`(범위 봉투·읍면동 계수·COG 후보) 녹색.
