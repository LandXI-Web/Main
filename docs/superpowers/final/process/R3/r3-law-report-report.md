  - 남원 계정 화면 확인은 같은 이유로 하지 않았다. 법령 찾기는 기관과 무관하게 같은 색인·같은 코드이고, 두 계정 결과가 같았다(1·2차).
  - 확인 뒤 localhost 세션을 원래 LX 관리자로 로그인 폼에서 되돌렸다.

## 기본값 (묻지 않고 정함)
- 풀어 쓴 말 표는 뜻이 하나로 정해지는 꼴만 넣는다. '빌리다'는 임대차로 본다(법 조문 제목 말). '사기'는 취득으로 본다(법령 질문에서 '사기'가 범죄를 뜻하는 일은 드물다).

## 넘길 것 (소유 밖)
- **(r3-ops · C9)** 한 브라우저에 LX 관리자 화면과 기관 화면이 함께 열리면 게이트웨이 연결 6칸이 차서 AI 도우미 답이 오지 않는다("지금은 답할 수 없습니다"). 실제 담당자가 여러 탭을 열 때도 생길 수 있다. 알림 연결을 탭끼리 나눠 쓰는 일(C9 에서 한 것)을 AI 도우미 답 받기에도 넓히거나, 연결이 막히면 결과를 한 번 조회로 받는 길이 필요하다.
- **(C6)** 같은 시각 기관 저장 용량 조회(`quota.storage_of`)가 DB 에서 시간 초과(TimeoutError)를 냈다. LX 관리자 화면이 자주 부르는 무거운 합계 조회다.
