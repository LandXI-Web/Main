   - 'How many GPUs are under high load'·'Is the power budget exceeded?'·'Which GPU is busy?' 에 GPU 실측(부하·전력)과 화면 표시 기준('고부하 n/1', 전력 예산 안/초과)으로 답한다.
   - 한국어 경로와 같은 직행 도구·같은 판정 함수를 쓴다. 모델이 숫자를 만들지 않게 영어도 모델 앞 직행으로 한다.
2. **시군구 이름 사용량** — '목포시 AI 도우미 사용량'처럼 시군구 이름으로 물으면 소속 기관(광주전남특별시) 값으로 답하고 "목포시는 광주전남특별시 기관 사용량에 포함됩니다" 한 줄을 붙인다. LLM 호출은 0이다.
3. **영어 차트 표기** — 숫자와 단위 사이를 띄운다('2,059,673 tokens').
4. **M8 로그인 늦음 안내**(`login/auth.js`)
   - 탭을 바꿀 때도, 기관 목록이 아직 없고 6초가 지났으면 안내를 띄운다.
   - 안내 문구는 할 일을 알려 준다: "서버 응답이 늦습니다 — 다른 Land-XI 탭을 닫거나 새로 고친 뒤 다시 시도하세요" + '다시 불러오기' 버튼.
   - 기관 목록 요청은 제한 시간(8초) 뒤 한 번 다시 시도한다.
5. **로그인 폼 첫 빈 화면** — 로그인 폼이 처음에 비어 보이고 휠을 한 번 굴려야 나타나는 문제(c2-xi 실증 참고)를 고친다.
6. **로그인 장면 숫자 한 출처** — 'HYPER SOLUTION' 장면의 남원 '20,852'(옛 정적 값)를 로그인 뒤와 같은 정본 값(`survey_sgg.findings`, 공개 요약 경로)으로 바꾼다. 정본을 받을 수 없으면 숫자를 빼고 문장만 둔다.

## 완료 기준 (측정 가능 · 화면만으로)
- M14: 관리자 Ctrl K 영어 3문 × 3회 → GPU 수·부하·예산 판정이 같은 시각 인프라 화면 값과 9/9 같다. 한국어 3문 회귀 0.
- 시군구 사용량: 서로 다른 시도 두 시군구(광주전남 목포·전북 남원 외 1곳, 예: 경남 산청 → 해당 기관이 없으면 "이 시군구 기관 계정 없음" 한 줄)로 묻는다. 기관 값 = 기관 화면 표(같은 시각), LLM 토큰 0.
- M8: 옛 탭 여러 개로 연결이 막힌 상태를 재현한다(같은 브라우저에서 첫 화면 탭 7개). 새 로그인 탭에서 6초 뒤 '기관'을 누르면 안내 + 다시 불러오기가 보인다. 탭을 닫고 '다시 불러오기' → 기관 목록이 뜬다. 기관 두 시도(전북 남원·광주전남) 로그인이 성공한다.
- 로그인 폼이 첫 화면에서 바로 보인다(휠 0회).
- 로그인 장면 남원 숫자 = 로그인 뒤 남원 '의심 필지' 값. 또는 숫자 없음.
