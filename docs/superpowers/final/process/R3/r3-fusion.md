## 할 일
1. **M6 새로고침·재로그인 유지**
   - 서버가 **사람별·기관별 최근 대장**을 기억한다: (tenant, user, sgg) → 최근 import_id. 올리기·확인 때 적는다.
   - 첫 화면은 브라우저 캐시가 아니라 이 기억으로 자기 대장을 다시 연다. 캐시는 빠르게 여는 용도로만 쓴다.
   - 다른 담당자가 올린 대장은 자기 대장이 없을 때만 '기관 최근 대장'으로, 올린 사람 표기(역할·날짜만, 이름 없이)와 함께 연다.
   - 이어 열기 조회가 실패하면 빈 '대장 올리기' 대신 "대장을 다시 여는 중" + 다시 시도 한 번을 보인다.
2. **M7 이름표 = 값**
   - 이어 열 때 결합표를 대장 행 전체로 다시 만든다. 또는 이름표가 결합표에 실제로 든 행을 따라가게 한다(`app.js` `baseLabel()`).
   - '올린 대장 필지' 값은 처음 올렸을 때와 같아야 한다.
3. **동작 끝 신호**(plan 3.1) — 첫 화면 지도 동작은 한 번만 처리한다(키트 기본 처리와 중복되는 것은 `preventDefault` 로 막는다). `ok` 를 정직하게 낸다.
4. **대장 화면 개발 정보 0** — 'V-World 값으로 대조', 필지 카드 'V-World' 줄 등 개발 정보를 사용자 말로 바꾼다('공간정보 공개 자료와 대조'). '에이전트 질의' 같은 용어표 밖 말은 쓰지 않는다('물어본 조건').
5. **열 자동 인식** — '일련번호' 같은 번호 열을 '지번'으로 잡지 않는다(값 모양 검사).
6. `ext/fusion.py` 답에서 규칙 코드를 0으로 만든다.

## 완료 기준 (측정 가능 · 화면만으로 · 두 시도 이상 · 광주전남·남원(전북) + 확인자 무작위 1곳)
- M6: 두 시도 계정에서 대장 올리기 → 결과 확인 → F5 → 같은 대장·같은 숫자. 로그아웃 → 재로그인 → 같은 대장·같은 숫자. 새 창 → 같은 결과. 같은 기관의 다른 담당자 계정(없으면 관리자 화면에서 승인된 기존 계정)은 자기 대장을 연다. 남의 대장이 먼저 열리는 경우는 0이다.
- M7: 새 창·재로그인 뒤 "{읍면동} 보여 줘" → '올린 대장 필지' 값 = 처음 올렸을 때 그 읍면동 값(예: 목포 달동 2,700·율도동 1,290 계열). 두 시도에서 확인한다.
- 대장 조건 질문('대장상 농지인데 AI가 건물') 값 = 도구 결과(회귀 0). "의심 필지 몇 건?"은 의심 필지와 어긋난 필지를 나눠 답한다(회귀 0).
- 화면 글: 대장 화면·필지 카드·답에서 'V-World'·규칙 코드·'에이전트' 0건.
- 지도 동작 완료 이벤트가 동작마다 1개다.
