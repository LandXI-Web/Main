## 제안 — 이런 것도 필요하지 않을까요?
1. **히어로 지도에서 시군구를 올리면 그 지역의 서비스 · 수** — LX 직원. 내 프로젝트가 없는 시군구(안성 토지피복 12,871 등)도 전국 현황으로 한눈에(지금은 점이 있는 7곳만 누를 수 있음).
2. **최근 분석 결과 작은 그림을 결과 확인 끝난 뒤에는 '확인됨' 색으로** — 프로젝트장. 같은 줄에서 확인 전 · 후가 그림 색으로 갈려 할 일 줄과 어긋나지 않음.
3. **히어로 띠 '오늘 할 일 6' 을 누르면 왼쪽 할 일 칸의 첫 줄이 잠깐 밝아짐** — 모든 직원. 띠와 칸이 같은 것을 가리킨다는 것이 손으로 느껴짐(이번 시안은 그 칸으로 내려가기만).
