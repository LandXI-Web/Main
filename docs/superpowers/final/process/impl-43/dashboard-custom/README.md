## 2. 사용자 설정 API(다른 화면도 쓰는 범용 길)

| 길 | 뜻 |
|---|---|
| `GET /api/v1/me/prefs` | 내 설정 전부 `{options: {screen: 값}, updated_at: {screen: 시각}}` |
| `GET /api/v1/me/prefs/{screen}` | 한 열쇠 `{screen, options: 값 \| null, updated_at}` |
| `PUT /api/v1/me/prefs/{screen}` (POST 도 같음) | 저장 — 본문 JSON 그대로(32KB) · 응답 같은 모양 |
| `DELETE /api/v1/me/prefs/{screen}` (`POST …/{screen}/reset` 도 같음) | 지우기(처음 모양으로) |
| `GET /api/v1/me/events?from=&to=` · `POST /me/events` · `PUT /me/events/{id}` · `DELETE /me/events/{id}` | 내 일정 `{title, day, time?, note?}` |
| `GET /api/v1/me/agenda?from=&to=` | (LX 계정) 플랫폼 날짜 일 — 공지 · 내가 올린 승인 요청과 결정 · 내 담당 분석 요청 · 내 프로젝트 시작 · 학습 시작 · 끝 · 전국 분석(날마다 끝난 읍면동 수) |

- 열쇠(screen) = 화면 이름 또는 화면.부분(영문 · 숫자 · `. _ -` 80자). 대시보드는 `dash.lx-console`, XI맵 통계 판은 예컨대 `lx-map.stats` 또는 `xi-clean.stats`.
- 계정 = (realm, tenant_id, user_id) — LX · 기관 모두, 로그인한 계정만 자기 것(다른 계정 값은 보이지 않음 · 익명 401 — api-test 확인).
- 응답의 값 칸 이름이 `options` 인 까닭: 게이트웨이 봉투 검사(envelope.py)가 통째로 데이터로 보는 칸이라 화면이 정한 JSON 안 숫자에 봉투를 강제하지 않는다.
- 화면 쪽(dashgrid.js): 서버 값 + 같은 값을 브라우저에도 두어 열자마자 그리고, 서버 답이 다르면 서버 값으로 바꾼다. 저장은 바꾼 뒤 0.7초 묶음 · '완료'에서 바로.
- 표: `user_prefs(realm, tenant_id, user_id, screen, value jsonb, updated_at)` · `user_events(id, realm, tenant_id, user_id, title, day, at_time, note, …)` · RLS realm lx · tenant · audit_log 는 건드리지 않음. 되돌리기 `down/0107_user_prefs.down.sql`.

| 칸 | 보기 방식 | 자료(한 출처) | 처음 모양 |

달력 모양 규칙: 자동 = 높이 4줄 이상이면 월, 넓고 낮으면 주, 작으면 다음 일. 월은 칸 폭이 좁으면(날 칸 96px 미만) 점 3개 + 수, 넓으면 글 칩(남는 수는 '외 n'). 주는 좁으면 일곱 날 세로 줄, 넓으면 일곱 열. 날짜 누르기 = 그 날 창(일 목록 · 내 일정 적기 · 고치기 · 지우기). 오늘 = 액센트 동그라미(현재 위치) · 내 일정 = 잉크 칩 · 플랫폼 일 = 회색 칩 · 일요일 빨강 안 씀(색 규칙).

## 7. 제안

1. **LX 관리자 대시보드 · 기관 첫 화면에 같은 부품 적용** — 관리자: 기관 · 배포 · 승인 요청 · 장비 숫자 칸을 끌어 바꾸고 달력(승인 기한 · 배포 날짜 · 공지)을 더함. 기관: 내 요청 · 새 결과 · 보고서 칸 + 달력(분석 요청 보낸 날 · 결과 온 날). 서버 설정 길은 이미 범용이라 화면마다 열쇠만 다르게(`dash.ops-core` · `dash.gov-fusion`). 왜: 세 역할 모두 "내가 보는 순서"가 다르고, 한 부품이면 디자인 · 동작이 같아 익히기 쉽다.
2. **달력에 마감 개념을 플랫폼에 넣기** — 지금 프로젝트 · 분석 요청에는 '언제까지'가 없어 달력이 지난 일만 보여 준다. 분석 요청(기관) · 프로젝트에 '희망 완료일' 한 칸을 두면 달력이 앞으로의 일을 보여 주고, 요청함 숫자 옆 '기한 지난 n'도 같은 출처로 셀 수 있다. 사용자 확인 뒤 구현.
3. (작은 것) XI맵 통계 판 자리를 브라우저 저장에서 `PUT /me/prefs/xi-clean.stats` 로 옮기면 다른 PC 에서도 같은 자리(XI맵 담당 에이전트와 길 이름 맞춤).
