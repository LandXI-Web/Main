## 한 줄
**XI ChatGEO 는 이제 화면이 실제로 바뀐 뒤에만 "옮겼습니다 · 켰습니다"라고 하고, 바뀐 것이 없으면 "이미 켜져 있습니다", 못 하는 요청에는 이유 한 줄 + 대신 한 일 + 누를 버튼을 둡니다. 지명이 있으면 먼저 그곳으로 가고, 같은 이름은 하나로 가며 '다른 뜻이면' 버튼을 둡니다. XI맵에서는 두 시점 영상을 좌우로 나란히 놓고, 범위 그리기를 켜고, 지금 지도를 그림 파일로 만듭니다.** 같은 31문으로 다시 재니 막다른 답 5 → 0 · 말과 화면 다름 2 → 0 · 물은 것과 다른 일 5 → 0, 언어 모델을 쓴 질문 9 → 0.

## 바뀐 것(사용자 말로)
| 답하는 법(대화-1) | 지금 |
|---|---|
| ① 그린 것만 '그렸습니다' | 지도 동작 문장은 화면이 끝 신호를 줄 때까지 **진행형**('옮기고 있습니다'), 신호를 받은 뒤에 '옮겼습니다'. 바뀐 것이 없으면 **'AI 분석 결과 층은 이미 꺼져 있습니다'** + 그 화면이 알려 준 다음 일('현장 확인 필요 층도 끄기'). 지도에 그리지 못하면 그린 흔적도 남기지 않는다(말과 화면이 같게). 동작 줄에 '이미 그래 있던 것'은 회색 ✓ |
| ② 못 하는 요청 | '그 지도 동작은 아직 할 수 없습니다'로 끝나던 자리를 서버가 **이유 한 줄 + 할 수 있는 것 버튼 2–3**으로 채운다. 풀어 쓴 법령 질문('허가 없이 지은 건물에 물리는 이행강제금은 얼마야?')은 법령 낱말로 다시 찾아 **가장 가까운 조문(건축법 제80조) 원문**을 그대로 · 무엇으로 찾았는지 밝힘. 대장 '논 위 비닐하우스'처럼 조건에 없는 것은 **왜 없는지(영농시설)** + 가까운 조건 버튼(다른 조건으로 바꿔 세지 않는다). 고른 필지 없이 '이 필지 영상 설명'은 되묻지 않고 **현장 확인이 먼저 필요한 필지 셋**을 버튼으로 |
| ③ 뜻이 둘이면 | 지명 > 지금 화면 지역 > 직전 답의 지역 순. '구례군 확대해 줘' = **구례군으로 옮기고 한 단계 확대**. 같은 이름(고성군)은 관할 · 지금 보는 시도 · 결과 있는 곳 순으로 하나로 가고 꼬리에 **'다른 뜻이면 [강원특별자치도 고성군]'** 한 줄. 기관의 '우리 시'는 관할 |
| ④ 지도 없는 화면 | 지도 동작을 보내지 않고 **'이 화면에는 지도가 없어 옮기지 못했습니다 — XI맵을 열면 구례군에서 시작합니다'** + 그 지역 대표 숫자 한 줄 + `XI맵을 구례군에서 열기`(그 지역 · 두 시점 · 범위 그리기를 이어 받는 주소). 차트는 **많은 곳부터 다섯 줄 + 'n곳 더 보기'**, 작은 표(관리자 GPU 상태 등)도 같은 모양 |
| ⑤ 같은 이름의 숫자 | '현장 확인 필요 필지 몇 건' = 현장 확인 필요(XI맵 큰 숫자와 같은 값) 먼저, 의심 필지는 다음 문장에 이름을 밝혀. 두 지역 비교는 **같은 이름 숫자끼리 + 막대 둘**(대장 숫자를 섞지 않음). 보고서 답의 '의심 20,872건' → '의심 필지 20,872건' |
| ⑥ 두 문장 · 쉬운 말 | 서버 문장은 모두 두 문장 안. 지역을 고르지 않은 '이 지역 결과 요약'은 직전 지역 요약 또는 **전국 요약 두 문장 + 막대**. 관리자 GPU 답은 두 문장 + 표 + `인프라 화면에서 크게 보기`. 답에서 프레임 · 레이어 · 폴리곤 → 범위 · 층 · 도형, '~해 주시기 바랍니다' · 사과 문장 금지(모델 지시) |
| ⑦ 실행 전 확인 카드 | 제목은 사용자 말('남원시 AI 분석을 실행할까요?' · '전역'이라 하지 않음), **둘째 줄에 범위 문장**(서버 값 그대로) + 앞에 기다리는 분석이 있으면 그 수. 기관의 '분석 실행해 줘' = **분석 요청 카드**(버튼 '분석 요청 보내기' · 'LX 관리자가 확인한 뒤에 합니다') — 서비스가 여럿이면 되묻는 문장 대신 서비스 버튼. 취소하면 **'취소해서 실행하지 않았습니다'** + `지금 있는 결과 요약` `읍면동별 차트` |

| **지도 그림 저장** | 지금 보이는 지도 한 장 → 채팅 안 그림 + 내려받기(PNG · 이 브라우저 안에서 만듦 · 서버로 보내지 않음) |
| 넓히지 않는 것 | 배포 조작 · 권한 · 결과 수정 · 승인 — 이유 한 줄 + 갈 화면 버튼(`배포 화면 열기` · `결과 확인 화면 열기` 등)만 |

## 남은 것 · 확인 못 한 것(정직하게)
- **개선 후보로 모았다는 꼬리 한 줄**(설계 rules ②-4 '이 요청은 개선 후보로 모았습니다')은 넣지 않았다 — 서버가 실제로 모았는지 화면이 알 수 없어, 말과 사실이 어긋날 수 있다.
- 차트 → 지도 색(읍면동 칠하기) · 리 단위 이동 · 지도 위 두 지역 칠하기는 셋째 묶음이라 하지 않았다(두 지역 비교는 막대로).
- 두 시점 나란히는 **XI맵 화면만**(다른 지도 화면은 XI맵 버튼). 시점은 그 지역을 넓게 덮는 등록 영상에서 해마다 하나(남원시 = 2023 · 2025년 10월 등) — 작은 드론 범위 시점은 고르기에 넣지 않았다.
- 지도 그림 저장은 지금 보이는 본 지도 한 장(가르기의 왼쪽 판은 들어가지 않음) · 보고서에 바로 넣는 것은 하지 않음(버튼으로 보고서 초안만).
- 기관 분석 요청은 공유 영상만 카드로 보낸다(서비스 범위에 걸치는 가장 최근 영상). 우리 영상을 올리는 요청은 `분석 요청 화면 열기`. 시험에서는 모두 취소해 실제 요청은 0건 — '보내기'를 누른 끝 흐름(결재함에 들어가는 것)은 이번에 눌러 보지 않았다.
- 전/후 숫자의 '전'은 구현 3차 채팅창 뒤 상태다(설계 실태 숫자와 다름 — 표에 함께 둠). 측정 중 다른 작업이 게이트웨이를 다시 띄운 순간에 걸린 질문은 그 화면만 다시 쟀다(과정은 `score.mjs` 머리말).
