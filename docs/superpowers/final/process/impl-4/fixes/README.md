## F-2 · 문제는 창으로(M-2)
- **언제**: 파일을 고르는 순간(한 바이트도 보내기 전) — 영상이 아닌 파일(예: 문서 · 이름만 .tif) · 빈 파일 · 너무 큰 파일 · 이 서버가 지금 받을 수 없는 형식. 올리기를 시작하자마자 서버가 거절한 것(같은 파일을 이미 올림 · 서버 저장 공간 부족)도 같은 창으로.
- **창**: 제목 한 줄(이유가 하나면 그 이유 — "영상으로 읽을 수 없는 파일입니다", 여럿이면 "올릴 수 없는 파일이 있습니다" + 파일마다 이유) · 파일 이름 · 나머지는 그대로 올린다는 한 줄(있을 때만) · **닫기 · 다른 파일 고르기**. 휴대폰에서도 화면 가운데 작은 창(전체 화면으로 덮지 않음).
- 같은 부품이라 기관 분석 요청과 LX 영상 등록이 같은 모양 · 같은 말입니다(원칙 43).

## F-3 · 영상 등록 = 파일 끌어 놓기
흐름(옛 깃헙 데이터 올리기의 기능 — 진행 · 멈춤 · 이어 올리기 · 취소 · 다 올리면 위치와 기본 정보 — 을 기준으로, 디자인은 지금 법전):
1. 데이터 → 지역 서랍 → **영상 등록** → 끌어 놓는 칸 하나 + 한 줄 "촬영 연도 · 해상도 · 위치는 파일에서 읽습니다".
2. 영상 파일과 위치 파일(TFW 등)을 함께 넣음 → 파일마다 진행 막대 · 멈춤 · 이어 올리기 · 취소. 큰 파일은 조각으로(끊겨도 받은 자리부터). 시트를 닫아도 올리기는 이어지고 다시 열면 같은 목록.
3. 다 올라가면 **저절로 등록** — 서버가 파일마다 읽음: 어디(시군구 · 읍면동) · 해상도 · 종류(드론 · 항공 · 위성) · 촬영일(파일 안 기록 → 파일 이름의 날짜 → 없으면 비움). 좌표계 기록이 없는 도엽은 보고 있던 지역에 떨어지는 좌표계를 붙임(영상이 다른 곳이면 영상이 이김).
4. 시트가 닫히고 알림 "○○군 항공영상 1장을 등록했습니다" → 그 지역 서랍 '영상'에 새 줄 · 단계 막대 '영상' ✓. 뒤에서 영상 등록 작업(CPU)이 표준본(COG · JPEG 90)을 만들어 지도 · 분석이 표준본을 읽음. 원본은 표준본 확인 날 + 90일에 정리(지난 차수 그대로).
5. 못 읽는 파일이면 등록하지 않고 창으로(F-2 와 같은 창 · '다른 파일 고르기'를 누르면 그 파일은 빼고 새로 고름).

화면 · 응답에 서버 경로 · 작업 번호가 나오지 않습니다(사용자 규칙 2).

## F-4 · 기관 — 'LX 담당자에게 보내 확인받기'(기관-6 ⓐ)
1. 분석 요청에서 못 읽는 파일을 고르면 창(F-2) → 아래 **'LX 담당자에게 보내 확인받기 ›'**.
2. 같은 창에서: 파일 이름(그대로) · 메모 한 줄(안 써도 됨) · **받는 사람** 한 줄(예: "이 서비스 담당 프로젝트장 ○○○" — 검토 요청과 같은 판정 · 서비스를 아직 안 골랐으면 'LX 관리자') · 돌아가기 · 보내기.
3. 보내면 "보냈습니다 — 답이 오면 알림으로 알려 드립니다" · **내가 보낸 요청 보기**.
4. LX 쪽: 그 직원의 **요청함**에 "못 읽는 파일 · 파일 이름" 한 건(보낸 기관 · 사람 · 메모 · 서비스) · LX 관리자는 모두 봄. 답하면 기관 '내가 보낸 요청'에 답이 옴.
- 파일 자체는 보내지 않습니다(이름만) — 받아 볼 칸이 요청함에 아직 없어서입니다(제안 ①).

- **제안 ① 요청함에서 '못 읽는 파일'은 파일 모양으로** — 누가: 받는 LX 담당 직원. 왜: 지금 요청함 상세는 필지 요청 모양이라 '필지 도형이 없습니다 · 대장 — · AI 분석 —'과 판정(맞음 · AI 오류 · 모름)이 함께 보입니다. 파일 이름 · 못 읽은 이유 · (원하면) 그 파일 한 장 받아 보기로. 서버는 이미 종류('file') · 파일 이름 · 이유를 내줍니다(요청함 화면은 다른 갈래 담당이라 손대지 않았습니다).
- **제안 ② 파일 이름의 날짜 읽기** — 누가: LX 직원. 왜: 드론 정사영상은 '220411_본사정사영상'처럼 이름 앞 여섯 자리에 찍은 날을 적는 일이 많은데 지금은 네 자리 연도만 읽어 '촬영 연도 모름'이 됩니다. 여섯 자리(YYMMDD)도 날짜로 읽기(맞는 날짜일 때만).
- **제안 ③ '촬영 연도 모름' 영상만 연도 한 번 고르기** — 누가: LX 직원. 왜: 국토지리정보원 도엽(위치 파일만)은 파일 안에 날짜가 없어, 해마다 비교하는 분석에 쓰기 어렵습니다. 등록은 지금처럼 입력 없이 하고, 연도를 모르는 영상 줄에만 '연도 고르기'(선택). 원칙 49(입력 최소)와 겹치므로 결정이 필요합니다.
- **제안 ④ 폴더째 끌어 놓기** — 누가: LX 직원. 왜: 도엽 수십 장을 폴더 그대로 넣으면 편하고, 폴더 이름(예: 2023_정사영상)에서 연도도 읽을 수 있습니다.
