# 구현 4차 · 못 한 요청 → 개선 후보 → '이제 됩니다' — 구현 확인 대기

> 2026-10-01 · 어느 플랫폼: **Land-XI 화면**(LX 관리자 대시보드 · LX 직원 요청함)과 **XI ChatGEO 채팅창**(로그인한 모든 화면 · 기관 분기 포함)
> 근거(사용자가 확인한 것만): 확인 요청 16차 **개선-1 확인** — "못 한 요청을 모아 '개선 후보'로 — 이 고리로". 원칙 98(못 한 것은 개선 재료) · 72(LX 관리자는 다 보고 돕는다) · 39(계정 범위 밖 0) · 59(개인정보는 정책과 함께).
> 채팅창 쪽(도움 안 됐어요 버튼 · 맨 위 한 줄 · 안내 줄)은 같은 시간에 채팅 갈래가 만들었고, 이 갈래는 서버 · 목록 화면 · 대장 잇기 · 90일 지우기를 만들었다.

## 한 줄
**XI ChatGEO 가 못 한 요청을 서버가 저절로 모아 비슷한 것끼리 묶고, LX 관리자 대시보드 → 배포 → '개선 후보' 탭에서 채택 · 보류 · 이미 됨을 고른다. 채택한 것이 만들어지면 '이제 됩니다 보내기' → 그 요청을 했던 사람이 다음에 채팅창을 열 때 맨 위에 한 줄이 보인다.**

- **한 줄 고침 한 번.** 처음 보낸 한 줄은 "…이 이제 XI맵에서 됩니다."였는데, 채팅창이 '이제 됩니다'라는 말이 붙어 있지 않은 한 줄을 요지로 보고 "지난번에 물으신 '…'가 이제 됩니다"로 한 번 더 감쌌다. 그 한 줄만 문구를 바꿔 다시 보이게 했다(감사 기록 남김). 채팅 갈래에 '서버가 준 한 줄은 그대로 보이기'를 전달 요청.
- 캡처 ②의 '2번'에는 같은 시간 채팅 갈래의 자동 시험 한 번이 들어 있었다. 시험 번호로 돈 답은 모으지 않도록 고치고 그 기록을 지워, 지금 그 줄은 1번이다.
- ⑥ 캡처 아래쪽 "서버 응답이 늦습니다" 알림은 그 시각 바깥 주소가 느렸던 XI맵 자체 알림이다(개선 고리와 무관).
