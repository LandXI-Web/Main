## 먼저 제안 — 이런 것도 필요하지 않을까요?
- **새 판 알림** — 도구의 `meta` 를 주기적으로 돌려, 가진 데이터셋의 판이 바뀌면(예: 위성 객체 판독 1.6 건물 라벨 수정) LX 관리자 공유 데이터 화면에 '새 판 있음'. 누가: LX 관리자 — 낡은 라벨로 모델을 다시 학습하는 일을 막는다.
- **모델 카드에 학습 자료 출처 한 줄 자동** — 대장의 출처 · 이용 조건을 모델 카드로 이어 받음. 누가: 해외 기관에 서비스를 열 때 반출 가능 여부를 보는 LX 관리자.
- **AI 허브에 국외 이용 문의 한 번** — '국내에서 학습한 모델을 해외 기관 서비스에 쓰는 것'이 별도 합의 대상인지. 누가: 키르기스 등 해외 사업 담당 — 위성 자료(71710 · 71805)를 받을지 이 답에 달림.
- **대장에 없던 보유분 정리** — 강원 · 충청 토지피복(36GB)처럼 디스크에는 있으나 대장에 없는 자료가 더 있을 수 있다. `compare` 를 다른 폴더에도 돌려 대장에 올림.
