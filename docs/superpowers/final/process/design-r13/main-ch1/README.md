지금(v3): "현장 확인이 필요한 필지 선별 · 필지 결합 → 대장 대조 → 현장 확인 목록". 첫 판 후보('현장에 가지 않아도 / 필지마다 판단' 등)는 사용자 답 "문구가 아직도 마음에 안 든다 — **고정밀 영상과 AI 기술로 분석하고 행정 정보를 융합하여 행정 혁신과 업무의 부담을 줄인다**는 취지를 잘 살려야"로 **반려**. 첫 판은 '현장에 안 간다'(결과 하나)만 말했고 **무엇으로**(고정밀 영상 · AI) **무엇과 합쳐**(행정 정보) **무엇이 좋아지나**(혁신 · 부담 줄임)가 빠져 있었다.

## 7. 구현 때 할 일(확인되면)
1. 요약 API(`/summary`)에 비닐하우스 항목(card · 남원시 · detected 1,674 · 단동/다동) 추가 → 메인 · 카드 · 서비스 상세 한 출처.
2. 공개 통계에 하천 외 세트(`set=farm` 등)는 **전국 결과가 생길 때** 더한다 — 지금은 지역 결과를 전국으로 보이지 않는다.
3. v3 `main.js` 둘째 장면: 차오름(sweep) 대신 고른 안의 동작 · 작은 지도 1 추가 · 결과 도형은 서버 공개 사본(`tools/build-data.py`)으로 만든다(이 시안의 `data/*.geojson` 은 손으로 자른 임시본).
4. 셋째 장면 문구(사용자가 고른 후보) · 카드 칩('대장과 다름' — 법전 §4-7 허용 라벨 '대장과 다른 필지'와 같은 뜻) · 판단 줄.
5. 넷째 장면(확정): XI ChatGEO 실제 응답 모양(계획 · 숫자 칩 · 막대 · 파일 줄은 키트 `.k-ck-*` 그대로) · 보고서 초안은 `/agent/report/draft` 실제 파일로 · 비닐하우스는 **면 층만**(점 층 없음) · 면이 면으로 보이는 크기로 카메라.
