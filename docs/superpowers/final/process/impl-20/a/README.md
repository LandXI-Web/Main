## 제안 — 이런 것도 필요하지 않을까요?
1. **진행 현황에서 '결과 확인' 칸을 빼고 다섯 단계로** — 누가 왜: LX 직원. 결과 확인이 막는 단계가 아니게 되어 그 칸은 늘 0이고, 지도에서 결과 보기는 추론 칸에서 바로 가면 된다.
2. **모아 둔 평가 질문으로 XI ChatGEO 를 잴 때 '답했음 n / 모아 둔 n' 한 줄** — 누가 왜: LX 관리자. 다음 LLM 개선 뒤 같은 질문 묶음을 다시 물어 나아진 수를 보면 '이제 됩니다'를 보낼 줄을 고르기 쉽다.
3. **로그인 화면에서 XI맵 파일 미리 받기** — 누가 왜: LX 직원. 로그인 직후 처음 여는 XI맵이 2.5~3.1초로 남아 있다. 로그인 화면이 비어 있는 동안 XI맵 파일을 미리 받아 두면 처음 열기도 다시 열 때(1.3초)에 가까워진다.
