# '할 수 없는' 지도 동작을 할 수 있게 — 넓힐 후보(우선순위)

> 2026-10-01 · Fable 5.1. 실태(`audit.md`) 31문에서 막혔거나 말과 화면이 달랐던 동작 가운데, **지금 플랫폼에 이미 있는 화면 기능에 말을 잇기만 하면 되는 것**을 앞에 두었다. 순서 = 자주 막힘 × 쉬움. 구현 추정은 설계자의 눈대중(갈래 하나 · 반나절~하루 단위)이고, 모두 사용자 확인 뒤 구현.

## 묶어서 보면
- **1·3·8·12** 는 코드 몇 줄 수준의 "말 풀기·신호" 정리 — 한 갈래로 묶어 먼저(막힘 9건 중 5건이 여기서 사라진다).
- **2ⓑ·4·5·6** 은 XI맵에 이미 있는 기능(가르기 · 범위 그리기 · 층 · 캔버스)에 **도구 이름 하나씩** 잇는 일 — 둘째 갈래.
- **7·2ⓐ·11** 은 그리기·자료가 드는 일 — 셋째.
- 넓히지 않을 것: 지도 밖 일(파일 시스템 · 배포 조작 · 권한), 사람이 할 판단(결과 수정·삭제 · 승인). 이건 규칙 ②의 '이유 한 줄 + 버튼'으로만.

## 넓히고 나서 확인하는 법
`audit.mjs` 를 같은 질문으로 다시 돌려 **막다른 답 0 · 말과 화면 다름 0** 을 숫자로 본다(지금 9 · 5). 새로 막히는 요청은 `improve-loop.md` 의 목록에 저절로 쌓인다.
