## 4. 바로 고칠 고장(다른 에이전트가 고치는 중인 것과 겹치면 그쪽 우선)
1. 채색·표시 동작을 처리하지 않는 화면(LX 직원 첫 화면 · 기관 할 일 화면)에서 서버가 보낸 채색이 조용히 사라지고, 끝 신호가 없어 3초 뒤 '확인되지 않음'(11 · 28).
2. XI맵 "AI 분석 결과 층 꺼 줘"가 "껐습니다"인데 결과 점이 그대로(18) — 켜고 끄는 층 이름과 화면 층이 안 맞음.
3. 기관 '우리 시' → 관할로 풀리지 않아 "해당 지역 데이터가 없습니다"(25) · 기관 '전역 분석 실행'이 같은 문구(29).
4. 지명 + 확대가 지명을 버림(2) · 읍면동 + 서비스 조건이 요약으로 대신됨(19).
5. 차트가 채팅창에서 3줄만 보임(8 · 17).
6. 관리자 사용량 답의 'AI 도우미' · '토큰'(22) — 원칙 91 · 96.
