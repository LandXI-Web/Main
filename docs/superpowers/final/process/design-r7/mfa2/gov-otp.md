# 정부 OTP 를 기관 로그인에 녹일 수 있나

> 2026-10-01 · Opus 5.5 · 지위: **사용자 확인 전 조사**(문서만 · 코드 수정 0). 그림: `shots/mfa2-2-gov-otp.png`(원본 `fig/02-gov-otp.html`). 공개 자료로 확인한 것만 적고, 확인 못 한 것은 6절에 모았습니다.
> 사용자 원문(10-01): "공무원 정부 OTP 서비스를 우리에도 녹일 수 있나? 검토가 필요하겠네..."
> 앞선 검토: `../../design-r6/mfa/public-sector.md` 2절(공무원·공공 인증 수단). 근거 원칙 78(기관은 자기 기관 분기 로그인) · 89(기관은 정부 OTP 를 녹일 수 있는지 검토).

## 1. 한 줄 답
**길은 있습니다.** 정부 OTP 는 '그 시스템을 운영하는 기관'이 연계를 신청하는 구조라, Land-XI 라면 **LX 가 신청**하고 지자체 공무원은 **이미 가진 정부 OTP 번호**를 넣으면 됩니다. 다만 ⓐ 공공기관인 LX 가 **인터넷에 열린 서비스**용으로 받을 수 있는지 ⓑ 비용 ⓒ 기간은 공개 자료에 없어 **인증관리센터에 물어봐야** 합니다. 해외 기관 · 공무원이 아닌 기관 직원은 정부 수단을 못 쓰므로 **표준 OTP 앱은 그대로 기본**이고, 정부 OTP 는 공무원이 고르는 **추가 선택**으로 둡니다.

## 2. 세 가지 공무원 인증 수단 — 우리에 쓸 수 있나
| 수단 | 제도상 | Land-XI 에 붙이면 | 판단 |
|---|---|---|---|
| **정부 OTP**(행정안전부 정부OTP인증센터 · 휴대폰 앱 또는 실물 토큰) | 연계를 원하는 **기관 담당자가 인증센터에 신청**. 준비물은 행정전자서명 연동 라이선스(기관마다 발급) + 정부 OTP 연동 키 + 국가정보자원관리원에 정부 OTP 서버로 가는 **연결 허용 신청**(행정망 창구와 인터넷망 창구가 따로 있음) | 기관 로그인 → 메일 아이디·비밀번호 → 정부 OTP 6자리 → Land-XI 가 정부 OTP 서버에 확인 | **가장 맞는 길.** 공무원이 새 앱을 깔 일 없음. LX 가 신청 대상인지 확인 필요 |
| **행정전자서명 인증서**(공무원 업무용 인증서) | 인증서를 확인하는 모듈(표준 API) 이용은 **공공기관도 신청서를 공문으로 제출**하는 절차가 공개돼 있음 | 기관 로그인 → 메일 아이디·비밀번호 → 업무용 인증서로 서명 → Land-XI 가 진짜인지 확인 | 가능하지만 **불편** — 인증서가 업무망 PC 에 있는 경우가 많고 프로그램 설치가 따름. 낮은 우선 선택 |
| **모바일 공무원증**(휴대폰 속 공무원증) | 바깥 서비스가 쓰는 통로(민간 SaaS 연계공통기반, 행정안전부·한국지능정보사회진흥원)는 **보안 인증을 받은 민간 서비스**와 그 서비스를 쓰는 기관이 대상. 2026년 9월–2027년 3월 고도화로 업무망까지 넓히는 중 | 기관 로그인 → '모바일 공무원증으로' → 휴대폰 확인 → 소속·이름을 받아 같은 계정으로 입장 | 제일 편하지만 **제일 불확실** — LX 가 직접 운영하는 공공 서비스가 이 통로를 쓸 수 있는지 행정안전부에 먼저 확인 |

## 3. 누가 신청하나 · 순서
**신청은 LX** 입니다(서비스를 운영하는 기관). 지자체가 따로 신청할 일은 공개 자료상 보이지 않습니다. 지자체 공무원은 정부 OTP 를 이미 갖고 있어야 하며, 발급은 소속 기관 보안 담당자가 재직·권한을 확인한 뒤 이뤄집니다.

1. **LX 안에서 정하기** — LX 정보보안 부서와 신청 여부 · 담당자 · 운영 서버 자리를 정합니다.
2. **연계 신청 공문** — 행정전자서명 인증관리센터(한국지역정보개발원)에 LX 이름으로 보냅니다.
3. **라이선스 · 연동 키 받기** — 확인 모듈 라이선스와 정부 OTP 연동 키(처음엔 임시 라이선스로 시험)를 받습니다.
4. **연결 허용 신청** — 국가정보자원관리원에 'Land-XI 서버 → 정부 OTP 서버' 길을 열어 달라고 신청합니다.
5. **시험 · 보안 점검** — 시험용 정부 OTP 로 기관 로그인을 확인합니다.
6. **공무원 등록** — 공무원이 처음 한 번 자기 정부 OTP **기기 번호**를 Land-XI 기관 계정에 등록(기관 관리자가 도움) → 이후 로그인 때 6자리.

**짝짓기**: Land-XI 기관 계정(메일 아이디) ↔ 그 공무원의 정부 OTP 기기 번호. 정부 OTP 연동 사례에서도 사용자마다 매체 종류와 기기 일련번호를 함께 맞춰 두는 방식을 씁니다. 공무원이 기기를 바꾸면 기기 번호를 다시 등록하고, 퇴직하면 정부 OTP 가 멈추므로 다음 로그인부터 막힙니다(기관 계정도 기관 관리자가 정리).

## 4. 필요한 것 · 비용 · 기간
| 무엇 | 내용 | 확인 |
|---|---|---|
| 라이선스 | 행정전자서명 연동 라이선스(기관마다 발급) | 공개 |
| 연동 키 | 정부 OTP 연동 키 | 공개 |
| 연결망 | 국가정보자원관리원 연결 허용(행정망 · 인터넷망 창구) | 공개 — 인터넷 쪽 서버가 받아 주는지 확인 필요 |
| 보안 점검 | LX 보안성 검토 · 인증관리센터 신청 검토 | 절차·기간 확인 필요 |
| 서버 자리 | 연결 허용은 고정된 운영 서버 기준이라 **운영 서버를 LX 전산센터로 옮길 때 함께** 신청하는 것이 현실적 | 확인 필요 |
| 비용 | 공개 자료에 없음 | 확인 필요 |
| 기간 | 공개 자료에 없음. 공문 왕복과 연결 허용 심사가 끼므로 정식 오픈 일정에서 넉넉히 거꾸로 잡아야 함 | 확인 필요 |

## 5. 이미 이렇게 하는 곳
- **e나라도움**(국고보조금 시스템) — 인터넷에 열린 시스템인데 아이디·비밀번호 + 인증서 두 겹으로 로그인하고, 공무원은 업무용(행정전자서명) 인증서를 씁니다. 공무원 인증 수단을 바깥 시스템 로그인에 쓰는 예입니다. ([e나라도움 로그인](https://www.gosims.go.kr/hf/login/loginView.do))
- **정부 OTP 연동** — 기관 내부의 접속 통제 시스템이 정부 OTP 를 2차 인증으로 붙인 연동 문서가 공개돼 있습니다(준비물 · 연결 허용 신청처 · 사용자별 기기 번호 맞추기). ([연동 문서](https://docs.genians.com/release/ko/authentication/enabling-authentication/sso/sso-gotp.html))
- **모바일 공무원증** — 전자결재 · 공직 메일 · 바로톡에 업무용 인증서 대신 로그인. 바깥 민간 서비스는 연계공통기반에 등록된 26개(공공용 네이버웍스 · NHN두레이 등). ([ZDNet 2026-07-15](https://zdnet.co.kr/view/?no=20260715103543) · [전자신문 2026-07-16](https://www.etnews.com/20260716000140))
- 공공기관이 운영하는 인터넷 서비스가 **정부 OTP** 를 지자체 공무원 로그인에 쓰는 사례는 공개 자료로 찾지 못했습니다.
