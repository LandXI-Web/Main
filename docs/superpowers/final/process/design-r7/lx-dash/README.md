> 2026-10-01 · Fable 5.1(기획·UI/UX). 지위: **사용자 확인 전 제안**(코드 수정 0 · GPU 0 · 서버는 로그인 폼으로 지금 화면 캡처와 숫자 읽기만).
> 받은 것 — 10차 답(10-01): 메뉴 1안 확정(홈 · 프로젝트 · 분석하기 · 서비스 카드 · 데이터 · 요청함, XI맵은 위 머리) · "홈이 결국 대시보드, 구성 다시 검토" · "분석하기는 너무 1차원적, 서비스별 카드와 이미지 등 다채로운 정보 필요, XI맵도 나쁘지 않다" → 원칙 90. 13차 답 분기-4: "카드도 디자인해야 하고 반영해야 한다" → 카드 한 벌.

## 한 장 요약
1. **대시보드**(`dashboard.md`) — 네 질문(내 프로젝트는 어디까지 · 기관이 나를 기다리는 것 · 우리 서비스는 어디서 잘 돌고 무엇이 문제 · 지금 무엇을 할까)에 칸 하나씩. 1안 = 내 프로젝트(6칸 진행 막대 + 다음 할 일) · 요청함(숫자 셋) · 우리 서비스(실제 결과 장면 썸네일 4 + 살펴볼 것) · 바로 분석하기(어디 한 칸) · 최근 활동. 2안 = 1안 + 우리 서비스 칸 안에 작은 지도 조각. 첫 뷰 약 300자 · 1차 버튼 1 · 내부 지표 0 · 숫자는 서버 요약 한 곳. **추천 1안.**
2. **분석하기 = 카드 갤러리 + XI맵**(`analyze.md`) — 길 둘(카드 먼저 / 지도 먼저)이 같은 작업(대기열)으로 이어지고 결과는 XI맵 하나. 카드 상세는 결과 장면 여러 장 · 영상↔결과 비교 · 지역별 결과 · 쓰이는 곳 지도 · 조건(영상 · 시점 · 걸리는 시간 · 버전·담당) + 오른쪽 고정 '이 카드로 분석'. 서비스 카드 메뉴(돌보기)와 분석하기(쓰기)는 같은 카드에 다른 1차 버튼.
3. **카드 한 벌** — 같은 부품(결과 장면 · 상태 · 어디·기준일 · 이름 · 한 줄 · 결과 예시 · 조건 두 칸 · 1차 버튼)을 네 자리에: ① LX 갤러리 ② 서비스 카드 관리 ③ 기관 1차 카드(기관 색 · 담당 부서 · 사업 연도) ④ 기관 2차 카드('우리 도가 만든 서비스' 배지 · 입력 1차 결과와 기준 시점).
4. **이미지 자산** — 13장 중 실제 결과 장면이 있는 카드 **5**(영농관리 · 비닐하우스 · 해양쓰레기 · 국토 변화 · 건축물[다른 지역 결과 · 예시 표기]). 나머지 8은 회백 판('결과 장면 없음' / '첫 결과 전') — 지어낸 그림 0.
