## 한 줄
**기관 분기 공간 = LX 서버 위에 기관마다 칸막이를 친 자리.** 그 안에 ① Land-XI 가 나눠 준 서비스(1차 AI 분석)의 결과와 결과 설명서, ② 그 결과로 기관이 만든 서비스(2차), ③ 기관 자료, ④ 기관 화면이 있다. Land-XI 본체에는 1차 서비스와 공통 기능만 두고, 한 기관만 쓰는 것은 그 기관 공간으로 보낸다. 공간 하나를 통째로 지워도 본체와 다른 기관은 그대로다 — 사용자가 말한 "잡동사니 막기 · 유지관리 · 폐기"가 이것으로 풀린다.

## 기술 방식 — 추천 ⓒ(`tech.md` · 그림 `shots/space-3-tech.png`)
- **ⓐ 가벼운 칸만**(기관마다 자료 칸 · 저장 폴더 · 서비스별 키) — 서버 부담 0 이지만 기관 계산 코드를 돌릴 곳이 없어 결국 본체가 무거워진다.
- **ⓑ 모든 기관에 상자**(컨테이너 묶음) — 가장 단단하지만 기관이 늘수록 서버 · 손이 는다.
- **ⓒ 둘 다 — 상자는 필요한 기관만(추천)**: 모든 기관은 가벼운 칸, 코드 2차가 있는 기관만 상자. 상자에는 **GPU 를 주지 않는다**(AI 분석은 LX 대기열 · 순번 · 승인). 올리기는 기관이 맡긴 개발자(또는 LX)가 화면에서 → **자동 점검 다섯 → LX 관리자 승인 · 자원 배정**(한도가 아니라 하드웨어 나눠 주기, 기관에는 사용 현황) → 폐기는 공간 이름 하나로 한꺼번에. 이 서버의 기관 공간 몫은 처리 몫 16 · 메모리 64GB · 저장 500GB(이 PC 의 1/8)로 시작을 제안.

## 실제 예 둘(`examples.md` · 그림 `shots/space-5-examples.png`)
- **광주전남 해양쓰레기** — 1차 탐지(AI 탐지 1,857건 · 2026.06.08 분석)를 공간에서 받아, 도가 맡긴 개발사가 해류·바람 예보와 합쳐 계산하는 **예측 지도**를 코드 틀(상자 하나)로 올린다. 새 탐지 회차가 공개되면 자동으로 다시 계산되고, 사업이 끝나면 예측 지도 상자만 지운다.
- **남원 영농** — 1차 경작 판정을 공간에서 받아, 농정과가 직불금 신청 명단을 올리고 공통 비교 기능에서 열만 골라 **직불금 대상 검토 표**를 만든다(설정만 · 상자 없음 · 개인정보는 공간 안에서만). 새 판정 · 새 명단이 오면 표가 다시 만들어지고, 검토가 끝나면 명단을 지운다.

| 코어 | 이 설계가 닿는 곳 |

| 필지 실태조사 · 행정데이터 융합 | 남원 직불금 표는 '행정정보와 결합하여 비교 분석'을 기관 공간 자료로 쓰는 것 — 기관 자료는 공간 밖으로 안 나감 |
| LX 생산 | 서비스 공개 요청에 '종류마다 한 줄 뜻 · 바뀐 점 한 줄'이 더해짐(결과 설명서). 형식이 바뀌는 재학습은 공개 전 표시 |
| LX 관리자 인프라 · 기관 · 배포 | 기관 → 기관 공간 목록 · 2차 승인 · 자원 배정 · 감시 · 끄기 · 폐기. 설정 한 곳(장비 대장 · 저장 위치 한 장)에 '기관 공간 몫'이 한 줄 더 |
| 관리-생산-서비스 한 흐름 | 같은 결과 회차가 1차 공개(관리자) → 공간 알림 → 2차 '입력 … 기준'으로 이어진다 — 공간이 기록 |
| 글로벌 | 해외 기관도 같은 공간 틀(영어 화면). 지금 해외 두 기관은 1차만 |
| 원스톱 | 올리기 · 점검 · 승인 · 끄기 · 폐기가 모두 화면 안. 개발자에게 서버 계정 없음 |
| 서비스 제공 체계 | '맞춤'과 '연결'이 본체가 아니라 기관 공간 안에 들어갈 자리가 생김. 여러 기관이 원하면 본체 서비스로 다시 만듦 |
| 외부 연동 API | 같은 서비스별 키 · 같은 결과 설명서를 공간 안 2차와 기관 자기 시스템이 함께 씀 |

## 확인 못 한 것(정직하게)
- 해류·바람 예보를 누가 · 어떤 형식 · 어떤 주기로 주는지, 27년 전남 사업에서 예측 지도를 누가 만드는지.
- 2025 항공 판의 신뢰 값이 왜 낮고 빈 조각이 왜 있는지 · 2026 드론 판을 언제 공개할지.
- 상자의 자원 제한은 도커 기본 기능이라 될 것으로 보지만 **이 PC 에서 띄워 보지 않았다.** 저장 폴더 크기를 딱 막는 장치가 이 PC(도커 데스크톱)에서 되는지는 모른다 → 감시 · 경보로 다루자고 제안.
- 남원 직불금 신청 명단의 실제 열 — 표본을 보지 않았다.
- 시안의 예측 값 · 해류 날짜 · 자원 숫자는 **예시**다. 실제 값은 1차 탐지 1,857건 · 2026.06.08 분석 · 여수 100m 칸(탐지 칸 위치)뿐이다.
- 메일 아이디(lxadmin@lx.or.kr)의 새 비밀번호는 파일에 없어, 지금 화면은 같은 사람의 옛 아이디로 로그인 폼을 거쳐 찍었다.
