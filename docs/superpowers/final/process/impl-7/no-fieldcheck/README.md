## 이런 것도 필요하지 않을까요?
- **카드 한 줄 소개 고치기** — 영농 카드 한 줄 '…판정해 확인할 필지만 남깁니다'(서비스 카드 관리 값)가 아직 '확인할 필지' 뜻을 품고 있습니다. 서비스 카드 관리에서 '필지마다 결과를 보여 줍니다'로 바꾸면 분석하기 카드도 같은 말이 됩니다(LX 직원이 카드를 보고 서비스가 무엇을 하는지 바로 알게).
- **도형 조각뿐인 네 카드에 숫자 주기** — 비닐하우스 · 건축물 · 곤포 · 주차장은 결과가 분석 칸 도형 조각이라 숫자가 비어 있습니다. 같은 결과를 물체 단위로 다듬어 두면(겹침 정리) '비닐하우스 n동'처럼 숫자가 생깁니다(정확도-3 셈 단위 · 분석하기에서 카드 비교가 쉬워짐).
- **면적 셈** — 토지피복처럼 개수가 뜻이 없는 서비스는 '면적(ha)'이 맞습니다. 지금 요약에는 면적 지표가 없어 화면에 못 싣습니다. 요약에 면적을 더하면 정확도-3 '동 · 필지 · 면적'이 다 갖춰집니다.
- **XI ChatGEO 답 맞추기** — 위 목록대로 LX 직원 질문에는 'AI 분석 결과'로 답하도록(지금은 지역 이동 답 끝에 현장 확인 숫자가 붙음).
