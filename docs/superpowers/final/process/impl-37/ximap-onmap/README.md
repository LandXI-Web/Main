## 1. 진단 — 지금 융합 대시보드가 왜 딱딱한가
1. 질문하면 **화면이 통째로 바뀐다** — 지도가 왼쪽 30% 작은 판으로 밀리고, 보던 지도의 맥락(영상 · 결과 · 자리)이 끊긴다.
2. 나머지 70%가 **흰 카드 격자**(큰 숫자 넷 + 차트 8~12칸) — 보고서를 펼쳐 놓은 모양이라 '업무 시스템'으로 읽힌다.
3. **지도와 숫자가 따로 논다** — 지도는 색칠만, 숫자는 카드 안. 막대를 눌러야 지도가 움직이고, 움직임이 없으면 지도는 정지 그림이다.
4. 지도에는 숫자가 하나도 없어 **어디가 얼마인지** 카드를 읽어야 안다.
