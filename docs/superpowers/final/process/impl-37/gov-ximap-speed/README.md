## 5. 남은 것
1. **처음 여는 기관 XI맵은 아직 4~7초** — 결과 층(특히 토지피복 2023)의 지역 축척 타일이 장당 최대 343KB 라 바깥 주소로 받고 그리는 데 1~2초가 듭니다. 화면 코드로는 더 줄이기 어렵고, 결과 파일을 만들 때 먼 축척용 가벼운 타일(단순화)을 함께 만들면 줄어듭니다(데이터 작업 · 결정 필요).
2. 다시 열 때는 3초 안팎 — 터널 왕복(0.3~1초)과 서버를 함께 쓰는 다른 작업에 따라 2.7~3.4초.
3. 서비스 카드 부품을 쓰는 다른 화면의 카드 설명도 같은 줄바꿈 규칙을 따릅니다(부품 한 곳). 분석하기 · 프로젝트 카드는 자기 줄을 따로 그려 이번에 바꾸지 않았습니다.

## 이런 것도 필요하지 않을까요? (원칙 57)
1. **결과 파일의 먼 축척 가벼운 타일** — 누가 왜: 기관 담당자. 남원처럼 시군구 전체를 처음 볼 때 받는 양이 1MB 넘게 줄어 처음 여는 지도가 3초 안으로 들어옵니다(결과를 만드는 작업기 쪽 일).
2. **기관 대시보드에서 XI맵을 미리 데워 두기** — 누가 왜: 기관 담당자. 서비스 대시보드를 보는 동안 지도 결과 파일 머리를 미리 받아 두면 '서비스로 열기'를 누른 뒤 기다림이 1초쯤 더 줄어듭니다.
