# 구현 1차 · 관할 · 광역 · 반려 기능 제거 — 구현 확인 대기

> 2026-09-30 · 어느 플랫폼: **기관 분기 화면**(기관 첫 화면 · 할 일 · 보고서 · XI맵)과 **서버**
> 근거(사용자가 확인한 것만): "다른 지역 정보는 호출도, 보지도, 열리지도 않는다" · "광역은 광역 전체나 시군구 단위로 보고 싶어 할 것"(광역 전체 집계로 도착, 시군구는 직접 고름) ·
> "보고서 생성이 주요 범위. 시정명령 등 강하게 드라이브 거는 것은 없어야" · "현장 확인 배정은 지금은 필요 없다"

## 무엇을 고쳤나

### 1. 계정 범위 밖 0 — 서버가 내주지 않는다
| 무엇 | 전 | 후 |
|---|---|---|
| 검색 제안 · 지역 목록 | 남원시 계정 검색에 '여수시'가 뜸 · 전국 256개 시군구 목록이 내려옴 | 기관 계정은 **관할 시군구만** 내려옴(남원 1곳 · 광주전남 27곳). '여수' 입력 → 제안 0 |
| 지역 상세 · 읍면동 경계 · 결과 층 | 관할 밖 시군구도 열림 | 관할 밖 = **없는 지역과 같은 답**(있다는 사실도 알리지 않음) |
| 분석 견적 · 등록 | 관할 확인 없음 | 범위가 관할을 **조금이라도 벗어나면 거절**(경계선 그리기 오차 약 10m 까지만 같은 곳) · 거절은 계획 · 분석 기계 사용 전에 |
| 필지 조회(지도에서 누른 곳) | 로그인 없이도, 기관 계정도 전국 | 로그인 필수 · 기관 계정은 관할 안만 |
| 공개 목록으로 우회 | 기관 계정이 '공개 목록'을 청하면 전국 배포본 · 지역 목록이 나옴 | 기관 계정은 자기 것만 |

- LX 계정(직원 · 관리자 · 영업)은 그대로 **전국**.
- 광역 기관의 **연안 바다**(읍면동 경계 밖이지만 관할 땅에서 약 5km 안이고 다른 시군구 땅에 닿지 않는 곳)는 관할로 본다 — 해양쓰레기처럼 바다를 보는 서비스가 막히지 않게.
- 해외 기관은 국내 관할 0 · 해외 사업 구역 안만.

### 2. 광역 기관 — 전체 집계로 도착, 시군구는 사용자가 고른다
| 화면 | 전 | 후 |
|---|---|---|
| 기관 첫 화면 | 서비스 줄만(시군구별) · 첫 필지의 시군구를 화면이 골라 물어보기 · 할 일 문맥으로 씀 | 맨 위 **'전체 · 광주전남특별시 · 의심 필지 35,031건'** 한 줄 · 시군구는 줄을 눌러 고름 · 최근 고른 곳은 '최근 고른 곳' 표시만(자동 선택 0) |
| 할 일 · 보고서 | 도착하면 **강진군**으로 자동 이동 | 도착 = **전체**(의심 필지 합계 + 시군구별 표) · 표에서 누르거나 고르기에서 고르면 그 시군구 · 고르기 목록 머리에 '최근 고른 곳' |
| 보고서 탭 | 강진군 읍면동이 미리 골라져 있음 | 전체일 때는 '시군구를 고르면 읍면동 보고서 초안을 씁니다' 한 줄 |
| XI맵 | 요약 첫 시군구를 화면이 고름 | 관할 전체 범위 · 큰 숫자 = 관할 전체 |

- 기초 기관(남원 등 관할 하나)은 그대로 그 시군구로 도착.

### 3. 반려된 기능 제거 — 보고서까지
| 무엇 | 전 | 후 |

| 조치 기록 종류 | 안내 · **시정명령 · 이행강제금 · 원상복구** · 없음 | **안내 · 재방문 · 이관 · 없음**. 서버도 시정명령 · 이행강제금 · 원상복구를 받지 않음 · 옛 기록 10건은 지우지 않고 '취소'로 둠(화면 · 보고서에 안 나옴) |

| XI맵 · 기관 첫 화면 필지 카드 | '현장 배정' 버튼 | 없음(상태 '판정 전'만) |

## 확인 방법(바깥 주소 https://gov.land-xi.dev · 계정 lxadmin — 비밀번호는 대화로만)
1. 기관 **남원시**로 로그인 → 위 **XI맵** → 검색창에 '여수' → 제안 0.
2. 기관 **광주전남특별시**로 로그인 → 첫 화면 왼쪽 위 **'전체 · 의심 필지'** 한 줄 → **할 일** → '의심 필지' 탭 = 전체 합계 + 시군구 표 → 한 줄을 누르면 그 시군구 → 다시 들어오면 전체로 도착하고 고르기 목록 머리에 '최근 고른 곳'.
3. 남원시 → **할 일** → 판정한 필지 → **조치 기록** → 종류 4개(안내 · 재방문 · 이관 · 없음). 의심 필지 탭의 필지 → '현장 확인 배정' 없음 · 판정 3택.
4. 남원시 첫 화면 → **물어보기** → '운봉읍 현장 조사 공문 초안 써 줘' → '공문은 만들지 않습니다 …' + 보고서 초안 파일.

## 시험
- 새 시험 13건 — 관할 밖 목록 · 검색 · 상세 · 경계 · 결과 층 · 견적/등록(시군구 · 범위 · 읍면동 · 위치 없음 · 경계 30m 밖) · 필지 조회(게스트 401 · 관할 밖 404) · 공개 목록 우회 · 광역 합계 = 시군구 합 · 배정 · 시정명령 거절 · 옛 기록 취소 · 보고서 문구.
- 고친 시험: 실태조사 상태기계(배정 없음) · 조치 종류 · 보고서 서술(처분 문장 빼기) · 공문 → 보고서 안내 · 지역 목록(기관 = 관할만) · 필지 조회(로그인) · 읍면동 경계 · 결과 층(관할 밖 404).
- 결과: 실태조사 44 통과 · AI 도우미 515 통과 · 서버 관련 시험 182 통과(분석 기계를 실제로 돌리는 시험 2건은 빼고 돌림) · 화면 시험 25 통과 / 2 실패(아래 '남은 것' — 이번 변경 전부터 있던 실패).

## 남은 것
- e2e 두 건은 이번 변경 전부터 실패: 종결을 판정 없이 청하면 서버가 409 가 아니라 400(판정 필요)을 먼저 답함 · 광주전남 계정의 남원 집계가 0 이 아니라 '값 없음'. 시험 기대값 정리가 필요(이번 갈래 밖).
- 공개 자료(누구나 보는 메인 화면의 전국 하천 점유 통계)와 지도 바탕 그림은 계정과 무관한 공개 자료라 그대로.
- 해외 기관의 '사업 구역'은 프로필 범위 + 그 나라 구역 범위로 봤다 — 해외 관할을 더 좁게 정하려면 해외 기관 설계에서 정할 것.
- 옛 '배정' 상태로 남은 필지 3건(남원)은 지우지 않았다 — 할 일에서 '판정 전'으로 보이고 같은 길로 판정된다.

## 먼저 드리는 제안(채택은 사용자)
- **관할 밖을 물었을 때 한 줄 안내**: 지금은 검색 제안이 비기만 한다. "이 기관의 관할이 아닙니다" 한 줄을 보여 줄까요? (누가: 기관 공무원 — 빈 목록이면 고장인지 헷갈림)
- **광역 기관의 부서 관할**: 도 농정과는 전체, 시군 파견 부서는 그 시군만 보게 — 계정 · 부서 체계가 들어올 때 같은 관할 판정 한 함수로 좁힐 수 있다.
- **조치 기록의 '기한' 칸**: 처분 기한처럼 읽힐 수 있다 — '다음 확인 날짜'로 바꿀까요?
