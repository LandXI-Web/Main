## 한 줄
**앞면은 전국 결과를 영상 원천 · 연도로 한눈에 보여 주고, 뒷면은 직원이 그 자리에서 고친 칸을 학습 자료로 쌓아 밤에 다시 학습하고, 같은 검증 묶음에서 나아진 판만 배포 신청 → 승인 → 기관 새 판으로 내보낸다.**

## 앞면 — 지난 시안 다섯 장면에서
남김: 전국 결과 장부(첫 화면) · 범위 그려 바로 분석 · 두 시점 변화 + XI ChatGEO · 같은 지도 해외. 줄임: 영상 판 → 위쪽 한 줄(브이월드 최신 · 국토지리정보원 연도별 · 올린 영상) + 연도 막대. 새로: **'고치기'**(LX 직원 · 관리자 — 기관은 '틀렸어요'). 지도 서비스로: 층 · 보고서 · 가르기 · 입체 · 필지 카드. 도구 = 영상 · 분석 · 변화 · 고치기.

## 뒷면 — 한 바퀴
| # | 단계 | 한 줄 |
|---|---|---|
| 1 | 보기 | XI맵 앞면에서 결과를 본다 |
| 2 | 고치기 | 지우기 · 모양 고치기 · 분류 바꾸기 · 놓친 것 그리기 → 그 칸 '다 봤음'. 고친 사람 · 영상 · 모델 판 · 고치기 전 모양이 남음 |
| 3 | 쌓기 | 다 봤음한 칸 = 학습 자료 한 장 → 학습 데이터 자산 '고친 것' 층(관리자 관리) |
| 4 | 다시 학습 | 기준(제안 200칸)을 넘으면 프로젝트장에게 알림 → 누름 → 밤 · GPU 한 장 · 고친 칸 + 되풀이 자료 |
| 5 | 비교 | 같은 검증 묶음 · 같은 설정으로 지난 판과 — **막는 자리**(나빠지면 후보로 남음) |
| 6 | 배포 신청 → 승인 | 나아지면 신청서가 미리 채워짐 · 신청 · 승인은 사람(지금 배포 길) |
| 7 | 새 판 | 공유 기관 알림 · XI맵 장부를 밤에 새 판으로 다시 분석 |

들어오는 길 셋이 한 기록으로: **XI맵 고치기** · **기관 '틀렸어요'**(LX 판정 'AI 오류'만 — 남원 신고 109건 중 6건, 103건은 업무 판정이라 학습 자료 아님) · **프로젝트 결과 확인**(같은 고치기 화면 — 결정 4).

## 새로 필요한 것(핵심)
고치기 기록 표(원래 모양 보존) · 라벨 칸 표(모델이 본 칸 = 학습 자료 한 장) · 학습 데이터 자산에 '고친 것' 층 · 학습 묶음 판(잠금) · 검증 묶음 등록(기준 3,000장 · 고친 곳 20%) · 비교 기록과 서버 판정 · 밤 시간 창 · 모델 계보 · 결과 판 꼬리표. 재사용: 결과 고치기 길 · 작업 대기열 · 학습 어댑터 · 전력 임대 · '검증만' 모드 · 재학습 회차 · 배포 신청 · 승인 · 새 판 알림. 자세히 `data-tables.md`.

## 위험 셋(전부는 design.md 4장)
1. **잘못 고친 라벨 · 한 사람 편향** → 칸 '다 봤음' · 원래 모양 보존 · 되돌리기 · 무작위 다시 보기 · 두 사람 다르면 학습 제외 · 한 사람 몫 상한.
2. **검증 묶음 오염 · 나빠진 판 승격** → 기준 묶음 잠금 · 고친 곳 검증 쪽 고정 · 설정이 다르면 비교 안 함(실제로 같은 모델이 62% · 68%로 갈림) · 자동은 '신청서 채우기'까지(10-08 비닐하우스 91% → 87% 실제로 막힌 사례).
3. **영상 저장(원칙 136) · GPU 전력** → 다 봤음한 칸만 작은 그림으로(1만 칸 약 3GB 추정 · 결정 2) · 브이월드 바탕 칸은 국토지리정보원 연도판으로 받음 · 학습은 밤 · 한 장 · 다른 장 고부하면 멈춤.
