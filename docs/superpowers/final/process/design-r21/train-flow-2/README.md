## 결정 1 · 서식(기본 흐름)은 누가 관리하나 — 다시
| | ⓐ LX 관리자가 기본 흐름 서식 관리 + 직원은 프로젝트에서 자유 편집 | ⓑ 서식 없이 자유 |
|---|---|---|
| 처음 연 화면 | 기본 흐름이 놓여 있음 → 학습 데이터만 고르면 됨(쉬움) | 빈 판 → 블록 일곱을 직접 놓고 이어야 함 |
| 자유도 | 같음 — 서식은 출발점일 뿐 잠그지 않음(블록 더하기 · 빼기 · 여러 개 모두 됨) | 같음 |
| GPU · 전력 규칙 | 관리자가 서식에 상한(반복 · 이미지 크기 · 한 번에)을 둠 → '관리자 영역'과 맞음 | 상한을 둘 자리가 없어 코드 기본값에 숨음 |
