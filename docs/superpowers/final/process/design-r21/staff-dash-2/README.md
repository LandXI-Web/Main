## 제안 — 이런 것도 필요하지 않을까요?
1. **왼쪽 메뉴 '대시보드' 옆에 할 일 수** — 모든 직원. 다른 화면에 있어도 손댈 일이 생긴 걸 안다(요청함 숫자와 같은 방식).
2. **메모에서 '할 일로 올리기'** — 프로젝트장. 메모를 적다가 날짜를 붙이면 오늘 할 일 줄로 들어가고 끝내면 사라짐(일정 · 마감 칸을 따로 두지 않고 할 일 하나로).
3. **결과 확인을 끝낸 프로젝트는 할 일에서 바로 '배포 신청'으로** — 프로젝트장. 지금 4건 모두 공개 뒤 결과 확인 남음 → 지도에서 '확인했음'을 누르면 다음 줄이 '배포 신청 가능'으로 바뀜.
