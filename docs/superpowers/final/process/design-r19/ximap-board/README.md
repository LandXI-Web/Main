## 한 줄
**XI맵에 들어가면 메뉴는 그대로이고, 지도 한 장이 전국 AI 현황판이다** — 최신 영상 위에 시군구마다 어떤 서비스의 결과가 있는지 색으로, 최근 갱신된 곳은 테두리로. 확대하면 객체, 객체를 누르면 그 자리에 작은 칸이 붙어 지우기 · 분류 바꾸기 · 모양 고치기 · 메모를 끝낸다. 나라를 바꾸면 같은 지도가 키르기스스탄 군별 경작지로 이어지고, 확대하면 실제 판정이 보인다.

## 5. 제안 — 이런 것도 필요하지 않을까요?
1. **띠에 '분석' 한 칸(나중)** — 누가 왜: LX 직원. 현황판에서 결과 없는 시군구를 보고 바로 '이 범위 분석'을 걸 수 있어야 '살아 있는 지도'가 된다. 영상 API 읽기기(open-api-3 ②)가 생긴 뒤.
2. **기관 계정의 XI맵은 관할만 색** — 누가 왜: 기관 담당자 · 보안. 같은 현황판에서 관할 밖은 윤곽만.
3. **고친 것 → 기관 '고쳤습니다' 한 줄** — 누가 왜: 기관 담당자. 기관 '틀렸어요'가 그 자리 고치기로 이어지면 답이 돌아가야 신뢰가 쌓인다(r17 뒷면과 한 몸).
