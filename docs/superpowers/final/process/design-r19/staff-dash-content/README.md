## 한 줄
**넷이 약했던 이유는 '보는 것'만 있고 '누를 것'이 없어서다.** 직원의 하루는 프로젝트 판정 · 멈춘 작업 · 후보 모델 판 · 새 영상 · 기관 요청에서 **오늘 손댈 일**이 생기고, 한 주 단위로는 **내 서비스가 얼마나 쓰이고 나아지나**가 궁금하다. 둘 중 무엇을 맨 위에 둘지가 방향 ⓐ ⓑ.

## 5. 제안 — 이런 것도 필요하지 않을까요?
1. **'오늘 할 일'을 왼쪽 메뉴 '대시보드' 옆 숫자로도** — 누가 왜: 모든 직원. 다른 화면에 있어도 손댈 일이 생긴 걸 안다(요청함 숫자와 같은 방식).
2. **멈춘 학습 '다시 돌리기' 한 번 누름** — 누가 왜: 프로젝트장. 10-08 실제로 메모리 부족 2건이 남았는데 지금은 프로젝트 › 학습까지 가야 한다. 같은 설정으로 다시 걸기(GPU 한 장 규칙 안에서).
3. **후보 판을 그냥 두면 n일 뒤 알림** — 누가 왜: 프로젝트장 · LX 관리자. 후보 판(비닐하우스 92%)이 신청도 폐기도 안 된 채 남아 있다 — 원칙 51(공개 뒤 갱신은 관리자 관리)과 맞물려 관리자 대시보드에도 '신청 안 한 후보 판' 한 줄.
