# 답을 기다리는 것 — 정리표 (10-10)

사용자(10-10): "나머지 답변을 기다리는 것들을 한꺼번에 다 대답하도록 해줘. 중복성 있는 문의도 많은거 같아서 그래"

확인 대장에서 상태가 확인 대기 · 결정 대기 · 검토 필요 · 구현 확인 대기 · 보류 · 다시(다시 그린 것 포함)인 줄을 모두 모아 셋으로 나눴습니다.

- **살아 있음** — 아직 정해지지 않았습니다. 한 번에 묻기 페이지의 질문 번호로 갑니다.
- **닫힘 후보** — 뒤에 나온 결정 · 원칙 · 완료된 구현으로 이미 정해졌습니다. 페이지 맨 아래 '닫아도 될까요' 한 묶음에서 한꺼번에 닫거나 남깁니다.
- **합침** — 다른 항목과 같은 결정입니다. 합칠 대상(질문 번호)으로 갑니다.

옛 항목의 상태는 사용자 답을 받기 전이라 확인 대장에서 바꾸지 않았습니다.
페이지: https://app.land-xi.dev/landxi/proto/review/confirm/all1010/
