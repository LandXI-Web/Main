## 지키는 것
- 키 값은 만들 때 한 번만 · 서버에는 한 방향 암호(HMAC-SHA256)와 끝 네 자리만 · 처리 기록(audit)에도 키 값 0.
- 사람 = 화면 로그인, 시스템 = 키 — 섞지 않음: 화면 토큰으로 외부 창구 401 · 키로 화면 API 401(원칙 173).
- 키가 살아 있는 조건 = 폐기 안 됨 · 끝나는 날 전 · 멈춤 아님 · **그 서비스가 그 기관에 지금 공유됨**(기관 '서비스 선택'과 한 판정). 공유를 거두면 멈춤, 다시 공유하면 그대로 이어짐(API-공유끔 ⓐ).
- 관할 밖 · 다른 서비스 · 없는 시점 = 404. 결과는 기관 화면 내려받기 함수를 그대로 씀(숫자 한 출처 · 원칙 39) — SHP 는 같은 결과를 SHP 로(경위도 · UTF-8).
- 한도 = 키마다 1분 60회 · 하루 20,000회(초기값 · 키를 만들 때 바꿈). 넘으면 429 + 다시 해도 되는 때. 틀린 키 반복은 접속 주소마다 10분 20번.
- 모든 호출 한 줄(시각 · 키 · 기관 · 서비스 · 무엇을 · 형식 · 몇 건 · 크기 · 결과 · 접속 주소). 시험 키 호출은 사용 현황에서 뺌.

## curl 예제(외부 개발자 안내는 2차)

```bash
curl -H "Authorization: Bearer $LANDXI_API_KEY" "https://api.land-xi.dev/v1/results?limit=1000"
```
