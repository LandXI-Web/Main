# 고침-범위조회 — 결과 조회에 범위(bbox)를 주면 서버 오류 500

원인 한 줄: 범위 값을 DB 에 배열 하나로 넘기고 `$2[1]` 처럼 꺼내 쓰는 바람에 DB 가 값 형식을 못 정해 오류가 났고, 숫자 개수·순서가 틀려도 같은 500 이 났다.

고친 곳: `01. 디자인/server/landxi_api/results.py` — 범위를 숫자 네 개(`::float8`)로 따로 넘기고, 새 `parse_bbox` 가 숫자 아님·개수 틀림·순서 거꾸로(경도,위도 순 확인)를 400 으로 돌려준다.

시험(`server/tests/test_f2b_api.py`, GPU 안 씀) 4건 통과:
- 범위 있음 / 없음 / 분류와 함께 — 200, 개수 맞음
- 좌표 순서 거꾸로 · 숫자 아님 · 개수 틀림 — 400 bad_request
- 관할 밖(바다 · 해외) 범위 — 200 · 0건

실제 확인: 게이트웨이 재시작(전후 health 정상) 뒤 바깥 주소 https://app.land-xi.dev 에서 로그인 후 호출 — 남원 비닐하우스 범위 200(2,154건) · 관할 밖 200(0건) · 순서 거꾸로 400.
