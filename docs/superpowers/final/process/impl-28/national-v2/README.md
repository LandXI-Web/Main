## 제안 — 이런 것도 필요하지 않을까요?
1. **관리자 한 줄에 '새 판으로 바꾸는 중 n/230'** — 누가 · 왜: LX 관리자. 지금은 다시 도는 동안 % 가 그대로라 바꿔 끼우기가 끝났는지 화면에서 알 수 없다. 숫자는 진행 응답 `redo` 에 이미 있다(화면 결정이 필요해 넣지 않음).
2. **같은 칸 옛 판 · 새 판 숫자 비교(전주 · 익산 끝난 칸)** — 누가 · 왜: LX 직원 · 관리자. 같은 검증 묶음 +1.7%p 가 실제 전국 칸에서 경작지 곳 수 · 넓이로 어떻게 나타나는지 보여 주면 새 판 교체의 근거가 된다.
