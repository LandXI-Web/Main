## 2. 관리자 '공유 데이터'
- 메뉴: LX 관리자 화면 메뉴 맨 아래 '공유 데이터'(기존 'data' 그림 · 현황 · 인프라 · 기관 · 배포 · 요청 관리 · 검토 요청 · 계정 관리 화면 모두 같은 메뉴). 기관 계정에는 없음(관리자 관문 · 서버 403).
- 목록: 직원 '공유 데이터에서 고르기'와 같은 `GET /projects/imagery`(관리자는 `?all=1` 로 비공개까지). 줄 = 그림 · 이름 · 지역 · 연도 · 종류 · 직원에게(공개/비공개) · 정보 고치기 · 지우기. 찾기 칸 글은 직원 쪽과 같은 '영상 이름 · 지역 · 연도'. 한 페이지 12줄.
- 올리기: '영상 올리기' → 영상 등록 그대로(조각 올리기 → `POST /catalog/imagery {draft_id}` — 새 프로젝트 창 · 데이터 올리기와 같은 길).
- 정보 고치기(이름 · 촬영 연도) · 공개/비공개 = `PATCH /catalog/imagery/{id}`(LX 관리자만). 비공개 영상은 직원의 고르기 목록 셋(새 프로젝트 창 · 분석하기 · 추론)에서 빠집니다(프로젝트에 이미 이은 영상은 그 프로젝트에서 그대로).
- 지우기(확인 한 번) = `DELETE /catalog/imagery/{id}` — 분석에 쓴 영상은 '분석에 쓴 영상이라 지울 수 없습니다'(409). 영상 파일은 지우지 않음. 기관 공유 · 프로젝트 잇기 · 표준본 기록 줄도 함께 정리.
- 시험(바깥 주소 · 14:03–14:04): 시험 영상 하나 올림 → 목록 84장 · 직원 목록 84 → 비공개로 직원 목록 83(관리자 목록에는 남음) → 이름 고침 → 영상 등록 작업 끝난 뒤 지움 → 83장. 시험 파일 · 올린 묶음 · 표준본 줄은 지웠습니다. `shots/after-admin-shared-*.png` · `shots/run-after-shared.json`.
