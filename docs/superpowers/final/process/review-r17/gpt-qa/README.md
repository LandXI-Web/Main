**'조사·검토 대상'과 원칙 135** — 부딪힙니다. 원칙 135는 분석하기 · 서비스 카드 · 대시보드 · **메인**에서 '현장 확인' 개념을 빼고 AI 분석 결과로 보이라는 것이고, XI ChatGEO 지시문은 '의심 필지 = 현장조사 대상 후보'로 정의합니다. '조사·검토 대상 확인'은 이 개념을 메인 제목으로 되살리므로 쓰지 않습니다.
