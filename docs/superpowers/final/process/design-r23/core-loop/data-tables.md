## 1. 새로 만드는 표

### 1-1. 클래스 목록 `classes` — 세 화면이 같은 이름을 읽는 한 곳
| 열 | 뜻 |
|---|---|
| id | cl_… |
| name | 화면 이름(예: 연동 비닐하우스) — 하나뿐(같은 이름 두 줄 금지) |
| aliases | 다른 이름(예: 비닐하우스_다동 · 다동 하우스) — 찾기 · 모델 머리 이름 맞춤 · XI ChatGEO 말 연결에 씀 |
| parent_id | 상위 클래스(연동 비닐하우스 → 비닐하우스). 있으면 '세부' |
| status | proposed(더함 · 승인 대기) · approved · merged(다른 클래스로 합침) · rejected · resting(오래 안 쓰임) |
| merged_into | 합친 곳 — 합치면 그 클래스로 된 고치기 · 칸이 저절로 옮겨 감 |
| std | 표준 클래스인가(설계 12차 표준 30) |
| created_by · created_at · created_from | 누가 · 언제 · 어느 고치기에서 더했나 |
| decided_by · decided_at · decide_note | 관리자 결정 |

씨앗: 지금 모델 21개의 분류 + 표준 클래스 30 + 서비스 판의 찾는 것을 한 번 모아, 같은 뜻은 다른 이름으로 묶는다(예: 비닐하우스_단동 · 다동 → 비닐하우스의 세부 두 줄). 세부를 만들지 합칠지는 관리자 한 번 정리.

### 1-2. 서비스 클래스 표 `class_sets` — 서비스마다 · 판마다
| 열 | 뜻 |
|---|---|
| id · card_id · ver | 어느 서비스의 몇 번째 클래스 표(1, 2, …) |
| classes | [{class_id, state: finds(지금 모델이 찾음) · learning(배우는 중 — 모델이 아직 못 찾음) · off(이 서비스에서 뺌), model_label(모델 머리 이름), how: head(탐지 모델) · split(세부 나누기)}] |
| model_id | 이 표가 맞춘 모델 판 |
| reason | 처음 · 새 클래스 승인 · 모델 새 판 |
| locked_at | 학습 묶음이나 승인된 서비스 판이 쓰면 잠김 — 그 뒤 바뀌면 새 ver |

`card_versions` 에 `class_set_id` 열을 더한다. 서비스 판이 찾는 것(`modules.classes`)은 이 표에서 state=finds 만 뽑아 만든다(한 출처).

### 1-3. 라벨 칸 `label_cells` — 17차 1-2를 고침(누르기 없음 · 원칙 203)
| 바뀐 열 | 뜻 |
|---|---|
| state | open(고치는 중) → **ready(마지막 고치기 뒤 조용한 시간이 지나면 저절로)** · disputed(같은 칸을 두 사람이 다르게 고침 — 학습 제외) · excluded(관리자가 뺌) |
| reviewed_by · reviewed_at | **뺌** — '다 봤음' 단추 없음. 대신 editors · last_edit_at |
| labels | 칸 안 도형 전부 [{class_id, 다각형, 출처: 모델 그대로 · 고침}] — 직원이 그 화면에서 본 그대로가 정답(고치지 않은 모델 결과는 '모델 그대로'로 표시) |
| classes_checked | 이 칸에서 사람이 손댄 클래스. 새 클래스 · 세부 학습에서는 이 클래스가 든 칸만 씀 |
| class_set_id | 고칠 때 서비스 클래스 표 판 |

나머지 열(칸 범위 · 해상도 · 영상 원천 · 칸 그림 · split train/holdout · license · asset_id)은 17차 1-2 그대로.

### 1-4. 클래스 층 `train_assets` — 질문 11 ⓐ 자산 표(데이터하우스 한 줄의 재료)
| 열 | 뜻 |
|---|---|
| id · class_id | 어느 클래스 |
| kind | std(표준 · 관리자) · free(프로젝트가 올린 그대로) · edits(XI맵 고친 것) · report(기관 신고 중 'AI 오류' 판정에서 고친 것) |
| imagery_kind · gsd_m | 항공 · 위성 · 드론 · 해상도 |
| origin | AI 허브 · LX 사업 · 공개 묶음 · XI맵 — 출처 |
| license | 이용 조건(확인됨 · 확인 필요) — 원칙 133 |
| n_images · n_objects · n_sgg · n_editors | 서버가 칸 · 라벨에서 센 값(화면 '학습 데이터 n장' — 원칙 209) |
| cur_version | 지금 판 |

### 1-5. 아카이브 판 `asset_versions`
| 열 | 뜻 |
|---|---|
| id · asset_id · ver | 클래스 층의 몇 판 |
| manifest_sha · n_images | 그림 목록 지문 · 장 수 |
| cells_cutoff | (edits 층) 이 시각까지 ready 가 된 칸 |
| locked_at · locked_by | 학습 묶음이 쓰면 잠김 — 잠긴 판은 바뀌지 않음(다음 고치기는 다음 판으로) |
| note | 바뀐 점 한 줄 |

### 1-6. 재학습 묶음 `train_sets` — 17차 1-4에 두 열
| 더한 열 | 뜻 |
|---|---|
| class_set_id | 이 학습이 맞추는 클래스 표(예: 비닐하우스 표 3판 — 연동 비닐하우스가 learning) |
| mode | head(탐지 모델 클래스 늘림 · 같은 모델의 모든 클래스 되풀이 자료 필수) · split(세부 나누기 — 상위 클래스 도형을 잘라 낸 그림만) · same(클래스 그대로 · 고친 것만 더함) |

parts(아카이브 판 + 장 수 + 규칙) · manifest_sha · per_editor_max · cells_cutoff 는 17차 그대로. 만든 순간 잠김.

### 1-7. 검증 묶음 `eval_sets` · 비교 기록 `model_evals` — 17차 1-5 · 1-6 그대로 + 한 가지
비교 기록의 '분류마다 값'을 **클래스 id 기준**으로 적는다. 판정 = 같은 모델을 쓰는 모든 서비스의 클래스가 하나라도 떨어지면 not_better(서버가 판정 · 명령줄 0).

### 1-8. 내려받기 요청 `asset_downloads` — 원칙 133 · 자산-3
id · asset_version_id · by · 쓸 곳 · 기간 · state(요청 · 승인 · 반려) · decided_by · 사유 · 받은 때 · 기한. 플랫폼 안 재사용(불러오기 · 학습)은 승인 없음.

## 4. 서버 기능 — 재사용 / 고침 / 새로
| 기능 | 지금 있는 것(재사용) | 고침 · 새로 |
|---|---|---|
| 객체 칸의 클래스 목록 | GET /ximap/feature 의 meta.classes(모델 분류) | **고침**: 그 서비스의 클래스 표(finds · learning) + 같은 모델의 다른 클래스(다른 서비스로 옮겨 감) + '해당 없음'. 모델 분류 글자 대신 클래스 목록 이름 |
| 클래스 찾기 · 더하기 | — | **새로**: GET /classes?q= (이름 · 다른 이름 · 세부 · 비슷한 글자) · POST /classes(proposed · 상위 = 고치던 객체의 클래스 · 상한 검사) |
| 클래스 결정 | — | **새로**: POST /classes/{id}/decide(승인 · 합치기 · 세부로 · 반려 — 합치면 고치기 · 칸 · 층이 저절로 옮겨 감 · 감사 기록) |
| 고치기 | POST /ximap/edits · undo(0037 · 원래 모양 · 되돌리기 · 시험 표시) | **고침**: cls_id · new_class · cell_id. 고치면 칸을 저절로 만들거나 이어 붙임 |
| 칸 → 학습 데이터 | (없음) | **새로**: CPU 작업 '칸 그림'(조용한 시간 뒤 칸을 잘라 작은 그림 · labels 고정 · ready) — 17차 1단 그대로, 누르기만 없음 |
| 데이터하우스 | (없음 — 질문 11 ⓐ 결정만) | **새로**: 클래스 층 등록(디스크 68층 한 번 · 이용 조건 첫 값) · GET /datahouse/classes(클래스마다 장수 · 출처별 · 판 · 쓰인 모델 · 승인 대기) · GET /datahouse/classes/{id}(지도 점 · 그림 몇 장 · 판 목록 · 이 클래스를 찾는 서비스) · 내려받기 요청 · 결정 |
