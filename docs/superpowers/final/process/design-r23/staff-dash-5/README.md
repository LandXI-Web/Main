| | 지난 ⓐ 4열(150px) | **이번 3열(196px)** | 지난 ⓑ 2×2(310px) |

| 지금 9건 | 3행에 빈 자리 2(지도 서비스 칸으로 하나 가림) | **3 × 3 = 9 꼭 맞음 · 빈 칸 0** | 4건만 보이고 5건은 지도 서비스로 |
