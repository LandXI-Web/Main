# 구현 32 · 융합 대시보드 '보고서로' = 한글 문서 (10-14 사용자 · 원칙 247)

> "대시보드에 보고서로 단추는 .dock 보고서가 아니라 .hwp로"

**받는 파일은 `.hwpx`입니다(`.hwp`가 아님).** `.hwpx`는 한글 표준 문서 형식(OWPML · KS X 6101)입니다. 한글 2014 이상과 한컴오피스 뷰어에서 바로 열립니다. `.hwp` 파일이 꼭 필요하면 한글에서 '다른 이름으로 저장 → 한글 문서(*.hwp)'로 바꿀 수 있습니다.

## 1. 길을 고른 근거 — `.hwp`(한글 자동화)와 `.hwpx`(직접 짓기) 비교
| | (a) 한글 자동화로 진짜 `.hwp` | (b) `.hwpx` 직접 짓기 (고름) |
|---|---|---|
| 이 서버 PC | 한컴오피스 2020이 깔려 있음(레지스트리 `HNC\Hwp` · `HWPFrame.HwpObject` 등록) | 따로 필요한 것 없음(파이썬 표준 zip · XML) |
| 서버에서 돌릴 때 | 화면이 있는 프로그램을 서버 프로세스가 띄워야 함. 파일을 열거나 저장할 때 **보안 승인 창**이 뜸. 이 PC에는 승인 모듈이 등록돼 있지 않아(`HwpAutomation\Modules` 비어 있음) 창이 뜨면 요청이 멈춤. 동시 요청 · 프로그램 멈춤 · 사용자 화면에 창이 뜨는 위험도 있음 | 메모리 안에서 짓기만 함 · 동시 요청 문제 없음 · 문서 하나 0.5–1초 |
| 다른 서버 · 해외 · 리눅스 | 한컴오피스 사용권이 있는 윈도 PC에서만 됨 | 어디서나 됨 |
| 형식 | 바이너리 `.hwp`(공개 문서는 있지만 쓰기 라이브러리가 사실상 없음) | 공개 표준(zip + XML) |
| 결론 | 운영 서버에는 맞지 않음 · **시험하지 않음**(멈추면 한글 프로세스를 강제로 꺼야 해서) | **채택** — 외부 서비스 · 유료 라이브러리 없음 |

이 PC에 있는 한글 2020은 **확인용으로만** 썼습니다. 받은 `.hwpx`를 한글 프로그램으로 직접 열어 화면을 찍었습니다(자동화는 쓰지 않음).

- 파일 이름: `남원시_비닐하우스_보고서_20261014.hwpx`(대시보드 제목 + 날짜).
- 서버: `POST /api/v1/ximap/report.hwpx`(LX 계정 · 로그인 없으면 401). 화면이 받은 대시보드 사양을 그대로 보내고, 서버는 숫자를 다시 세지 않고 그 값으로 문서를 만듭니다(숫자 한 출처).

## 3. 문서 모습 (`opened/*.png` = 한글 2020에서 연 화면)
- A4 · 좌우 25mm · 글꼴 **함초롬바탕**(본문) / **함초롬돋움**(제목 · 표).
- 차례
  1. 제목 '남원시 · 비닐하우스 보고'
  2. 개요 표: 지역 · 업무 · 비교 · 만든 날짜 · 자료 · 작성
  3. **1. 주요 숫자**: 큰 숫자 표, 화면 카드와 같은 값 · 단위 · 보조 줄
  4. **2. 해석**: XI ChatGEO 해석 줄을 '○'로
  5. **3. 차트**: 화면 차트(막대 · 히트맵 · 산점 · 면적 구간 · 도넛 · 누적 막대 · 선)를 같은 색 규칙으로 PNG로 그려 넣고 '그림 n. 제목 (단위: …)'을 붙임
  6. **4. 표**: 순위 · 지목 표, 머리 줄 회색 바탕 · 숫자 오른쪽 정렬 · 표 번호는 표와 같은 쪽
  7. 출처 줄 · 만든 날짜
- 문서에 넣지 않는 것: 작업 id · 파일 경로 · 시군구/읍면동 코드 · 내부 규칙 이름 · 지도 색칠 값. 시험으로 0건을 확인했습니다.
- 견본: `견본_남원시_비닐하우스_보고서.hwpx`(128KB · 4쪽 · 그림 4장 · 표 3개).

## 남은 것
1. 지도 그림은 넣지 않았습니다. 대시보드 지도 판은 화면 위성 영상 위에 칠한 것이라 서버에서 같은 그림을 다시 그려야 합니다.
2. 휴대폰 화면(390)에서 단추 자리는 찍어 보지 않았습니다.
3. 아주 긴 차트(읍면동 16줄 막대 등)는 쪽 넘김 때문에 1쪽 아래가 비는 경우가 있습니다. 그림이 쪽을 넘어 잘리지 않도록 일부러 그렇게 두었습니다.

## 제안 — 이런 것도 필요하지 않을까요?
1. **기관 'AI 분석 결과 보고서' 탭도 한글 문서로**: 지자체 담당자는 공문을 한글로 씁니다. 같은 짓기 함수를 쓰면 작은 일입니다.
2. **보고서에 지도 그림 한 장**: 결재 문서에는 '어디가 많은지' 지도가 먼저 들어갑니다. 읍면동 색칠 지도를 서버에서 그리면 됩니다.
3. **기관 서식(머리 · 꼬리 · 기관 이름)**: 기관마다 공문 머리가 달라서, 기관 브랜드에 문서 머리글 칸을 두면 받아서 바로 쓸 수 있습니다.
