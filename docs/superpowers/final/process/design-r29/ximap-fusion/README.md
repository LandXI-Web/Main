## 먼저 드리는 제안
1. **대시보드 '보고서로' 단추** — 누가 왜: 지자체 담당자가 화면에 낸 통계를 그대로 실태조사 보고서 초안으로 받게(지금 보고서 초안 도구에 대시보드 묶음을 넘기면 됨).
2. **기상 특보가 나면 XI맵이 먼저 묻기** — 누가 왜: 호우 · 산불 특보가 난 순간 "특보 지역 비닐하우스 · 축사 몇 동 볼까요?"를 ChatGEO 가 먼저 띄워 재난 대응 담당자가 바로 대시보드로.
3. **대시보드 고정** — 누가 왜: 자주 보는 대시보드(예: 우리 시 농지 이용)를 직원 대시보드에 붙여 매일 바뀐 숫자만 보게.
