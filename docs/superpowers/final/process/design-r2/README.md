## 옛 자산에서 찾은 핵심 근거(요약)
1. 옛 '데이터 관리'에는 **지역을 고르는 칸이 없었다.** 파일을 끌어 놓으면(ECW·GeoTIFF·ZIP·SHP·XLSX, 1TB) 좌표를 읽어 4단으로 지도에 발행하고, 기관 공유 권한(뷰어/편집)을 두며, 원본 영상은 LX가 보관했다. 기관은 영상을 올리지 않았다.
2. 사용자 09-20 원문: "카드 발행 관리는 잘 만들어진 AI 모델 분석 서비스를 카드 형태로 발행하는 기능" · "서비스 카드는 카드 발행이랑 다른 개념" · "AI 서비스를 생산 양산하는 게 LX 몫, 행정서비스로 분기화하여 지자체에 제공". 옛 발행 흐름은 직원 요청 → 관리자 검토·승인 → 공개.
3. 옛 대시보드는 "AI 분석 결과와 학습데이터가 어디에 쌓였는지 한눈에"였고, 09-20 명세는 LX 화면이 네 질문(만드는 중·공개 대기·어디에 깔렸나·다음에 무엇)에 답하라고 했다.
4. 옛 남원시청 사용자 관리에는 **기관 안 위계**가 있었다: 직원이 부서·직위로 가입 → '남원시청 관리자'가 승인 → 서비스 단위 권한 1개(사료작물/농지 활용/영농 정보/일반) · 5회 실패 잠금·초기화·로그인 이력. 09-24 '기관 완전 별도' 결정 뒤 이 위계가 사라졌다.
5. 09-20 생산화 명세: 재학습 기준은 신뢰도 0.60·겹침 0.70·365일·표본 100이고 **기관 신고 5건은 '표본 검수' 신호**(보조)였다. 지금은 신고 5건이 곧 재학습이고 화면마다 계산이 다르다.
6. 옛 관리자 인프라 화면에는 노드 가입 토큰·대기열 취소/재큐/우선순위·모델 상주·증설 계산이 있었고, 서버는 지금도 전력 임대(동시 고부하 1장)를 강제한다. 기관 저장 한도는 알림뿐.
7. 표본 대장 11개(모두 농지 목록 XLSX)에서 변형 4가지 확인: 지번 뒤 지목('1답'), 주소가 네 열로 나뉨(시군·읍면·리·지번), '법정동' 열, 소재지에 시군 이름 접두. 결합 규칙이 브라우저·서버 두 벌.

## 확인 못 한 것(정직)
- 옛 관리자 인프라 화면(별도 주소)의 로그인 스크립트가 자동 브라우저에서 실행되지 않아 옛 인프라·기관 화면 캡처는 없다(D6·D4는 지금 화면 캡처 + 코드 근거로 대신).
- 개발행위 허가·공유재산·하천 점용·시설원예 대장의 실제 표본 파일은 저장소·데이터 폴더에 없어 명세의 열 정의로만 정리했다.
- GPU를 쓰는 실행(학습·분석·AI 도우미)은 누르지 않았다. 옛 화면 목록의 숫자는 모두 옛 목업 데이터다.
