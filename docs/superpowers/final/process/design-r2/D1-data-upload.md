# D1. 데이터 올리기 — 재정의 (FR-7 · FR-1)

> 지위: 사용자 확인 전 제안(확인 대장 12번 · FR-7 "다시 기획" · FR-1 "기존 자산 기준으로"). 코드는 고치지 않았다.
> 사용자 원문(09-30): "기존 자산에서 데이터 업로드를 어떻게 하는지 컨셉을 보고 판단. 굳이 지역을 골라서 올릴 필요 없다. 올릴 것 = 위성·항공·드론 영상과 각종 융복합할 수 있는 행정 자산." · "기존 자산에 데이터 업로드 기능이 구현·디자인되던 부분이 있다."

## 1. 원래 의도 (근거에서 찾은 것)
- 옛 화면 **'데이터 관리'** 는 LX 직원이 **원천 자료를 올려 쌓아 두는 보관소**였다. 네 칸 = 데이터 업로드 → 업로드 완료 → 레이어 발행 중 → 아카이브. 올린 파일은 좌표계·범위를 읽어 지도 레이어로 발행하고, 아카이브에서 기관에 공유했다.
- **지역을 고르는 칸이 없었다.** 지역은 파일에 딸린 속성(파일 이름·좌표)이었다. 09-20 명세도 "지역은 배포본의 속성"이라 했다. '고른 지역에 영상·대장이 갖춰졌는지 본다'는 정의는 09-27 최종 명세에서 새로 들어온 것이고, 화면이 스스로 지역을 고르는 동작은 구현 편의로 생겼다.
- 올릴 수 있던 것: 정사영상(GeoTIFF·ECW), 드론 원본 이미지 묶음(ZIP 안에 사진 + GPS 기록), 공간정보(SHP), 표 자료(XLSX). 한도 1TB. 끌어 놓기·여러 파일·일시정지·재개·이어 올리기·취소·실패 시 조치(좌표계 지정·원본 다시 올리기)·미리보기·기관 공유 권한(뷰어/편집)·디스크 사용량·증량 신청이 있었다.
- 누가: **영상은 LX 직원(관리자 포함)만.** 기관은 옛 화면에서 영상을 올릴 수 없었고, 지금 명세에서도 '영상 등록 요청'만 한다. **행정 자산(대장)은 기관이 자기 플랫폼에서 올린다.**
- 원본 영상은 LX가 보관하고 밖으로 내보내지 않는다(기관에는 타일만).

## 2. 지금 무엇이 어긋났나
| 어긋남 | 근거 |
|---|---|
| 화면이 지역을 먼저 고른다(도착 0.7초 뒤 자동 선택 · 최근 지역 · 배포 수 정렬) → "구례군이 되었다가 남원시가 된다" | 재검수표 §4 |
| 영상 등록이 '파일 또는 경로' 글자 한 칸 — 파일을 올릴 수 없다(명령줄 복사 필요) | S1-04 캡처 · 구현 보고서 "파일 선택은 대용량 업로드 결정 뒤" |
| 옛 업로드 기능(여러 파일·멈춤·재개·실패 조치·미리보기·보관함·공유 권한)이 모두 빠짐 | 옛 데이터 관리 화면 대비 |
| 서버 업로드 한도 2GB(옛 1TB) · 이어 올리기 없음 | 서버 영상 등록 규칙 |
| 올린 뒤 '갖춤 현황'(지역별 영상·대장 있음/없음)만 남고, 올린 파일 목록·상태를 보는 곳이 없다 | 재검수표 §5 |

## 3. 설계 — "파일이 먼저, 지역은 파일에서"

### 3-1. 한 줄 정의
**데이터 올리기 = LX 직원이 위성·항공·드론 영상과 융복합 행정 자산을 끌어 놓으면, 플랫폼이 좌표·범위를 읽어 어느 지역인지 스스로 알아내고, 지도 레이어와 필지 결합까지 준비해 두는 보관소.**

### 3-2. 올릴 대상
| 구분 | 종류 | 형식 | 올린 뒤 자동으로 되는 일 |
|---|---|---|---|
| 영상 | 위성 영상 | GeoTIFF · JP2 · IMG · ECW | 좌표계·범위·해상도 인식 → 겹치는 시군구 판정 → 지도 레이어(타일) → 촬영 연도·해상도로 종류(위성/항공/드론) 자동 표시 |
| 영상 | 항공 정사영상 | GeoTIFF · ECW · VRT | 위와 같음 |
| 영상 | 드론 정사영상 | GeoTIFF | 위와 같음 |
| 영상 | 드론 원본 사진 묶음 | ZIP(사진 + GPS 기록) | 사진 수·촬영 범위 인식 → '정사화 필요'로 표시(정사화는 이번 범위 밖, 목록·보관만) |
| 행정 자산 | 대장(농지·개발행위 허가·공유재산·하천 점용 허가·시설원예 등) | XLSX · CSV | 열 자동 인식 → 필지 결합(D7) → 대장 종류 추정 → 어느 시군구인지 판정 |
| 행정 자산 | 공간 자료(허가 구역·하천구역선·시설 위치 등) | SHP(zip) · GPKG · GeoJSON | 좌표계 인식(없으면 지정 요청) → 필지 결합 → 지도 레이어 |
| 학습 자료 | 라벨(정답 폴리곤) | SHP(zip) · GeoJSON | 좌표계·범위 인식 → 학습 표본으로 연결(학습 화면) |
| 학습 자료 | 학습 표본 묶음 | ZIP(사진 + 라벨) | 표본 수 확인 → 학습 화면으로 연결 |
- 성명·연락처 등 개인정보 열은 읽지 않고 저장하지 않는다(지금 규칙 유지).
- 한 번에 여러 파일, 파일당 대용량(목표: 옛 자산과 같이 TB급). 브라우저에서 **나눠 올리기(청크) + 이어 올리기**로 받는다. 서버 폴더에 이미 있는 파일은 '서버 폴더에서 가져오기'로도 등록(원스톱: 명령줄 복사 0).

### 3-3. 누가 올리나
| 누가 | 어디서 | 올리는 것 |
|---|---|---|
| LX 직원·LX 관리자 | Land-XI 데이터 올리기 | 영상 전부 · 행정 자산 · 학습 자료 |
| 기관 담당자(기관 관리자·부서 사용자) | 기관 플랫폼(서비스 안 '대장 올리기') | 행정 자산(대장·공간 자료)만. 영상은 '영상 등록 요청' |
- 기관이 드론 영상을 직접 올리게 할지는 갈림길(§6 ①). 옛 자산·명세는 둘 다 "기관은 영상을 올리지 않는다".

### 3-4. 화면 흐름(LX 직원)
1. **도착** — 지역 선택 없음. 위: 큰 드롭존("영상·대장·공간 자료를 끌어 놓으세요"). 아래: 올린 파일 목록(전국) — 네 상태 칸 `올리는 중 · 올라옴 · 지도에 올림 · 보관`. 오른쪽 서랍은 비어 있음.
2. **올리기** — 여러 파일을 끌어 놓으면 파일마다 한 줄: 이름 · 종류(자동) · 진행 막대 · `멈춤 / 이어 올리기 / 취소`. 창을 닫았다 와도 이어 올린다.
3. **인식(자동)** — 올라오면 플랫폼이 읽는다: 좌표계 · 범위 · 해상도 · 촬영 연도(파일에 있으면) · **겹치는 시군구**(여러 곳이면 모두). 대장이면 열 인식 + 필지 결합(D7). 파일 줄에 지역 이름이 나타난다(예: "남원시 · 구례군 일부").
4. **확인이 필요할 때만 묻는다** — 좌표계를 못 읽음 → '좌표계 지정'(EPSG 5186/5179/5174/4326). 연도·해상도를 못 읽음 → 두 칸 입력. 대장 열 뜻이 불확실 → 열 확인 표(D7).
5. **지도에 올림(자동)** — 영상은 타일 만들기 → XI맵·기관 화면에 '있음'으로. 공간 자료는 레이어로.
6. **보관·공유** — 파일을 열면 서랍: 인식 결과(지역·범위·해상도·연도) · 미리보기(영상 축소판 / SHP 실루엣 / 표 첫 5행) · 기관 공유(권한 없음/뷰어/편집 — 원본 영상은 항상 LX 보관, 기관은 타일만) · 표시/숨김 · 메모.
7. **다음 할 일(원스톱)** — 인식이 끝나면 파일 줄에 버튼 하나: 영상 → '전역 분석 요청' 또는 '학습 표본으로'; 대장 → '결과와 대조'(D7); 라벨 → '학습 화면으로'.
- **지역별 갖춤 보기**는 목록의 거르기(지역 이름으로 찾기)로 남긴다: "남원시"를 치면 그 지역에 걸린 영상·대장·라벨이 보이고 없는 것은 '없음'으로. 화면이 지역을 고르는 일은 0. 앞 화면(배포·결과 확인)에서 넘어올 때만 거르기 값이 채워진다(출처 한 줄 표시: '배포 화면에서 이어짐').

## 4. 구현 계획(백본 먼저 → 화면)
1. **서버**: ① 나눠 올리기·이어 올리기 엔드포인트(파일 조각·재개 토큰·완료 조립) ② 올린 파일 목록·상태 API(올리는 중/올라옴/지도에 올림/보관, 기관 공유 권한 포함) ③ 인식 작업: 영상은 지금 타일 작업의 '검사' 단계 결과(좌표계·범위·해상도)를 그대로 목록에 쓰고 **겹치는 시군구 판정**을 추가 ④ 공간 자료(SHP/GPKG/GeoJSON) 레이어 등록 ⑤ 좌표계 지정 재처리 ⑥ 드론 원본 묶음은 목록·보관만.
2. **화면**: 데이터 올리기를 §3-4 로 재구성. 지역 콤보·자동 선택·700ms 타이머·최근 지역 정렬 제거. 앞 화면에서 넘어온 지역은 목록 거르기 값으로만.
3. **연결**: 기관 플랫폼의 '대장 올리기'는 같은 업로드 부품을 쓴다(D7). 학습 화면의 '학습 표본 올리기'도 같은 부품.
4. **실증**: 서로 다른 시도 두 지역(예: 남원·구례) + 확인자가 고른 한 지역. GPU 한 장 규칙(타일 작업은 CPU).

## 5. 완료 기준(측정 가능)
- 새 브라우저로 도착: 지역 이름 0개, 드롭존 + 전국 목록. 검색·앞 화면 연결 외에 지역이 바뀌는 일 0.
- 영상 1개(2GB 초과) + 대장 1개 + SHP 1개를 한 번에 끌어 놓기 → 진행 막대 → 영상 올리는 중 '멈춤' → 브라우저 새로 고침 → '이어 올리기' → 완료.
- 완료 뒤 파일 줄에 지역 이름이 **파일에서** 나타남(예: 남원시). 잘못된 좌표계 SHP 1개 → '좌표계 지정' → 재처리 성공.
- XI맵에서 그 지역 영상이 '있음'으로, 대장은 결합 결과가 나옴(D7 기준).
- 새로 고침 뒤 목록·상태 유지. 명령줄 단계 0.

## 6. 확인받을 선택지
1. **기관 영상 올리기** — ⓐ 기관은 행정 자산만 올리고 영상은 요청(옛 자산·명세 그대로) / ⓑ 기관도 자기 드론 영상을 올릴 수 있게(LX가 확인 후 지도에 올림).
2. **대용량 방식** — ⓐ 브라우저 나눠 올리기(TB급, 이어 올리기) + 서버 폴더 가져오기 둘 다 / ⓑ 서버 폴더 가져오기만(브라우저는 2GB까지).
3. 재정의 자체(파일 먼저 · 지역은 파일에서 · 네 상태 칸 · 옛 기능 되살림) — 확인 / 보류 / 반려.
