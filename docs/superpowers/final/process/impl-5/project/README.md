### 저장 용량 — 어떻게 보이고 어디서 오나
- 보이는 말: **'할당 없음 · 지금 쓴 양 29.8 MB'** + '내가 프로젝트장인 프로젝트 n개의 학습데이터 · 올린 파일'. 할당이 정해지면 '29.8 MB / 50 GB 할당'과 막대로 바뀝니다.
- **할당** = 계정마다 한 칸(LX 관리자가 정하는 값). 할당 · 요청 · 승인 화면은 아직 확인 전이라 지금 모든 계정이 비어 있고, 비어 있으면 지어내지 않고 '할당 없음'.
- **쓴 양** = 내가 프로젝트장인 프로젝트(진행 중 · 보관)의 저장 공간 합 — 이은 학습데이터 파일(이을 때 잰 크기) + 올린 파일. 프로젝트 한 장의 '저장 공간'과 **같은 계산 한 곳**을 씁니다(숫자 한 출처). 10월 1일 저녁 test@lx.or.kr = 비닐하우스 10.2 MB + 주차장 9.0 MB + 건축물 8.7 MB + 곤포사일리지 1.9 MB = **29.8 MB**(1000 단위 — 서버 사용 현황과 같은 단위). 캡처 때는 넘기기 알림용 시험 프로젝트가 잠깐 있어 '프로젝트 5개'로 보입니다(크기는 0).
- 정직하게 밝힐 점: 지금까지 서버 '사용 현황'은 기관 단위(기관 저장 공간)만 있었고 사람 단위 값은 없었습니다. 이번에 프로젝트 저장 공간을 사람(프로젝트장) 단위로 묶는 한 곳을 만들었습니다. 영상 원본 · 분석 결과처럼 프로젝트에 이어지지 않은 저장은 사람에게 나누지 않았습니다.
