## 1. 한 줄 결론

**틀의 절반은 이미 돌고 있다**(못 한 질문 모으기 · 밤 2시 바퀴 · 새 판 · 승인 대기 · 400문 시험). 빠진 것은 셋 — ① 지침을 '한 덩어리'가 아니라 조각 파일로 두고 판 번호를 매기는 것 ② 지침 자체를 고치는 **제안 단계**(지금은 낱말 바꾸기 · 답 문구만 자동, 지침은 사람만 고침) ③ 시험 문제를 **고치기용 · 최종 확인용**으로 가르는 것. 이 셋을 기본값으로 더하면 사람이 없어도 "제안 → 재기 → 승인 요청"까지 저절로 간다. 켜는 것은 늘 사람이다.

## 3. 설계 — 네 가지 발상을 기본값으로

### 3-1. 지침을 조각 파일로 · 판 번호 · 한 조각만 되돌리기
- 코드 안 글 덩어리를 **조각 파일**로 꺼낸다: `말투` · `쓰지 않는 말` · `숫자 규칙`(자리표 · 한 출처) · `지도 동작 규칙` · `도구 설명(도구마다 한 파일)` · `기억(예시 질문 → 도구 짝)` · `영어`. 각 조각은 판 번호(1, 2, 3…)와 '언제 · 누가(시스템 · 사람) · 왜(어느 질문 묶음 때문에)'를 머리에 적는다.
- **판 = 조각마다 어느 번호를 쓰는지 적은 목록 한 장.** 운영 판 하나 · 후보 판 여럿. 서버는 판 목록을 읽어 지침을 조립한다(다시 켜지 않아도 다음 질문부터).
- 되돌리기 = 판 목록에서 그 조각 번호만 한 단계 내림. 다른 조각은 그대로. 지금 '새 판 거절 · 되돌리기'와 같은 단추에 조각 단위를 더하는 것.
- 금지어 표(쓰지 않는 말 → 바꿀 말)는 이미 코드에 있다. 그대로 두고, 조각 파일 자체도 저장 전에 그 표로 검사한다(지침 안에 금지어가 들어가면 후보가 되지 못함).

### 3-2. 질문 묶음 둘 · 실제 사용에서 저절로 늘기
- **고치기용**(제안 단계가 봄) · **최종 확인용**(제안 단계는 절대 못 봄 · 사람도 자주 보지 않음). 400문을 묶음(최고 · 높음 · 보통 · 정상)마다 같은 비율로 가른다 — 추천 320 : 80. 바퀴 22 새 25문은 고치기용. 최종 확인용은 분기마다 새로 뽑아 바꾼다.
- **수확**: 서버가 모은 못 한 질문(○○ 가림)을 밤 바퀴가 그 역할의 예시 지역으로 채워 고치기용에 더한다. 기대값은 사람이 적지 않아도 되는 공통 기대만(끝남 · 도구 이름 0 · 권한 밖 0 · 물은 지역 이름 있음 · 금지어 0). 더하는 것: 못 한 답 · 거절(다음 할 일 없는) · **느린 답(10초 넘음)** · 3분 안 다시 물음. 10초 넘는 답은 지금 400문에 2건이라 따로 세어 둔다.
- 개인정보 · 보안: 원문 · 토큰 · 사람 이름은 지금처럼 저장하지 않는다. 수확 질문에는 '가린 요지'만, 채운 지역은 시험 계정이 볼 수 있는 예시 지역만. 시험 질문은 다시 모으지 않는다(이미 그렇다).

### 3-3. 바퀴 — 모은다 → 제안한다 → 잰다 → 견준다 → 묻는다
| 단계 | 누가 | 무엇을 | 기본값 |
|---|---|---|---|
| 모은다 | 서버(있음) | 못 한 질문 · 느린 답 · 다시 물음 | 그대로 |
| **제안한다(새로)** | 밤 바퀴 | 실패를 **까닭별로 묶고**(못 알아들음 · 도구 설명 모호 · 말투 · 금지어 · 지역 빠짐) 묶음마다 **고칠 조각 하나**를 고른다. 그 조각 글 + 실패 묶음 요지(질문 본문 아님) + 바뀌면 안 되는 규칙(숫자 자리표 · 쓰지 않는 말 · 두 문장)을 주고 **조각 새 글 후보를 셋까지** 받는다 | 제안 모델 = 지금 답을 쓰는 로컬 모델(온프레미스 · 비용 0). 예약된 Claude 실행은 켜면 쓰는 선택(기본 끔). 외부 유료 API 기본 0 |
| 잰다 | 밤 바퀴 | 시험 게이트웨이에서 **운영 판 1번 · 후보 판 각 1번** 고치기용 전부. 나빠진 질문만 두 번 더(한 번이라도 전과 같으면 '흔들림'). 고치기용에서 이긴 후보만 **최종 확인용을 한 번** | 서버 응답 없음 · 시간 초과는 **'없음'으로 뺀다**(0점 아님 · 개수 따로 적음). 한 질문 한 번씩 · 동시 0 |
| 견준다 | 밤 바퀴 | 한 장 비교: 좋아진 질문 · 나빠진 질문 · 흔들림 · 없음 · 금지어 · 권한 밖 · 숫자 어긋남 · 평균 답 시간 · 바뀐 조각의 전/후 글 | 통과 = 고치기용 나빠진 0 · 좋아진 1 이상 · 최종 확인용 나빠진 0 · 금지어 0 · 권한 밖 0 · 숫자 어긋남 0 |
| 묻는다 | 사람 | 통과한 후보 하나만 '새 판 n' 승인 요청. **now 페이지 질문 한 줄**(한 장 비교 링크 · 켠다 / 안 켠다) + LX 관리자 대시보드 같은 줄 | 자동으로 켜지는 길 없음 |

- 운영 판은 바퀴가 끝나도 바뀌지 않는다. 후보 판은 시험 질문에만 열린다(지금 '승인 전 판 = 시험 질문에만'과 같은 길).
- 제안이 두 바퀴 연속 통과하지 못한 묶음은 '사람이 볼 것' 꼬리표를 달고 멈춘다(끝없이 같은 것을 고치지 않게).
- 한 바퀴 밤 안에 끝나는가: 10-22 최종 400문의 순수 답 시간 8.4분 + 질문 사이 1.5초 ≈ 20분/판. 운영 판 1 + 후보 3 + 최종 확인 1 = 약 1시간 40분. 상한 3시간 안.

### 3-4. 사람 문 · 되돌리기
- now 페이지에 '구현 확인' 모양으로: **"새 판 n — 고친 답 7 · 나빠진 답 0 · 없음 1 · 바뀐 조각: 도구 설명(읍면동 통계) → 켤까요?"** 예 → 운영 판 교체(다음 질문부터) · 처음 물었던 사람에게 '이제 됩니다'(있음). 아니오 → 후보 닫음 · 묶인 후보는 새로 옴.
- 되돌리기 한 번: LX 관리자 대시보드 '새 판' 줄 · now 답 모두 같은 단추. 조각 단위로도 됨(3-1).
