# 큰 드론 영상 올리기 — 한 장 안내 (10-22)

> 사무실 PC에서 바깥 주소 **https://app.land-xi.dev** 로 수백 GB 드론 정사영상을 올릴 때 보는 안내입니다.
> 10-22에 3GB 시험 파일로 직접 올려 보고, 중간에 두 번 끊었다가 이어서 끝까지 올렸습니다(받은 파일이 원본과 똑같음을 확인 · 시험 파일은 지움).

## 1. 어느 화면에서

1. https://app.land-xi.dev 에서 **LX 직원 계정**으로 로그인합니다.
2. 왼쪽 메뉴 **프로젝트** → 영상을 쓸 프로젝트를 엽니다(없으면 새로 만들되, **영상은 만든 뒤에** 올립니다).
3. 위쪽 단계 막대에서 **데이터 올리기**를 누릅니다.
4. 지도 왼쪽 위 검색칸에서 **남원시**를 고르면 오른쪽에 남원시 칸이 열립니다.
5. 칸 아래 **영상 등록** 단추 → **영상 파일을 끌어 놓거나 눌러 고르세요** 칸에 파일을 끌어 놓습니다.

- 여러 파일을 한 번에 넣어도 됩니다. 위치 파일(TFW · JGW 등)이 따로 있으면 함께 넣습니다.
- 받는 형식: TIF · TIFF(COG 포함) · JP2 · ECW · IMG · JPG(위치 파일과 함께).
- 촬영 연도 · 해상도 · 위치는 파일에서 읽습니다. 입력할 칸은 없습니다.

## 2. 어떤 순서로 진행되나

| 화면 글 | 뜻 |
|---|---|
| 파일을 확인하는 중 | 영상 파일이 맞는지 앞부분만 봅니다(몇 초) |
| 올리는 중 12GB / 480GB · 남은 시간 약 9시간 | 올리는 중입니다. 막대가 찹니다 |
| 다 올렸습니다 — 확인하는 중 | 마지막 확인(몇 초) |
| ○○시 드론 n장을 등록했습니다 | 영상 목록에 새 줄이 생깁니다 |

등록 뒤에는 서버가 분석용 표준본을 따로 만듭니다(파일이 크면 몇 시간). 이 동안 화면은 닫아도 됩니다.

## 3. 끊기면

- **잠깐 끊김(와이파이 · 회선):** 아무것도 누르지 않아도 됩니다. '연결이 끊겨 다시 잇는 중'이 보이다가 저절로 이어서 올립니다(최대 30분까지 계속 다시 시도).
- **30분 넘게 끊김:** '멈췄습니다'가 보이면 **이어 올리기**를 누릅니다.
- **창을 닫았거나 PC를 껐다 켬:** 1장의 같은 화면을 다시 열고 **같은 파일을 다시 고릅니다.** 이미 받은 자리부터 이어집니다(처음부터 다시 올리지 않음).
- 이어 올리기는 **7일 안에** 해야 합니다. 7일이 지나면 받다 만 조각은 지워집니다.
- **멈춤** 단추로 잠시 멈출 수 있고, **×** 는 취소(받은 조각을 지움)입니다.
- 올리는 동안에는 로그인이 저절로 연장됩니다. 창을 닫으려 하면 브라우저가 한 번 묻습니다.

## 4. 미리 알아 둘 것

- **속도:** 이 서버에서 바깥 주소를 거쳐 잰 값은 초당 약 5.5MB(3GB에 약 10분)였습니다. 사무실 회선의 올리기 속도에 따라 다릅니다. 이 속도면 100GB에 약 5시간입니다. **처음에는 수 GB짜리 한 장으로 먼저 시험해 보세요.**
- **크기:** 한 파일은 2,000GB까지 받습니다. 다만 서버 저장 공간은 늘 200GB를 남겨 두므로, 지금은 **한 번에 약 1.1TB까지** 올릴 수 있습니다(서버 E: 남은 공간 약 1.3TB). 원본이 2TB면 한 번에 다 들어가지 않습니다. **COG 변환본을 올리거나, 몇 장씩 나눠 올리세요.** 자리가 모자라면 고르는 순간 '저장 공간이 모자라' 창이 뜹니다(한 바이트도 보내기 전).
- **사무실 PC가 잠들지 않게:** 올리는 동안 PC가 절전 모드로 들어가면 멈춥니다. Windows 설정 → 전원 → '절전 모드 안 함'으로 두세요. 깨어나면 3절처럼 이어집니다.
- 같은 파일을 두 번 올리면 '이미 등록한 영상입니다' 창이 뜨고 올리지 않습니다.
- **새 프로젝트 만들기 창에서 큰 파일을 올리지 마세요.** 그 창은 작은 파일용입니다. 큰 영상은 위 1장의 '데이터 올리기'에서 올립니다.

## 5. 다 올린 뒤

- 남원 6월 영상이 등록되면 곤포 사일리지 분석을 돌려 남원에 공유합니다(원칙 316 · now21 '곤포-남원' ⓐ).
- 문제가 생기면 화면에 보이는 글을 그대로 알려 주세요. 서버 기록에 같은 내용이 남습니다.
