- 이 지시서 하나로 **배경 → 목표 → 현재 상태 → 보유 자산 → 개발 범위 → 검수 기준**을 모두 파악할 수 있게 썼다.

## 5. 개발 범위

### P0 — 시연 성립 조건 (전부 완료해야 녹화 가능)

#### P0‑1. 「국토 변화 분석서비스」 정식 등록 (G1)
- 분석하기 카드로 등록. 분야 "건축·변화". 입력: 범위 + 연도 A·B.
- 처리 파이프라인:
  1. 범위 bbox로 연도 A·B 영상 확보(P0‑2) — 동일 격자(L17 또는 L18)로 정합
  2. U‑Net(ap25) 피복 추론 ×2 (기존 1024 타일 + 12.5% 겹침 방식 재사용)
  3. 픽셀 클래스 전이 맵 → 연결 성분 → 폴리곤화 → **최소 면적 50㎡ · 형태(세장비) 필터**
  4. 변화 유형 분류:
     | 유형 | 정의(A→B) |
     |---|---|
     | 신축 | 비건물 → 건물 |
     | 소실 | 건물 → 비건물 |
     | 경작 전환 | 나지·초지·도로 → 경작 |
     | 포장 확대 | 나지·초지·경작 → 도로 |
     | 식생 증감 | 기타 식생 전이(참고용, 기본 숨김) |
  5. 구역선 중첩 → `inside_row`(내/외) 플래그, 필지 교차 → `pnu` 부여
- 출력: geojson 레이어(속성: 유형·면적·inside_row·pnu·지목·소유구분·thumb_a·thumb_b) + 통계(건수·면적·유형별·내/외) + 폴리곤별 A/B 썸네일 PNG(필지 중심 정사각 크롭, `case_images_sarye.py` 방식)
- 결과 확인(지도 서비스): 유형별 색 범례, 구역선 내=강조·외=옅음, 폴리곤 클릭 팝업에 A/B 썸네일 나란히 + 유형·면적·지번
- 성능: 담양IC 3~5km 구간 전체 추론이 A6000에서 10분 내. 시연은 사전 계산 결과 로드 허용.

#### P0‑2. 연도별 항공영상 API 자동 호출 (G2)
- `ngii.py` 이식. 서비스 레이어에 `fetch_imagery(bbox_5179, year, zoom)` → 타일 모자이크 → 캐시.
- 프로젝트 생성 모달 "브이월드에서 영상 가져오기"에 **연도 선택(복수)** 추가. 가용 연도 목록은 NGII 레이어 존재 여부로 자동 감지(2019~2025 프로브).
- ChatGEO가 "2019년과 2024년 비교"처럼 연도를 말하면 해당 연도 영상을 자동 확보. **"한 시점뿐" 응답 제거.**
- 타일 캐시는 범위·연도·줌 키로 디스크 저장(재사용).

#### P0‑3. 선형(구역선) 범위 프로젝트 (G3, G7)
- 대상지 지정 방식 추가: ① 구역선 shp/geojson 업로드(+버퍼 m) ② PNU 목록 업로드(토지마스터 추출) ③ 기존 행정구역
- 데이터 올리기 패널에 "벡터 등록"(구역선·필지·용도 레이어) 추가. 연속지적도 CRS 벨트 자동 탐지(`common.detect_belt_crs`) 적용.
- 범위는 EPSG:5179 폴리곤으로 저장 → P0‑1·P0‑2의 bbox·마스크로 사용.

#### P0‑4. ChatGEO 도구 3종 (G4)
| 도구 | 시그니처 | 동작 |
|---|---|---|
| `run_change_detection` | (range_id, year_a, year_b) | P0‑1 실행(또는 캐시 로드) → 지도에 레이어 켜고 두 연도 스와이프 세팅 → 요약 문장(건수·유형·내/외·면적 상위 3건) |
| `intersect_parcels` | (layer_id, filters: {유형, 지목, 소유구분, inside_row}) | 조건에 맞는 필지 표(지번·지목·소유구분·유형·면적) + 지도 하이라이트 + CSV 내보내기 |
| `describe_change` | (polygon_id) | thumb_a·thumb_b 2장을 멀티모달 LLM에 입력 → 변화 내용 1~2문장(예: "나지였던 곳에 약 180㎡ 가설건축물과 컨테이너 2동 확인") |
- 도구 호출 과정을 채팅에 단계별 표시(영상 확보 → 추론 → 교차). 녹화에서 "AI가 일하는 과정"이 보여야 함.
- 꼬리 질문 컨텍스트 유지: 직전 결과 레이어를 기본 대상으로.

### P1 — 시연 완성도 (P0 완료 후)

#### P1‑5. 판정 상태 저장 (G5)
- 폴리곤 속성 `status ∈ {미확인, 불법, 적법, 현장확인, 철거완료}` + 판정자·일시·메모. 팝업에서 변경, 지도 아이콘 색 반영. 통계 패널에 판정 현황.

#### P1‑6. 보고서 생성 연결
- ChatGEO "보고서 초안"을 변화탐지 결과에 연결. **개조식**(명사형 종결·불릿·수치). 구성: 구간 개요 → 변화 요약(유형·내/외) → 필지별 목록(근거 썸네일 A/B) → 권고 조치. HTML 미리보기 + PDF.

#### P1‑7. 모바일 현장점검 뷰 (G6)
- 1화면: 현장확인 목록 → 상세(썸네일·위치) → 사진 첨부 → 판정 저장. 반응형으로 충분, 네이티브 불필요.

#### P1‑8. 영상 비교 스와이프
- 지도 서비스·XI맵의 "영상 비교"에 좌우 스와이프 바 추가(연도 라벨 표시).

## 7. 검수 시나리오 (이것이 플랫폼에서 끝까지 돌아가면 완료)

녹화 대본이기도 하다. 각 단계는 실제 UI 조작으로 수행한다.

1. **프로젝트 생성** — 이름 "고속국도 담양IC 변화 모니터링", 범위 = 구역선 geojson 업로드 + 버퍼 50m, 영상 = 브이월드/NGII 2019·2024 선택 → 생성 즉시 두 연도 영상이 지도에 보임
2. **ChatGEO**: *"2019년과 2024년 항공영상 비교해서 구역선 안에 새로 생긴 것 찾아줘"* → 도구 호출 단계 표시 → 스와이프 자동 세팅 → 변화 폴리곤 표출 → 요약(예: "구역선 내 변화 N건. 신축 a · 경작 전환 b · 포장 확대 c · 소실 d")
3. 폴리곤 클릭 → A/B 썸네일 나란히 + 유형·면적·지번. ChatGEO *"이거 뭐야?"* → `describe_change` 문장 출력
4. **ChatGEO**: *"지목이 도로인데 건물 생긴 필지만 소유구분이랑 같이 표로"* → 표 + 지도 하이라이트 + CSV
5. **ChatGEO**: *"철도용지도 같은 방식으로"* → 철도 프로젝트 전환, 2~4 반복(1회)
6. 폴리곤 2건 판정 "현장확인" 저장 → 아이콘 변경 → 모바일 뷰에서 해당 건 보임 → 사진 첨부 → 판정 "불법" 저장
7. **ChatGEO**: *"도로공사 보고용 보고서 만들어줘"* → 개조식 보고서 미리보기(썸네일 포함) → PDF
8. 배포 신청 화면에서 "한국도로공사" 공유 → 대시보드에 변화 건수·판정 현황 표시

합격 기준: 1~8이 끊김·에러·수동 개입 없이 연속 수행, 총 8분 이내. 2번 응답은 15초 이내(캐시 사용 시).
