## 1. 학습 그림 JPEG 95

- **XI맵 학습 칸**(`train_tiles`): 새로 만드는 칸은 `{칸}.jpg`(품질 95)로 저장한다. 예전에 PNG로 만든 칸을 다시 만들면 PNG 그대로 둔다(옛 묶음은 건드리지 않음).
- **학습데이터 구축(라벨링)**: 묶음의 형식은 묶음마다 정한다. 새 묶음은 .jpg이고, PNG로 시작한 옛 묶음은 끝까지 PNG다. 그림 보기, 학습 폴더 하드링크, 지우기 모두 두 형식을 읽는다.
- **경작지 묶음 스크립트**(`farm_v2_bundle`): 영상 API로 새로 굽는 조각만 .jpg다. 원천 PNG는 지금처럼 하드링크다(하드링크라 자리를 더 쓰지 않으므로 다시 굽지 않는다).
- 학습기(ultralytics)와 목록 검사(`training.IMG_EXT`)는 원래 .jpg를 읽는다.

## 2. 결과 원본 FlatGeobuf · 좌표 소수 7자리

- 한 곳에서 정한다: `server/landxi_api/result_store.py`(자리 · 형식 · 두 형식 읽기 · 크기).
- **쓰기**: 작업기 마무리(`cpu_worker.finalize`)가 `{작업}.fgb`를 쓴다. 좌표는 소수 7자리(약 1cm)이고 공간 색인이 들어 있다. 지도 조각(pmtiles)도 .fgb에서 굽는다. 이름 붙여 게시할 때도 같은 형식을 복사한다.
- **읽기(두 형식)**:
  - 지도는 pmtiles를 읽는다(형식과 상관없음).
  - 통계 · 내려받기 · 보고서는 DB 결과 줄에서 그때그때 GeoJSON · SHP · 엑셀을 만든다. 그래서 "GeoJSON은 내려받을 때 만든다"가 이미 지켜진다.
  - 전국 결과처럼 DB에 줄을 쌓지 않는 결과는 결과 파일을 읽는다. XI맵 객체 누르기, 그 자리 고치기, 학습 칸 만들기(`edit_memory.result_file_features`), 해외 공개 판 · 도시 확장(`overseas/publish` · `sprawl`)이 .fgb와 옛 .geojson을 모두 읽는다.
  - XI ChatGEO 도구는 결과 API(`/results/…`)를 부른다. 세트 이름이 그대로라 고칠 것이 없었다.
- 시험: .fgb 쓰기 · 읽기 · 범위 읽기 · 정수 칸 · 빈 값, .fgb → pmtiles 굽기 통과(pytest `test_p4_storage`).

## 3. 드론 4밴드

- 설정 `server/config/imagery.yaml`의 `standard.four_band: {split: true, suffix: ".b4"}`.
- 8비트 4밴드인데 넷째 밴드가 투명 칸이 아니라 실제 값이면 이렇게 나눈다: 색 3밴드 표준본(JPEG 90 · 마스크) 한 장과, 넷째 밴드 곁 파일 `{표준본}.b4.tif`(ZSTD 무손실 · 같은 격자). 곁 파일도 확인한다(같은 격자). 표준본을 지울 때 곁 파일도 함께 지운다(올린 파일 지움 · 변환 중 지움).
- **분석이 넷째 밴드를 쓰는 곳**: 작업기 창 읽기(`gpu_worker.read_window`) 한 곳뿐이다. 넷째 밴드를 '투명 칸' 확인에만 쓴다. 나눈 표준본은 3밴드 + 마스크라서, 다른 색 표준본과 같은 길(빈 창 건너뛰기)로 읽는다. 넷째 밴드 값 자체를 분석에 쓰는 곳은 없다. 쓰게 되면 `imagery_std.band4_path()`로 곁 파일을 읽는다.
- **지금 있던 1건을 다시 만듦**: 남원 산내면 드론(원본 ECW 511MB는 그대로).

  | | 전 | 후 |
  |---|---|---|
  | 표준본 | 4밴드 통째 무손실 3,659MB | 색 643MB + 넷째 밴드 24MB = **667MB** |
  | 화질 확인 | — | 통과(같은 격자 · 넷째 밴드 같은 격자) |

  영상 표와 표준 기록을 새 표준본으로 바꾼 뒤 옛 표준본을 지웠다. 근거: `_backup/p4-20261022/drone-restd.json`.

## 4. 결과 폴더 `results/{주인}/{연-월}/`

- 연-월은 작업 번호(ULID)에 든 만든 시각(한국 시각)으로 정한다. DB를 보지 않고도 경로가 나온다.
- **옛 자리 먼저**: 옛 자리(`results/{주인}/{작업}…`)에 무엇이든 있으면 옛 자리를 쓴다. 그래서 옛 결과와, 바꾸는 순간 돌던 작업이 그대로 이어진다.
- **세트 이름은 그대로**(`results/{주인}/{작업}`): 서명, 화면, 기록, XI ChatGEO의 세트 모양 검사를 고치지 않았다. 실제 파일 자리만 바뀐다.
- 같이 고친 곳: 작업기 조각 · 결과 · 스냅샷 자리(`bus`), 결과 API(조각 · qa), 지도 조각 경로(`catalog.resolve_set_path`), 보관 정리, 기관 저장 사용량, 전국 · 해외 작업기, 시험 정리.
