## ② 추천 틀 하나

### ②-1 서비스 정의(메타) — 통계 선언 + 기본값

**어디에 사나:** 서비스 카드 표 옆에 **표 하나 `card_stats`**(card_id 가 열쇠 · `card_info` 와 같은 자리 · 씨앗 값은 표 만들 때 한 번). 파일로 두면 LX 관리자가 못 고치고, 코드에 두면 지금처럼 흩어집니다. 카드 하나 = 선언 한 줄.

**덮어쓰기 순서(아래가 위를 덮는다 · 각 층은 따로 저장 · '기본값으로 되돌리기' 단추 하나):**
서비스 선언 기본값 → 기관 설정(그 기관 관할에서 바꾼 것 · 예: 버퍼) → 사람 설정(지금 서버가 기억하는 색 · 끈 분류) → 이번 화면 조건(지역 · 연도 · 상태 거르기 · 저장 안 함).

| 칸 | 경작·휴경 | 비닐하우스 | 건축물 | 주차장 | 국토 변화 |
|---|---|---|---|---|---|
| **분류축** | 경작지 · 비경작지 | 단동 · 연동 | 건물 종류(모델 분류) | 주차장(1종) | 신축 · 소실 · 경작 전환 · 포장 확대 (식생 증감 = 참고 · 기본 끔) |
| **공간축** 기본 단계 | 시군구 → 읍면동 | 시군구 → 읍면동 | 시군구 → 읍면동 | 시군구 → 읍면동 | **대상지(구역선 안/밖)** → 읍면동 |
| **수량** | 필지 수 · 넓이 | 동 수 · 넓이 | 동 수 · 넓이 | 곳 수 · 넓이 | 건수 · 면적 |
| **상태축** (공통 3단 + 확인 끝 안 결과 말) | 미확인 · 현장확인 · 확인 끝(맞음 · AI가 잘못 봄) | 같음 | 같음 | 같음 | 미확인 · 현장확인 · 확인 끝(**불법 · 적법 · 철거완료**) |
| 기본 연도 | 가장 최근 결과 영상 연도 | 같음 | 같음 | 같음 | 쓸 수 있는 첫 해 → 끝 해(두 해 비교) |
| 버퍼 | 0 m | 0 m | 0 m | 0 m | **50 m**(상한 1,000 m) — 화면 · 서버 같은 값 |
| 최소 면적 | 4 ㎡ | 4 ㎡ | 4 ㎡ | 4 ㎡ | 50 ㎡ · 경작 전환 200 · 식생 증감 300 |
| 표시 분류(기본 켬) | 둘 다 | 둘 다 | 전부 | 하나 | 4가지(식생 증감 끔) |
| 색 | 지금 `board.js` 색표 그대로 옮김 | 같음 | 같음 | 같음 | `change-layer.js` 색 4 → XI맵 색표에 **추가**(한 벌) |
| 셈 단위 | **필지** | **동** | **동** | **곳** | **건** |

- 공간축 **단계는 다섯 서비스 모두 같은 목록**(전국 · 시도 · 시군구 · 읍면동(법정동 기본 · 행정동 선택) · 대상지(구역선 안/밖)). 선언은 "기본으로 여는 단계"만 다릅니다. 그래서 경작·휴경도 대상지(예: 사업 구역선)로 셀 수 있고, 국토 변화도 읍면동으로 셀 수 있습니다.
- 상태축은 **큰 단계 3개가 공통**(미확인 · 현장확인 · 확인 끝) · 확인 끝 안의 결과 말만 서비스마다. 그래서 상태 칸은 어느 서비스든 막대 3개 + 한 줄.
- 선언이 없는 카드(곤포 · 토지피복 · 해양쓰레기 · 전국 분석)는 **빈 선언 기본값**(분류 = 결과 이름 · 단위 '건' · 상태축 없음)으로 돌아갑니다 — 서비스별 예외 코드 0.

### ②-2 집계 하나 — `/ximap/agg` 를 넓힌다 (새 길을 내지 않음)

| | 내용 |
|---|---|
| 입력 | `service`(카드) · `space`(nation · sido · sgg · emd · site) · `code`(지역 코드 또는 대상지) · `inside`(안 · 밖 · 전체 — site 일 때) · `years`(하나 또는 둘) · `state`(상태 거르기) · `off`(끈 분류) · `by`(class · space · state · year · area · time) |
| 출력(숫자 묶음 한 꼴) | `{service, unit, space:{level, code, name}, years, as_of, source, total:{n, area_m2}, rows:[{k, label, n, area_m2, in, out}], note}` — 숫자마다 지금 `env()`(값 · 단위 · 잰 것/추정/기록 · 출처) 그대로 |
| 세는 재료 | 서비스 결과 장부(결과 세트) + 전국 분석 + 실태조사 판정 + **변화 탐지 결과(장부에 등록된 것)** + 판정 표(`change_marks` · `survey_findings`) |
| 캐시 | 지금 그대로(60초 + 오래된 값 먼저 주고 뒤에서 새로 셈 2시간) + **결과 세트 · 판정이 바뀌면 그 서비스 · 지역 열쇠만 비움** |
| 누가 무엇을 | LX = 전국. 기관 = 관할 시군구(`_scope_sql` 과 같은 규칙) + **공유받은 대상지**. 관할 밖 숫자는 응답에 넣지 않음(0 으로 보이지 않고 칸이 없음) |
| 부르는 곳 | XI맵 판 · 크게 보기 · 한글/PDF 보고서(`xreport` · `change/report`) · 지도 서비스 보고서(`mapsvc`) · 기관 '통계·보고서' 탭 · ChatGEO 도구(`dash.py` · `ext/change.py`) — **전부 이 함수 하나**. 지금 다섯 곳은 얇은 호출로 줄이고 공식은 지운다 |

### ②-3 같은 판 — 지금 XI맵 통계 판을 공통 판으로 승격

3단계는 그대로(한 줄 → 판 → 크게 보기 → 보고서). **칸 순서 고정:** ⓐ 큰 숫자(수량 · 단위 · 기준) ⓑ 분류별 ⓒ 확인 상태(3단 + 한 줄) ⓓ 공간별(순위 · 지도 색 · 대상지면 안/밖 두 줄) ⓔ 해마다(연도 둘 이상일 때만) ⓕ 내려받기 4종. 서비스가 바뀌어도 칸이 바뀌지 않고 **글자만** 선언에서 바뀝니다.

| 맞지 않는 곳(조사 ⑥-3) | 고치는 것 |
|---|---|
| 상태 칸 없음 | ⓒ 칸 추가 — 선언의 상태축 3단 · 확인 끝 안 결과 말 |
| 공간축에 대상지 없음 | 지역 칩 옆 **'구역선 안 / 밖 / 전체'** 칩(site 일 때만 보임) · 공간별 표에 '밖 n' 보조 열 |
| LX 전용 | 기관 XI맵에도 같은 판(③ 추천) · 숫자는 관할 안만 · 집 이름 '기관 · 남원시' |
| 변화 결과를 못 읽음 | 장부 등록(②-2) 뒤 저절로 — 서비스 고르기에 '국토 변화' · 공간 기본 단계 = 대상지 |
| 단위 '개' | 선언 단위로(필지 · 동 · 곳 · 건) · 여러 서비스 합계 줄만 '건' |

**모든 화면 = 같은 판의 다른 보기:** 지도 서비스 층 보고서 = 판의 ⓐⓑⓓ 를 한글 문서로 · 기관 '통계·보고서' 탭 = 크게 보기 그대로(관할 안) · PDF/한글/엑셀 = 크게 보기의 칸을 순서대로 · ChatGEO 숫자 = 같은 함수의 `total` 과 `rows` 한 줄 말로. 어느 화면도 **더하거나 나누지 않는다**(비율도 서버가 준다).
