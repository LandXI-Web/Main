## 3. 화면 배치 규칙(원칙 309) — 자리 다섯 · 한 자리 하나 · 자동 검사

### 3-1. 규칙(법전 §6-1 초안 — 아래 §8 에 조문)

1. **떠 있는 요소의 자리는 다섯 개뿐.** ① 왼쪽 위 판(층 · 규칙 · 대조 · 보고서 — 300) ② 오른쪽 도구 열(96) ③ 오른쪽 기둥(서랍 392 / 지도 없는 화면은 오른쪽 칸 440) ④ 아래 가운데 대화(XI ChatGEO 입력 + 답 띠 · 280 ~ 680) ⑤ 왼쪽 아래 결과 카드(360). 떠 있는 요소는 이 중 하나를 **선언**한다(`data-zone`). 자리 없는 떠 있는 요소는 만들지 않는다.
2. **한 자리에는 하나.** 같은 자리에 둘째가 열리면 첫째는 닫히거나 한 줄로 접힌다. 오른쪽 기둥을 쓰는 것: 필지 카드 · 목록 · XI ChatGEO 대화 서랍 · 결과 설명 · 지도 위 통계 · 층 판(**층 판은 ①로 옮김** — 지금은 오른쪽에 떠서 서랍과 100% 겹침). 모달은 예외(뒤를 흐리게 · 동시에 1).
3. **대화는 틈에 선다.** ④는 ① ③ ⑤ 사이 가장 넓은 빈 틈의 가운데. 틈이 280 아래면 ⑤ 결과 카드 → ① 판 순으로 접는다. 답 띠 폭 · 글은 줄이지 않는다.
4. **지도 없는 화면의 대화창은 오른쪽 기둥의 서랍이다.** 대화 단추는 **레일 맨 아래**(기관 정보 · 계정 위)로 옮긴다. 누르면 K5 서랍(오른쪽 392 · 다른 서랍과 같은 스택)으로 열린다. 오른쪽 칸(필지 카드 440)이 고정된 화면에서는 필지 카드가 머리 한 줄로 접히고 그 아래 대화가 선다(같은 기둥 안 세로 나눔).
5. **휴대폰(≤ 640)은 아래 시트 하나.** ① ③ ④ 가 모두 아래 시트 하나로 모인다(높이 3단 · 접힘 · 반 · 전체 — 10-18 '아래 시트 세 높이' 시안의 높이 규칙만 가져옴). 지도 위에는 입력 한 줄(시트 머리에 붙음)과 도구 열만. ⑤ 결과 카드는 지도 왼쪽 위 한 줄 칩.
6. **검사로 막는다.** 굽기 전 · 배포 전 `node tools/check/all.mjs` 에 네 번째 검사 `overlap` — 떠 있는 요소 쌍이 4px 넘게 겹치면 불합격(0 이어야 통과).

### 3-2. kit 에 박는 법 — `kit/layout.js`(자리 관리자 · 새 파일 · kit 소유)


### 3-3. 자동 검사 — `kit/lint/overlap.mjs`(새 파일) + `tools/check/all.mjs` 네 번째

## 4. 필지 변동(병합 · 분할) — 자료 모델과 화면(원칙 311)

### 4-1. 사실
- 필지 번호(PNU 19자리)는 **분할**하면 본번은 남고 새 부번이 생기고(123 → 123 · 123-1), **합병**하면 흡수된 번호는 말소(폐쇄)된다. 지적 용어: **토지이동**(분할 · 합병 · 지목변경 · 등록전환 · 말소), 토지(임야)대장의 '토지이동 사유', 부동산종합증명서 '연혁'. 연속지적도(브이월드 · LX맵 편집지적)는 달마다 갱신된다.
- 우리 기록 중 **필지 번호에 붙는 것**: `parcel_notes`(메모) · `survey_findings`(실태조사 판정) · 필지 요약(계획 · OVERLAP 2단 `parcel_summary`) · 대장 행(ledger_rows 의 지번). **도형에 붙는 것**: AI 결과(detections · result_objects) — 필지 선을 따르지 않는다(OVERLAP 1-3 · 84%가 두 필지 이상에 걸침).
- 따라서 AI 결과는 필지가 바뀌어도 잃지 않는다(다시 교차하면 된다). 잃는 것은 **사람이 적은 것**(메모 · 판정)과 **해마다 비교**(작년 PNU ≠ 올해 PNU → 전이표에서 '신규 · 사라짐'으로 잘못 셈).

### 4-2. 자료 모델(마이그레이션 0116 안 · 이름은 안)

```
parcel_snapshots(pnu, sgg_cd, geom, jimok, area_m2, valid_from date, valid_to date null, src text)   -- 연속지적 월 갱신마다 바뀐 필지만 새 줄(바뀌지 않은 필지는 valid_to null 유지)
parcel_lineage(id, sgg_cd, kind text,            -- split 분할 · merge 합병 · renum 지번변경 · reg 등록전환 · close 말소
               at date, from_pnus text[], to_pnus text[], share jsonb,   -- share = {to_pnu: 종전 필지 면적 비율} (분할 때 메모 · 통계를 나눌 때 씀)
               src text, detected_at timestamptz)
```
- **잡는 법(자동 · ⓐ)**: 연속지적 새 벌을 받을 때(이미 있는 `survey_parcels` 갱신 작업기에 단계 하나) 사라진 PNU 집합과 새 PNU 집합을 도형 교차(≥ 1㎡ · 작은 쪽 10% 이상)로 묶는다 → 1→n 분할 · n→1 합병 · n→m 토지이동 정리 · 도형 같고 번호만 다름 = 지번변경 · 짝 없음 = 말소/신규. 판정은 `src='cadastre-diff'`.
- **보강(ⓑ · 뒤에)**: 기관이 지적전산 '토지이동 연혁' 파일을 올리면 `src='ledger'` 로 같은 표에 넣고 자동 판정을 덮는다(날짜 · 사유가 정확).
- **읽는 법**: `lineage_of(pnu)` = 그 PNU 를 to 또는 from 으로 가진 사건을 시간 역순으로 따라 **종전 필지 집합**과 **후속 필지 집합**을 돌려준다(재귀 CTE · 깊이 ≤ 5).

- 왜 감이 안 왔나: '오늘'이 무엇을 뜻하는지(배정? 알림?) 화면이 말하지 않는다. 실제 기능은 거르기 5개(읍면동 · 종류 · 대장과 다름 · 메모 없음 · 정렬)와 여러 필지 고르기다.
- 다시: 탭 이름 **필지 목록** 그대로. 거르기 줄 맨 앞에 **업무 묶음 칩 3**(한 번에 조건 묶음이 걸림 · 묶음 홈 대시보드 칸과 같은 조건 — 숫자 한 출처):
  - '직불 점검 대상' = 공익직불 신청 대장 올림 + 대장과 다름만
  - '휴경 의심' = 종류 비경작 + 지난해 경작(전이 있을 때만 칩이 생김)
  - '메모 없음' = 메모 없음만
  - 칩을 끄면 조건이 풀린다(제안-조건풀기한단추와 같은 단추).
- 큰 숫자 라벨은 조건에 따라 바뀐다('직불 점검 대상 249필지') — 지금처럼 'AI 분석 결과 필지'로 고정하지 않는다.
- 뺄까? — 기능(거르기 · 고르기 · 메모 일괄)은 남긴다. 빼는 것은 **이름 '오늘 볼 필지'와 하루 시작 자리(영농-S1)**: 하루 시작은 묶음 홈 '이번 달' 띠가 맡는다.

## 8. 디자인 법전 §6-1 조문 초안(system-v2.2-toss.md 에 넣을 글 — 사용자 확인 뒤)

> ### 6-1. 떠 있는 요소의 자리 — 겹침 0(2026-10-22 원칙 309 · 사용자: "겹치면 안 되는 기본 가이드에 담겨져 있을 건데 … 왜 계속 위반하는 거지?")
> 1. 지도 위 · 본문 위에 떠 있는 요소(서랍 · 카드 · 판 · 대화 입력 · 답 띠 · 시트 · 단추)는 **자리 다섯** 중 하나를 선언한다: 왼쪽 위 판 · 오른쪽 도구 열 · 오른쪽 기둥 · 아래 가운데 대화 · 왼쪽 아래 결과 카드. 자리 없는 떠 있는 요소는 만들지 않는다(`K.zone`).
> 2. **한 자리에는 하나.** 같은 자리에 둘째가 열리면 첫째는 닫히거나 머리 한 줄로 접힌다. 모달만 예외(동시에 1 · 뒤를 흐리게).
> 3. **대화(XI ChatGEO)는 틈에 선다.** 지도 화면에서는 다른 자리 사이 가장 넓은 틈(280 ~ 680)에, 지도 없는 화면에서는 오른쪽 기둥의 서랍으로. 틈이 모자라면 결과 카드 → 왼쪽 위 판 순으로 접는다. 답 띠는 줄이지 않는다.
> 4. **휴대폰(≤ 640)은 아래 시트 하나.** 왼쪽 위 판 · 오른쪽 기둥 · 대화가 시트 하나로 모인다(높이 3단). 지도 위에는 입력 한 줄과 도구 열만.
> 5. **검사.** `node tools/check/all.mjs`(overlap) 가 1280 · 1440 · 390 에서 떠 있는 요소 상자를 재어 4px 넘게 겹친 쌍이 있으면 불합격. 굽기 전 · 배포 전 0 이어야 통과. 새 떠 있는 요소를 만들면 검사 상태 목록에 그 상태를 더한다.
