- 플랫폼 지금 상태: 서버 DB 를 읽기 전용으로 조회(분석 서비스 13개 · 모델 32개 · 서비스 판 16개 · 작업 · 결과 건수), `server/adapters/*`, `server/change/*`

- 성능 출처: `results.csv` 최고 epoch, 체크포인트 안에 든 값, 플랫폼 고정 시험(`02. 데이터/models/eval/*.json`), 사업 보고 문서. 출처가 없으면 '기록 없음'
- 기존 대장: `recon-0924/ASSET-LEDGER.md`, `recon-1012/PYTHON-CODE-CLEANUP.md`, `recon-1022/CHANGE-DEMO-ORDER.md`
- 개인정보: 소유자 이름 같은 값은 옮기지 않음. 열 이름과 건수만 적음

표 읽는 법
- 성능 값 표기: mAP50(M) = 마스크 기준, mAP50(B) = 상자 기준. 학습 끝 검증값은 학습 자료와 같은 데서 뽑은 시험이라 실제보다 높게 나오기 쉬움. **'고정 시험'은 학습에 쓰지 않은 칸으로 따로 잰 값**
- 등록 상태: 운영 / 검토 / 준비 중 = 서비스 카드 상태(DB `cards`). 모델만 등록 = 모델 대장(`models`)에는 있으나 카드 판에 연결 안 됨. 미등록 = 플랫폼에 없음
- 준비도: **바로 카드 가능**(모델 · 성능 · 플랫폼 연결 다 있음) / **카드 껍데기만 필요**(모델 · 결과는 준비, 카드 · 판만 만들면 됨) / **검증 필요**(모델은 있으나 성능 근거가 약하거나 우리 영상에서 안 돌려 봄) / **학습 필요**(자료만 있음)

## 4. 이런 것도 필요하지 않을까요? (제안 — 채택은 사용자)
