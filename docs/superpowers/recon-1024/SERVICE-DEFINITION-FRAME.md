## ④ XI ChatGEO 가 정의를 쓰는 법

ChatGEO 는 카드마다 코드를 갖지 않습니다. **정의 장을 읽어 도구 부름을 조립**합니다.

| 단계 | 하는 일 | 예 "섬진강 하천구역 50m 안 건물" |
|---|---|---|
| 1 고르기 | 말에서 재료 층 · 범위 종류 · 도구 말을 찾아 **맞는 정의**를 고른다(업무 조합이 먼저 · 없으면 기본 탐지) | 건물 + 하천구역 → '하천구역 건물 점유' 정의 |
| 2 채우기 | 정의의 기본값에 말에서 나온 값만 덮는다(덮어쓰기 순서의 '이번 화면 조건' 층) | 범위=하천구역 '섬진강'(공유 범위 고르기) · 버퍼 50(기본 100 을 덮음) · 안/밖=안 |
| 3 부르기 | `범위_고르기 → 버퍼 → 안밖 → 필지별(켬이면) → 통계` 를 **같은 작업 장부**로 부른다. 결과 세트가 있으면 세고, 없으면 "이 범위는 아직 분석 전 · 분석 시작할까요"로 묻는다(원칙 320 · 사전 계산 없는 범위) | 섬진강 하천구역 결과 세트 있음 → 집계 |
| 4 답하기 | 통계 묶음의 `total` + 첫 분류를 한 줄로 · 지도에 층 + 대상지 · **같은 통계 판**(STATS ②-3) 을 열어 준다. 숫자는 더하거나 나누지 않음 | "섬진강 하천구역 50m 안 건물 n동(2024 영상 · 전부 점유 a · 일부 b) · 미확인 c" + 판 |
| 5 이어 묻기 | 꼬리 질문은 2 의 조건만 바꾼다("100m 로" · "구례군만" · "현장확인만") | 같은 결과 세트 · 다른 열쇠 → 다시 집계 |

- 정의에 **없는 조합**(예: "주차장 중 하천구역 안")은 기본 탐지 층 + 도구로 **답은 하되 저장하지 않습니다**. "이 조합을 카드로 저장"은 새 기능이라 ⑦ 질문 5 로 올립니다(원칙 323).
- 권한은 정의의 '누가' 칸을 그대로 — 기관 계정은 관할 밖 범위를 고를 수 없고, 답에도 관할 밖 숫자가 없습니다(칸 자체가 없음).
- 원칙 321(스스로 나아지는 틀)은 여기서 가볍게: 정의를 못 고른 말 · 덮어쓴 값은 대화 장부에 남기고, 주마다 LX 관리자 화면에 "자주 묻는데 카드가 없는 조합" 목록만 보여 줍니다(자동 반영 없음).
