# 서비스 정의 틀 — 기본 탐지 · 공통 공간 도구 · 업무 조합 (10-24 · 설계만 · 확정은 사용자)

> 사용자 10-24: "세 층 구조는 서비스 정의 틀을 설계한다."(원칙 334) · "너무 어렵게 설계 되었다 … 오른쪽은 영상 넣으면 바로 분석되는 1차원 구조, 고급 기능 모드 탭 … 부연 설명이 너무 많은건 지양한다."(원칙 335) · "기존 합의 했던 부분들 모두 뭉게고 다시 만드는게 너무 싫다."(원칙 336)
> 코드 · DB · 화면은 바꾸지 않았습니다. 시안은 **바깥 주소 실제 카드 상세(로그인 폼)에서 오른쪽 칸만 바꿔** 찍었습니다.

## 무엇이 바뀌나 (5줄)

1. 분석 서비스 하나 = **정의 한 줄**(재료 AI 층 · 켠 공간 도구와 기본값 · 규칙 · 통계 네 칸). 카드 · 지도 서비스 · 통계 판 · XI ChatGEO 가 이 줄을 읽어 그립니다.
2. 카드 오른쪽 '이 카드로 분석'은 **기본 = 영상 고르기(또는 업로드) → 분석 시작** 한 단계. 그 밖의 것은 없습니다.
3. **'기본 | 고급 기능'** 탭. 고급 기능 = 레이어 구간 분석(구역선 · 하천구역 파일 + 거리) · 행정지역 분석(시군구 · 읍면동) · 필지 단위 집계(켬/끔). 짧은 이름 + 조작 하나, 설명 글 없음.
4. 업무 조합 카드(예: 하천구역 건물 점유)도 **같은 화면**. 고급 기능에 그 카드의 레이어(하천구역 · 100m)가 미리 골라져 있을 뿐입니다.
5. 국토 변화에만 있던 범위 도구와 경작·휴경에만 있던 필지 대조는 **공통 도구**가 되어 모든 카드 · ChatGEO 가 같은 것을 씁니다. 숫자는 집계 한 곳(10-23 통계 틀)에서만.

## 부록 D. XI ChatGEO
