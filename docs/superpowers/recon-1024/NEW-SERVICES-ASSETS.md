### 1-4. 서비스 흐름(5줄)
1. **범위:** 관광지(관광정보 점 + 버퍼) 또는 기관이 그린 구역 · 둘레 주차장(표준데이터 점 + 항공 4분류 주차장 면)을 대상 범위로 정함
2. **영상:** 행사 · 주말에 드론을 시간대별로 2~3번 띄워 정사영상을 올림(춘향제 원본이 이 모양)
3. **AI 분석:** 차량 탐지 → 주차장마다 차량 수 ÷ 주차구획수 = **점유율** · 주차장 밖 도로 위 차량 수 / 사람 탐지 → 10m 격자마다 사람 수 → **㎡당 사람 수**
4. **판정:** 주차장 '여유 · 혼잡 · 만차', 격자 '보통 · 주의 · 위험'(기준값은 사용자 결정. 국내 연구 예: ㎡당 4~5명부터 압력 커짐 — [논문](https://www.koreascience.or.kr/article/JAKO202413848089120.pdf))
5. **결과:** 시간대별 격자 지도 · 주차장별 점유율 표 · 관광지별 보고서(축제 안전관리계획 첨부용)

### 1-5. 준비도
- **주차 혼잡도: 카드 껍데기만 필요** — 차량 모델 · 주차장 면 모델 · 범위 만들기 다 있음. 주차장 표준데이터를 받아 붙이고, 주차장 면 안 차량 세기(겹침 계산)만 새로 씀. 단 남원 밖 드론 영상 시험 기록 없음
- **인파: 학습 필요** — 사람 탐지 모델 없음. 춘향제 원본(4090)을 가져와 플랫폼 안 라벨링(수동부터 · 기반 모델로 초안)으로 사람 점 · 상자를 만들고 학습. AI 허브 182(드론 사람 상자)로 보강
- CCTV 판: 공개 기본 모델로 사람 수는 바로 나오지만 지도 좌표가 없어 '카메라 점 + 숫자'뿐 — 뒤로 미룸이 맞아 보임

### 1-6. 남은 질문
1. 첫 시험 지역을 남원 춘향제(2025-05-04 원본)로 해도 되는지 · 4090 #8(21.4GB)을 가져와도 되는지. 원본에 사람 라벨이 이미 있는지
2. 영상은 '행사 당일 드론 정사'로 정하는지(CCTV 는 빼는지)
3. 인파 등급(보통 · 주의 · 위험)과 주차 등급(여유 · 혼잡 · 만차)의 기준값을 누가 정하는지
4. 표준데이터에 없는 임시 주차장(행사용 공터)을 어떻게 셀지 — AI 가 찾은 주차장 면 넓이로 주차면 수를 어림할지

### 2-3. 서비스 흐름(5줄)
1. **범위:** 취약지구 면(기관 제공) 또는 지정현황 표(지번 → 필지 / 점 + 면적) + 버퍼(예: 50m)를 지구별 분석 구간으로 만듦
2. **영상:** 국토지리정보원 항공영상 두 해(예: 2021 · 2024)를 지구마다 자동으로 받음(기존 기능)
3. **AI 분석:** 피복 U-Net 으로 두 해 피복 → 지구 안 전이 계산. 새 유형: **산림 → 나지초지(훼손 · 붕괴 의심)** · **산림 → 도로(절개 · 임도)** · **산림 · 나지 → 건물(개발)**. 경사(선택)로 급한 곳 표시
4. **판정:** 지구마다 바뀐 넓이 · 비율로 '변화 없음 · 확인 필요 · 현장 확인 필요'(기준값은 사용자 결정)
5. **결과:** 지구 목록(지구명 · 유형 · 바뀐 넓이 · 판정) + 두 해 영상 견주기 + 보고서. 과거 산사태 이력과 겹치면 함께 표시

### 2-4. 준비도
- **카드 껍데기 + 유형 몇 개 추가로 1차 가능** — 영상 받기 · 피복 분류 · 범위 만들기 · 변화 계산 · 결과 화면이 국토 변화에 다 있음. 새로 할 일: 산림 전이 유형 3개(지금 '식생 증감'은 숨김) · 지구별 집계 · 카드
- **막혀 있는 것 = 취약지구 레이어.** 공개로는 점 · 지번 표가 시군 · 도 단위로 흩어져 있고, 전국 경계 면은 기관 요청이 필요함
- 약한 곳: '나지'가 '기타 · 불확실'과 한 묶음이라 산림 → 나지 변화에 그림자 · 계절 차 오탐이 섞일 수 있음 → 첫 지역에서 사람이 보고 기준을 정해야 함. U-Net 은 우리 고정 시험이 없음
- 2단계(선택): AI 허브 71363(이미 받음) 산사태 · 벌목지 라벨로 직접 찾는 모델 — 해상도(0.5m · 10m)가 달라 시험 학습부터

### 2-5. 남은 질문
1. 취약지구 레이어를 **서비스 기관(산림청 · 시군)이 올리는 방식**으로 할지, 공개 지정현황 표(점 · 지번)로 먼저 시작할지
2. 첫 시험 지역(남원 · 지정현황 표가 공개된 고양 · 경남 등)
3. 두 해 간격(국토지리정보원 영상은 1년 1회라 '우기 전 · 후' 비교는 안 됨 — 드론 영상을 함께 받을지)
4. 경사를 쓸지(쓰면 30m 공개 지형으로 시작 · 정밀 지형은 신청)
5. 판정 기준값(예: 지구 안 산림 → 나지 몇 ㎡ · 몇 % 부터 '현장 확인 필요')

## 4. 이런 것도 필요하지 않을까요? (제안 — 채택은 사용자)

1. **불법 주정차 지도(관광지 판)** — 주차장 면 밖 도로 위 차량을 따로 셈. 교통 · 주차 부서가 행사 당일 단속 위치를 정할 때 씀(지자체 교통과)
2. **축제 안전관리계획 첨부 보고서** — 재난안전법상 순간 최대 1천 명 넘는 축제는 개최 3주 전 안전관리계획을 냄. 지난해 같은 축제의 시간대 격자 · 주차 점유율을 한 장으로 뽑아 주면 계획서에 바로 붙음(지자체 안전 · 관광 부서)
3. **취약지구 밖 '새로 위험해진 곳' 목록** — 산림 안 새 절개지 · 임도 · 나지를 지구 밖에서도 찾아, 다음 해 취약지구 지정 실태조사 후보로 넘김(산림청 · 시군 산림 부서)
4. **과거 산사태 이력으로 판정 맞추기** — 산림청 발생 이력 API 의 지점과 우리 '현장 확인 필요'가 얼마나 겹치는지 보면 기관에 정확도를 말할 근거가 생김(LX 직원 · 영업)
