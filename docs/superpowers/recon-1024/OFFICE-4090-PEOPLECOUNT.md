# 사무실 4090 지시서 — 춘향제 사람 계수 자산 분석 · 가져오기 준비 (2026-10-24)

> 이 지시서를 사무실 4090 의 Claude Code 에 그대로 붙여 넣는다.
> 목적: `D:\python\peoplecount` 를 빠짐없이 분석해, A6000(Land-XI 서버)으로 옮길 **정사영상 · 학습데이터 · 학습 모델**을 찾아 한 폴더에 모으고 확인 기록을 남긴다.

## 지켜야 할 것
1. **원본은 읽기만.** 옮기기 · 지우기 · 이름 바꾸기 · 덮어쓰기 금지. 모을 때는 **복사만** 한다.
2. **개인정보.** 사람 얼굴이 찍힌 사진이다. 사진 · 그림을 대화창에 띄우거나 미리보기 · 썸네일을 만들지 않는다. 인터넷 · 외부 서비스로 올리지 않는다.
3. **GPU 를 쓰지 않는다.** 모델은 파일 정보와 학습 기록만 읽는다(다시 돌리지 않음).
4. 확실하지 않은 것은 추측하지 말고 '확인 필요'로 적는다.

## 1. 폴더 전수 분석
`D:\python\peoplecount` 아래 모든 폴더 · 파일을 훑어 아래를 표로 정리한다(하위 폴더마다 개수 · 크기 · 날짜 범위).

| 찾을 것 | 알아낼 것 |

| **정사영상**(.tif · .tiff · .ecw · .jp2) | 파일 이름 · 크기 · 촬영 시각(이름 · 메타데이터) · 좌표계(EPSG) · 해상도(cm) · 범위(경위도) · 몇 시간대(1차 · 2차 · 3차 비행) |

| **라벨 원본** | 라벨링 도구 파일(json · xml · shp · csv) · 사람 수 합계(라벨 수) |
| **학습 모델** | `best.pt` · `last.pt` · .onnx 경로 · 크기 · 날짜 · 모델 종류(yolo 버전 · 탐지/분할/점 계수) · 클래스 |
| **학습 기록** | `results.csv` 마지막 줄(mAP50 · mAP50-95 · precision · recall) · `args.yaml`(epochs · imgsz · 바탕 모델) · 검증 그림은 열지 말고 파일 이름만 |
| **추론 결과** | 사람 수 결과(csv · geojson · shp) · 격자 밀도 결과 · 시간대별 합계 |
| **코드** | 학습 · 자르기 · 추론 · 계수 스크립트(.py · .ipynb) 이름과 하는 일 한 줄 |
| **원본 사진** | `LX\원본사진` 장수 · 크기 · EXIF 촬영 시각 범위 · 비행 구분(시간대) · GPS 유무 |
| 그 밖 | 보고서 · 발표 자료 · 설명 문서 이름 |

## 2. 가져올 것 고르기
아래 우선순위로 **옮길 목록**을 만든다(경로 · 크기 · 이유).
1. 학습에 쓴 **정사영상**(시간대별 전부)
2. **학습데이터** 묶음(images · labels · data.yaml) — 마지막으로 학습에 쓴 판
3. **가장 좋은 모델** `best.pt` + 같은 실행 폴더의 `results.csv` · `args.yaml`

## 3. 모으기 · 검증
- 옮길 것을 **외장 디스크** 의 `LANDXI-TRANSFER-peoplecount-20261024\` 에 **복사**한다(폴더 구조: `ortho\` · `train\` · `model\` · `labels\` · `results\` · `code\` · `raw\`(선택)).

- 디스크 남은 자리가 모자라면 우선순위 1~3 만 먼저 담고 나머지는 목록으로만 남긴다.
