## 1. 한 장 요약
- 분석 서비스(내 영상 올리기 → 분석 → 지도 서비스에서 보기)는 **직원 혼자 끝까지 된다**(1분 안에 결과 · 올리기 안내 · 중복 · 해상도 거름 모두 좋음).
- 프로젝트 1~6단계 화면은 **다 있고 직원이 혼자 걸을 수 있게 만들어져 있다.** 그러나 **걸은 뒤에 관리 · 정리 · 알림 · 비교 · 설명이 비어 있다.**
- 가장 큰 구멍 셋: ① 내가 돌린 작업의 상태 · 취소 · 실패 이유가 분석 서비스에는 없음(원칙 320 중 절반만) ② 결과끼리 비교가 없음(원칙 329 의 '비교 분석') ③ 올린 영상 · 프로젝트 · 결과를 직원이 지우거나 고칠 수 없음.

## 3. 에이전트(Claude)가 대신 해 주고 있는 것 — 직원이 스스로 못 하는 단계
(원칙 327 기준. 코드 · 장부에서 보이는 것만.)
1. **학습데이터 준비**: 건축물 · 주차장 · 곤포사일리지 · 비닐하우스 묶음(60~200장)은 스크립트로 만들어 올려 둠(`P4-RESULT` 의 '경작지 묶음 스크립트'). 직원 화면 길로는 YOLO zip 만 올릴 수 있어(#7) 같은 일을 직원이 하려면 변환 도구가 없다.
2. **전국 분석 · 국토 변화 담양IC 판**: 달력 '전국 분석 2025년 영상 · 농지 전수 …개 읍면동'은 작업 흐름으로 돌린 것. 직원이 같은 일을 하는 길은 지역별 '분석 시작'뿐이고 **전국 · 여러 지역 한 번에는 화면 없음**(분석 서비스는 지역을 하나씩 고름).
3. **XI ChatGEO 가 돌리는 분석**: 정식 작업 장부에 넣도록 고쳤다고 하나(원칙 320) 직원 화면 '내 작업'에 모이는 곳이 없어 확인할 수 없음(#11).
4. **클래스 · 규칙 · 대장 형식**(결과를 '의심 필지'로 바꾸는 규칙): 직원 배포 신청서에는 '대장 형식 선택'만 있고 규칙을 직원이 만드는 화면은 못 찾음(서버 `survey/rules` 쪽).

## 6. 사용자에게 올릴 '이런 것도 필요하지 않을까요?'(원칙 57 — 근거 포함)
- **전국 · 여러 지역 한 번에 분석**: 지금 직원은 지역을 하나씩 골라야 하는데 전국 단위 업무(농지 전수 등)가 주 업무. 누가: 직원 · 왜: 반복 · 실수.
- **분석 서비스 안에서 '내 영상 여러 장 · 두 시점'**: 국토 변화만 두 시점. 경작 · 휴경은 영농기 2시점이 조건인데 내 영상은 한 장만 받음.
- **같은 영상 · 같은 범위 다시 분석(모델 새 판으로)** 한 번에: 모델이 새로 승인되면 지난 분석을 새 판으로 다시 돌리는 단추.
- **프로젝트 '요약 한 장'**(올린 영상 수 · 라벨 수 · 학습판 · 결과 · 신청 상태): 프로젝트 첫 화면이 '다음 할 일'만 있고 현황이 없음(`07-project-detail.png`).
