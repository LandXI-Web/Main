## 1. 지금 화면이 지어진 모양(조사)

| 무엇 | 지금 | 한 페이지로 옮길 때 걸리는 점 |
|---|---|---|
| 화면 단위 | 화면마다 폴더 하나 — `index.html`(모양 · 지도 엔진 싣기 · 몸 표시) + `app.js`(모듈) | 모듈은 한 번만 실행된다 → 화면 코드를 '다시 부를 수 있는 함수'로 감싸야 한다 |
| 시작 | `app.js` 맨 위에서 `await K.gate()`(로그인 확인) → `K.shell()`(머리줄 · 왼쪽 메뉴 · ChatGEO · 업로드 상태) → `S.main` 에 화면 | 셸이 화면마다 새로 세워진다 → 한 번 세운 틀을 다음 화면이 그대로 받아야 한다 |
| 창 · 문서에 건 것 | `addEventListener('resize' · 'keydown' · 'lx:upload-done' …)` · `setInterval`(목록 30초 다시 받기) · `ResizeObserver`(칸 크기) · 부품(dashgrid · panes · colors · swipe)도 같음 | 페이지를 닫지 않으므로 화면을 떠날 때 떼지 않으면 쌓인다(새는 것) |
| 지도 | `kit/stage.js` → `xi/engine/lx-map.js createMap`(MapLibre) — 지도 서비스 · 분석 서비스 카드 | 떠날 때 `map.remove()` 를 하지 않으면 그림판(WebGL)이 남는다(브라우저 한도 약 16개) |
| 점검 손잡이 | `window.__lm`(지도 서비스) · `__lxProject` · `__lxConsole` · `__lxChange` | 다음 화면이 지난 손잡이를 잡지 않게 지워야 한다 |
| 주소 값 | 대부분 화면 코드 안에서 읽음. 단 **`lx-project/context.js PID` · `kit/change-layer.js Q` 는 모듈을 불러올 때 한 번** | 그 둘은 주소가 바뀌어도 그대로 → 프로젝트 한 장(?project=) · 단계 화면은 2단계에서 고친다 |
| 모양(css) | 화면 폴더 css(`la-` · `lm-` · `ld-` · `lxp-` 접두어) + kit css. 첫 그림 가리개 `body.la-boot .k-app{visibility:hidden}` | 화면 css 를 켜고 끄고, 가리개는 새 페이지일 때만 |
| 바깥 관문 | `tools/public-gate.mjs` 가 모듈 · 모양 주소에 파일마다 판 번호(`?v=`)를 붙여 내준다 | 쓰는 도중 파일이 바뀌면 새 판 모듈이 따로 불린다 → 새 판 화면은 페이지를 새로 열어 연다 |
| 업로드 | 따로 열리는 업로드 창(`landxi/v3/upload/`)이 파일을 쥐고 보냄 · 다른 화면은 BroadcastChannel 로 진행만 봄 | 한 페이지면 이 페이지가 직접 올려도 메뉴를 옮길 때 멈추지 않는다 |

## 2. 라우터(주소 ↔ 화면) — `landxi/v3/kit/spa.js`

- **주소는 지금 그대로**: `/landxi/v3/lx-map/?job=…` 같은 주소를 그대로 쓴다. 새로 고침 · 바로가기 주소 · 즐겨찾기 = 그 폴더의 `index.html` 이 열리고 같은 화면이 뜬다(서버 바꿈 없음).
- **길 하나**: 브라우저의 navigate 사건(Navigation API · Chrome · Edge) 하나로 링크 · 화면 코드의 `location.href` · 뒤로 · 앞으로 · '다시 시도'(`location.reload()`)를 모두 받는다. 주소 기록은 `history` 그대로(뒤로 = 앞 화면). 이 사건이 없는 브라우저는 링크 누름 + `popstate` 로(같은 동작).
- **표(ROUTES)**: 한 페이지로 여는 화면 · 그 주소를 한 페이지로 열 수 있는지(`ok(url)`). 표에 없거나 `ok` 가 아니면 예전처럼 페이지를 새로 연다(대체 길).
- **화면을 처음 열 때**: 그 폴더 `index.html` 을 한 번 받아(이후 기억) 모양 · 지도 엔진 · 제목 · 몸 표시를 읽고 모듈을 불러온다. 첫 화면이 다 그려지면 쉬는 틈에 나머지 화면을 미리 받아 둔다 → 첫 메뉴 바꿈도 빠르다.
- **판 번호가 바뀌면**: 불러온 화면이 다른 판의 라우터에 등록되면 그 화면은 페이지를 새로 열어 연다(섞인 판 0).
- 화면 코드 안의 주소 고침(목록 거르기 `?scope=` · 국토 변화 `?change=` 등 `replaceState`)은 화면 바꾸기로 보지 않는다.

## 3. 화면 계약 — mount / unmount

```
export async function mount(host, params) { …지금 화면 코드 그대로… ; return (선택) 정리 함수 }
screen(import.meta.url, mount);          // 맨 끝 한 줄 — 처음 열린 화면이면 틀을 세우고, 아니면 등록만
onLeave(fn)                              // 화면 코드가 직접 정리할 것(점검 손잡이 지우기 · 다른 부품에 준 지도 놓기)
```
- **감싸기만**: 지금 `app.js` 의 import 아래 전부를 `mount` 안으로 옮긴다(들여쓰기 그대로 · 화면 코드 고침 거의 0). `K.gate()` 는 기억된 답을 바로 주고, `K.shell()` 은 한 페이지에서는 이미 선 틀을 돌려준다(메뉴 불만 옮김).
- **떼어 내기는 라우터가**: 화면이 열려 있는 동안 창 · 문서에 건 듣기 · `setInterval` · 50ms 넘는 `setTimeout` · 관찰자(Resize · Mutation · Intersection) · 지도를 적어 두었다가 떠날 때 모두 뗀다. **누가 걸었나 = 호출 자리**: 화면 폴더 코드가(직접 · 부품을 거쳐) 건 것만 화면 것, 살아 있는 부품(셸 · ChatGEO · 업로드 · 알림 · 로그인 시계 · 가운데 창 · 서랍)이 건 것은 그대로 둔다.
- 떠날 때 함께: 열린 가운데 창 · 서랍 닫기 · 가운데 '불러오는 중' 놓기 · ChatGEO 의 지도 손잡이 놓기 · 판 비우기 · 머리줄의 화면 칸 · 신선도 점 숨기기 · 몸(body) · 문서(html)에 화면이 더한 표시 되돌리기.

## 4. 모양(css)

- 화면 `index.html` 에 적힌 **화면 폴더 css 만** 켜고 끈다. 끈 것은 `media="not all"`(받아 둔 채 적용만 안 함 → 다시 올 때 즉시). kit css · 지도 엔진 css · 화면 코드가 스스로 붙인 css 는 늘 켜 둔다(모두 접두어가 있어 서로 겹치지 않음).
- 새로 붙이는 css 는 `index.html` 순서대로 끼운다(kit.css 와의 앞뒤가 새 페이지와 같다).
- 첫 그림 가리개(`la-boot` · `lm-boot`)는 새 페이지일 때만 — 틀이 이미 그려져 있으므로.

## 5. 살아 있는 틀

머리줄(이름 · 로그인 시계 · 내 정보 · ? · 나가기) · 왼쪽 메뉴(요청함 숫자 1분마다) · **업로드 상태(머리줄 '업로드 중' + 상태 창)** · XI ChatGEO(대화가 이어짐) — 한 번 세우고 화면이 바뀌어도 그대로. 화면이 `K.shell()` 을 부르면 메뉴 불 · ChatGEO 화면 이름만 바꾼다.

## 6. 업로드

- 한 페이지 틀이 서면 이 페이지가 직접 올린다(`kit/uploads.js mountUploads({ inPage: true })`) — 따로 열리는 업로드 창 없음 · '업로드 시작'을 누르면 바로.
- 업로드 창이 이미 열려 있으면 그 창이 계속 맡고 이 페이지는 진행만 본다(올리는 곳은 하나 — Web Locks).
- **아직 바꾸지 않은 화면으로 갈 때**(요청함 · 데이터 올리기 · 학습 …): 그 누름 안에서 업로드 창을 열어 올리던 파일을 넘기고(BroadcastChannel 로 파일 그대로 · 받은 자리부터) 간다. 팝업이 막혔으면 '이 화면에서 업로드가 멈춥니다 · 팝업 허용' 알림.
- 탭을 닫거나 새로 고치면 멈춘다(브라우저가 나가시겠습니까를 묻는다 — MYBOX 와 같음). 다시 열면 상태 창에 남아 '이어서 업로드' → 받은 자리부터.

## 7. 새는 것 점검

- `window.__spa.leak()` — 창 · 문서 듣기 수 · 타이머 · 관찰자 · 지도 · 캔버스 · 요소 수 · JS 메모리(MB).
- 시험: 네 화면을 50번 넘게 돌고 처음 · 끝을 견준다. 지도는 지도 서비스를 떠나면 0 이어야 한다.

## 8. 역할마다 앱 하나

| 앱 | 화면 | 첫 화면 | 비고 |
|---|---|---|---|
| LX 직원 | 대시보드 · 프로젝트 · 분석 서비스 · 지도 서비스 · 요청함 · (프로젝트 안) 데이터 올리기 · 학습데이터 구축 · 학습 · 추론 · 결과 확인 · 배포 신청 | `lx-console` | 1단계 시범 = 앞 넷 |
| LX 관리자 | 대시보드(ops-core) · 인프라 · 공유 데이터 · 배포(ops-infra · 이미 탭은 `#/…` 로 한 페이지) · 계정(ops-accounts) | `ops-core` | **공유 데이터 업로드가 있는 곳(사용자 지적의 출발) — 2단계 첫 대상** |
| 기관 | 서비스 고르기 · 묶음 · 지도 서비스 · 보고서 · 요청 · 공간 · 계정 | `gov-select` | 업로드는 기관에 없음 · 3단계 |

- 앱 사이(직원 ↔ 관리자 ↔ 기관)는 계정이 다르므로 페이지를 새로 연다. 같은 표(ROUTES)에 앱 이름을 붙여 다른 앱 화면은 한 페이지로 열지 않는다.
- XI맵(xi-clean)은 화면 가득 지도 두 장 · 일꾼(worker) · 큰 상태가 있어 마지막 — 그때까지 XI맵으로 가면 페이지를 새로 연다(업로드는 업로드 창으로 넘김).

## 9. 옮기는 차례(화면 하나씩 · 대체 길 유지)

| 차례 | 화면 | 할 일 | 어림(에이전트 작업) |
|---|---|---|---|
| 1 ✓ | 직원 대시보드 · 프로젝트 목록 · 분석 서비스(목록 · 카드) · 지도 서비스 | 감싸기 · 국토 변화 층 붙이기/떼기 | 시범 끝 |
| 2 | 관리자 ops-core · ops-infra · ops-accounts | 감싸기 · 셸 메뉴(관리자) · 해시 경로(#/…) 그대로 | 반나절 |
| 3 | 직원 요청함 · 서비스 카드(lx-cards) · 배포(lx-release) | 감싸기(전역 적음) | 2~3시간 |
| 4 | 프로젝트 한 장 · 단계 화면(lx-ingest · lx-train · lx-review · lx-deploy) | `context.js PID` 를 주소에서 그때그때 읽게 · 단계 줄(S.sub) 붙이기/떼기 · lx-train 2,970줄 | 1~1.5일 |
| 5 | 기관 화면 묶음 | 기관 셸 · 기관 메뉴 · gov-fusion 3,200줄 | 1~1.5일 |
| 6 | XI맵(xi-clean 6,500줄 · 전역 64곳) | 지도 두 장 · 일꾼 · 재생 정리 | 2일 |

화면마다: 감싸기 → 50번 돌기 새는 것 0 → 겹침 · 낱말 · 숫자 검사 → 바깥 주소 그림. 바꾸지 않은 화면은 언제나 페이지를 새로 여는 길이 살아 있다.

## 10. 시험

- 지금 검사 문(`tools/check/gate.mjs` — 겹침 · 낱말 · 숫자 · 글꼴)은 그대로(주소로 여는 화면 = 같은 틀).
- 더하는 것: **메뉴 바꿈 시간**(누름 → 새 화면 첫 그림 · 자료까지 — `__spa.times`) · **새는 것**(50번 돌기 — `__spa.leak()`) · **같은 모양**(메뉴로 연 화면 ↔ 주소로 연 화면 그림 견주기) · **업로드 계속**(큰 파일을 올리며 메뉴 돌기 · 한 페이지 밖으로 넘기기) · 뒤로 · 앞으로 · 새로 고침 · 바로가기 주소. 스크립트 = `impl-46/spa-pilot/{smoke,shots,upload}.mjs`.

## 11. 위험 · 막는 법

| 위험 | 막는 법 |
|---|---|
| 화면 코드가 떠난 뒤에도 늦게 도는 일(느린 자료가 떠난 뒤 도착) | 떠난 화면의 판은 이미 떼어져 보이지 않음 · 그때 건 타이머 · 지도는 다음 떠날 때 함께 정리 |
| 호출 자리로 '누가 걸었나'를 못 알아보는 것(부품 안에서 늦게 건 것) | 50번 돌기 새는 것 시험이 잡는다 · 걸리면 그 화면에 `onLeave` 한 줄 |
| 모듈 머리에서 주소를 한 번 읽는 파일(PID · change-layer) | 그 주소 꼴은 표에서 빼 두었다가(대체 길) 고친 뒤 넣는다 |
| 다른 에이전트가 같은 화면 파일을 고침 | 감싸기는 위 · 아래 몇 줄만 바뀐다 · 화면 코드 본문은 그대로 |
| 팝업이 막힌 브라우저에서 한 페이지 밖으로 갈 때 | 알림 + 그 업로드는 멈춤(다시 오면 '이어서 업로드') |
| Navigation API 없는 브라우저(파이어폭스 등) | 링크 누름 · popstate 로 같은 동작(화면 코드의 `location.href` 만 페이지를 새로 엶) |
