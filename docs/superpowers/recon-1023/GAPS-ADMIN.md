## 조사 방법
- https://app.land-xi.dev 에 lxadmin@lx.or.kr 로 로그인 폼으로 들어가(세션 주입 없음), 메뉴 8개(현황 · 인프라 · 기관 · 배포 · 요청 관리 · 검토 요청 · 계정 관리 · 공유 데이터)와 그 안의 탭을 전부 눌러 보았다. 승인 · 삭제 · 공유 같은 실제 변경은 누르지 않았다.
- 서버 `server/landxi_api/*.py` 의 주소 목록을 화면 코드 `landxi/v3/ops-*`, `lx-*` 가 부르는 주소와 맞대어, 서버에만 있고 화면이 없는 것을 찾았다. 도구 폴더 `server/ops`, `server/change`, `server/config` 의 스크립트와 설정 파일도 본다.
- 그림(내 컴퓨터에만 저장, 커밋 안 함): `docs/superpowers/final/process/impl-46/gaps-1023/admin/` (00~32번)

## 중요도 상위 10 (관리자 일을 막는 순)
1. **새 기관 만들기 + 관할 + 첫 계정(1·2·3)** — 지금은 Claude 없이는 새 기관이 하나도 안 생긴다. 원칙 327의 핵심.
2. **실패 · 멈춘 분석 다시 돌리기 · 취소 · 이유(8)** — 서버는 준비됨, 화면 연결만 빠짐. 가장 싸고 효과 큼.
3. **전체 작업 목록(9)** — 8번과 한 묶음. "왜 안 나오지?"에 답하는 첫 화면.
4. **밖에서 학습한 모델 등록(6)** — 원칙 329 · '이미 학습된 모델은 분석 서비스에서'를 실제로 받치는 입구.
5. **관리자 모델 장부 + 판 비교 + 내리기(5·7·23)** — 승인 전에 비교하는 곳이 없다.
6. **감사 기록 한 곳에서 보기(14)** — 공유 · 승인 · 삭제의 '누가 언제'.
7. **기관 공지(15)** — 기관에 알릴 길이 없다.
8. **GPU · 동시 작업 설정과 화면 글 바로잡기(10)** — 글이 실제 규칙과 달라 즉시 고칠 수 있음(S).
9. **저장 공간 정리 화면(12)** — 여유가 줄 때 쓸 도구. 자동 정리는 이미 돈다.
10. **기관 한도와 사용 기록 내려받기(13·27)** — 사용자가 '보기만'인지 '막기'인지 먼저 정해야 함.

정식 오픈 때로 미룰 수 있는 것(원칙 314): 17(백업 되살리기 화면), 20(바깥 메일), 21 일부(사람별 비밀번호), 25(재부팅 자동 시작), 14의 '감사 기록 잠금'.
