# PLATFORM-EVAL — F2 2차 통합 뒤 플랫폼 종합 평가 (2026-09-27 · Fable 5.1)

- 판정 자료: 평가관 2인 결과(직접 기동 · Playwright · API·에이전트 직접 호출 · 영상 스틸 8장) · 에픽 7건 Craft 판정(F2-A/B/S/E/C/D/R) · 통합 보고(112.3 s 영상 · e2e 894/10/51 · 커밋 8) · 내 추가 확인 2건(아래 §0.1).
- 기준: 사용자 5축 **완성형 · 유일함 · Hyper Solution · Hyper Performance · 관리-생산-서비스 일원화** + 세 사용자(공무원 · 시민 · LX 직원) '우와'. 우선순위 **기능 · 퍼포먼스 · 서비스 · UI/UX**. 행정·조달 항목은 이 문서에 넣지 않는다.
- 결론 한 줄: **F2는 '완성형 시연 경로'다. 플래그십 한 줄기(프레임 → GPU 실추론 → 필지·대장 대조 → 배정·보고서 → 관제·롤백)는 같은 id로 실제로 관통하며 국내외 어느 경쟁 서비스에도 없는 장면이 됐다. 그러나 처음 쓰는 사람이 정문(로그인)으로 들어오면 그 장면에 닿지 못한다. 3차의 일은 새 기능이 아니라 이 간극을 닫아 한 제품으로 보이게 만드는 것이다.**

### 2.4 증빙 정확성(정직 항목)

- 통합 보고의 황등 job(…6XBQ… · 29.3/17.8 s)과 영상 속 job(…TE7Q0HQ3 · 29.5/17.7 s)은 다른 촬영분. F2-A 결과 문서 §2 표도 재녹화 전 작업을 실었다가 정정됐다. → 3차부터 **결과 문서 수치는 `marks.json`에서 생성**(손으로 옮기지 않는다).
- HUD 'p95 16.8 ms'는 rAF 간격(60 Hz 수직동기)이라 성능 지표가 아니다 → 공개판에서 제거, LX 직원 HUD에서는 '프레임 간격'으로 이름을 바꾼다.
- 평가 시작 시 게이트웨이 :8700이 내려가 있었다(보고서 '전부 정상'과 불일치). `-Restart all`이 워커 기동에서 멈추고 GPU 워커가 둘 뜬 사례 2회.
- F2-B 판정관은 313 s 무편집 실시간 녹화로 재현했고, 영상 편집에 '21 s 건너뜀'이 있다 — 건너뜀 자막은 유지하되 3차 영상은 무편집 구간을 따로 첨부한다.

## §4. 3차 제안 — F3 "한 제품 · 처음 쓰는 사람의 길"

원칙 셋.
1. **판정 경로 = 처음 쓰는 사람의 길.** 3차 통합 영상과 모든 게이트는 정문 로그인에서 시작한다. 녹화 스크립트의 세션 주입은 금지한다. 세션을 심어야 나오는 장면은 없는 장면이다.
2. **숫자는 한 출처.** 화면에 찍히는 모든 수는 `/results` · `/survey/stats` · `/registry` · `/jobs` · `/ops` 봉투에서 온다. 시연 고정값은 폐기하거나 `시연` 꼬리표를 달고 레일 밖으로 나간다. 결과 문서 수치는 `marks.json`에서 생성한다.
3. **새 기능보다 닫기.** 3차의 새 화면은 현장 PWA 하나다. 나머지는 이미 있는 장면을 정문에서 닿게 만들고 하나의 언어로 묶는 일이다.

## §6. 정직 항목 — 이 평가가 재지 않은 것

- 나는 통합 영상과 서버를 이번에 직접 재기동·재측정하지 않았다. 수치는 두 평가관과 에픽 판정관의 독립 실측을 인용했고, 내 손으로 확인한 것은 §0.1의 두 건(인증 호출 0 · 시연 꼬리표 27 파일)뿐이다.
- 두 평가관의 점수 차(완성형 6 vs 4 · 일원화 8 vs 5)는 A가 '플래그십 경로 안'을, B가 '정문에서 시작하는 길'을 판정했기 때문이다. 종합 점수는 B의 기준(처음 쓰는 사람)을 채택하되 A가 재현한 실측을 그대로 인정했다.
- F2-A/E/C/D의 must_fix 반영은 통합 보고의 주장이며 재게이트 전이다. F3-∑ 첫 작업으로 둔다.
- 남원 외 지역 · 국가 단위 처리량 · A100×8 확장은 아직 어떤 화면에서도 실측되지 않았다. 3차 F3-P가 실증하기 전까지 '전국 단위 실시간'은 설계 목표이지 증명이 아니다.
