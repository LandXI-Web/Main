# F2-D 보고 — Land-XI Global v2 (3차 재작업)

상세 근거는 `F2-D-result.md`에 있다. 판정 영상은 `shots/f2/D/f2d.mp4`다. 길이는 72.5 s이고, on 모드(실 게이트웨이와 CPU 워커 NDVI 8칸 실도착)에서 빈 캐시로 찍었다. 영상에서 잘라 낸 구간은 작업 대기 한 곳뿐이다. 사본은 `shots/f2/F2-D/`에 있다.

|---|---|
