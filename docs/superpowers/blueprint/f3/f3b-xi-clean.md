## 3. 전국 구조(남원은 예시)

- 도착은 전국(z7.2, V-World 위성)에서 시작해 관내 전역으로 내려온다(2,400ms).
- LX 계정에서는 마스트의 지역 버튼을 누르면 전국 시군구 경계(`sigungu`, 252개)가 켜진다. 거기서 시·군·구를 누르면 그 지역이 선택된다.
  - 결과가 있는 지역(코드 `52190`, 남원)을 누르면 관내로 돌아간다.
  - 결과가 없는 지역(예: 익산 `52140`)을 누르면 그 경계를 흰 선으로 두르고 카메라가 이동한다. 숫자 · 결과 층 · 결과 도구는 거둔다. 오른쪽에는 빈 상태 카드가 뜬다: 국토위성 캐릭터, "첫 결과 전 · 익산시 · 영상 반입 필요", 문장 1개, LX 직원에게만 `생산 콘솔에서 반입 →` 링크 1개.
- 기관 계정에서는 관할이 곧 지역이라 지역 버튼이 고정 표기로 바뀐다.
- 지역을 늘리는 방법은 그대로다. 시군구 코드와 실태조사 필지 타일을 잇는 한 줄(`SURVEY_TILES`)만 추가하면 된다.

## 5. 정직 항목

- 도착 시간은 헤드리스 Chrome의 보이는 탭에서 잰 값이다. 숨김 탭에서는 브라우저가 rAF를 멈추므로 판정 때의 86–117초 같은 값은 여기서 제어할 수 없다.
- 영상은 두 구간을 자르고 1.52배속한 편집본이다(원본은 33.8초). 로그인 폼은 영상 녹화 중에 실제로 입력했다.
- SSE 503 시험은 라우트 가로채기로 만든 조건이다. 이 경우 브라우저 콘솔에는 네트워크 503 줄이 남는다. 코드 예외는 없다.
- 결과가 없는 지역의 경계 상자는 전국 축척에서 렌더된 시군구 조각을 합쳐 잡는다. 저해상 경계라 가장자리가 수십 m 어긋날 수 있다.
- 빈 상태의 반입 링크는 콘솔로 이동만 한다. 쓰기 API는 부르지 않는다.
- `ask.js`는 이전 판처럼 vLLM(:8000)을 직접 호출한다. 게이트웨이 `/agent/runs` 경유는 gov-fusion must_fix이고, 이 화면의 must_fix에는 없어 이번에 바꾸지 않았다(요청 사항으로 남긴다).
- 대조 작업을 녹화와 시험에 쓰느라 서버에 CPU 작업 약 7건이 생겼다. GPU는 쓰지 않았고, Ollama · vLLM · 서버 프로세스는 종료하지 않았다. git 조작은 하지 않았다.
