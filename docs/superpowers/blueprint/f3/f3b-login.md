## 1. 장면 전환 중 빈 회백 판 + 흰 글자 → 해결
- 원인: `arrive()`가 새 제목을 먼저 세우고 `el.cut`으로 지도만 투명하게 만들었다. 그래서 `--bg-0` 판 위에 흰 제목과 이전 크레딧이 남았다.
- 조치: `.hero__cover`(덮개 사진 1장)를 둔다.
  - 전환 시작 때 떠나는 장면의 마지막 프레임을 덮개로 즉시 세운다(`preserveDrawingBuffer` → `toDataURL`, 디코드 후 교체).
  - 덮개 밑에서 도착지로 jumpTo 한다. 보이는 타일이 다 차면(`areTilesLoaded` · 최대 9 s · 래스터 페이드 520 ms 포함) 그때 제목·크레딧을 바꾸고, 덮개를 750 ms 페이드로 걷은 뒤 마지막 구간을 카메라로 내려앉는다.
  - 기다리는 동안 덮개는 9 s 에 걸쳐 1.06 배로 아주 느리게 다가선다(멈춘 화면처럼 보이지 않게).
  - 지도 `background` = 잉크 `#1C1F25`. 카드 면 = `var(--ink)`. 카드 겉 바탕만 `--bg-0` 이고, 라운드 24는 늘 유지된다.
- 측정: 녹화 영상을 20 fps로 잘라 히어로 영역 평균 밝기를 쟀다(`ffmpeg` crop → PIL).

## 2. 첫 페인트 후 히어로 카드 3~7 s 빈 회백 → 해결
- 첫 장면 스틸(`still-performance.webp`)을 `<link rel=preload>` 로 미리 받는다. 스틸은 비슈케크 시작 구도(zoom −1.2)를 실제 EOX 영상으로 찍은 것이다.
- 이 스틸과 3축 색인, 첫 제목 'Hyper Performance', 한글 한 줄, 크레딧 © EOX · Esri 를 0 s 에 세운다.
- 히어로의 투명도 등장을 없애고 20 px 상승만 남겼다. 그래서 첫 프레임부터 카드 면이 있다(스틸 디코드 전 한두 프레임은 잉크 면).
- 타일이 차면(실측 약 3.3 s) 같은 구도의 실지도 위에서 덮개를 페이드로 걷고 내려앉는다. 증거는 `01-first-paint-0.6s-1440.png` · `08-first-paint-390.png`.
- 이전의 `.hero:not(.is-lit)` 숨김 규칙(축·음영·지도 투명)은 없앴다.

## 3. 비슈케크 열지도가 카드 전면을 덮음 → 해결
- 시가지 비율 증가 8 %p 미만 격자는 그리지 않는다(`KG_MIN` · 2208 → 약 650 셀). 산지·외곽의 저증가 잡음이 이 컷에 걸린다.
- 설정값 변경
  - `heatmap-intensity` 2.6 → 1.2
  - radius z13 80 → 38, z11 24 → 14
  - weight 램프는 8 %p 에서 0.25 부터 시작
  - 밀도 0.12 미만은 거의 투명, 최고 불투명도 .86
- 결과: 도시 윤곽과 농경지 격자가 그대로 읽히고, 확장 가장자리만 얇게 청록으로 빛난다(`02-performance-1440.png` · `07-performance-1280x720.png`). 결과 숫자 44.4 km² 는 파일 요약값 그대로이며 셀 컷의 영향을 받지 않는다.

## 4. (권장) 1280×720 제목 두 줄 · 390 히어로 과밀 → 반영
- `.axis__t`에 `white-space: nowrap` 을 주고, ≤1300 px 에서는 `--fs-h3`(32/42)로 내린다. 1280×720 제목 높이는 42 px 한 줄이다.
- 390 히어로 높이를 272 → 320 으로 늘렸다.

  - 색인 여백도 줄였다. 가로 스크롤 0(scrollWidth 390).

## 8. 남은 것 · 정직 항목
- 1440 에서 'Hyper Performance'(48)의 끝과 결과 카드 사이 여백은 약 28 px, 1280 에서는 약 20 px 로 좁다. 겹치지는 않는다.
- 스틸은 1장(Performance)뿐이다. 첫 장면 데이터가 없어 Solution 부터 시작하는 드문 경우에도 첫 스틸은 비슈케크다. 이때는 제목만 바뀌고, 덮개는 타일이 찬 뒤 걷힌다.
- 덮개가 걷히기까지 기다리는 시간은 타일 서버(EOX · V-World) 속도에 달려 있다. 실측 1.3~3.3 s, 최대 9 s 까지 기다린 뒤 걷는다. 그때도 빈 칸은 잉크다.
- 전환 주기가 늘어 색인 진행 막대 `--hold` 를 11.9 s 로 맞췄다. 실제 체류와 ±1 s 정도 어긋날 수 있다.
