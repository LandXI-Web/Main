## 1. 화면이 하는 일(한 줄)
공무원이 **자기 대장 파일을 떨어뜨리면** 필지로 이어 붙이고(PNU 사다리), **AI 판독 × V-World** 와 합쳐 **대장과 다른 필지**를 바로 지도에 칠한다. 한 문장으로 물으면(vLLM) 그 표에 필터를 걸어 지도·집계·목록이 함께 바뀐다.

## 3. 숫자는 어디서 오나(가짜 0)
- **대장**: 업로드한 파일 그대로. 표본 파일 `landxi/v3/gov-fusion/sample/운봉읍_농지목록.xlsx`(13,866행 = 운봉읍 지목 전·답·과수원 전 필지). **정직 표기: 기관 원본 농지대장 표본은 아직 없다.** 사용자 결정("대장 대조는 V-World 레이어 먼저")에 따라 V-World 연속지적 속성(소재지·지번·지목·면적·용도지역·농업진흥)을 대장 형식으로 뽑은 것이며, PNU 열은 일부러 넣지 않았다(지번 해석 사다리를 실제로 타게).
- **AI 판독**: `02. 데이터/survey/namwon-parcel-survey.pmtiles` 의 `parcels` 층(XI맵이 그리는 같은 파일)을 브라우저가 z14 타일 단위로 직접 읽어 pnu 색인을 만든다(최소 MVT 디코더 · 속성+bbox만). 운봉읍 39타일 · 약 7MB · 0.2–0.35초.
- **V-World**: 게이트웨이 프록시 `GET /proxy/vworld/search`(키는 서버). 운봉 표본은 법정리 18개 → 호출 18회로 13,864행 결합.
- 실측(개발자 서랍 `?dev=1`, 1440×900 · 이 PC): 파일 읽기 0.19–0.28초 · 매칭 0.35–0.95초 · 결합률 99.9%(2행 미결합: V-World 에는 있으나 AI 판독 범위 밖) · ⌘K 첫 토큰 0.2–0.45초, 전체 1.8–2.9초.
- 3분류 임계는 README 규칙과 같은 [추정 초기값](건물 ≥ 33㎡ · 주차장 ≥ 100㎡ · 1,000㎡ 이상 & 농경 < 15% & 건물 < 30%). 결과 숫자 옆 `~`(호버: AI 판독 기준 추정치 · 검수 전). 결합률은 결정적 계산이라 `✓`.
- 같은 질문을 ⌘K 로 물어도 카테고리 숫자와 같다(696 = 696). XI맵의 R1(20,852 중 규칙 후보)과 다른 이유: R1 은 '객체 과반 포함·신뢰도 ≥ 0.5' 면적을 쓰고, 이 화면은 **올린 대장의 필지 범위**에서 교차면적 전체를 쓴다 — 다른 지표이므로 라벨도 다르게 붙였다("대장은 농지 · AI는 건물").

## 4. ⌘K 가 실제로 만든 필터(실측)
| 질문 | 필터(모델 출력) | 결과 |
|---|---|---|
| 대장상 농지인데 AI가 건물로 본 필지 | 지목 in [전,답,과수원] · AI 건물 ≥ 33 | 696필지 |
| 화수리에서 농업진흥구역인데 경작 흔적이 없는 필지 | 소재지 contains 화수리 · 농업진흥 in [농업진흥구역] · AI 농경 비율 < 0.15 · 면적 ≥ 1000 | 58필지, 카메라 화수리로 |
| 비닐하우스가 있는 과수원 | 지목 in [과수원] · AI 비닐하우스 ≥ 100 | 0필지(운봉 과수원 10필지뿐 — 정직한 0) |
| 권포리로 가서 주차장으로 쓰는 농지 | 소재지 contains 권포리 · 지목 농지 · AI 주차장 ≥ 100 | 0필지 |
- 모델에게는 **열 이름과 값 예시만** 준다(숫자·결과는 주지 않음). 셈은 브라우저가 결합표 13,864행 전체에서 한다.
- JSON 스키마 제약은 공백 폭주(개행만 수백 토큰)로 한 번 멈췄다 → **EBNF 문법 제약**(공백 없는 한 줄 JSON, 필드 이름은 열 목록 enum, 값은 문자열·숫자·배열)으로 바꿔 해결.

## 7. 정직 항목
1. **실제 쓰기 2건**: 녹화·검증 중 기관 계정(namwon-manager)으로 `f_R1_5219025024105080003`(운봉읍 행정리 508-3) · `f_R1_5219025026106210000`(운봉읍 동천리 621) 을 `open → assigned` 로 바꿨다. 기관 쓰기는 되돌리는 전이가 없어 그대로 남는다(오늘 할 일 '현장 확인 배정' 수에 포함). 최종 영상은 추가 쓰기 없이 이미 배정된 카드를 보여 준다.
2. **정문**: `landxi/v3/login/` 이 아직 없어 이 화면 안에 기관 로그인 카드를 두었다(실제 `/auth/login` · 같은 세션 키 `lx_api_session`). v3 정문이 생기면 그쪽 세션을 그대로 받는다(기관 → 이 화면 착지 경로 연결은 정문 쪽 몫).
3. **vLLM 은 브라우저가 :8000 을 직접 부른다**(CORS `*` 확인). 게이트웨이 `/agent/runs` 를 거치지 않아 에이전트 감사 기록(agent_runs)에 남지 않는다 — 계약에 `ledger_*` 도구가 생기면 옮길 자리.
4. 대장 반입 서버 엔드포인트(§3 `registry/import` 등)는 소유 범위 밖이라 만들지 않았다. 반입·매칭·융합은 **브라우저 안**에서 끝나고 파일은 서버로 가지 않는다(현장 배정 쓰기만 서버).
5. AI 판독은 2023 25cm 모델(비닐하우스 약함 · 태양광·축사 오탐 가능). 영상 속 1위 행정리 508-3 도 건물+비닐하우스가 겹쳐 잡힌 대형 시설이다 — '의심 후보'이지 위법 판정이 아니다.
6. 390px 폭은 겹치지 않게만 접었다(현장 모바일은 범위 밖).
