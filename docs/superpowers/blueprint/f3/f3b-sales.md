## 3. 규칙을 지키려고 한 선택

- **숫자는 업무 결과만.** 필지·건 수만 크게 쓴다. `현장 확인 필요` 는 XI맵 정돈판과 같은 조회(우선순위 A · 미조치/배정)라 두 화면 값이 같다(판정 시점 1,053).
- **실결과 있는 배포본만.** `ga`/`canary` + 결과 봉투 + 범위가 있는 것. 이름에 `test`·`테스트`·`시연` 이 들어간 배포본(소쿨룩 테스트 20건, 메이크틸라)은 제외한다. 사례는 앞 사례와 다른 지역이 이어지게 정렬한다(남원 → 광주전남 → 남원).
- **지역은 변수.** 코드에 좌표·지역명 0. 카메라·이름표 위치는 결과 GeoJSON 범위에서 계산한다. 결과 크롭만 결과 세트 이름 → 크롭 폴더 표 한 줄(`CROP_PICK`)이고, 없으면 첫 장, 그것도 없으면 캐릭터 스틸로 대체한다.
- **죽은 버튼 0.** 이식 요청처럼 쓰기 API 가 없는 행동은 두지 않았다. "이 서비스 열기"는 어느 지역이든 화면 안에서 실제 결과 지도를 연다. XI맵 링크는 실태조사 범위(읍면동 경계 상자) 안 사례에만 보인다.
- **V-World 바다 얼룩.** 먼바다 일부 칸이 출처가 다른 보라빛 저해상 칸이라 확대하면 네모 얼룩이 생겼다(07 스틸 수정 전). 이 화면의 타일 프로토콜에서 z9 이상의 물 화소만 바다색 쪽으로 80% 섞어 대부분 지웠다(아주 옅은 경계는 남음). 받지 못한 타일은 투명 처리해서 콘솔 404 가 나지 않는다.
