## 3. 실제 동작 확인 — 정문 로그인 경로만 사용, 세션 주입 없음

스크립트는 scratchpad `oc2-shoot.mjs`(검사·캡처)와 `oc2-rec.mjs`(녹화)이다. 흐름은 매번 같다.
1. `ops-core/`에 직접 들어간다.
2. 세션이 없으므로 정문 `v3/login/?next=`로 넘어간다.
3. 관리자 탭 + 틀린 비밀번호 → 서버가 401로 거절한다.
4. `lx-admin` 실로그인 → ops-core 현황에 도착한다.
5. 해외 · 국내 전환 → 지역 핀 → 지역 시트 → 결재함(첫 건 시트 자동) → 인프라 → 기관 → 배포 셀 시트 순서로 돈다.

## 4. 남은 것 · 정직 항목

- **글 예산을 넘는 화면**:
  - 기관 341자, 결재 376자(1440)로 ≤ 300을 넘는다.
  - 기관은 카드 5장 × 한도 3종이고, 결재는 오른쪽 시트의 계보 4줄이 함께 세어진다. 더 줄이려면 한도 막대를 2종으로 줄이거나 계보를 접어야 하는데, 관리자 판단에 필요한 정보라 남겨 두었다.
- **1280×720 현황의 카드 면적 20.7%**: 할 일을 2건으로 줄인 뒤의 값이다. 기준(≤ 20%)을 0.7%p 넘는다.
- **버튼 수**:
  - 배포 매트릭스의 셀(17)은 데이터 칸이라 버튼 예산에서 뺐다.
  - 기관 화면의 '한도 조정' 4개는 기관 카드마다 하나씩 있다.
  - 이 두 가지를 예산에 넣을지는 판정자가 정할 몫이다.
- **색 판단**:
  - 액센트는 레일·스텝퍼의 현재 위치, 포커스, 선택 셀 테두리에만 썼다.
  - 청록 `--ai`는 마스트 신선도 점(`.t-fresh` 규격) 하나뿐이다.
  - 단계 구분을 잉크 농도와 모양으로 바꾼 것은 법전 §1 '상태 = 잉크 농도 3단'을 배포 단계에 넓혀 적용한 해석이다.
- **지도 바탕**: 위성 대신 라이트 벡터를 골랐다. 해외에서 줌하면 경계선과 AOI만 보인다. 검정은 아니지만 아직 성긴 느낌이 남는다.
- **로그인 화면**: 정문(`v3/login`)은 이 작업 중에 login 담당이 동시에 고치고 있었다. 셀렉터(`#id` `#pw` `#go` `input[name=who]`)는 현재 파일 기준으로 동작을 확인했다.
