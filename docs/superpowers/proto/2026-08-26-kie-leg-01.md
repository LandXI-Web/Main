# 순백 배경 (#FFFFFF) — 후처리

클라이언트 지시(2026-08-26): 라운드 2 납품본은 검수를 전부 통과했으나 배경이
**크림(#ECE4D6)** 이다. 크림 기미 없는 **완전한 흰색 #FFFFFF** 로 바꿀 것.

## 결론 (한 줄)

**재생성 없이 후처리로 끝났다. 크레딧 0.** 배경은 프레임 전역이 정확히
`255,255,255`(비교 픽셀 152만 개 중 순백 비율 **1.000000**), 지구본·링·위성·솜구름
픽셀은 **양자화 오차 미만(최대 편차 0.04/255)** 으로 그대로다. 예비로 잡아둔
재생성 1회(14.5)는 **쓰지 않았다** — 잔액 987.0 유지.

## 왜 임계값 컷아웃이 아니라 알파 매팅인가

배경만 흰색으로 미는 흔한 방법 셋은 이 그림에서 전부 실패한다.

| 방법 | 이 스틸에서 깨지는 지점 |
|---|---|
| 전역 레벨/흰점 보정 | 배경이 균일하지 않다. 좌상단 (234,225,208) ↔ 우하단 (239,232,220) 로 **최대 12레벨 기울기**. 상수 흰점으로 밀면 기울기가 회색 얼룩으로 남고, 지구본 픽셀까지 같이 밝아진다(= 승인된 그레이드 훼손). |
| 마스크 컷아웃 후 흰 배경 합성 | 상단 극관 림이 **디포커스로 20~40px 에 걸쳐 흐리다.** 하드 컷은 그 자리를 잘라 회색 림을 남기고, 페더를 넓히면 크림이 흰색으로 번지는 **할로**가 생긴다. |
| 밝기 임계값 마스크 | 극관(흰 석고)과 배경(크림)의 **대비가 20레벨뿐**이라 지구본 윗부분이 마스크에서 통째로 빠진다. |

그래서 매팅 합성식을 그대로 되돌리는 **더하기 보정**을 썼다.

```
관측  obs = a·F + (1−a)·B        a = 피사체 커버리지, B = 크림 배경
목표  out = a·F + (1−a)·W        W = (255,255,255)
따라서 out = obs + (1−a)·(W − B)
```

`(1−a)` 는 그 픽셀에 원래 섞여 있던 **배경의 양**이다. 디포커스로 배경이 절반
섞인 림 픽셀은 정확히 절반만 밝아진다. 경계에서 값이 튀지 않으므로 **할로도
회색 림도 원리적으로 생기지 않는다.** `a=1` 이면 `out = obs` — 지구본은 자동으로
무손실이다.

세 가지 세부:

1. **B 는 공간 필드**다. 피사체를 뺀 배경 픽셀만으로 정규화 컨볼루션(σ=110)을
   돌려 기울기를 그대로 따라가는 부드러운 배경을 추정한다. 상수가 아니다.
2. **알파를 두 갈래로** 만든다. 지구본은 **원 피팅**(구는 원이다 — 경계점 최소제곱,
   흐린 상단 30% 는 피팅에서 제외, 이상치 3회 트림) 후 림 흐림 폭만큼 smoothstep
   램프. 링·위성은 배경 편차 기반(황동은 채도가 높아 잘 분리된다).
3. `a≈0` 인 곳은 잔차까지 죽여 **정확히 255** 로 만든다. 필름 그레인(파랑 채널
   ±20레벨 크로마 노이즈)이 남으면 순백이 아니다. **비네트·헤이즈는 더하지 않았다.**

## 다음 시도에 반영할 것 (재생성 승인 시)

1. **"pure white background" 는 프롬프트로 5초를 못 버틴다.** 스틸 때와 같은 결론:
   배경은 생성이 아니라 **후처리(매팅)로 잡는다.** 대신 생성 프롬프트에서는
   배경을 아예 언급하지 않거나 "empty studio backdrop" 정도로 두고,
   `clouds, sky, fog, mist, atmosphere` 를 네거티브 앞쪽에 못박는다.
   (현재 네거티브의 `blue sky` 만으로는 회백색 구름을 막지 못했다.)
2. **"about 8%" 같은 % 지시는 무시된다** — 스틸의 "55%" 가 73% 로 나온 것과 같은 실패.
   돌리인은 아예 빼고 **후처리 스케일 램프**로 넣는 편이 정확하고 공짜다.
3. **회전 35도도 안 먹었다.** 지구본 회전이 필요하면 kling 에 맡기지 말고
   `landxi/proto/spikes/three-globe` 렌더러로 정확한 회전을 굽는 편이 낫다.
   kling 은 재질·빛·솜구름의 미세 움직임에만 쓴다.
4. **duration 5 는 이 모델에게 길다.** 무너짐이 정확히 2.3초 부근에서 시작한다.
   같은 크레딧이면 3초 두 컷이 5초 한 컷보다 안전할 가능성이 높다.
