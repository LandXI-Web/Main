## 0. 이 덱의 규칙 — 왜 지금 카피가 사람처럼 안 읽히는가

1차안의 문장은 **누가 썼는지, 누구에게 쓰는지, 어디 이야기인지가 없다.** "AI 기반 통합 플랫폼", "효율적인 국토관리 솔루션" 같은 문장은 어느 기관 홈페이지에 붙여도 말이 된다. 그래서 생성물처럼 읽힌다.

이 덱이 지키는 5원칙:

| # | 원칙 | 나쁜 예 | 이 덱의 예 |
|---|---|---|---|
| 1 | **숫자가 형용사를 대체한다** | "초고해상도 영상" | "GSD 1.54 cm" |
| 2 | **지명과 날짜를 반드시 붙인다** | "전국 각지에서" | "신안 임자면 도찬리 1.5㎢, 2025-03" |
| 3 | **사람의 일을 말한다** — 기술이 아니라 대체된 노동 | "AI 자동 탐지" | "해안선을 걸어 세던 연 2회 조사 → 드론 1회 + AI" |
| 4 | **모르는 건 모른다고 쓴다** | "AI 신뢰도 94%" | "변화 지수(비지도) · 학습 모델의 탐지 결과 아님" |
| 5 | **사과하지 않고 다음 행동을 준다** | "죄송합니다. 오류가 발생했습니다." | "타일 서버가 응답하지 않습니다. 저해상도 배경으로 계속 보기" |

**고정 문안(변경 금지, 스펙 §1).**
- 모토: **LX 전 직원이 Geo-AI 전문가입니다**
- 비전: **범부처 AI 기반 국토정보 통합조사**
- 3축: **노코드 · 워크플로우 기반 AI 모델 개발 · 전국단위 AI 실태조사**

**서체 배역.** Gothic A1 900 = 디스플레이(장면 카피). IBM Plex Sans KR = 본문·버튼·상태. IBM Plex Mono = 모든 수치·좌표·날짜·모델명·GSD·건수. 수치가 본문 서체로 나오면 카피가 무너진다.

## 3. 히어로 톤 3안 + 권고

같은 챕터 1을 세 목소리로 쓴 것. **한 안을 고르면 4개 챕터 전체·13개 카드·버튼까지 같은 목소리로 간다.**

### A안 · 관공서 격식

```
디스플레이   범부처 국토정보
            통합조사 플랫폼
서브        국토교통부·농림축산식품부·환경부·해양수산부·산업통상자원부 공동 활용
버튼        로그인하고 시작하기 / 사업 개요 보기
HUD         운영기관 LX 한국국토정보공사 · 서비스 13종 · 참여 부처 5 + LX
```
- **장점**: 결재 라인에서 안전하다. 부처 담당자가 그대로 보고서에 인용할 수 있다.
- **단점**: "인간성이 없다"는 지적을 그대로 재생산한다. 이 톤은 이미 1차안이 실패한 톤이다.
- **쓸 곳**: 홈이 아니라 로그인 하단 고지, 푸터, 정책 모달.

### B안 · 편집 에세이

```
디스플레이   땅은 말이 없고
            사람은 늘 늦는다
서브        그래서 우리는 1년에 한 번 하늘에서 국토를 다시 읽는다
버튼        같이 내려가 보기 / 로그인
HUD         (최소 — 시각·고도만)
```
- **장점**: 목소리가 확실히 있다. Awwwards 문법과 가장 잘 맞는다.
- **단점**: 공공기관 발주처가 "우리 이야기가 아닌 것 같다"고 느낄 위험. 두 번째 문장부터 근거가 없으면 공허해진다. 수치를 HUD로 밀어내는 순간 신뢰 근거가 사라진다.
- **쓸 곳**: 챕터 전환의 한 줄 문구(예: "이제 한 곳으로 내려간다"), 스토리 패널의 슬라이드 인트로.

### C안 · 데이터 저널리즘 ★ 권고

```
디스플레이   국토는 매일
            조금씩 달라진다
서브        위성 2m, 항공 25cm, 드론 1cm — 같은 땅을 세 고도에서 본다
모토 줄     LX 전 직원이 Geo-AI 전문가입니다
버튼        로그인하고 시작하기 / 스크롤해서 내려가기
HUD         KST 2026-08-25 14:32:07 · ALT 1,204 km · 한반도까지 3,180 km
```
- **장점**: 문장은 사람의 말이고, 근거는 화면의 수치가 댄다. 발주처가 인용해도 안전하고(모든 수치가 실제 데이터) 대국민에게도 읽힌다. 안티패턴 #11("AI 기반" 배지 대신 구체 수치)의 정면 대응.
- **단점**: 수치가 하나라도 틀리거나 하드코딩이면 신뢰가 즉시 붕괴한다. 데이터 파이프라인이 카피의 전제 조건이 된다.

> **권고: C안(데이터 저널리즘).** 이유는 셋. (1) 클라이언트 불만의 원인은 "격식이 부족"이 아니라 "구체가 없음"이었다. C안만 그 원인을 직접 친다. (2) 우리가 가진 자산(GSD 1.54cm 4시점, 38,057건, 9,032셀, 71% 절감)이 이미 카피 재료다 — 지어낼 필요가 없다. (3) B안의 서정성은 챕터 전환 한 줄에서만 쓰면 C안의 건조함을 인간적으로 만들어 준다. **C를 뼈대로, B를 전환 문구에만, A를 푸터·법적 고지에만.**

## 4. 버튼 라벨 — 동사 우선, 흐름 전체에서 일관

같은 행동은 화면이 바뀌어도 같은 동사로 부른다. 상태 변화는 **동사의 시제**로 표현한다.

```

실행 화면     분석 실행

### 4-3. 공통 동사 사전 (이 표에 없는 동사를 새로 만들지 않는다)

## 7. 출처 · 신뢰도 표기 규칙 (Provenance)

Palantir 벤치마크 §"AI 신뢰도를 정직하게" 준수. **원형 신뢰도 게이지 금지.** 점수는 근거와 함께만 나온다.

### 7-1. 4줄 프로버넌스 블록 (모든 탐지 결과 패널 하단 고정)
```
출처   드론 정사영상 · 남원 농경지 · 2025-08 · GSD 1.54 cm
모델   비닐하우스 탐지 (YOLOv8, 2025-07 학습, 118.6 MB)
판정   신뢰도 임계 0.50 · 표시 12,904 / 38,057건
검수   사람 확인 0 / 2,418 · 최근 갱신 2026-08-12 14:32
```
필드 포맷:
- `출처 {센서 종류} · {지역명} · {YYYY-MM} · GSD {n.nn} cm` — 위성은 `GSD 0.5 m` 처럼 단위를 바꾼다.
- `모델 {모델명} ({아키텍처}, {YYYY-MM} 학습, {n.n} MB)`
- `판정 신뢰도 임계 {0.nn} · 표시 {n,nnn} / {n,nnn}건`
- `검수 사람 확인 {n} / {n} · 최근 갱신 {YYYY-MM-DD HH:mm}`

### 7-2. 신선도 표기 (데이터 관리·대시보드)
```
● 3분 전      ● 2일 전      ● 10개월 전      ○ 갱신 이력 없음
```
- 7일 이내 `● {n}분/시간/일 전`(완료색) · 30일 이내 `● {n}일 전`(조치중색) · 그 이상 `● {n}개월 전`(보류색) · 기록 없음 `○ 갱신 이력 없음`.
- **상대 시간 옆에 절대 시각을 툴팁으로 반드시 붙인다**: `2026-08-25 14:32:07 KST`.

### 7-3. 정직 라벨 (필수 표기 3종)
```
변화 지수(비지도)      학습 모델의 탐지 결과가 아닙니다.
라인업 예시           실제 분석 결과가 아닌 소개용 수치입니다.
— (값 없음)          이 항목은 측정되지 않았습니다.
```
- `namwon-change.geojson`, `namwon-change-grid.geojson`을 쓰는 모든 화면은 레이어 이름·범례·툴팁 **세 곳 모두**에 `변화 지수(비지도)`를 쓴다. "AI 변화탐지"로 줄여 쓰지 않는다.
- 값이 없을 때 `0`을 쓰지 않는다. `0`은 측정해서 없다는 뜻이고, `—`는 측정하지 않았다는 뜻이다.

## 9. 대시보드 마이크로카피

### 9-1. 페이지 헤더
```
대시보드
2026-08-25 (화) · 처리 대기 10건 · 최근 분석 6시간 전
```
포맷: `{YYYY-MM-DD (요일)} · 처리 대기 {n}건 · 최근 분석 {상대시간}`

**공지 스트립**
`[공지] 08-27(목) 02:00–04:00 타일 서버 정기 점검 — 이 시간대 분석 실행은 대기열에 쌓입니다.` `[자세히]`

### 9-2. KPI 타일 (dashboard.js 실제 값)
라벨은 명사, 보조줄은 **분해된 내역** — 요약이 아니라 다음 클릭의 예고다.
```
전체 사용자        21명    정상 19 · 승인 대기 2
발행 분석 카드      8건     공개 7 · 비공개 1
카드 발행 승인 대기  2건     최장 102일 대기          ← 이 문구가 행동을 만든다
미답변 문의        6건     전체 12 · 최장 8일
가입 승인 대기      2건     최장 2일
```
- 숫자는 클릭 가능. 호버 툴팁: `클릭하면 이 2건만 남깁니다`

### 9-3. 처리 대기 큐 (좌 400px)
```
처리 대기                                          10건 · 오래된 순
──────────────────────────────────────────────
카드 발행   해양쓰레기 격자 집계 (전남)      102일   [검토]
가입 승인   최OO · 전라남도 해양수산과        2일    [승인] [반려]
문의       GPKG 좌표계 문의 · 김OO           8일    [답변]
```
- 대기 일수 색: 7일 이하 보류색 / 30일 이하 조치중색 / 그 이상 발견색
- 빈 상태: `대기 중인 항목이 없습니다. 마지막 처리는 오늘 11:20입니다.`
- 호버 툴팁: `지도에서 해당 지역 보기`

### 9-4. 전국 커버리지 카드
```
전국 커버리지                        시군구 229곳 중 조사 완료 18곳
매트릭스 축 라벨:  시군구 ↓  ×  조사 항목(부처) →
```
- 셀 툴팁: `남원시 × 도로안전 다시점 조사 (국토교통부) · 1,264건 · 2026-08-19`
- 빈 셀 툴팁: `아직 조사 대상이 아닙니다`
- 카드 하단 설명 한 줄: `채워진 칸 하나가 부처 한 곳의 현장조사 한 건을 대체한 자리다.`
- 클릭: `XI 맵에서 남원시 열기`

### 9-5. 백본 모델 / 스토리지 / 용량
```
백본 모델      12종 · 최근 학습 2025-08 도로망 세그멘테이션
스토리지       44.5 TB   원시 정사영상 22.1 · 탐지 결과 9.8 · 타일 캐시 8.4 · 로그 4.2
프로젝트 용량   상위 5개 · 남은 용량 3.2 TB          [증량 신청]
```
- 용량 경고: `남은 용량 3.2 TB — 현재 업로드 속도로 11일 뒤 가득 찹니다.` `[증량 신청]`

### 9-6. 상태 어휘 (6색 매핑 — 문구도 고정)
```
발견     대기 · 신규 · 미확인

## 10. 금지어 20 — 템플릿으로 읽히는 말

이 단어가 화면에 있으면 카피 리뷰에서 반려한다. 오른쪽은 대체 방법이며, **대부분 단어 교체가 아니라 수치로 바꾸는 것**이다.

| # | 금지어 | 왜 | 대신 |
|---|---|---|---|
| 1 | 혁신 / 혁신적인 | 어느 기관 자료에나 있음 | 무엇이 바뀌었는지 수치로: `30일 → 1일` |
| 2 | 스마트 | 의미가 비어 있음 | 그 기능의 이름을 그대로: `자동 도엽 분할` |
| 3 | 솔루션 | 영업 자료의 지문 | `서비스` 또는 그 조사의 이름 |
| 4 | 최적화된 | 무엇을 무엇에 맞췄는지 없음 | `GSD 1.54cm 영상에 맞춰 학습한` |
| 5 | 원스톱 | 2010년대 포털 어휘 | `한 화면에서` / `로그인 한 번으로` |
| 6 | 첨단 / 최첨단 | 시점이 지나면 거짓이 됨 | 모델명·연도: `YOLOv11-OBB, 2025-07 학습` |
| 7 | 차세대 | 위와 동일 | 버전 표기: `Land-XI v2` |
| 8 | 극대화 / 극대화된 | 측정 불가 | `71% 절감` |
| 9 | 효율성 제고 | 보고서 상투구 | `조사원 2명이 하던 일을 1회 촬영으로` |
| 10 | 패러다임 전환 | 발표자료 관성 어휘 | 그냥 뺀다 |
| 11 | 사용자 친화적 | 스스로 평가할 수 없는 말 | 보여준다 — 클릭 수를 줄인다 |
| 12 | 강력한 / 파워풀한 | 형용사 낭비 | `5,000 폴리곤을 60fps로` |

| 14 | 다양한 (수식어로) | 몇 개인지 안 밝힘 | `13종` / `부처 5곳` |

| 17 | AI 기반 (배지·수식어로) | 안티패턴 #11 | 모델명과 학습 일자로 대체 |
| 18 | 통합 (수식어로) | 무엇과 무엇을 합쳤는지 없음 | `농식품부·환경부·국토부 조사를 한 영상으로` |
| 19 | 미래를 열다 / 새로운 시대 | 카피라이팅 클리셰 | 삭제 |
| 20 | 언제 어디서나 | 브라우저 요구사항이 있는데 거짓 | `Chrome·Edge 최신 · 1280px 이상` |

**추가 금지(표현 습관)**
- 문장 끝 느낌표 — 발표자료에서 넘어온 습관(`사각지대 발생!`). 화면에서는 전부 제거.
- "죄송합니다 / 불편을 드려" — §5 규칙 위반.
- 이모지 — 스펙 §5 아이콘 규칙과 안티패턴 #10 위반.
- "~하실 수 있습니다" 남용 — `~합니다` / 명령형 버튼으로.
- 괄호 안 영어 병기 남발 — 첫 등장 1회만 (`공간지능정보(Geo-AI)`), 이후 한 표기로 통일.
