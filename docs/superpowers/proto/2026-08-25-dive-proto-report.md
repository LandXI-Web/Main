## 0. 한 문장

스크롤 하나가 **궤도 → 성층운 돌파 → 전국 점등 → 남원 사면 강하 → AI 결과 판독**을 끊김 없이 통과하고,
전국 화면의 서비스 지점을 클릭하면 **같은 지도가** 그 지역으로 날아가 **실제 GPKG 분석 결과**를
신뢰도 슬라이더·클래스 범례와 함께 3D로 얹는다. 지도 인스턴스는 처음부터 끝까지 하나다.

## 1. 챕터별 구현

카메라는 `js/camera.js` 의 키프레임 14개를 구간별로 다른 이징(`power1.inOut / power2.in / expo.in /
expo.out / power2.out / power3.inOut / expo.inOut / power3.out / power4.out`)으로 보간하고,
`map.jumpTo` 를 매 프레임 호출한다. bearing 에는 상시 미세 드리프트가 걸려 있고(착지 이후 0 으로 수렴),
스크롤을 멈추면 카메라도 멈춘다. 자동재생은 챕터 4의 4시점 타임라인 하나뿐이다.

### 프리로더 (p 이전)
`LAND-XI PLATFORM` 을 mono 글자 단위로 스크램블→정착(글자당 46ms 오프셋)시키고, **실제 타일
프리페치 진행률**(EOX z2 16장 + 남원 z17 20장 = 36장)과 `map.load` 를 0.76/0.24 로 가중해 카운터를
굴린다. 좌표 판독기가 난수에서 `127.3524 / 35.5311`(남원 AOI 중심)로 수렴한다. 완료 시 mono 워드마크가
실제 CI 워드마크 PNG 로 교체되고 커튼이 `clip-path` 로 1.2s expo.inOut 걷힌다. 가짜 로딩·가짜 진행률 없음.

### 챕터 1 · 궤도 (p 0 – 0.18)
- MapLibre **globe** + EOX Sentinel-2 cloudless + `sky.atmosphere-blend`.
- **별밭**: 절차적 3층 시차 캔버스(920개, 색온도 3종). 지도 `background` 레이어를 줌 5.2 이하에서
  투명하게 두어 우주가 비친다.
- **three.js 오버레이 캔버스**(지도 GL 컨텍스트와 분리): 궤도 링 1개 + 꼬리 56점 + 위성 1기.
  - 위성은 병렬 작업물 `assets/proto/models/satellite.glb`(금색 MLI 버스·셀 패널, 3.6k tri). 없으면
    절차적 메쉬로 자동 폴백한다. `RoomEnvironment` + `PMREMGenerator` 를 `scene.environment`(0.55)로
    넣어 금속 머티리얼이 검게 렌더되는 함정을 피했다.
  - 궤도는 **Sentinel-2 실제 제원**(고도 786 km · 경사 98.62° 태양동기 역행 · 주기 100.6분)을 그대로
    쓴다. 이 페이지의 전지구 베이스맵이 Sentinel-2 이므로 위성이 곧 데이터다. 260배속.
  - 태양전지 요크는 SunCalc 태양 방향을 따라가고, 아주 느린 자세 드리프트가 걸려 있다.
  - **오클루전**: 지구 크기의 depth-only 구체가 링·꼬리의 뒷면을 가린다(자체비평 #11 해소).
- **터미네이터**: SunCalc 로 지금 이 순간의 태양 직하점을 2단 argmax 로 구해(HUD 에 실값 표시),
  글로브 실루엣 원판 위에 각도·오프셋을 계산한 그라디언트를 얹는다.
- 타이포: Gothic A1 900, 글자 단위 `from:'random'` 스태거 0.03 + blur 12→0.
- HUD(실값): KST 초시계 · 궤도체 · 고도 · **한반도까지 거리**(궤도 위치에서 ECEF 실계산) · 태양 직하점 · 축척바.

### 챕터 2 · 성층운 돌파 (p 0.18 – 0.33) — *코디네이터 지시 반영, 브리프에 없던 챕터*
- 구름 판 3장(`assets/proto/clouds/cloud_far|mid|near.webp`, 없으면 그 자리에서 구운 절차적 값노이즈
  fbm 텍스처)이 서로 다른 속도로 스케일 1.0→9.0 되며 지나가고, 각 판의 가운데가 `mask-image`
  radial-gradient 로 **먼저 뚫린다**(갈라짐). 커서 시차(depth 7/15/24, lerp 0.06).
- 화이트아웃 헤이즈가 p≈0.258 에서 정점(0.94). **이 순간에 `setProjection` globe→mercator 를 실행**해
  투영 전환을 구름 뒤에 숨겼다. (deck.gl 9.3 은 표현식 투영을 해석하지 못하고 예외를 던진다 — §5 참조.)
- 구름을 뚫고 나오면 hillshade 가 켜진 한국 지형이 아래에서 드러난다.

### 챕터 3 · 전국 점등 (p 0.33 – 0.545)
- z6.8 pitch 30. 실제 해안선(`korea-outline.geojson`)을 **링→LineString 으로 변환**해 시안 글로우로
  두르고, 실제 시도 경계(`sido.geojson`, 17개)를 점선으로 얹는다. 시도 라벨 17개는 rank 로 등장 줌을 나눈다.
- **13개 서비스가 `lastRun` 순으로 스태거 점등**. `lit / ring / dim / hot` 은 전부 `feature-state` 로
  굴려 매 프레임 재타일링이 없다. 실데이터 서비스는 링이 한 번 더 뛴다.
- **타임라인 바**가 스스로 재생(스크롤을 멈추면 멈춘다). 축은 2025-04 → 2026-08 실축이되, 재생 헤드만
  구간 속도를 달리해(앞 12% 로 13개월, 뒤 88% 로 4개월) 정사영상 4시점 눈금과 서비스 점등이 모두 보이게 했다.
- **deck.gl ArcLayer**: LX 본사(전주 만성동 127.148, 35.824)에서 점등된 서비스로 아크가 흐른 뒤 옅게 남는다.
- 좌측 부처 칩 5개가 해당 서비스 점등과 동기화되어 켜진다. 문장의 숫자(부처 수·서비스 수·실탐지 합계)는
  `services.js` 에서 매번 다시 센다.

### 챕터 4 · 남원 사면 강하 (p 0.545 – 0.80)
- 키프레임 6개: 전국(z6.8) → 전북(z8.5,p45,b−15) → **지리산 서릉(z11,p68,b−35, terrain ON, 과장 1.4)**
  → 남원 분지 활강(z13.5,p62) → AOI 상공(z16,p46) → **착지(z18.2, pitch 0)**.
- 지형은 p 0.578–0.778 구간에서만 켜고 착지 직후 끈다. 켜기 직전 pitch 가 이미 68°라 시각적 튐이 없다.
- V-World 위성 → 우리 정사영상 `namwon_2508` 크로스페이드. HUD 가 실측 메타로 갱신
  (좌표 · GSD 1.54 cm · 촬영 2025-08 · 줌 · 축척 실계산).
- 착지 순간 **스캔라인 1회**(0.8s)가 위→아래로 지나간다.

### 챕터 5 · 증명 (p 0.80 – 1.0)
- **4시점 자동재생**(각 1.2s 정지, 마지막에 멈춤). 필름스트립 썸네일 4장은 **실제 z16 타일에서 구운
  캔버스**다(플레이스홀더 없음). 클릭하면 그 시점으로 간다.
- 재생이 끝나면 **스와이프 커튼**(2025.04 ↔ 2025.10). compare 플러그인은 지도 인스턴스를 2개 요구하므로
  쓰지 않고, B 시점 z17 타일 20장을 뷰포트 좌표에 정확히 붙인 뒤 `clip-path` 로 가른다.
  pitch/bearing 이 0 이 아니면 아핀이 깨지므로 스스로 숨는다(그래서 착지 후 bearing 드리프트를 0 으로 수렴시켰다).
- **변화 지수(비지도)** 오버레이: `namwon-change.geojson` 456폴리곤을 클래스 고정색 + `score` 높이로 얹고,
  자동재생 중에는 시점 전환에 맞춰 pair(04→06, 06→08, 08→10)가 따라 바뀐다. 하단 범례 상시 표기.
- 마지막 CTA 2개는 자석(lerp 0.12).

## 2. 클릭 경로 — "서비스 지점 → 실제 분석 결과" (코디네이터 지시의 핵심)

챕터 3 화면의 서비스 점을 클릭(또는 `.sr-only` 목록에서 키보드로 진입)하면 **탐사 모드**로 들어간다.
페이지 전환 없음, 같은 지도가 날아간다. `Esc` 또는 「← 전국으로」로 복귀.

**결과가 있는 서비스는 실제 산출물이 주 장면이다.** `landxi/assets/data/results.js`(GPKG 4종 변환본)를
`assets.json` 으로 존재 확인 후 동적 import 한다.

| 서비스 | 결과 | 화면 |
|---|---|---|
| 해양쓰레기 | `yeosu-marine-2025-aerial`(1,860 · 스티로폼) / `yeosu-marine-2026-drone`(2,078 · 8클래스) | 사이트 선택 3개(항공·드론·전남 신안 격자), 클래스 범례, 신뢰도 슬라이더 + 히스토그램 |
| 농지이용 | `namwon-farmland-2025`(2,098 필지 · 경작지/비경작지) | 필지 분포 산포 → 「정밀·입체」에서 최밀집 구역 z15.4 pitch 54 압출 |
| 비닐하우스 | `namwon-greenhouse-2025`(1,674 · 단동/다동) | 동일 |
| 도로안전(남원) | 4시점 정사영상 + 변화 지수(비지도) | 시점 4버튼 · pair 4버튼 · 스와이프 · 「평면·비교 / 입체·변화」 |
| 드론 변화탐지(국산리) | `kuksan_a68` ↔ `a71` 소티 비교 | 스와이프 |
| 나머지 9종 | 없음 | 좌표로 날아가되 **결과를 지어내지 않고** "실탐지 레이어 준비 중"이라고 적는다 |

결과 렌더러(`js/results.js` + `stories.js`)는 **스키마를 못 박지 않는다**. 피처를 보고
클래스 키(`class|cls|label|code|category|kind|type`)·신뢰도 키(`confidence|conf|score|prob`)·
지오메트리 종류를 추론해 색/높이/필터를 결정하고, 색·높이를 피처에 구워 넣어 스타일 표현식을
스키마별로 다시 쓰지 않는다. 새 결과가 추가되면 코드 수정 없이 붙는다.
저줌에서는 폴리곤이 픽셀 이하로 사라지므로 **중심점 산포 레이어를 클라이언트에서 생성**해 z13.4 이하에서
띄우고, z13 이상에서 실제 폴리곤 압출로 교대한다.

## 3. 의견을 낸 지점 (브리프가 열어둔 곳 / 브리프와 달리 한 곳)

1. **three.js 를 MapLibre CustomLayer 가 아니라 오버레이 캔버스로 올렸다.** 브리프는 CustomLayer 를
   지정했지만, (a) 글로브 투영에서 `defaultProjectionData.mainMatrix` 의 좌표계 규약이 문서화돼 있지
   않아 위성 배치가 추측이 되고, (b) deck.gl·지형과 GL 상태를 공유하는 리스크가 있으며,
   (c) 무엇보다 **오클루전 구체를 내가 통제**할 수 있어야 궤도 뒷면이 지구에 가려진다.
   대신 MapLibre 글로브의 실제 화면 반지름을 실측으로 역산해(= `worldSize / (2π·cos lat)`, 원근
   D/R≈5.3) three 카메라를 정확히 일치시켰다. 이 값은 문서에 없다 — `map.project` 로 각거리별 화면
   거리를 재서 구했다.
2. **신뢰도 램프를 파랑에서 호박→적색으로 바꿨다.** 브리프의 `--conf-ramp` 는 LX 블루 계열인데,
   해양쓰레기는 연안 수면 위에 놓인다. 저채도 위성영상 위에서 살아남는 축은 채도이고(cartography 스킬),
   파랑은 물 위에서 사라진다. `--conf-1..5` 로 토큰화했다.
3. **부처 칩은 브리프의 5개(농식품·환경·국토·해수·행안) 대신 `services.js` 의 실제 5개**
   (국토교통부·농림축산식품부·환경부·해양수산부·산업통상자원부)를 쓴다. 데이터에 없는 부처를 화면에
   적으면 안티패턴 #11(카피가 생성물처럼 읽힘)이다.
4. **해안선을 벡터타일 폴리곤의 line 으로 뽑지 않았다.** OFM `water` 폴리곤을 line 레이어로 그리면
   **타일 클립 모서리가 동해 한가운데 곧은 흰 선으로 남는다**(실측: z6 타일 경계 lat 40.98°).
   실제 해안선 GeoJSON 을 링→LineString 으로 변환해 쓴다. 시도 경계도 OFM 대신 우리 `sido.geojson` —
   OFM `boundary` 는 규슈·산둥 경계까지 함께 그린다.
5. **`is-light` 전환 시점을 p 0.30 이 아니라 0.755 로 잡았다.** 위성영상 구간(챕터 3–4)의 실제 배경은
   어둡다. 밝기 반전은 "챕터 번호"가 아니라 **실제 배경 밝기**를 따라야 한다.
6. **제주 장면을 실제 좌표대로 둘로 쪼갰다.** `jeju-illegal.geojson`(2건)은 `jeju_2022` 도엽이 아니라
   **`jeju_2020` 도엽 안**에 있다(7 km 떨어져 있다). 한 화면에 억지로 합치지 않고 사이트 2개로 나눴다.
   토지형질 마스크는 흑백 이진 영상이라 그대로 얹으면 검은 판이 되므로, 흰 영역만 루미넌스 기준으로
   탐지색으로 다시 칠해 얹었다. **이 도엽의 분할 면적은 전체의 0.06 % 로 매우 작다 — 패널에 그렇게 적었다.**
7. **변화 지수 표기**: 코디네이터 지시대로 「변화 지수(비지도)」로만 부르고, `built_new` 는 「나지/정지
   변화」(신축 아님), 04→10 구간은 「계절 변화 우세」로 적는다.

## 4. 스택 / CDN 핀 (전부 브리프 고정)

```
maplibre-gl 5.6.0 (unpkg)      deck.gl 9.3.10 UMD (jsdelivr)
three 0.185.1 importmap        gsap 3.15.0 + ScrollTrigger
lenis 1.3.26                   suncalc 1.9.0
```
빌드 없음. `landxi/proto/` 안에서 자체 완결(기존 `assets/js/map/shell.js` 미사용).
타일: EOX Sentinel-2 cloudless(전지구, 키 없음) · V-World(키 있으면 WMTS z7–18, 없으면 xdworld z5–19) ·
Mapterhorn terrarium DEM(`encoding:'terrarium'`, bounds 국토로 제한) · OpenFreeMap 벡터(도로/지명).

`tools/serve.mjs` 에 라우트 2개를 추가했다.
- `/landxi/proto/env.js` — `.env.local` 의 `VWORLD_KEY` 를 `window.VWORLD_KEY` 로 주입(소스에 키 없음).
- `/landxi/proto/assets.json` — 병렬 산출물(위성 glb·구름·변화지수·results) 존재 여부.
  **404 로 존재를 확인하면 콘솔 오류가 남기 때문**이다.
