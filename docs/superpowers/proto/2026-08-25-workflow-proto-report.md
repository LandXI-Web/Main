## 0. 한 줄

**후처리 블록의 신뢰도 임계 = 지도 슬라이더 = 히스토그램 커서.** 세 구역(노드 캔버스 · 결과 지도 · 지표)이
하나의 상태를 보고, 어디를 만져도 같은 프레임에 세 곳이 다시 그려진다. 1차 시안이 "정적"이라고 반려된
이유가 이 연결의 부재였으므로, 이 프로토는 그 연결 하나를 증명하는 데 전부를 걸었다.

## 1. 무엇을 만들었나

### 1.1 좌측 — 노드 캔버스 (`wf-graph.js`)

실행 가능한 블록 그래프. 기본 파이프라인은 **전남 해양쓰레기 탐지** 6블록이다.

```
01 영상 입력 ─image─▶ 02 타일 분할·SAHI ─tiles─┐
03 모델      ─model──────────────────────────┴─▶ 04 탐지 ─det─▶ 05 후처리 ─det─▶ 06 지도 출력
```

- **포트 타입 시스템.** `image / tiles / model / det / table / grid` 6종. 포트에서 드래그하면 호환 포트만
  켜지고 나머지는 흐려진다. 입력 포트는 1개만, 순환은 금지. 포트 옆 `+` 와 우클릭 라이브러리는
  **호환되는 블록만** 목록에 띄운다(Roboflow P10). 블록 카탈로그 13종.
- **팬·줌(0.32–2.2배)·8px 스냅·미니맵**(뷰포트 사각형, 클릭 시 이동).
- **자동 정렬은 사람에게 양보한다(P7).** 손으로 노드를 3px 이상 끌면 자동 배치가 멈추고 캔버스 HUD에
  `자동정렬 일시정지 — 수동 배치` 가 뜬다. 상단 토글로 다시 켜면 재배치.
- **키보드**: Tab 으로 6개 노드 순회, Enter/Space 로 인스펙터, Delete 로 노드·엣지 삭제,
  Ctrl+Z 로 되돌리기(스냅샷 40단계), Esc 로 닫기.
- **엣지 흐름**: 실행 중에만 켜지고, 메시는 움직이지 않고 `stroke-dashoffset` 만 이동한다(iGPU 예산).
  경로마다 위상 `random(0,1)`·속도 `random(0.7,1.3)` — 완벽히 동기화된 모션은 "기계가 만든 티"다.

### 1.2 실행 엔진 (`wf-run.js`) — 여기서 "진짜"인 것

| 항목 | 실제로 무엇을 하는가 |
|---|---|
| 썸네일 | `landxi/assets/tiles/<도엽>/{z}/{x}/{y}.webp` 를 3×3 모자이크로 실제 로드해 그린다 |
| 탐지 오버레이 | 실제 GeoJSON 좌표를 타일 픽셀로 투영. 외곽 2px · 채움 22% · 클래스 고정색 |
| SAHI 격자 | 슬라이스 px × 도엽 GSD × (1−중첩) 로 **지상 스텝(m)** 을 계산해 긋고, 도엽 실범위로 총 타일 수를 낸다 |
| 진행률 | 검출 폴리곤을 6청크로 나눠 실제로 그리며 올린다. 타이머 페이크 없음 |
| 지연시간 | `performance.now()` 실측. 블록별 스택 바 + 최근 14회 총소요 추세 |
| 캐시 | 캐시 키 = 자기 파라미터 + 상류 키. 상류가 바뀌면 자동 무효. 임계값만 바꾸면 01–04 는 `캐시됨`, 05–06 만 재계산 → **1,263 ms → 24 ms** (스크린샷 `slider-090.png` 에 그대로 찍혀 있다) |
| Sink 안전 | `국토조사 DB 반영` 체크 해제 상태에서 `GeoJSON 내보내기` 블록은 건너뛴다. 시험 실행은 아무것도 망가뜨리지 않는다 |

인스펙터는 **Visual / JSON / 로그** 3탭. Visual 은 노드의 336px 캔버스를 확대하는 게 아니라
768px 로 다시 그린다. 로그는 `추론 체인` 으로 0.06s 간격 순차 스트리밍된다.

### 1.3 우상단 — 결과 지도 (`wf-map.js`)

- 배경: V-World 위성(`/landxi/proto/env.js` 의 키가 살아 있으면 WMTS, 아니면 키 없는 xdworld 로 조용히 폴백).
  Hybrid 라스터를 지명·도로 오버레이로 얹고 토글 가능. **위성 위 라벨 규칙**(흰 글자 + 어두운 반투명 헤일로)은
  V-World Hybrid 타일이 이미 그렇게 구워져 있어 그대로 쓴다.
- 데이터: 전남 해양쓰레기 **3개 실산출물의 합집합 8,339건 · 9클래스**
  - `marine-debris.geojson` 5,000 (conf 0.51–1.00)
  - `results/yeosu-marine-2026-drone.geojson` 8클래스 (conf 0.108–0.874)
  - `results/yeosu-marine-2025-aerial.geojson` (conf 0.05–0.72)
  뒤의 둘은 병렬 작업 산출물이라 **없으면 조용히 빠진다**(필수는 5,000 폴리곤뿐).
  스키마가 세트마다 달라(`confidence/conf`, `class/cls`, `area_m2/area`) 로더에서 한 번만 정규화한다.
- **신뢰도 슬라이더는 `setFilter` 로 같은 프레임에 반영**되고, 같은 호출에서 카운트·요약·필터 칩·
  히스토그램·클래스 막대·후처리 노드 파라미터가 전부 갱신된다(`applyAll`).
- **걸러진 것은 사라지지 않는다.** `det-dim`/`pts-dim` 레이어가 opacity 0.12 로 남고, 상단에 제거 가능한
  필터 칩이 생긴다(되돌리기 비용 0).
- **줌 아웃 = 격자.** z10.6 아래에서는 500 m 셀로 **지금 통과한 검출만** 다시 세어 개수 비례 원으로 그린다
  (미리 구운 `marine-debris-grid.geojson` 의 `mean_conf` 로 근사하지 않는다). 셀을 클릭하면 그 셀로 내려간다.
- **호버 툴팁**: 클래스·신뢰도(모노)·면적·출처 파일명 + **V-World 타일에서 잘라낸 256px 미니 크롭**에
  해당 폴리곤을 실제로 그려 얹는다. 광역 줌에서 격자 버블을 호버하면 셀 요약이 뜬다.
- **시점 비교 탭**: 남원 4시점(2504/2506/2508/2510) 정사영상을 실제 타일로 4×4 모자이크해 스와이프.
  B 면에는 `namwon-change.geojson` 456폴리곤(변화지수·비지도)을 현재 임계값으로 얹는다.

### 1.4 우하단 — 지표 (`wf-charts.js`)

캔버스 4장(ECharts 미사용 — 축·색·히트영역을 토큰과 정확히 맞추기 위해).

1. **신뢰도 히스토그램** 24빈. 임계선 표시, 아래쪽은 감쇠. **막대 클릭 = 임계값 설정**(차트가 필터를 겸한다).
2. **클래스별 막대**. 회색 = 전체, 채색 = 현재 통과. **막대 클릭 = 클래스 토글**, 꺼진 행은 취소선.
3. **학습 곡선** — 저장소에 학습 로그(`results.csv`)가 **없다**. 그래서 그리는 곡선은 예시이며
   차트 헤더에 `예시 · 실 로그 없음` 배지를, 모델 노드 썸네일 안에는 `예시 곡선 · 실 학습 로그 없음` 을
   직접 그려 넣었다. 모델 id 로 시드를 고정해 새로고침마다 값이 달라지지 않는다.
4. **최근 실행 지연** — 전부 실측. 캐시 적중 블록은 회색, 실계산 블록은 블록색.

### 1.5 디자인 규칙 준수

- **유리는 화면당 2개**(하단 실행 바 · 지도 필터 패널). 노드 카드는 불투명 종이. `blur:12px` 고정, 애니메이션 없음.
- **아이콘 3단 상태** — 기본 `--sl-8`(뮤티드) → hover `--ink-2` → selected `--lx`.
- **UI 전환 100ms(`--t-ui`) / 카메라 1.2s** 두 축을 섞지 않는다.
- **모든 수치가 IBM Plex Mono** — 좌표·신뢰도·면적·ms·타일 수·GSD.
- **검출 팔레트를 토큰화**해 `landxi/assets/css/tokens.css` 에 **가산 전용**으로 추가
  (`--det-0..9`, `--conf-0..5`, 슬레이트 램프 `--sl-1..15`, 모션 사전). 기존 블록은 한 줄도 건드리지 않았다.
- **판독(다크 ops) 모드** — 색 반전이 아니라 별도 세트. 토큰을 `:root[data-ops="dark"]` 에 얹어
  `tokens.js` 의 `cssVar()`(documentElement 를 읽는다)가 캔버스 차트 색까지 같이 따라오게 했다.
- **상시 모션은 1개** — 실행 노드 칩의 맥동 링. 엣지 흐름은 실행 중에만.

## 2. 왜 이렇게 했나 — 결정 3개

**(1) 노드 썸네일은 "샘플 도엽 즉시 추론" 이다.**
여수 해안에는 우리 정사영상 타일이 없다(정사영상 9종은 남원·국산리·제주뿐). 없는 영상을 만들어낼 수는
없으므로, 노드 썸네일은 Roboflow 의 *"전체 1,024타일을 돌리기 전에 샘플 1장으로 임계값을 눈으로 맞춘다"*
패턴을 쓴다. 도엽마다 **실제로 존재하는 산출물만** 연결했고(남원 → 변화지수 456, 제주 2020 → 불법건축물 2),
없는 도엽은 화면에 `이 도엽에 저장된 탐지 산출물 없음` 이라고 쓴다. 남원 변화지수는 학습 모델의 탐지가
아니므로 인스펙터 로그에 `학습 모델 탐지가 아니라 4시점 영상 차분이다` 를 항상 남긴다.

**(2) 격자는 미리 구운 파일이 아니라 지금 센 값이다.**
`marine-debris-grid.geojson`(9,032셀)에는 `mean_conf` 가 있어 그것으로 필터할 수도 있었지만, 그러면
"격자가 슬라이더와 연결되어 있다"는 인상이 근사값 위에 서게 된다. 8,339건을 매 필터마다 다시 세는 편이
싸고(Map 1회 순회) 정확하다.

**(3) 슬라이더 하한을 0.05 로 열었다.**
브리프는 0.5–1.0 이었으나 여수 산출물의 신뢰도가 0.05–0.87 이라, 0.5 를 하한으로 두면 1,800여 건이
기본값에서 이미 사라진 채로 시작한다. 하한은 **데이터에서 계산**(`floor(min,0.05)`)하고 초기값만 0.50 으로
둔다. `marine-debris.geojson` 단독으로 로드되면 브리프대로 정확히 0.50–1.00 이 된다.

| 5 | 결과 스트리밍 | △ | 탐지 블록이 6청크로 쌓이며 그려진다. 지도 쪽 스트리밍은 없음 |
| 6 | "내 영상으로 지금 해보기" | △ | 영상 입력 블록에서 도엽 9종 즉시 교체 → 자동 재실행(1클릭). **업로드 경로 없음** |
| 7 | AI 예측과 사람 확정의 시각적 분리 | ✗ | 미구현 |
| 8 | 부정 예제 피드백 경로 | ✗ | 미구현 |
| 9 | 포트 기반 그래프 편집 | ✅ | 드래그 연결 + 포트 `+` + 우클릭 라이브러리. 드롭다운 배선 아님 |
| 10 | 호환성 인지 추천 | ✅ | 포트 타입이 맞는 블록만 목록에 뜨고, 드래그 중 비호환 포트는 감쇠 |
| 11 | 노드 실행 상태 배지 | ✅ | 대기 / 계산중 n% / 완료 / 캐시됨 / 실패 5상태 |
| 12 | 자동 정렬이 사람에게 양보한다 | ✅ | 드래그 시 일시정지 + HUD 고지 + 토글로 복귀 |
| 13 | 버전 히스토리 + Live 배지 + 복원 | △ | `v3 ● Live` 배지와 Ctrl+Z 스냅샷 40단계. **버전 목록·롤백 UI 없음** |
| 14 | 클래스 → 색 고정 매핑 | ✅ | `tokens.css --det-0..9` + `DET_SLOT` 매핑. 캔버스·지도·차트가 같은 값을 읽음 |
| 15 | 어두운 이미지 뷰어 + 밝은 크롬 | ✅ | 썸네일·인스펙터·스와이프는 다크, 주변 UI 는 라이트 |
| 16 | 키보드 우선 | △ | Tab/Enter/Delete/Ctrl+Z/Esc 동작. 라벨링 단축키는 이 화면 범위 밖. **상시 힌트 바 없음** |
| 17 | 수치는 모노스페이스 | ✅ | 예외 없음 |
| 18 | 공유 링크가 그 자리에서 실행된다 | ✗ | 미구현 |

**점수: 9 ✅ + 6 △(0.5) = 12.0 / 18.** 합격선을 겨우 넘었다. △ 6개 중 ④⑤⑬ 은 분석 실행 화면(§5.7)과
프로젝트 화면(§5.5)에서 채워야 할 몫이고, ③⑥⑯ 은 이 화면 안에서 더 밀 수 있다.

## 4. 남은 구멍 (우선순위)

1. **실행 관측 3종 세트(④⑤)** — 지금 파이프라인은 0.3초에 끝나므로 스트리밍할 시간이 없다.
   전국 배치 실행(1,024타일 급) 화면을 별도로 만들어 *누적 검출 곡선 · 신뢰도 히스토그램 누적 ·
   최근 검출 썸네일 스트림* 3종을 붙여야 한다. 발주처에 "살아있음"을 가장 강하게 전달하는 장치다.
2. **검수 루프(⑦⑧)** — 예측(점선) ↔ 확정(실선) 분리, 승인 게이트, 오탐 신고 → 재학습 큐.
   공공 국토조사 맥락에서 Land-XI 만의 서사가 될 수 있는 부분인데 통째로 비어 있다.

# §v3 — 전면 재구축: "워크플로우 캔버스" → **국토 조사 보드** (2026-08-25)

## v3.0 왜 다시 만들었나

발주처 판정: **"너무 업무 시스템. 우와, 혁신이다? 가 없다. 기대의 2%. 폰트도, 디자인도, 차트 디자인도 마음에 안 든다."**

노드 벤치마크(`docs/superpowers/research/2026-08-25-bench-nodes-creative.md`)의 진단은 잔인할 만큼 단순했다 — **죽은 캔버스의 노드 안에는 텍스트가 있고, 살아있는 캔버스의 노드 안에는 그 노드가 방금 만든 그림이 있다.** 1차 시안은 흰 카드 + 아이콘 + 파라미터 요약이었다. 그래서 고친 것이 아니라 다시 만들었다.

구성은 벤치마크 권고(A 메인 · C 진입 · B 심층)를 그대로 따랐고, 세 배율이 **같은 `state.t` 와 `state.selection`** 을 본다.

## v3.4 시간과 선택

- **상주 타임라인**(화면 폭 전체, 132px, 이 화면에서 허용된 단 하나의 유리 `rgba(36,39,48,.85)`): 4시점 눈금 + 구간별 **실제 변화 건수 스파크 112 / 79 / 109**(`change.js`, 계급별로 쌓음). `▶` 자동재생은 **호버하면 멈춘다.**
- **결손을 숨기지 않는다** — 전역 정사영상은 04·10 두 시점뿐이다. 06·08 눈금은 무채 점선 + `AOI 전용`이고, **누르면 그 도엽(금지 농경지)으로 카메라가 간다.**
- **삼면 결속** — `selection` 하나가 지도(흰 사각형) ↔ 좌하단 타일 스트립(z17 실제 타일 + 탐지 오버레이) ↔ 타임라인(시점별 커버리지 눈금)을 동시에 좁힌다. 스트립 타일에 호버하면 지도에 같은 앰버 브래킷이 뜬다.
- **뷰어 플래그** — 정확히 한 액자만 `지도에 표시 중`. 다른 액자를 누르면 플래그가 옮겨가고 지도 레이어가 그 단계의 산출물로 교체된다(SOURCE=영상만 / DETECT=통과만 / POST=통과+감쇠).
