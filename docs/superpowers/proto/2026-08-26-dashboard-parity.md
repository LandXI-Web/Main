원본: <https://mini531.github.io/namwon-smart-village/landxi7/dashboard.html>
(좌측 레일은 `include/header.html`, 로더는 `assets/js/layout.js`)
우리 구현: `landxi/proto/dashboard.html` + `dashboard.js` + `db-*.js`

원칙(클라이언트 지시, 2026-08-26): **"최대한 기능적으로 추가가 없게. 왼쪽 메뉴(데이터 관리 등)도
구현. 현재 구현된 기능에 디자인을 입힌다."** → 이 표의 모든 행이 1:1로 대응해야 하고,
표에 없는 기능은 새로 만들지 않는다.

**채택안: A안 "지도 위 원장"**(`docs/superpowers/specs/2026-08-26-map-dashboard-options.md` §3.1).
레일 `A1–A11` + 원장 `B1–B15`(원본 순서 그대로, 좌측 372px) + 판(정사영상 풀블리드).
초기 구현의 **레지스터 탭(01/02/03) · 처리 대기 큐 7건 · 전국 커버리지 매트릭스는 삭제**했다 —

### B-표 밖에 있는 것 = 판 위 계기 (전부 원본 위젯의 다른 표현)

| 계기 | 무엇을 하나 | 대응하는 원본 기능 |
|---|---|---|
| 취득 밀도 스캔 스트립 `#scan` | 남원 농경지 정사영상 **4시점** + 변화 지수(비지도) **4쌍**의 눈금. 틱을 누르면 카메라가 그 범위로 간다 | B2 기준일 · B11 시점축 |
| 어두운 유리 시간 스크러버 `#strip` | 화면에 허용된 **단 하나의 유리**. 스스로 재생하다 사건(분석 완료)에서 **2.2초 선다** | B10–B12 시점 구동 |
| 임계 드래그 범례 `#thr` | 슬라이더가 아니라 **실제 신뢰도 히스토그램 위의 마커**. 숫자는 항상 보이고 통과 건수가 즉시 재계산된다 | B9 모델 카드(신뢰도) · B13 검토 대상 산정 |
| 벡터 추출 카드 `#vcard` | 정사영상 크롭과 추출 벡터를 같은 액자에 나란히 — 백본 모델이 하는 일의 **증거** | B9 |

## C. 원본에 없어서 만들지 않은 것 (Playwright 실측)

| 항목 | 실측 | 우리 처리 |
|---|---|---|
| 탭 UI | `[role=tab]` · `.tab` · `[data-tab]` **0개** — 차트 3개는 탭이 아니라 나란한 3열 | 레지스터 탭 01/02/03 **삭제**. e2e 가 `탭 0개`를 검증한다 |
| 커버리지 위젯 | 없다. `<table>` **0개** | 전국 커버리지 매트릭스 **삭제** |
| 처리 대기 큐 | 없다. 대기 목록은 **카드 발행 승인 2건뿐** | 7건짜리 합성 큐 **삭제**. 사용자·문의 건수는 원본대로 KPI 부제(B4·B8)로만 |
| 지도 | 원본 대시보드에 지도 요소는 **없다** | 그래서 판은 위젯이 아니라 **바탕**이다 — B1–B15 를 조판하기 위한 사진이며, 그 위에 그리는 것은 실존 결과 4건과 정사영상 11종 풋프린트뿐이다 |
