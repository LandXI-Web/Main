## 3. 고칠 것 (우선순위)

1. **Pages 에서 안 열리는 링크를 캡처나 영상으로 바꾼다.** 백엔드가 필요한 v3·XI맵·관제·Global 18장과 로그인 가드에 걸리는 v1 29장이 대상이다. 로컬에서 찍은 스크린샷이나 동작 영상을 `assets-thumbs/` 에 두고 카드 썸네일과 열기를 그 파일로 연결한다. 토스 제안 14장은 Pages 에 올라간 이미지로 바꾼다(.md 링크는 제거).
2. **썸네일 23장을 채운다.** v3 5장은 로컬 :8700 에서 캡처하고, 토스와 카카오 결정 카드는 벤치 캡처를 쓴다.
3. **카드 글을 사용자 말로 바꾼다.** 제목은 "무슨 화면"이 되게 하고, 이유는 "무엇이 좋아서"를 한 줄로 쓰고, 다음은 "어느 화면에 들어간다"로 쓴다. D·F·B·§·ⓐ·스펙시먼·토스 n-n·v1/v2/v3·파일 경로는 호버(개발자 정보)로 옮긴다. 생성기 `tools/review/masters.mjs` 의 `card()`/`targetLine()` 과 assets.json 의 `reason/later/next` 를 함께 고쳐야 한다.
4. **화면 한 줄 원칙을 적용한다.** 화면마다 「지금」→「다음(승인 대기)」 두 카드만 보여 주고, 원판·스펙시먼·지난 안은 접기에 넣는다. 52개 화면이 대상이며 로그인이 1순위다.
5. **ops·global 절대경로 404** 는 Pages 가 `/Main/` 하위라서 생긴다. 해당 폴더는 다른 워크플로 소관이라 이번에는 보고만 한다.
6. **현황판**: 카드에 캡처 확대와 열기(가능한 것만)를 넣고, v3 카드 제목을 한글 화면명으로 바꾼다. "실제 서버 연결 14개"에는 "Pages 에서는 캡처로만 보임"을 표시한다.
