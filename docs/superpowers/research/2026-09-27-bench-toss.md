## 1. 기술 실측 — "WebGL"의 실체

| 항목 | 실측 |
|---|---|
| 스택 | Next.js App Router(`__next_f`) · vanilla-extract 해시 클래스 · **Lenis** 부드러운 스크롤(`window.lenis`, 데스크톱만) · **lottie-web**(`lottie.min.js` 62KB, `main_check.json`, `gradient-progress-mono.json`) · 모션은 WAAPI(`Element.animate`, 스프링을 `linear(...)` 곡선으로 변환해 넣음 → Motion/Framer 계열 추정) |
| three.js·Rive·Spline·GSAP | **없음**(전역·스크립트·네트워크 모두 흔적 0) |
| WebGL | **webgl2 컨텍스트 2개뿐** — 투자 섹션 카드 속 **점 지구**(1400², `framer-globe-dots.bin` 158KB 점 데이터). 페이지 전체에서 유일한 실시간 3D |
| 캔버스 2D(주력) | **스크롤 스크럽 이미지 시퀀스 3개**: 히어로→송금 `hero-frame-*/frame_#.avif` **138장**(sticky 트랙 5,850px) · 쇼핑 상자 `shopping-box-intro` **90장**(4,500px) · 토스플레이스 `place-kr` **144장**(9,300px). 그 밖 2D: 광고 점 구름 파도(1440×893), 글로벌 와이어 지구(1140×684), 눈송이 입자 |
| 영상 | mp4 9개(히어로 루프 1920×1080 4s, 결제 UI 2880×1800 루프 6–8s, 미니앱 세로 영상 4개). 모바일은 이미지 시퀀스 대신 **mp4로 교체**(`hero-mobile/intro-loop.mp4`, `intro-flow-kr.mp4`), WebGL 지구 없음 |
| 비율(데스크톱 홈, 56화면) | 실사 이미지 시퀀스 ≈ 35% · 실제 UI 목업(이미지·영상) ≈ 35% · 실사 사진·영상 ≈ 20% · 실시간 WebGL ≈ 2%(카드 하나) · Lottie는 체크·진행바 같은 **작은 강조**에만 |
| 전송량 | 이미지 11.0MB · 영상 9.7MB · 폰트 2.6MB(Toss Product Sans 5굵기 각 ~0.5MB) · 스크립트 0.7MB · 프레임 fetch 385건 |
| 스크롤 트리거 | `position: sticky` 900px 판 + 부모 트랙(2,250–9,300px = 2.5–10화면) 안에서 스크롤 진행률 → 캔버스 프레임 번호. 텍스트는 진입 시 WAAPI 1회 재생 |

**결론: 토스의 "WebGL 느낌"은 대부분 _미리 렌더한 3D·실사 프레임을 스크롤에 묶은 것_이다.** 실시간 3D는 점 지구 하나. Land-XI는 반대로 실시간 지도·지구가 진짜 자산이므로, 토스의 연출 문법만 가져오고 재료는 실데이터 WebGL로 채우면 된다.

## 4. '콘텐츠별 소개' 문법 분해

**한 섹션 = 한 서비스 = 4요소.**

1. **브리지 한 줄**(5–15자, 판 위 중앙) — 앞 장면에서 넘어오는 순간에만 뜬다. "몇 번만 누르면", "이제는 토스로".
2. **헤드라인 2줄**(13–25자, 48px) + **보조 1문장**(≤60자, 회색 16px). 끝.
3. **큰 비주얼 하나**가 화면의 60–80%: 실사 이미지 시퀀스, **실제 제품 UI**(휴대폰·POS·모니터 속 진짜 화면), 점 지구·점 구름 같은 데이터형 그래픽. 일러스트 없음.
4. **하위 항목 3–4개**(제목 ≤20자 + 본문 1문장) — 탭·아코디언·가로 카드로 **한 번에 하나만 펼침**(자산 섹션: 4항목 중 활성 1개만 진한 잉크, 나머지 20% 투명).

**섹션 사이 리듬**: sticky 판(2.5–10화면)에서 카메라가 한 번 움직임 → 흰 숨 쉬는 구간(패딩 200) → 다음 판. 배경은 흰 → 회 → 검정(반전 1회) → 남색 마감. **한 화면에 동시에 움직이는 것은 하나.** 모든 챕터가 같은 틀을 반복하므로 11개 서비스를 늘어놔도 어수선하지 않다.

**연속 카메라**(`_strip-video-0-12s.jpg`): 히어로 카드(둥근 모서리, 여백 8px) → 스크롤하면 카드가 풀블리드로 커지고 → 인물에서 손, 손에서 휴대폰 화면으로 밀고 들어가고 → 다시 카드로 줄어들며 → 휴대폰만 흰 판 위로 떠올라 다음 섹션의 비주얼이 된다. **장면이 끊기지 않고 '물건'이 다음 섹션으로 건너간다.**

**텍스트 절제**: 56화면에 헤드라인 ~20개, 본문 문장 ~40개. 화면당 평균 60자 이하. 숫자는 사용자 가치(3,000만 고객, 800만 방문, 2일 정산)만 쓰고, 기술 지표는 없다.

| 4 | 서비스 카드 생산 | **한 번 만든 분석이 / 서비스가 된다** · "모듈과 모델을 묶어 실태조사 카드로 만듭니다." | 카드 3–4장이 모듈·모델 조각에서 조립되어 떠오름(실제 카드 UI) | 토스 쇼핑 상품 그리드처럼 카드 가로 등장 750 스태거 120 | 3화면 |
| 5 | 지자체 제공 | **어느 시군구든 / 그대로 배포한다** · "지역만 바꾸면 같은 서비스가 바로 열립니다." | 전국 시군구 경계 지도 위에 배포본이 켜지는 점(실배포 목록만, 없으면 결손 점선) | 필라멘트가 남→북 차오름 | 3화면 |
| 6 | 글로벌 | **국경 밖에서도 / 같은 지도** · "Sentinel·WorldCover로 해외 사업지를 같은 방식으로 분석합니다." | GLOBE-STAGE(순백 지구) → 대상국 면 채색 | 카메라 이동 2400 · 한반도에서 대상국으로 곡면 따라 이동 | 3화면 |
| 7 | 마감 | **Hyper Performance · Hyper Solution · Hyper GeoAI** · CTA "로그인하고 시작하기" | 큰 워드마크(토스 "All in one App" 마감 문법) | 글자 인 500 | 1화면 |

- 챕터 간은 흰 숨 구간(패딩 200) 하나. 화면당 동시에 움직이는 것 1개.
- 글자 예산: 헤드라인 7개 + 보조 7문장 + 하위 항목 ≤ 9개. **숫자는 봉투 있는 업무 결과만**, 없으면 넣지 않는다.
- 전국 관점: 모든 챕터의 기본 카메라는 전국. 남원·여수 등은 챕터 2의 줌 대상 하나일 뿐, 이름을 헤드라인에 쓰지 않는다.

### 5-3. 로그인(플랫폼 소개)

- 좌 로그인 패널(종이 무대) + 우 소개 판 3장면 자동 순환(6s): ① 전역 추론이 차오르는 지도 ② 대장 대조 락온 ③ 에이전트 질문 → 지도. 각 장면 **헤드라인 1줄(≤15자) + 보조 1문장**, 3축 모토는 하단 한 줄.
- 전환은 토스 히어로 단어 교체(퇴장 −40px / 입장 +40px, 750 `--e-cam`, 스태거 100→120).

### 5-4. 기능별 소개 섹션(각 화면 첫 진입·빈 상태·서비스 카탈로그)

토스 하위 페이지(`sec-d-*`, `pos-d-*`) 문법: **히어로(헤드라인 2줄 + 실사/실제 UI) → 좌 글·우 비주얼 교차 블록 3–5개(헤드라인 ≤20자 + 1문장 + "자세히 보기") → 관련 서비스 카드 → 마감**. Land-XI 서비스 카탈로그(부처별 실태조사 카드)의 상세 페이지를 이 틀로 통일하면 15종을 늘어놔도 한 제품으로 읽힌다. 블록 비주얼은 해당 카드의 실제 결과 화면만(지어낸 목업 금지).

### 5-5. 기존 디오라마 스크럽 필름과의 관계

- **유지하되 쪼갠다.** 토스 홈도 결국 "스크럽 필름 3편 + 사이사이 소개 섹션"이다. 12 leg 60초 필름을 한 덩어리로 두지 말고, **leg 1–2(지구→하강)는 챕터 0→1의 연결 카메라**, leg 11–12(줌아웃·귀환)는 **챕터 6→7의 마감 카메라**로 재배치한다.
- 가운데 leg 4–10(남원 농지·여수 해양쓰레기·울주 산림 등 지역별 장면)은 **메인에서 뺀다**: 지역 이름이 앞에 나오고, 샷리스트에 '시연' 라벨이 남아 있어 전국 관점·'시연' 금지 규칙과 충돌한다. 이 장면들은 서비스 카탈로그 상세(5-4)의 히어로 비주얼로 옮긴다(예: 해양쓰레기 카드 상세 = leg 7).
- 기술: 필름 legs를 토스처럼 **sticky 트랙 + 진행률 → 카메라/프레임**으로 묶고, 모바일·저사양은 같은 leg를 AVIF 시퀀스/mp4로 사전 렌더해 교체(토스 모바일 방식).

### 5-6. 가져오지 않을 것

오버슈트 이징(1.15·1.275·1.56) · 둥근 카드 · 실사 인물 연출(우리는 실제 영상·결과로 대접) · 56화면 길이 · 포인트 블루 채움 버튼 · Lenis 관성 스크롤은 지도 제스처와 충돌하므로 메인 소개 구간에만 한정(지도 판 안에서는 끔).
