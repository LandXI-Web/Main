### 2-1. `LAND-XI PLATFORM` 워드마크 — 기하 실측 (1280×720 기준)

t = 64.17 s 프레임(`shots/promo/brand-wordmark-globe.png`)에서 화이트 임계(R,G,B > 225) 바운딩박스 실측:

| 항목 | 실측값 | 프레임 대비 |
|---|---|---|
| 워드마크 폭 | **398 px** (x 437–834) | **31.1 % 화면폭** |
| 캡 하이트 (`I` 글리프 y 369–409) | **41 px** | **5.7 % 화면높이** |
| 폭 : 캡하이트 | **9.7 : 1** | — |
| 스트로크 두께 | ≈ 9–10 px | 캡 대비 **0.23**(= ExtraBold/Black) |
| 베이스라인 | y = 409 | **56.8 % 화면높이**(중앙보다 아래) |
| 광학 중심 x | 635.5 | 화면 중앙 −4.5 px |
| 워드스페이스(`LAND-XI` ↔ `PLATFORM`) | **22 px** | 캡 대비 **0.54** |
| 3D 압출 깊이 | ≈ 8–10 px, 좌하 방향 | 캡 대비 0.22 |

- **자족**: 올캡, 지오메트릭 그로테스크 **ExtraBold/Black**. `A` 뾰족한 정점, `R` 직선 다리, `M` 베이스라인까지 내려오는 뾰족한 중앙 꼭짓점, `O` 거의 정원, 터미널 평절. **Montserrat ExtraBold / Poppins ExtraBold 계열**로 읽힌다.
- **색**: 면 **솔리드 화이트 `#FCFFFD`** — 그라디언트 없음. 압출 측면은 한 톤 어두운 회백, 아래로 부드러운 드롭섀도.
- **레터스페이싱**: 트래킹은 사실상 0(노멀). 단, `LAND-XI` 구간 22.1 px/글리프 vs `PLATFORM` 구간 27.6 px/글리프로 **화면상 자간이 다르다** — 이는 트래킹이 아니라 **문자열이 지구 적도를 감는 곡면 링 위에 배치되어 생기는 원근**이다. 중앙에 가까운 글자가 넓게 보인다.
- **인/아웃**:
  - **인** = 스케일업이 아니라 **알파 머티리얼라이즈 0.17 s**. 지구 풀백 도중 62.83 s에 나타난다.
  - **온 상태 1.33 s** 동안 워드마크가 커지지 않고 **지구와 함께 −35 % 축소**된다. 관객은 "로고가 붙는다"가 아니라 "이 세계가 이 이름을 갖고 있다"로 읽는다. — **홍보영상 브랜드 문법의 핵심**.
  - **아웃** = 배경 화이트아웃과 **동시** 페이드(0.33 s). 별도 아웃 애니메이션 없음.
- **최종 브랜드 마감 프레임 타이밍**: 워드마크 최초 가시 **62.83 s** / 최대 가독 크기 **63.50 s**(폭 506 px = 39.5 % 화면폭) / 소멸 **64.67 s**. **총 노출 1.84 s.**

## §3. 홍보영상이 말하는 플랫폼 vs 우리 13종

### 3-1. 영상의 스토리 비트 (5막)

1. **관성**(0–8 s) — 뉴턴의 요람. "가만두면 그대로 반복된다."
2. **위기**(8–17 s) — 벌목·산불·토네이도·폐허. 국토가 훼손된다.
3. **개입**(17–23 s) — 공 하나가 민트로 바뀌어 연쇄를 때린다. **한 점의 개입이 전체를 움직인다** = 플랫폼의 은유.
4. **작동**(23–60 s) — ① 센싱(드론/항공 도시 비행) → ② 판독(플랫폼 대시보드) → ③ **AI 탐지 4종 정량화** → ④ **지도 위 결과 집계** → ⑤ **`과학적 의사결정 지원`**(여러 담당자가 동시에 쓴다).
5. **회복 · 브랜드**(60–71.5 s) — 초록 지구 풀백 → 워드마크 → 태그라인 → LX.

**핵심 주장**: "국토를 촬영하고, AI가 훼손·방치를 **면적/부피/무게 숫자로** 뽑고, 지도 위에 모아, 담당자가 **과학적으로 의사결정**하게 한다."

### 3-2. 영상에 나온 항목 ↔ 우리 13종 (`landxi/assets/data/services.js`)

### 3-3. 우리가 그대로 가져와야 할 것

1. **"검출명 + 단위 붙은 숫자"의 카드 포맷.** `검출명: X` (볼드) / `측정항목:` / **박스 안에 큰 숫자 + 작은 단위**. 우리 13종은 이미 `count` + `unit`(건/필지/개소/동/개)을 갖고 있다 — **홍보영상과 같은 3줄 포맷으로 통일하면 클라이언트에게 즉시 "우리 영상 그거"로 읽힌다.**
2. **숫자 카운터 틱업.** `25 ㎡ → 62 ㎡` 처럼 정지 수치가 아니라 올라가는 수치. 우리 실측(남원 변화지수 456, 해양쓰레기 38,057건)에 그대로 적용 가능.
3. **탐지 대상을 감싸는 와이어메시 돔 + 코너 브래킷.** 우리 dive 프로토의 탐지 하이라이트를 이 문법으로 바꾸면 영상과 한 세계가 된다. (단, 필름 프리앰블은 "HUD 없음"이므로 **필름이 아니라 페이지 오버레이/dive 프로토에만** 적용.)
4. **결과 집계 지도.** 지도 위 5개 카드 = 우리 `home-hud` 의 13포인트 리더선과 정확히 같은 구조다. 다만 **영상은 5개만 띄운다** — 우리 카피 덱의 "13개 라벨 금지, 최근 4건만" 규칙과 일치. **유지.**
5. **`과학적 의사결정 지원` 이라는 한 줄.** 우리 카피 덱에 이 문장이 없다면 **넣어야 한다** — 클라이언트가 자기 영상에서 이미 승인한 유일한 가치 문장이다.
6. **`탄소 흡수량` · `산림 훼손` 격차.** 두 항목은 클라이언트가 홍보영상에 넣을 만큼 중요하게 본 것인데 우리 13종에 없다. **선택지**: (a) 13종 유지 + 필름/카피에서 언급하지 않는다(정직성 규칙 준수, 권장), (b) 라인업 확장 여부를 클라이언트에 질의. **없는 수치를 만들어 붙이지 않는다.**

### 4-0. 전제 (기존 필름 구조와의 정합)

- 12-leg 스크럽 필름은 이미 **Leg 11 = 줌 아웃 · 국토 변화**(5 s, 남 → 북 색 띠 확산 + 풀백), **Leg 12 = 귀환**(5 s, 지구본 복귀 + 황동 링, 마지막 프레임 = Leg 1 첫 프레임 = 루프 조인트)로 설계돼 있다.

- 루프 조인트를 깨지 않으려면 **Leg 12 영상 자체는 손대지 않는다.** 마감 판은 필름 종료 후 **핀 구간**으로 이어 붙인다.

### 4-2. 워드마크 렌더 스펙 (홍보영상 비율 그대로)

```

캡하이트   = 워드마크폭 ÷ 9.7
베이스라인 = 화면높이 × 0.568                            # 지구본 적도선 = 홍보영상 실측
좌우 중심  = 화면 중앙 (offset 0)
워드스페이스 = 캡하이트 × 0.54
```

- **3D 압출은 재현하지 않는다.** 필름 세계는 실사 미니어처(tilt-shift)이고, 3D 압출 CG 문자는 `NOT CGI` 프리앰블과 충돌한다. **압출 대신 솔리드 화이트 + 소프트 드롭섀도**로 "빛이 닿는 물체" 감각만 가져온다.
- **곡면 배치도 재현하지 않는다.** 정지 프레임 위에서는 원근 자간이 오히려 오류로 읽힌다. **직선 배치 + 트래킹 0.**

### 4-5. 왜 이 마감이 "같은 브랜드"로 읽히는가

- **순서가 같다**: 풀백 → 제품 워드마크 → 태그라인 → 운영기관. 3단 분리를 그대로 유지한다(제품 마크와 LX 락업을 절대 겹치지 않는다).
- **길이가 같다**: 워드마크 노출 1.6 s(영상 1.84 s), LX 홀드 2.4 s(영상 2.34 s), 마감 총 7.0 s(영상 8.68 s — 스크롤 매체이므로 12 % 압축).
- **인 방식이 같다**: 워드마크는 **알파만**, LX는 **블러만**. 슬라이드·바운스·글로우 없음.
- **비율이 같다**: 워드마크 화면폭 34 %, 베이스라인 56.8 %, LX 락업 32.7 % — 전부 실측 이식.
- **다른 점 2가지는 의도적이다**: (a) 3D 압출 → 솔리드+섀도(필름의 실사 미니어처 세계 유지), (b) 배경 화이트 → **크림 헤이즈**(필름 프리앰블의 `pale cream haze` 유지). 두 변경 모두 필름 승인 팔레트 안에 있다.
