## 3. Land-XI에 주는 것
1. **우리 필름은 스크럽 전용 = v1 단계에 머물러 있다.** 영상의 핵심은 v1→최종의 차이: 커서에 반응하는 실시간 층. "인터랙티브가 없다"는 1차 피드백의 직접 처방 — 필름 위(또는 Leg 1 지구본 구간)에 WebGL 층(패럴랙스 · 빛/물결 반응 · 구름 입자)을 얹는 스파이크가 가능.
2. **통과 전환(drive-through)**: 선형 이동 대신 오브젝트를 뚫고 다음 장면으로. 우리에겐 이미 황동 고리(A01·A02)와 구름 천장(A02→A03)이 있다 — 고리/구름 통과를 전환 문법으로 승격.
3. **시안 이미지 → 구현 일치**: "이미지의 폰트·구도대로 다시"가 품질을 끌어올린 지점. 우리 규칙(B 아트보드 = 픽셀 템플릿, 나란히 비교)과 같은 결론.
4. 오버레이 금지 · 섹션당 카피 최소 — 우리 메인 규칙과 일치.

## 4. 한계 (과장 걸러 읽기)
- 결과물은 오브젝트 1개 + 수면 1장의 단순 장면. 실데이터·지도·다중 장면 없음 — 우리 12 leg 서사와 규모가 다르다.
- "$10K"·"원샷"은 마케팅 문구(실제로는 4회 반복). 모델명 "GPT Astra"·"Kling 3.0"은 영상 속 발언 그대로이며 검증하지 않음. kie.ai에서 Kling 3.0 제공 여부 미확인.
- 참조 이미지에 타사 캐릭터가 포함돼 있음 — 기법만 취하고 자산은 가져오지 않는다.
