> **핵심 구분** — 남원 2종은 *필지 단위 집계*(폴리곤 = 지적 필지 경계), 여수 2종은 *탐지 객체 단위*(폴리곤 = 쓰레기 덩어리 윤곽)다. 두 계열의 `count` 는 의미가 다르므로 섞어서 합산하면 안 된다.

공통 사항
- 4개 파일 모두 **레이어 1개 / 벡터 폴리곤**. 래스터·50k 초과 레이어는 없다.
- 원본 좌표계는 전부 **EPSG:5186 (KGD2002 / Central Belt 2010)**, 축 순서 northing·easting.
- 전부 EPSG:4326 로 재투영, `COORDINATE_PRECISION=6` (≈ 0.1 m) 으로 기록. `stats.count` 는 원본 건수, `stats.countWeb` 는 파일에 실제로 기록된 건수(둘이 다른 데이터셋은 여수 항공 1종뿐)다.
- 4개 파일 모두 웹 예산 2.5 MB 이하 → `_lite` 축약본은 만들지 않았다. 격자 동반본은 객체가 육안으로 안 보이는 여수 2종에만 생성.
- 통계(`results.js`)는 **단순화 이전 원본** 기준이다.

## 5. 기존 자산과의 중첩

### 5.1 남원 결과 vs 정사영상 AOI (`IMAGERY` namwon_2504/2506/2508/2510)

AOI = 127.3481, 35.5276 ~ 127.3567, 35.5347 (**61.4 ha**, 남원 북단 덕과면).

| 데이터셋 | AOI 에 걸치는 피처 | 피처 비율 | AOI 내 면적 | 전체 면적 대비 | AOI 채움률 |
|---|---:|---:|---:|---:|---:|
| namwon-farmland-2025 | 2 (경작지 2, 덕과면) | 0.10 % | 0.45 ha | 0.14 % | 0.73 % |
| namwon-greenhouse-2025 | 0 | 0.00 % | 0 | 0.00 % | 0.00 % |

**결론: 남원 AI 결과는 정사영상 AOI 보다 압도적으로 넓다.** 두 결과의 bbox 면적은 약 118,000 ha 로, 정사영상 AOI 는 그 **0.05 %** 에 불과하다. 정사영상 타일이 깔린 구간은 **덕과면 북단의 1개 AOI 뿐**이고 그 안에 있는 결과는 농지이용 경작지 2필지가 전부다. 나머지 남원시 전역(운봉읍·금지면·송동면 등)의 결과에는 대응하는 정사영상 타일이 없다.
→ 화면 설계 시: 결과 레이어는 밝은 지도 바탕 위에 단독으로 올리고, 정사영상은 덕과면 AOI 로 줌인했을 때만 배경으로 켜지는 "확대 근거" 로 쓰는 편이 정직하다. `shots/results/namwon-*.png` 에 AOI 를 빨간 사각형으로 표시해 두었다.

### 5.2 여수 결과 vs `marine-debris.geojson`

| 비교 | 결과 |
|---|---|
| `marine-debris.geojson` (5,000 피처 표본, 원본 38,057건) bbox | 125.777, 34.250 ~ 126.998, 35.249 (전남 **신안·완도** 해역) |
| yeosu-marine-2025-aerial bbox | 127.509, 34.555 ~ 127.750, 34.750 |
| yeosu-marine-2026-drone bbox | 127.643, 34.568 ~ 127.713, 34.636 |
| bbox 교차 | **없음**. 항공본은 최단 **46.8 km**, 드론본은 **59.1 km** 떨어져 있다 |

**결론: 겹치지 않는 별개 조사구역이다.** 기존 해양쓰레기 자산(신안·완도)과 이번 여수 자산은 동일 서비스(`marine`)의 서로 다른 지역 사례로 병렬 표출해야 하며, 합산 통계로 묶으면 안 된다.

### 5.3 여수 항공(25년) vs 여수 드론(26년) — 두 결과 사이

드론(26년) 촬영범위 bbox 안에 들어오는 항공(25년) 탐지는 **305 / 1,860 (16.4 %)** 이다.
즉 드론 조사는 항공 조사구역의 일부를 고해상도로 다시 훑은 것으로, **"광역 항공 스캔 → 우심지역 드론 정밀조사"** 라는 2단계 스토리를 그대로 보여줄 수 있는 조합이다. 같은 곳을 1년 간격·다른 센서로 본 결과라 항공 24.0 ㎡ 평균 vs 드론 2.5 ㎡ 평균이라는 해상도 차이도 수치로 설명된다.
